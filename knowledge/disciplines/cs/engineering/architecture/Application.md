# 应用

应用架构描述应用的组成、职责分配与协作方式，包括客户端与服务端的组织、内部模块划分及服务边界等。

## 1. 客户端与服务端组织

- [C/S 架构](ClientServer.md)：客户端发起请求，服务器处理请求并提供服务，常以专用客户端为例。
- [B/S 架构](BrowserServer.md)：以浏览器作为客户端，通常通过 HTTP 或 HTTPS 与服务器交互。

B/S 是广义客户端／服务器架构的一种形式；日常比较 C/S 与 B/S 时，C/S 通常特指使用专用客户端的形式。

## 2. 分类维度

客户端与服务端组织不是应用架构的唯一维度。分层架构关注内部职责划分，单体与微服务关注服务边界及部署方式，事件驱动架构关注组件协作方式。

这些维度可以组合使用，不应将它们理解为必须单选的互斥类型。
