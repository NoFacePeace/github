# 字

按字切分以单个汉字作为词元，不需要先判断自然语言中的词边界。在中文检索中，它是一种不依赖词典的字符级切分方式。

## 1. 基本示例

```text
原文：苹果手机
词元：苹 / 果 / 手 / 机
位置：0    1    2    3
```

多字词会被拆开，例如“苹果”不再作为一个完整词元保留。标点、空白、英文和数字如何处理，由具体分词规则决定；中英文混合文本也可以只对中文按字切分，对英文保留单词。

## 2. 与 n-gram 的关系

按字切分可以看作字符级 n-gram 在 n = 1 时的特例，也称字符级 unigram。n 表示连续字符的数量：

| 方式 | “苹果手机”的切分结果 |
| --- | --- |
| 1-gram | 苹 / 果 / 手 / 机 |
| 2-gram | 苹果 / 果手 / 手机 |
| 3-gram | 苹果手 / 果手机 |

n-gram 也可以以词为单位，因此讨论按字切分时应明确是字符级。具体实现还应明确字符边界，例如按 Unicode 码点遍历，避免将一个汉字的编码单元拆开。

## 3. 检索中的特点

- 不依赖词典：新词和专有名称可以直接拆为单字，不受词条是否收录的限制。
- 区分能力有限：常用汉字会出现在大量文档中，单字倒排表可能较长，匹配结果也可能包含较多噪声。
- 词序需要额外约束：把多个字作为 AND 条件，只保证这些字都出现，不保证相邻或顺序一致。
- 开销需要实际评估：相对按词切分通常产生更多词元，但与多长度 n-gram 相比可能更少，不能仅凭切分名称判断索引大小。

例如，查询“苹果”被切分为“苹”和“果”后，按 AND 匹配可能命中“苹”和“果”分散出现的文档。若需要连续匹配，必须保留位置并使用合适的短语或邻近约束，同时考虑字符过滤是否改变位置关系。

## 4. 使用与验证

按字切分可以用于单字查询、缺少领域词典的场景，或作为其他分词方案的补充字段。需要保留完整术语及其相关性信号时，可以同时建立按词切分的字段。

验证应覆盖单字、多字词、字序颠倒、字符间插入其他内容以及中英文混合查询，并检查索引和查询两侧的位置处理。按字切分本身不保证任意子串查询的语义。
