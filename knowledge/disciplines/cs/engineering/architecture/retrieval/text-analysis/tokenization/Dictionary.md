# 词典

词典分词通过预先收录的词条识别文本中的词语。词典通常保存词语，并可附带词频、词性或切分优先级等信息；分词器根据匹配结果和选择规则确定词边界。

这里的词典用于识别文本中的词语；倒排索引中的词项字典则记录已经建立索引的词项及其倒排表入口，两者职责不同。

## 1. 基本示例

假设词典包含“我”“喜欢”“苹果”“手机”“苹果手机”等词条：

```text
原文：我喜欢苹果手机
候选一：我 / 喜欢 / 苹果手机
候选二：我 / 喜欢 / 苹果 / 手机
```

同一词典可以产生多种合法切分。最终采用哪一种，取决于最长匹配、词频评分或其他消歧规则；收录词条不代表分词器一定会输出该词条。

## 2. 常见匹配与选择方法

| 方法 | 做法 | 特点 |
| --- | --- | --- |
| 正向最大匹配 | 从左向右，每一步选择当前位置能匹配的最长词条 | 简单高效，局部最长不一定符合整句含义 |
| 逆向最大匹配 | 从右向左，每一步选择当前位置能匹配的最长词条 | 可以处理部分正向匹配歧义，也有自身局限 |
| 双向最大匹配 | 分别执行正向和逆向匹配，再按词数、单字数量等规则选择 | 效果取决于比较规则，不能解决所有歧义 |
| 候选词图与路径选择 | 将匹配到的词条组织成候选词图，结合词频等信息选择切分路径 | 能比较整句候选方案，依赖词典和评分信息质量 |

词条查找可以使用前缀树等结构加速。词典负责提供候选词，统计规则或模型可以参与候选选择，两者可以组合使用。

## 3. 领域词典与未登录词

领域词典用于补充产品名、业务术语和专有名称，例如“倒排索引”。部分工具还允许调整词频、优先级或删除词条，具体行为取决于实现。

未登录词是词典中尚未收录的词。遇到这类内容时，分词器可能退化为单字或较短词，也可以结合 HMM 等模型尝试识别新词。

添加词条后，应检查它在不同上下文中的实际输出。过长或存在歧义的词条也可能改变相邻词语的切分，增加词条数量并不必然提高检索效果。

## 4. 在检索中的使用

完整术语有利于区分主题，但查询可能只包含术语的一部分。例如，文档只保留“苹果手机”时，查询“苹果”未必能够通过普通词项匹配命中，需要结合多粒度切分或多字段索引评估。

词典和分词器配置应记录版本，检查索引阶段与查询阶段的输出是否兼容。若更新词典改变了索引词项或位置，已有文档通常需要重建索引才能应用新规则。

验证应覆盖领域术语、歧义短语、新词和短查询，并结合真实检索结果评估召回、误匹配、索引大小和延迟。
