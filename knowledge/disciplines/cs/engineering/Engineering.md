# 软件工程

软件工程（Software Engineering）研究如何运用系统化的方法开发、交付和维护软件，涵盖需求分析、设计、编码、测试、发布和维护。

## 1. 架构

- [架构](architecture/Architecture.md)：系统整体结构、组件职责与交互方式，以及存储、检索、故障检测和协调等通用设计机制。

## 2. 兼容性

- [兼容性](Compatibility.md)：软件发生变化后，对既有调用方、数据、版本和运行环境的支持。

## 3. 发布与迁移

- [发布与迁移](ReleaseAndMigration.md)：新实现的验证、流量灰度、逐步切换和异常回退。

## 4. API 设计

- [API 设计](api/API.md)：接口的资源建模、操作语义、请求与响应约定及演进规则。

## 5. 设计模式

- [设计模式](design-patterns/DesignPatterns.md)：常见设计问题的可复用解决思路及适用边界。
