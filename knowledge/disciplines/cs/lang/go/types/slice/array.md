# 切片 array

array 是运行时 slice 结构中的 unsafe.Pointer 字段，定位切片关联的底层元素存储。它不是数组值本身，也不保存数组长度。

## 1. 切片起点

```go
values := [5]int{10, 20, 30, 40, 50}
s := values[1:3]
```

s 的数据指针定位到 values 中的元素 20，而不是整个数组的起始元素 10。切片的长度为 2、容量为 4，分别决定当前可访问范围和可重新切片的范围。

## 2. 赋值与共享

```go
a := []int{1, 2, 3}
b := a
b[0] = 99
// a[0] 也为 99。
```

赋值和传参复制切片描述信息，通常仍共享底层数组。修改共享元素相互可见，但重新给 b 赋一个切片不会自动改变 a 的描述信息。

## 3. append 与存储变化

容量足够时，append 通常复用原底层数组；容量不足时，准备更大的存储、复制原元素，并返回新的切片描述信息。

因此，必须保存 append 返回值，不能假定原指针总保持不变。不同切片若仍关联旧数组，也不会随着另一个切片扩容自动迁移。

## 4. 生命周期与特殊情况

只保留一个小切片，也可能让整个底层数组继续存活。缩短长度和限制容量不等于分配更小存储，需要断开共享时可显式分配并复制。

nil 切片的数据指针为 nil，但空切片不一定为 nil。零大小元素还有特殊布局，不应仅凭地址判断逻辑元素数量或身份。

## 5. 使用边界

array 是运行时内部字段，不可用 `s.array` 访问。通过 unsafe 取得或构造底层指针时，需要保证类型、范围和存储生命周期；普通切片操作应优先遵守语言提供的边界检查。
