# 切片 len

len 是运行时 slice 结构中的 int 字段，记录切片当前的元素数量。业务代码通过内建函数 `len(s)` 查询，而不是使用 `s.len`。

## 1. 下标访问范围

```go
s := make([]int, 2, 5)
s[0] = 10
s[1] = 20
// s[2] = 30 // 越界：虽然容量为 5，但当前长度为 2。
```

合法元素下标满足 `0 <= i < len(s)`。长度按元素计数，不是占用字节数；例如两个 int64 元素的切片长度为 2，而不是 16。

## 2. 重新切片

```go
s := make([]int, 2, 5)
t := s[:4]
// len(s) 为 2，len(t) 为 4。
```

可以在容量范围内扩展长度，已有底层数据会直接暴露，不保证都是新初始化的零值。新切片与旧切片各自有独立的长度字段，但仍可能共享元素存储。

## 3. append 与传参

append 返回包含新增元素的切片，调用方保存返回值后，自己的长度才随之更新。

函数参数接收切片描述信息的副本。函数内将参数重新切片或 append，不会自动更新调用方的长度；需要更新时，通常返回新切片并由调用方赋值。

## 4. 空切片与遍历

nil 切片和非 nil 空切片的 len 都为零，range 均不执行循环体。不能只根据长度判断是否为 nil。

range 使用开始遍历时确定的范围；循环内 append 不会让本次遍历自动扩展到新增元素。修改底层元素则需结合共享关系和访问时机判断。

## 5. 长度与内存

将切片缩短为 `s[:0]` 只改变描述信息，不保证释放底层数组，也不自动清除原元素持有的对象引用。

需要清除不再使用的引用时，应在正确范围内清理元素并管理切片生命周期。共享访问仍需要同步，len 查询本身不使并发修改变得安全。
