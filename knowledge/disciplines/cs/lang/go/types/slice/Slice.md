# 切片

切片（slice）描述底层数组中的一段元素，包含数据指针、长度和容量。切片长度可以通过重新切片或 append 等操作改变，但它本身不是会自动调整长度的数组。

## 1. 声明与创建

```go
var empty []int             // nil 切片，长度和容量都是 0。
values := []int{1, 2, 3}    // 切片字面量。
reserved := make([]int, 2, 5) // 长度 2，容量 5，两个元素均为 0。
```

`[]T` 是切片类型，`[N]T` 是数组类型。数组的长度属于类型，切片的长度和容量则是值的属性。make 创建切片时，容量不能小于长度。

## 2. 长度与容量

| 属性 | 含义 |
| --- | --- |
| `len(s)` | 当前可以通过下标访问的元素数量 |
| `cap(s)` | 从切片起点到底层数组可用末端的元素数量 |

```go
s := make([]int, 2, 5)
s[0] = 10
// s[2] = 20 // 越界：下标必须小于 len(s)，不能只看容量。

t := s[:4] // 可在容量范围内重新切片，len(t) 为 4。
t[2] = 20
```

增加长度不代表所有新露出的元素都是刚初始化的零值；如果底层数组此前已有内容，重新切片会直接暴露原有元素。

## 3. 底层数组共享

```go
a := []int{1, 2, 3}
b := a[1:]
b[0] = 99
// a 变为 [1, 99, 3]。
```

赋值、传参和截取通常只复制或调整切片描述信息，不复制全部元素。多个切片可能引用同一个底层数组，修改共享元素会相互可见。

对 a 使用 `a[low:high]` 时，结果长度为 `high-low`，容量通常为 `cap(a)-low`。完整切片表达式 `a[low:high:max]` 可将结果容量限制为 `max-low`，从而限制后续追加能使用的原数组范围。

## 4. append 与扩容

```go
s := []int{1, 2}
s = append(s, 3)
s = append(s, []int{4, 5}...)
```

append 返回更新后的切片，调用方需要保存返回值：

- 容量足够时，通常复用原底层数组，并在末尾写入元素。
- 容量不足时，分配更大的底层存储，复制原有元素，再追加新元素。

扩容倍率不是语言保证，不能依赖固定的翻倍规则。append 也不一定分配堆内存，实际分配和优化由编译器及运行时决定。

## 5. 函数传参

```go
func Change(s []int) {
    s[0] = 99 // 修改共享元素，调用方可以看到。
    s = append(s, 4) // 只更新局部切片描述信息。
}
```

函数接收切片值的副本，修改元素和修改长度是不同的操作。局部 append 不会自动改变调用方切片的长度；若复用了共享数组，追加写入的内容仍可能通过其他切片被观察到。

需要更新调用方的切片时，通常返回新切片并由调用方赋值，而不是将传参理解为自动按引用更新。

## 6. nil 与空切片

nil 切片可以查询长度、容量、range 遍历和 append，不能直接访问下标。`make([]int, 0)` 是非 nil 的空切片，长度同样为零。

切片只能与 nil 比较，不能直接用 `==` 比较两个切片内容；比较内容可按需要使用标准库 slices 中的相应函数。

nil 与非 nil 空切片在部分编码和 API 语义中可能不同，例如默认 JSON 编码通常分别得到 null 与空数组。

## 7. 复制与内存保留

```go
source := []int{1, 2, 3}
target := make([]int, len(source))
copied := copy(target, source)
// copied 为 3，target 使用独立底层数组。
```

copy 复制数量为两个切片长度的较小值，不自动扩容，允许源和目标重叠。元素若包含指针、map 或切片，复制元素后仍可能共享它们关联的数据，不能据此认为完成了深拷贝。

小切片可能让较大的底层数组继续存活。需要缩小保留范围时，可以显式分配较小数组并复制；仅缩短长度或容量不保证原数组被释放。

## 8. 并发访问

共享底层数组上的冲突读写需要同步。同一个切片变量上的并发 append 也可能竞争描述信息和底层数据，不能因为 append 可能扩容就认为天然安全。

是否可以并发操作，应根据实际访问的元素、描述信息和生命周期判断，并使用锁、channel 等机制建立正确的同步协议。

## 9. 源码入口

- `src/runtime/slice.go`：切片创建、扩容和部分复制辅助逻辑。
- `src/slices`：切片比较、排序及其他通用操作。
- `src/cmd/compile/internal`：切片表达式、append、copy 等操作的检查与代码生成。
