# 字符串 len

`len` 是运行时 stringStruct 中的 int 字段，记录字符串的字节数量。语言中的内建函数 `len(s)` 返回字符串字节长度；业务代码不能通过 `s.len` 直接访问内部字段。

## 1. 计数单位是字节

```go
s := "Go语言"
// len(s) == 8。
// ASCII 的 G、o 各占 1 字节，语、言的 UTF-8 编码各占 3 字节。
```

len 不记录 Unicode 码点数量，也不记录用户感知的字符数量。按码点计数可以使用 `unicode/utf8.RuneCountInString`，但组合音标和某些 emoji 可能由多个码点组成。

长度已经包含在字符串值的描述信息中，查询字符串 len 不需要扫描全部数据；码点计数则需要按编码规则解码。

## 2. 索引与截取边界

字符串索引和切片使用字节下标：

```go
s := "hello"
first := s[0]   // byte，值为 'h'。
part := s[1:4]  // "ell"，len(part) == 3。
_ = first
_ = part
```

单字节索引要求 `0 <= i < len(s)`，截取要求 `0 <= low <= high <= len(s)`。编译期可确定的非法情况会被拒绝，执行时越界会 panic。

按字节截取可能切断 UTF-8 编码，不保证结果仍是有效文本。

## 3. 空字符串与容量

空字符串长度为零，可以执行 `s[0:0]`，但不能访问 `s[0]`。string 不能为 nil，也不能使用 cap 查询容量。

字符串结构没有切片的容量字段。即使子串共享更大的存储，其可访问范围仍由自己的长度决定，不能向外扩展到原字符串的其他字节。

## 4. 长度不会被原地修改

字符串内容不可变，长度也不能通过普通代码原地修改。拼接、截取或重新赋值会产生或使用另一个字符串值，各自有对应长度。

```go
s := "Go"
t := s + "语言"
// len(s) == 2，len(t) == 8。
```

不能通过 unsafe 随意扩大长度，否则可能使字符串覆盖无效内存或违反内存安全要求。
