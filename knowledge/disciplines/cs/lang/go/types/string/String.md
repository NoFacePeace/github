# 字符串

Go 的 string 是不可变的字节序列，零值为空字符串 `""`，不能为 nil。字符串可以保存任意字节，不保证内容一定是有效 UTF-8；使用文本字面量时，中文等字符通常以 UTF-8 编码保存。

## 1. 声明与字面量

```go
var empty string
text := "hello\nGo" // 双引号字面量处理转义。
raw := `hello
Go` // 反引号原始字面量可以跨行，不处理反斜杠转义。
```

字符串变量可以重新赋值，但不能修改已有字符串中的某个字节：

```go
s := "Go"
s = "Hello" // 可以，变量改为保存另一个字符串。
// s[0] = 'h' // 编译错误，字符串内容不可修改。
```

## 2. 字节与 Unicode 码点

| 概念 | Go 表示 | 含义 |
| --- | --- | --- |
| 字节 | byte，即 uint8 | 字符串底层序列的单位 |
| Unicode 码点 | rune，即 int32 | Unicode 编码空间中的一个码点值 |
| 字符串 | string | 字节序列，可按 UTF-8 解码遍历 |

```go
s := "Go语言"
// len(s) == 8：两个 ASCII 字节，加上两个各占 3 字节的汉字。
// len([]rune(s)) == 4：按 UTF-8 解码得到四个码点。
```

`len` 返回字节数，不是用户感知的字符数量。一个视觉上的字符可能由多个码点组成，例如组合音标或某些 emoji，因此 rune 数量也不一定等于屏幕上看到的字符数。

## 3. 索引、切片与遍历

`s[i]` 返回 byte，`s[a:b]` 按字节下标截取。下标越界会 panic，截取位置落在 UTF-8 编码中间时，结果可能包含不完整编码。

```go
s := "Go语言"
first := s[0]       // byte，值为 'G'。
word := s[2:]       // "语言"。
_ = first
_ = word

for index, r := range s {
    // index 是起始字节下标，r 是按 UTF-8 解码的 rune。
    _ = index
    _ = r
}
```

range 遇到无效 UTF-8 编码时，会产生 RuneError（U+FFFD）并按规则前进。需要检查文本编码是否合法时，可以使用 `unicode/utf8.ValidString`。

## 4. 转换与修改

```go
s := "Go"
bytes := []byte(s)
bytes[0] = 'g'
changed := string(bytes) // "go"，原 s 仍为 "Go"。

runes := []rune("语言")
runes[0] = '中'
text := string(runes) // "中言"。
_ = changed
_ = text
```

普通转换遵守互不因后续修改而改变的值语义；编译器可以在不影响行为的场景优化复制或分配，不能一概断言每次转换都分配堆内存。

`string(65)` 得到码点 U+0041 对应的字符串 `"A"`，不是十进制文本 `"65"`。数值格式化应使用 `strconv.Itoa`、`strconv.FormatInt` 或格式化输出等工具。

## 5. 拼接与比较

字符串支持 `+` 拼接，以及 `==`、`!=`、`<`、`>` 等比较。比较基于字节序列的字典顺序，不自动进行大小写折叠或 Unicode 规范化，也不等同于语言学排序。

少量固定拼接可以直接使用 `+`。循环中大量构造字符串时，可按场景使用 `strings.Builder` 或 `strings.Join`，避免重复复制；Builder 首次使用后不能复制。

字符串可以作为 map 键。两个字符串即使底层存储地址不同，只要字节内容相同，就比较相等。

## 6. 运行时表示与共享

数据指针、长度字段及存储共享的具体说明参见[字符串结构](struct.md)。

常见实现使用数据指针和字节长度描述字符串。赋值和传参复制的是字符串值，不必复制全部字节；子串也可能共享底层存储，因此保留一个很小的子串可能使较大的原始存储继续存活。

确实需要断开这种存储关联时，可以考虑 `strings.Clone`，但应基于实际生命周期和内存需求使用。具体布局和优化属于实现细节，不应依赖 unsafe 修改字符串内容。

字符串内容不可变不代表字符串变量可以被多个 G 无同步地读写。同一变量的并发重新赋值与读取仍可能产生数据竞争。

## 7. 常用标准库

| 包 | 用途 |
| --- | --- |
| strings | 查找、分割、替换、拼接与构造 |
| strconv | 数字与文本转换、引号处理 |
| unicode/utf8 | UTF-8 校验、解码与码点计数 |
| unicode | Unicode 字符分类等操作 |
| fmt | 格式化输入输出 |

## 8. 源码入口

- `src/runtime/string.go`：字符串构造、拼接和转换等辅助实现。
- `src/strings`：字符串处理标准库。
- `src/unicode/utf8`：UTF-8 编码与解码。
- `src/cmd/compile/internal`：字符串操作的类型检查、优化和代码生成。
