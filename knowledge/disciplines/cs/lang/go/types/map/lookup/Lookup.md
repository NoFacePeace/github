# Map 查找

map 查找根据键取得对应值，并可判断键是否存在。本文按 Go 1.27.2 的 Swiss Table 实现说明一般流程；编译器可能为特定键类型生成专用路径，实际步骤和优化以对应源码为准。

## 1. 语言层面的结果

```go
value := m[key]
value, ok := m[key]
```

找到键时返回对应值，ok 为 true；未找到时返回值类型的零值，ok 为 false。仅根据零值不能区分键不存在，还是键存在但值恰好为零。

nil map 和空 map 对合法键的查询返回未找到。接口类型键若承载不可比较的动态值，查询仍可能 panic，不能把 nil map 理解为会绕过所有键合法性要求。

## 2. 整体路径

常规目录模式的一般查找路径为：

```text
key 与 map 的哈希种子 → 哈希值
    ↓ 提取高位目录索引
目录项 → table
    ↓ 根据哈希和组数掩码
起始 group
    ↓ 批量匹配 H2 指纹
候选槽位
    ↓ 比较完整 key
命中返回值，或继续判断是否探测下一组
```

定位负责确定要检查的位置，查找还需要探测、比较键和判断是否存在。结构层次参见[Map 结构](../structs/structs.md)。

## 3. 计算哈希与选择 table

哈希前缀提取、目录索引及指针读取过程参见[Map 定位 table](LocateTable.md)。

运行时结合键的类型对应的哈希算法、键值和 Map.seed 计算哈希。常见 64 位平台使用 64 位哈希，32 位平台及 Wasm 使用 32 位哈希。

常规目录使用哈希最高 globalDepth 位选择目录项，globalShift 保存对应右移量。只有一个目录项时直接选择索引零；否则通过移位提取索引，再从 dirPtr 指向的目录取得 table。

```text
64 位哈希，globalDepth = 3：
[最高 3 位][剩余 61 位]
     ↓
目录索引 0～7 → 目标 table
```

多个目录项可以指向同一个 table，目录项数量不等于不同表的数量。

## 4. 定位起始组

哈希低 7 位作为 H2 指纹，其余部分形成 H1，用于表内探测。探测起点结合 H1 与 groups.lengthMask 计算，将索引限制在组数组范围内。

通过组索引和类型元数据中的 GroupSize，从组数组起点计算目标组地址。哈希前缀选择 table 与 H1 选择组是不同层次，并不是为每层重新计算一份独立哈希。

## 5. 匹配指纹与完整键

每组有 8 个逻辑槽位及对应控制字节。运行时批量比较目标 H2 和占用槽保存的指纹，获得候选槽位置，再逐个比较完整键。

```text
指纹不匹配 → 跳过该槽，不比较完整键
指纹匹配   → 比较完整键
                 ├─ 相等 → 找到条目，返回值
                 └─ 不等 → 继续检查其他候选槽
```

H2 只有 7 位，不同键可以拥有相同指纹。因此指纹匹配只是筛选，不是最终命中，也不能仅凭哈希相同判断键相同。

## 6. 终止或继续探测

检查完组内候选后，如果没有命中：

| 状态 | 处理 |
| --- | --- |
| 组中存在真正空槽 | 可以按探测不变量判定不存在 |
| 没有空槽 | 沿探测序列继续检查下一组 |
| 存在删除槽 | 不能仅凭删除标记结束查找 |

删除标记表示这里曾有条目，目标键可能仍在后续探测组中。普通表通过负载与重建规则维持可终止的探测条件。

探测不一定按物理组索引逐个加一；必须使用与插入规则一致的探测序列。相关设计参见[瑞士表](../../../../../data-structures/hash-table/SwissTable.md)。

## 7. 小 map 单组路径

`dirLen == 0` 表示单组模式，dirPtr 直接指向一个组，省去目录和 table 选择。未找到匹配键时，不需要跨组探测。

通用路径可以使用哈希指纹筛选，再比较完整键；特定键类型的专用实现还可能采用其他快速检查。因此，小 map 并不保证执行与常规模式完全相同的哈希和探测步骤。

不能用当前 `len(m) <= 8` 代替单组模式判断，因为增长后的 map 删除条目不保证退回该模式。

## 8. 返回与并发

语言层面取出的 map 值遵守赋值复制语义；如果值包含指针、切片或 map，副本仍可能共享关联数据。查到条目不代表取得其独占访问权限。

普通 map 的查找与并发写入必须正确同步。运行时的写入检测标记用于发现部分误用，不是读写锁，也不保证检测到每一次数据竞争。

## 9. 源码入口

- `src/internal/runtime/maps/map.go`：Get、目录选择与小 map 路径。
- `src/internal/runtime/maps/table.go`：表内查找、候选键比较与探测。
- `src/internal/runtime/maps/group.go`：控制信息匹配和组内数据访问。
- `src/runtime` 中 map 相关入口：编译器调用及特定键类型的快速路径。
