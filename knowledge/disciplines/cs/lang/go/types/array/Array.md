# 数组

数组（array）是具有固定长度、元素类型相同的值类型。类型写作 `[N]T`，其中 N 是非负常量，长度属于类型的一部分。

## 1. 声明与初始化

```go
var zero [3]int          // [0, 0, 0]。
values := [3]int{1, 2}   // [1, 2, 0]，未指定的元素取零值。
inferred := [...]int{1, 2, 3} // 根据字面量推断为 [3]int。
indexed := [5]int{2: 9}  // [0, 0, 9, 0, 0]。
```

`[3]int` 和 `[4]int` 是不同类型，不能直接相互赋值。`[...]` 用于数组复合字面量，不是运行时动态长度数组。

## 2. 长度、容量与零值

数组的 len 和 cap 都等于类型声明中的长度。数组的零值由每个元素的零值组成，数组本身不能为 nil。

```go
var values [3]int
// len(values) == 3，cap(values) == 3。

var empty [0]int // 合法的零长度数组。
```

不能对数组直接使用 append，也不能通过 make 创建数组。需要改变元素数量时通常使用切片，或创建另一个长度的数组并复制元素。

## 3. 索引与遍历

```go
values := [3]int{10, 20, 30}
values[1] = 99

for index, value := range values {
    _ = index
    _ = value
}
```

索引要求 `0 <= index < len(values)`，结果是一个元素值；数组变量的元素可以赋值。编译期可确定的越界会被拒绝，执行时才确定的越界会 panic。

range 中的 value 是对应元素的副本，修改它不直接修改数组元素。需要修改元素时可以使用 `values[index]`。range 一个数组值通常涉及对数组值求值、复制的语义，具体复制可能被优化；遍历数组指针或切片则有不同的共享行为。

## 4. 赋值与函数传参

```go
a := [3]int{1, 2, 3}
b := a
b[0] = 99
// a 仍为 [1, 2, 3]。

func Change(values [3]int) {
    values[0] = 99 // 修改参数副本。
}
```

数组赋值和传参复制全部元素。需要修改原数组时，可以传数组指针，或传引用该数组的切片：

```go
func ChangePointer(values *[3]int) {
    values[0] = 99
}

func ChangeSlice(values []int) {
    values[0] = 99
}
```

复制元素不一定是深拷贝。如果数组元素是指针、切片或 map，副本中的元素仍可能关联同一份可变数据。

## 5. 从数组取得切片

```go
values := [4]int{1, 2, 3, 4}
part := values[1:3]
// len(part) == 2，cap(part) == 3。

part[0] = 99
// values 变为 [1, 99, 3, 4]。
```

从可寻址数组截取得到切片，不复制底层元素。切片从指定起点引用数组，长度由截取范围决定，容量通常延伸至数组末端。

完整切片表达式 `values[low:high:max]` 可以限制结果容量，但不会复制数据或改变数组的固定长度。

## 6. 比较与 map 键

元素类型可比较时，数组也可以比较，按对应元素是否相等判断。数组长度为零也不能绕过元素类型的可比较要求。

```go
a := [2]int{1, 2}
b := [2]int{1, 2}
equal := a == b // true。

counts := make(map[[2]int]int)
counts[a] = 1
_ = equal
```

`[2][]int` 等元素不可比较的数组不能直接进行相等比较，也不能作为普通 map 的键。元素为接口时，即使数组静态类型可比较，比较过程中仍可能因不可比较的动态值而 panic。

## 7. 与切片的区别

| 对比 | 数组 | 切片 |
| --- | --- | --- |
| 类型写法 | `[N]T` | `[]T` |
| 长度是否属于类型 | 是 | 否 |
| 长度变化 | 固定 | 可重新切片，或通过 append 得到新切片 |
| 赋值与传参 | 复制元素 | 复制描述信息，通常共享底层数组 |
| 是否可以为 nil | 不可以 | 可以 |
| 是否可以比较内容 | 元素可比较时可以 | 不能直接用 == 比较两个切片 |

## 8. 存储与并发

数组元素按类型布局组织，存储位置由编译器和运行时决定，不能认为数组必然在栈上。被切片或指针引用的数组，其生命周期由相应引用和逃逸分析等机制处理。

多个 G 通过指针、切片或其他共享引用访问同一数组时，冲突访问仍需要同步。数组按值复制不代表其内部引用的数据自动获得并发保护。

## 9. 实现位置

- `src/cmd/compile/internal/types`：数组类型与布局相关信息。
- `src/cmd/compile/internal`：数组初始化、索引、复制和比较等代码生成。
- `src/runtime`：分配、内存复制或比较等操作可能需要的辅助实现。

数组没有一个必须随每个值携带的运行时长度字段，长度已经由其类型确定。具体指令与辅助调用取决于元素类型、大小和优化结果。
