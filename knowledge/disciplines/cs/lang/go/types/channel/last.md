# last

`last` 是 `waitq` 的队尾指针，类型为 `*sudog`，指向队列中的最后一个等待节点。

## 1. 状态含义

- 空队列中，`last` 与 `first` 均为 `nil`。
- 只有一个节点时，`last` 与 `first` 指向同一节点。
- 多个节点时，从 `last` 沿节点的 `prev` 字段可以依次访问前面的节点。

队尾节点的 `next` 为 `nil`。

## 2. 队列操作中的变化

`enqueue` 通过 `last` 直接找到队尾，无需遍历整个队列。非空队列入队时，将原队尾的 `next` 指向新节点、新节点的 `prev` 指向原队尾，再将 `last` 更新为新节点。

向空队列入队时，`first` 与 `last` 一起指向新节点。从队首出队通常不改变 `last`；移除最后一个节点时，`last` 与 `first` 一起变为 `nil`。

清理 `select` 遗留的等待节点时，如果被移除的是队尾，`last` 需要更新为其前驱节点。相关操作由调用方通过 channel 的锁保护。
