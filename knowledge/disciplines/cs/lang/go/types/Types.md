# Types

Go 的类型决定值的表示、允许的操作及赋值规则。语言层面的类型规则主要由编译器检查，部分类型的分配、扩容、通信和动态操作由运行时实现。

## 1. 类型分类

| 分类 | 类型 | 主要特点 |
| --- | --- | --- |
| 布尔类型 | `bool` | 表示真或假 |
| 数值类型 | 整数、浮点数、复数 | 表示不同范围和精度的数值 |
| 字符串类型 | `string` | 不可变的字节序列，不保证内容是有效 UTF-8 |
| 数组类型 | `[N]T` | 长度属于类型，赋值时复制数组值 |
| 切片类型 | `[]T` | 引用底层数组，包含长度与容量 |
| 结构体类型 | `struct` | 将多个字段组织成一个值 |
| 指针类型 | `*T` | 指向某个类型的变量 |
| 映射类型 | `map[K]V` | 根据键查找值，键类型必须可比较 |
| 通道类型 | `chan T`、`<-chan T`、`chan<- T` | 传递指定类型的值，支持方向约束 |
| 函数类型 | `func(...) ...` | 表示具有特定参数和结果签名的函数 |
| 接口类型 | `interface` | 描述方法或类型集合；可作值类型的接口承载动态类型和值 |

`byte` 是 `uint8` 的别名，`rune` 是 `int32` 的别名，`any` 是 `interface{}` 的别名。`int`、`uint` 等类型的大小与目标架构有关。

## 2. 类型定义与别名

```go
type UserID int64
type ID = int64
```

`UserID` 是新定义的类型，与 `int64` 是不同类型；`ID` 是 `int64` 的别名，两者表示相同类型。是否允许赋值或转换，还需要结合底层类型、定义类型及语言规则判断。

Go 使用静态类型检查。接口值可以承载不同的动态类型，但变量的静态类型仍然明确。

## 3. 值复制与共享数据

Go 的赋值和函数传参会复制值。复制之后是否共享底层数据，取决于值的表示方式：

- 数组与结构体复制其元素或字段；其中包含的指针、切片等仍可能关联共享数据。
- 切片复制描述信息，通常仍引用同一个底层数组。
- map、channel 和指针的复制不会复制其关联的全部数据。
- 字符串赋值可以共享不可变的底层字节数据。

因此，不能将切片、map 等简单理解为“函数按引用传参”。传递的仍是值，只是这些值可以关联同一份底层数据。

## 4. 零值与 nil

未显式初始化的变量具有对应类型的零值，例如数值的 `0`、布尔值的 `false` 和字符串的 `""`。指针、切片、map、channel、函数和接口的零值为 `nil`。

不同类型对 nil 的行为不同：nil 切片可以使用 `append`，nil map 可以读取但不能直接写入，nil channel 的普通发送和接收会永久阻塞。

接口值只有在动态类型和值都不存在时才等于 `nil`。把一个 nil 指针赋给接口变量后，该接口通常不等于 `nil`，因为它仍包含动态类型。

## 5. 实现位置

数据类型没有全部集中在一个运行时模块中，编译器与运行时承担不同职责。

| 内容 | 主要源码位置 | 职责 |
| --- | --- | --- |
| 编译器内部类型表示 | `src/cmd/compile/internal/types` | 支持类型布局与代码生成 |
| 类型检查 | `src/cmd/compile/internal/types2` | 检查类型规则、泛型约束等 |
| 公共类型检查工具 | `src/go/types` | 为源码分析工具提供类型检查 API |
| 运行时类型元数据 | `src/internal/abi/type.go` | 描述运行时需要使用的类型信息 |
| 切片 | `src/runtime/slice.go` | 分配、扩容等运行时操作 |
| 字符串 | `src/runtime/string.go` | 部分构造、拼接和转换操作 |
| map | 新版的 `src/internal/runtime/maps` 及 `src/runtime` 相关入口 | 映射的底层存储与操作 |
| channel | `src/runtime/chan.go` | 创建、通信与关闭 |
| interface | `src/runtime/iface.go` | 部分接口转换与动态类型操作 |
| 反射 | `src/reflect` | 运行时类型和值的检查与操作 |

整数、布尔值、数组和结构体等的布局与普通操作，主要由编译器确定并生成代码，必要时调用运行时辅助函数。具体组织可能随 Go 版本变化。
