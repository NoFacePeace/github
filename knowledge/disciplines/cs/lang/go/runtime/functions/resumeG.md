# resumeG

`resumeG` 是 Go runtime 与 `suspendG` 配套的内部函数，定义于 `src/runtime/preempt.go`。它接收暂停凭据，释放对目标 G 的检查权限，并在需要时恢复其运行资格。具体实现以所用 Go 版本为准。

## 1. 输入与职责

调用方完成栈扫描等操作后，将 `suspendG` 返回的 `suspendGState` 传给 `resumeG`。凭据包含目标 G 及暂停结果，恢复行为取决于这些信息和目标状态。

```go
// 运行时内部调用关系示意，并非业务代码可调用的 API。
state := suspendG(target)
// 在取得的权限范围内检查目标状态。
resumeG(state)
```

## 2. 恢复过程

1. 如果凭据表明目标已结束，则无需恢复活跃执行。
2. 释放 `suspendG` 取得的扫描状态保护，使其他运行时操作可以继续管理目标。
3. 如果目标是由本次暂停请求停止的，通过就绪路径恢复其运行资格。

若目标本来就在等待 channel、锁或其他条件，检查结束不会无条件唤醒它。它仍由原来的等待机制在条件满足时唤醒。

若目标原本可运行，仅因扫描保护暂时不能执行，释放保护后调度器即可继续按原有可运行状态处理。

## 3. 恢复资格与实际执行

恢复运行资格不代表立即切换到目标 G，也不保证它回到原来的 M。目标仍需由调度器选中，才能从保存的执行现场继续运行。

`resumeG` 不执行 channel 数据交接，也不表示某项业务等待条件已经满足。它结束的是本次运行时暂停或检查操作。

## 4. 相关函数

- [suspendG](suspendG.md)：暂停目标并取得检查权限，返回恢复所需的凭据。
- [goready](goready.md)：将等待的 G 置为可运行的通用入口；`resumeG` 根据暂停结果使用对应的内部就绪路径。
