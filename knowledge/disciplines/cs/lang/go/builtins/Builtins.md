# Go 内建函数

内建函数由语言预声明，不需要导入包，调用规则和实现由编译器特殊处理。它们不是关键字，可以被同名声明遮蔽，但通常应避免这样做。

## 1. 常见内建函数

| 分类 | 函数 | 用途 |
| --- | --- | --- |
| 创建与初始化 | [make](Make.md) | 创建并初始化切片、map 和 channel |
| 分配与指针 | [new](New.md) | 创建变量并返回指针，类型参数形式初始化为零值 |
| 长度与容量 | `len`、`cap` | 查询支持的类型的长度或容量 |
| 切片操作 | `append`、`copy` | 追加元素、复制元素 |
| 删除与清空 | `delete`、`clear` | 删除 map 条目，或清空 map、将切片元素置零 |
| 最小与最大值 | `min`、`max` | 求有序值的最小值或最大值 |
| 复数 | `complex`、`real`、`imag` | 构造复数、读取实部和虚部 |
| 异常处理 | `panic`、`recover` | 发起和按条件恢复 panic |
| 简单输出 | `print`、`println` | 实现相关的简单输出，不宜作为正式日志接口 |

不同函数的支持版本和参数规则不同。例如 clear、min、max 从 Go 1.21 开始提供；new 的表达式参数形式从 Go 1.26 开始提供。

## 2. make 与 new 对比

| 对比 | `make` | `new(T)` |
| --- | --- | --- |
| 支持类型 | 切片、map、channel，包括相应自定义类型 | 任意类型 T |
| 返回类型 | 传入的切片、map 或 channel 类型 | `*T` |
| 初始化结果 | 按参数创建并初始化对应数据结构 | 创建一个 T 的零值变量 |
| 是否返回指针 | 不额外增加指针层级 | 返回指向新变量的指针 |
| 是否一定在堆上分配 | 不一定 | 不一定 |

### 2.1 创建与初始化

```go
m := make(map[string]int)
m["a"] = 1 // 已初始化，可以写入。

p := new(map[string]int)
// p 本身不为 nil，但 *p 是 nil map。
// (*p)["a"] = 1 // panic：向 nil map 写入。
*p = make(map[string]int)
(*p)["a"] = 1
```

make 只支持上述三类，不能使用 `make(int)`、`make([3]int)` 或 `make(User)`。其他类型可以使用变量声明、复合字面量或 new；例如 `new(int)` 返回指向值 0 的指针。

### 2.2 nil 值不等于不能使用

`new([]int)`、`new(map[string]int)` 和 `new(chan int)` 返回的指针本身不是 nil，但它们指向的值是 nil，操作行为如下：

| 零值 | 可以进行的操作 | 需要注意的操作 |
| --- | --- | --- |
| nil 切片 | len、cap、range、append | 长度为零，直接下标访问会越界 panic |
| nil map | 读取、len、range、delete、clear | 写入会 panic，需要先初始化 |
| nil channel | len、cap | 普通发送或接收永久阻塞，close 会 panic；select 中相应通信分支不可选中 |

nil 切片可以追加，并将结果保存回指针指向的变量：

```go
s := new([]int)
*s = append(*s, 1)
first := (*s)[0] // 可以访问，值为 1。
_ = first
```

append 返回新的切片值，赋值后长度为 1，下标 0 有效，下标 1 仍会越界。它可能分配底层数组，也可能在已有容量允许时复用原数组。

### 2.3 Go 1.26 的 new 表达式形式

上述零值对比针对 `new(T)`。Go 1.26 起还支持 `new(表达式)`，例如 `new(42)` 返回指向值 42 的 `*int`，并非总是初始化为零值。具体规则参见前面的 new 文档。

## 3. 与普通函数的区别

内建函数可能接收类型作为参数，或针对不同类型采用特殊规则，不能一概视为某个固定签名的普通 Go 函数。它们也不能直接作为普通函数值赋给变量。

例如 `make([]int, 3)` 的第一个参数是类型，`append` 的返回类型与切片参数相关，这些规则由编译器检查。

## 4. 与其他预声明标识符的区别

预声明标识符不只有内建函数，还包括 int、string、any 等类型名，true、false、iota 等常量标识符，以及 nil。它们不应全部归类为内建函数。

## 5. 实现位置

- `src/builtin/builtin.go`：内建标识符的文档化声明，不是普通函数实现。
- `src/cmd/compile/internal`：类型检查、内建操作转换及代码生成。
- `src/runtime` 及其他内部包：部分操作需要的运行时辅助实现。

内建操作不一定都会调用 runtime，也不一定对应一次堆分配，具体取决于类型、逃逸分析和编译优化。
