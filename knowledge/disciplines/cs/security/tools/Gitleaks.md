# Gitleaks

Gitleaks 是开源的敏感信息检测工具，用于发现源码、配置文件和 Git 历史中可能泄露的密钥、Token、密码、私钥等内容。

项目地址：[gitleaks/gitleaks](https://github.com/gitleaks/gitleaks)。

## 1. 检测方式

通过正则表达式、关键词和信息熵等规则识别疑似敏感信息，也支持配置自定义规则与允许列表。检测基于规则，不需要调用大语言模型；实际覆盖范围取决于启用的规则。

## 2. 输入与输出

- 输入：文件内容、目录或 Git 仓库，具体取决于调用方式。
- 输出：命中规则、疑似敏感内容、文件路径及位置等检测结果。

检测结果可能包含原始秘密值，保存报告与日志时需要控制内容和访问范围。

## 3. 使用方式

- 命令行：扫描本地目录或 Git 历史，也可集成到提交检查和 CI 流程中。
- Go 库：在进程内向检测器提供文件路径和正文，接收命中结果。

```go
// 示意代码：检测器需预先加载规则。
findings := detector.Detect(detect.Fragment{
    FilePath: "config.yaml",
    Raw:      string(content),
})
```

## 4. 检测与脱敏

检测负责识别疑似秘密及其位置。需要构建脱敏副本时，调用方可以根据命中范围替换内容，再扫描处理结果；遇到无效范围或仍有命中时返回错误。

检测、替换和复检是不同职责。按范围替换时应处理重叠命中，并根据来源引用要求保留换行，避免破坏行号对应关系。

规则未命中不代表内容一定不含秘密；它也不能证明已泄露的凭据仍然安全，确认泄露后还需要撤销或轮换凭据。
