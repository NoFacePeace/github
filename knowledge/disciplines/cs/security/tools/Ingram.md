# Ingram

Ingram 是面向网络摄像头的漏洞扫描框架，支持海康、大华、宇视、D-Link 等常见设备，属于漏洞扫描与 IoT 设备安全工具。

## 1. 主要用途

- 识别目标摄像头的设备类型及服务特征。
- 使用已有检测规则检查潜在安全问题。
- 汇总检测结果，帮助后续定位、修复与复测。

检测能力取决于项目集成的规则和设备版本，未发现问题不代表设备不存在漏洞。涉及主动检测时，应在已获授权的目标范围内使用。
