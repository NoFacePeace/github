# 计算机安全

计算机安全研究如何保护系统、网络、应用与数据，识别安全风险并设计相应的防护和验证措施。

## 1. 内容范围

- 系统与网络安全：访问控制、服务暴露、配置和隔离。
- 应用与数据安全：身份认证、权限、输入处理和敏感数据保护。
- 漏洞管理：识别、验证、修复和复测安全问题。
- IoT 设备安全：摄像头等联网设备的固件、服务与访问控制。

- [沙箱](sandbox/Sandbox.md)：通过受限执行环境约束程序对文件、网络及系统资源的访问。
