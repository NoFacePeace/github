# 统计镜子反射路径数目

相关知识：[动态规划](../../algorithms/dp/DP.md)。

## 1. 题目描述

[LeetCode 3665：统计镜子反射路径数目](https://leetcode.cn/problems/twisted-mirror-path-count/description/)。

给定一个 `m × n` 的二进制网格 `grid`，其中 `0` 表示空格，`1` 表示镜子。机器人从左上角 `(0, 0)` 出发，希望到达右下角 `(m - 1, n - 1)`，只能向右或向下移动。

机器人试图进入镜子所在格子时，会在进入前发生反射：

- 试图向右进入镜子时，转向下方，移动到镜子正下方的格子。
- 试图向下进入镜子时，转向右方，移动到镜子正右方的格子。
- 如果反射后仍遇到镜子，按照当次进入的方向继续反射，直到进入空格或越界。
- 越界的路径无效，不计入答案。

求从起点到终点的不同有效路径数量，结果对 `10^9 + 7` 取模。题目保证起点与终点均为空格，且 `2 <= m, n <= 500`。

## 2. 示例

```text
grid = [
  [0, 1, 0],
  [0, 0, 1],
  [1, 0, 0]
]
输出：5
```

连续反射的示例：

```text
grid = [
  [0, 1, 1],
  [1, 1, 0]
]
输出：1
```

第二个示例中，从起点先向右会连续触发两次反射，最终到达终点；先向下则会在连续反射后越界。
