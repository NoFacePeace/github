# Kubernetes 生态

Kubernetes 生态包括围绕 Kubernetes 的项目、标准与接口、托管服务与发行版、社区组织，以及集成方案和选型对比。

## 1. 项目

- [Agent Sandbox](agent-sandbox/AgentSandbox.md)：管理面向 AI Agent 等场景的隔离、有状态执行环境。

## 2. 标准与接口

- CRI：容器运行时接口。
- CNI：容器网络接口。
- CSI：容器存储接口。

## 3. 托管服务与发行版

- 托管服务：EKS、GKE、AKS。
- 发行版：K3s、OpenShift。

## 4. 社区与组织

- CNCF：云原生计算基金会。
- Kubernetes SIGs：按技术领域组织的特别兴趣小组。
