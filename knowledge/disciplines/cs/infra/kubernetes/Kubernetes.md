# Kubernetes

Kubernetes（K8s）是容器编排平台，用于管理容器部署、扩缩容和故障恢复。它通常通过 containerd 或 CRI-O 等容器运行时运行容器。

## 1. 与 Docker 的关系

Kubernetes 可以运行 Docker 构建的兼容镜像，但不要求安装 Docker。两者分别承担容器编排与镜像构建、容器管理等职责。
