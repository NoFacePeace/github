# InnoDB 自增锁

## 1. 定义

AUTO-INC 锁是 InnoDB 为协调 AUTO_INCREMENT 值分配而使用的特殊表级锁。它不等同于整表 X 锁，也不代表每次插入自增列都会获取这把锁。

自增值分配还可以使用短时间的内部互斥保护。具体采用什么机制，取决于 innodb_autoinc_lock_mode 和插入语句类型。

## 2. 插入语句类型

| 类型 | 特点 | 示例 |
| --- | --- | --- |
| 简单插入 | 执行前通常能确定需要插入的行数。 | INSERT ... VALUES，包括多行 VALUES。 |
| 批量插入 | 执行前通常不能确定最终插入行数，逐步分配自增值。 | INSERT ... SELECT、LOAD DATA。 |
| 混合模式插入 | 部分行显式指定自增值，部分行需要生成，或存在分配后可能不使用的值。 | 同一条 VALUES 中混合显式值和 NULL；部分 INSERT ... ON DUPLICATE KEY UPDATE 场景。 |

这里的“批量插入”是自增分配语境中的分类，不是所有一次写入多行的语句。例如多行 VALUES 通常属于简单插入。

## 3. 三种分配模式

| innodb_autoinc_lock_mode | 名称 | 主要行为 |
| --- | --- | --- |
| 0 | 传统模式 | INSERT 类语句使用表级 AUTO-INC 锁协调分配，并通常持有到语句结束。 |
| 1 | 连续模式 | 简单插入通常预留所需值，仅短暂使用内部互斥保护；批量插入使用表级 AUTO-INC 锁。简单插入遇到已有 AUTO-INC 锁也可能等待。 |
| 2 | 交错模式 | 不使用表级 AUTO-INC 锁，允许多个插入语句交错分配自增值，仍有必要的内部同步。 |

MySQL 8.0 默认采用模式 2，MySQL 5.7 默认采用模式 1。实际配置应通过实例变量确认，不应仅凭版本推断。

模式 0、1 更强调语句执行期间的可预测分配；模式 2 提高并发度，但同一条语句生成的值可能与其他语句交错。即使使用模式 0、1，混合模式插入等情况也不能简单保证最终数据的编号连续。

## 4. 生命周期与并发影响

需要表级 AUTO-INC 锁时，该锁通常在语句结束时释放，而不是一直持有到事务提交。

```sql
-- 假设模式为 1，目标表含 AUTO_INCREMENT 列。
START TRANSACTION;
INSERT INTO target_table (payload)
SELECT payload FROM source_table;
-- INSERT 结束后，其 AUTO-INC 锁通常已释放。
-- 事务仍可能持有其他数据锁。
COMMIT;
```

长时间的 INSERT ... SELECT 在模式 0、1 下可能使同表其他自增插入等待。切换模式不能消除唯一键冲突、记录锁等待或其他并发瓶颈。

## 5. 自增值不保证连续

AUTO_INCREMENT 主要提供自动生成键值的能力，不是无间隙序号服务。事务回滚、插入失败、提前预留值或重复键处理等都可能留下空缺，已分配的值通常不会因事务回滚而回收。

自增值也不代表事务提交顺序：先取得较小 ID 的事务可能后提交。业务若要求连续单号或严格提交顺序，需要单独设计相应规则。

## 6. 复制与配置

交错模式不适合依赖自增分配可重复性的基于语句复制。使用模式 2 时应结合复制格式判断，基于行的复制不依赖副本重新执行相同的自增分配过程。

```sql
SHOW VARIABLES LIKE 'innodb_autoinc_lock_mode';
SHOW VARIABLES LIKE 'binlog_format';
```

innodb_autoinc_lock_mode 在常见 MySQL 版本中是非动态变量，调整通常需要修改启动配置并重启，具体以版本为准。

## 7. 与其他锁的区别

| 锁 | 主要作用 |
| --- | --- |
| AUTO-INC | 协调自增值分配，通常按语句管理。 |
| IX 意向锁 | 声明表内排他记录加锁意图，通常按事务管理。 |
| 插入意向锁 | 协调目标索引间隙内的插入。 |
| 新记录的 X 保护 | 防止未结束事务的新记录被冲突访问，可以采用隐式锁形式。 |

一次 INSERT 可以涉及其中多种机制，不能因名字相近或都在插入时出现就视为同一把锁。

MySQL 8.0 中，可以结合 performance_schema.data_locks 和 data_lock_waits 查看等待；表级 AUTO-INC 锁通常可由 AUTO_INC 模式识别。短暂的内部互斥保护不等同于这些事务数据锁。
