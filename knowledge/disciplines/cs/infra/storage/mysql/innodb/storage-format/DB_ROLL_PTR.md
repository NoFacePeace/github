# DB_ROLL_PTR

## 1. 定义

DB_ROLL_PTR 是 InnoDB 普通聚簇索引记录中的内部回滚指针字段，大小为 7 字节，用于定位相关 undo 记录。

它不是应用可直接解引用的内存指针，也不是用户定义的普通列，不能直接通过 SELECT DB_ROLL_PTR 查询。

## 2. 回滚与历史版本

undo 信息保存撤销修改所需的内容，可用于事务回滚。对于更新产生的历史版本，一致性读可以结合当前记录和 undo 信息重建旧版本，继续判断其可见性。

因此，历史版本不一定以完整行副本的形式直接保存，DB_ROLL_PTR 也不等于指向另一条完整业务行的地址。

## 3. 源码标识与编码

在常见 MySQL InnoDB 源码中，相应的系统列标识为 DATA_ROLL_PTR，长度常量为 DATA_ROLL_PTR_LEN，值为 7。

回滚指针编码包含用于识别 undo 类型和定位相应 undo 页、页内记录位置等信息。具体位布局及表空间定位方式需结合源码版本理解。

## 4. 生命周期边界

undo 不会永久保留所有历史版本。事务状态、活跃 Read View 和 purge 等机制决定相关历史信息何时可以清理。

长时间运行的一致性读可能延迟所需历史版本的清理，但不能把 DB_ROLL_PTR 当作长期审计或任意时间点查询接口。
