# DB_TRX_ID

## 1. 定义

DB_TRX_ID 是 InnoDB 普通聚簇索引记录中的内部事务 ID 字段，大小为 6 字节，用于标识最近插入或更新该记录的事务。删除标记操作也涉及记录的事务信息更新。

它不是用户声明的普通列，不能直接通过 SELECT DB_TRX_ID 从业务表查询。

## 2. 在 MVCC 中的作用

一致性读取到记录时，InnoDB 将记录的事务 ID 与 Read View 等信息结合，判断该版本是否对当前读取可见。

若当前版本不可见，可能需要结合 DB_ROLL_PTR 定位 undo 信息，重建并检查更早的版本。不能只比较事务 ID 数值大小就判断可见性，还需要考虑创建 Read View 时的活跃事务等信息。

## 3. 源码标识

在常见 MySQL InnoDB 源码中，相应的系统列标识为 DATA_TRX_ID，长度常量为 DATA_TRX_ID_LEN，值为 6。

DB_TRX_ID 是系统列名称；DATA_TRX_ID 是源码使用的系统列类型标识，二者不是需要业务手动声明的字段。

## 4. 使用边界

DB_TRX_ID 不是业务更新时间，也不代表事务提交顺序。二级索引叶子记录不直接保存聚簇记录中的整套事务隐藏字段，相关可见性判断有自己的实现路径。
