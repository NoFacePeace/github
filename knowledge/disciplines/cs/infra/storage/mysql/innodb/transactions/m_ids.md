# m_ids

## 1. 含义

m_ids 是 Read View 创建时活跃的其他读写事务 ID 集合。本文采用 MySQL 5.7、8.0 系列 ReadView 类中常见的字段名称，具体实现应以目标版本为准。

集合用于描述创建视图时哪些事务尚未结束，不是所有连接、所有已提交事务或所有只读事务的列表，创建者按自身可见性规则单独处理。

## 2. 可见性判断

当某个其他事务的版本 ID 位于两个快速判断边界之间时，需要检查它是否存在于 m_ids：

- 在集合内：创建视图时仍活跃，对该视图不可见。
- 不在集合内：在普通版本判断语境中，视为创建视图时已提交，对该视图可见。

实际实现通常保持集合有序，以便查找。

## 3. 示例与固定性

假设 m_ids 为 `{100, 102}`，边界区间为 `[100, 105)`。版本 100 和 102 不可见，101、103 和 104 可见，前提是排除创建者自身及内部特殊情况。

即使事务 100 在查询期间提交，原视图也不会因此从集合中删除它并改变可见性。READ COMMITTED 下的新一次一致性读可以建立新视图，REPEATABLE READ 则通常继续复用原视图。

## 4. 空集合

集合为空并不表示所有事务版本都可见。视图仍保留分配边界，之后获得事务 ID 的其他事务版本依然可能不可见。
