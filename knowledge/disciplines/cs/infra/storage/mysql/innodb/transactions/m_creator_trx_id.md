# m_creator_trx_id

## 1. 含义

m_creator_trx_id 是 Read View 创建者的事务标识，用于识别当前事务自身产生的版本。本文采用 MySQL 5.7、8.0 系列 ReadView 类中常见的字段名称，具体实现应以目标版本为准。

## 2. 可见性作用

当记录版本的 DB_TRX_ID 与有效的创建者事务 ID 相同时，通常视为自身修改，对当前事务可见，不按其他活跃事务版本的不可见规则处理。

因此，即使 REPEATABLE READ 复用旧视图，事务仍可以读取自己的后续修改。事务看到的状态可能同时包含快照中的其他事务版本和自身新修改，并不是一份完全冻结的历史数据库副本。

## 3. 事务 ID 分配

事务开始时不一定立即取得非零读写事务 ID，只读事务可能采用延迟分配。创建者字段可能先使用相应的未分配值，事务转为读写后再按实现更新。

不能仅凭字段名推断它总是从 START TRANSACTION 开始就固定为一个非零值，也不能将其等同于连接 ID。

## 4. 边界

这个字段描述版本的创建者可见性，不决定锁定读的全部行为，也不能代替隔离级别、事务状态或其他版本边界。
