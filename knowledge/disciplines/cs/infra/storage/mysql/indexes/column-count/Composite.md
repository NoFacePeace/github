# 联合索引

## 1. 定义

联合索引显式指定多个列，按列组合的顺序排序。例如 `(name, age)` 先按 `name` 排序，再在相同 `name` 下按 `age` 排序。

## 2. 示例

```sql
CREATE INDEX idx_name_age ON users (name, age);
```

示例假设 `users` 已包含 `name` 和 `age` 列。

## 3. 最左前缀与查询

该索引通常适用于按 `name` 查找，或同时按 `name` 和 `age` 查找。SQL 中条件书写的顺序不决定索引列的顺序。

仅按 `age` 查询时，通常不能使用普通的最左前缀定位；特定版本和条件下，优化器可能选择跳跃扫描或全索引扫描。

范围条件通常限制后续列继续缩小扫描区间的能力，但后续列仍可能用于索引条件下推、过滤或覆盖查询，应结合执行计划判断。
