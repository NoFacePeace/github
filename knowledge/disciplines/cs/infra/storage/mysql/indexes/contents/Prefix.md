# 前缀索引

## 1. 定义

前缀索引只保存字符串列的前一部分，可减少索引空间，但相同前缀可能对应多个不同的完整值。

## 2. 示例

```sql
CREATE INDEX idx_title ON articles (title(20));
```

示例假设 `articles` 已包含可索引的 `title` 字符串列。非二进制字符串的前缀长度按字符计，二进制字符串按字节计；实际索引还受字节长度上限限制。

## 3. 使用注意

查询完整字符串时，可能需要读取原值继续判断。前缀索引不能仅凭保存的前缀覆盖对完整列值的读取，也不能直接保证完整字符串的排序。

唯一前缀索引要求前缀唯一，可能拒绝完整值不同但前缀相同的记录。
