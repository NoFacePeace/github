# 唯一索引

## 1. 定义

唯一索引用于防止重复键，一张表可以有多个唯一索引。MySQL 允许唯一索引中存在多个 NULL；联合唯一索引中，只要键包含 NULL，也可以存在重复组合。

## 2. 示例

```sql
CREATE UNIQUE INDEX uk_email ON users (email);
```

示例假设 `users` 已包含 `email` 列。需要禁止 NULL 时，还应将列定义为 NOT NULL。

## 3. 使用注意

联合唯一索引约束整个列组合，不要求每个列分别唯一。唯一前缀索引约束的是所索引的前缀，可能拒绝完整值不同但前缀相同的数据。

InnoDB 中，显式主键存在时，其他唯一索引通常是二级索引；没有主键时，合适的唯一索引可能被选作聚簇索引。
