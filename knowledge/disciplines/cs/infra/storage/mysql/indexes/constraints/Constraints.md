# 约束维度

本维度按索引承担的唯一性约束分类。约束规定数据规则，索引提供访问结构；普通索引不承担唯一性约束。

## 1. 索引类型

- [主键索引](PrimaryKey.md)：唯一且不允许 NULL，一张表只能定义一个主键。
- [唯一索引](Unique.md)：保证索引键唯一，允许多个 NULL。
- [普通索引](Ordinary.md)：不要求索引键唯一，用于加速查询。

## 2. 索引与约束的关系

约束的语法和语义由 MySQL 定义，检查由 Server 层与存储引擎按各自职责完成。

| 约束 | 与索引的关系 |
| --- | --- |
| PRIMARY KEY | 通过主键索引保证唯一性，并禁止 NULL。 |
| UNIQUE | 通过唯一索引检查重复键。 |
| NOT NULL | 禁止列值为 NULL，不要求建立索引。 |
| FOREIGN KEY | 保证引用关系；InnoDB 使用相关索引支持检查，具体支持范围取决于引擎和版本，MyISAM 不执行外键约束。 |
| CHECK | 检查数据是否满足表达式，不要求建立索引；MySQL 8.0.16 起执行检查。 |

NOT NULL、FOREIGN KEY 和 CHECK 是约束，不作为本维度下的索引类型。
