# MySQL 函数

MySQL 内置函数通过 SQL 表达式调用，用于计算、转换、查询信息或执行特定操作。它们由数据库提供，使用前不需要自行创建函数。

## 1. 调用方式

```sql
SELECT 函数名(参数);
```

函数不仅可以计算值，部分函数还会操作会话状态或申请资源。使用时需明确返回值、作用域和副作用。

## 2. 锁函数

- [锁函数](locking/Locking.md)：通过 GET_LOCK、RELEASE_LOCK 等函数操作会话级命名锁。

## 3. 与其他 SQL 能力的区别

内置函数不同于自行定义的存储函数；锁函数也不同于 LOCK TABLES 等语句。SQL 语句执行过程中自动申请的数据锁，需要按对应锁机制理解。
