# always

`always` 是 `appendfsync` 的可选值，要求每批 AOF 写入后都同步到磁盘。

## 1. 同步行为

Redis 在写入 AOF 后执行同步，等待同步完成后再向客户端确认对应的写操作。多个命令可以在同一批次中写入并同步，并非每条命令都独立触发一次磁盘同步。

## 2. 性能与持久性

同步频繁，写入延迟和吞吐量更容易受到磁盘同步性能影响。适合对已确认写入的持久性要求较高、能够承担同步开销的场景。

持久性仍依赖操作系统、文件系统和存储设备正确完成同步，不能替代备份。

## 3. 配置方式

在已开启 AOF 的实例中设置：

```conf
appendfsync always
```

也可以动态修改：

```redis
CONFIG SET appendfsync always
```

运行时修改不会自动写回配置文件。
