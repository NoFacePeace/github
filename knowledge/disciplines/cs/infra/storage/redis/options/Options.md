# Options

Redis 命令的选项用于控制执行条件、过期方式或返回内容。选项属于具体命令的语法，不是可以用于所有命令的全局设置。

## 1. 选项与参数

```redis
SET lock:task:123 unique-token NX PX 30000
```

| 部分 | 含义 |
| --- | --- |
| `SET` | 命令名称。 |
| `lock:task:123` | key 参数。 |
| `unique-token` | value 参数。 |
| `NX` | 条件选项，不带额外值。 |
| `PX 30000` | 过期选项及其时间参数，单位毫秒。 |

Redis 根据具体命令的语法识别选项及参数，不能把未知关键字自动当作有效选项。不同命令对选项位置、组合和返回值的规定可能不同。

## 2. 常用选项

| 选项 | 常见用途 |
| --- | --- |
| [PX](PX.md) | 在 `SET` 中设置以毫秒为单位的相对有效期。 |
| [NX](NX.md) | 在 `SET` 中仅写入不存在的 key，在 `ZADD` 中仅添加不存在的 member。 |

## 3. 组合使用

上面的 `SET ... NX PX 30000` 在 key 不存在时写入值，并同时设置 30 秒有效期。条件检查、写值和设置有效期在一条命令中完成，适合临时占用或锁获取等场景。

选项的原子组合不代表整个业务流程自动安全。业务仍需要处理请求超时、有效期耗尽、旧持有者继续运行等情况。
