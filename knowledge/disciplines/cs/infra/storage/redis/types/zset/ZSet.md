# ZSet

有序集合（Sorted Set），成员唯一，每个成员关联一个分数，按分数排序；分数相同时按成员字节的字典序排序。

## 1. 数据模型

Key、member、score 的关系，以及唯一性和排序规则见 [Model](Model.md)。

## 2. 常见用途

排行榜、延迟任务。

## 3. 常用命令

`ZADD`、`ZREM`、`ZSCORE`、`ZINCRBY`、`ZRANGE`、`ZRANK`、`ZCARD`、`ZSCAN`。

命令用法、参数与示例见 [Commands](Commands.md)。

## 4. 底层编码

小集合使用 listpack，大集合通常使用跳表与字典的组合。结构特点、编码转换与查看方式见 [Encoding](Encoding.md)。

## 5. 时间复杂度

设 `N` 为集合中的成员总数，`M` 为操作涉及的成员数。常用命令的时间复杂度如下：

| 操作 | 命令 | 时间复杂度 |
| --- | --- | --- |
| 添加或更新一个成员 | `ZADD` | `O(log N)`。 |
| 增加一个成员的分数 | `ZINCRBY` | `O(log N)`。 |
| 查询一个成员的分数 | `ZSCORE` | `O(1)`。 |
| 查询一个成员的排名 | `ZRANK`、`ZREVRANK` | `O(log N)`。 |
| 按排名或分数查询范围 | `ZRANGE` | `O(log N + M)`，`M` 为返回的成员数；按分数查询时使用很大的 `LIMIT offset` 会增加跳过成员的开销。 |
| 删除一个成员 | `ZREM` | `O(log N)`；一次删除 `M` 个成员时为 `O(M log N)`。 |
| 获取成员总数 | `ZCARD` | `O(1)`。 |
| 统计分数区间内的成员数 | `ZCOUNT` | `O(log N)`。 |
| 增量遍历 | `ZSCAN` | 单次调用通常按 `O(1)` 描述，完整遍历为 `O(N)`；单次返回量不固定，`COUNT` 是提示而非严格上限。 |

一次 `ZADD` 添加或更新 `M` 个成员时，复杂度为 `O(M log N)`。范围查询除了定位起点，还需要遍历返回的成员，因此不能只按 `O(log N)` 估算。

上述复杂度描述常规规模下的命令成本，不代表所有编码的底层操作具有相同复杂度；编码差异见底层编码章节。
