# Message

消息是 Stream 中的一条记录，由消息 ID 和一组有序的 field-value 对组成。

## 1. 消息内容

消息内容由一组有序的 field-value 对组成，字段和值都是字符串。字段结构、重复字段及与 Hash 的区别见 [KV](KV.md)。

## 2. 消息 ID

消息 ID 在同一个 Stream 内唯一，追加消息时必须严格递增。格式、自动生成、手动指定及重复 ID 的处理见 [ID](ID.md)。

## 3. 读取与保留

普通读取 `XREAD` 根据调用方传入的 ID 返回后续消息，不保存客户端读取进度，也不创建待确认记录。只要消息仍保留，客户端就可以重复读取。

消费者组中的确认状态不属于消息正文。`XACK` 只移除指定组的待确认记录，不删除消息；消息通过 `XDEL`、`XTRIM` 等操作删除或裁剪。
