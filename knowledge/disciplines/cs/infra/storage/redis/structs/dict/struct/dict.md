# dict

`dict` 是 Redis 字典的管理结构，维护字典类型、两套哈希表及渐进式 rehash 状态。以下以 Redis 7.2 为例，列出主要字段，省略部分辅助字段。

## 1. 主要字段

| 字段 | 作用 |
| --- | --- |
| `type` | 指向字典类型描述，包含哈希计算、键比较、内存释放等回调与配置。 |
| [ht_table[2]](ht_table.md) | 保存两套桶数组的指针，渐进式 rehash 时分别用于旧表和新表。 |
| [ht_used[2]](ht_used.md) | 两张表各自保存的条目数量，不是非空桶数量。 |
| `ht_size_exp[2]` | 桶数量的指数；已分配表的桶数量为 `2^exp`，特殊值表示未分配。 |
| `rehashidx` | 正在迁移的旧表桶下标；`-1` 表示没有进行 rehash。 |
| [pauserehash](pauserehash.md) | 暂停 rehash 的控制计数。 |

Redis 7.2 将哈希表相关信息保存在 `dict` 的这些数组字段中；旧版本资料里常见的独立 `dictht` 结构与此不同，阅读源码时需要对应版本。

## 2. 两套哈希表

`ht_table` 的每个元素指向一套桶数组。桶数组的每一项保存一个 `dictEntry *`，指向冲突链的首条目；空桶为 `NULL`。

正常状态主要使用第 0 张表；rehash 时分配第 1 张表，分批迁移旧表条目。迁移完成后，新的表接替旧表，`rehashidx` 恢复为 `-1`。

`ht_used` 统计条目数量，`ht_size_exp` 描述桶数量，两者不能混淆：一个桶可以通过链表保存多个条目。
