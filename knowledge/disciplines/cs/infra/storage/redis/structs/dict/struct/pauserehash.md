# pauserehash

`pauserehash` 是 Redis 7.2 字典中临时暂停渐进式 rehash 的控制计数，用于避免条目迁移干扰某些遍历操作。

## 1. 字段与取值

```c
int16_t pauserehash;
```

| 值 | 含义 |
| --- | --- |
| `0` | 没有暂停请求，常规 rehash 步骤可以推进。 |
| 大于 `0` | 存在尚未解除的暂停请求，常规 rehash 步骤会跳过迁移。 |

字典初始化时该字段为 `0`。它不表示迁移进度；迁移进度由 `rehashidx` 记录。

## 2. 暂停与恢复

`dictPauseRehashing` 增加计数，`dictResumeRehashing` 减少计数。使用计数器可以支持嵌套暂停：

```text
初始状态       0 → 可以推进
第一次暂停     1 → 暂停
第二次暂停     2 → 暂停
恢复一次       1 → 仍然暂停
再次恢复       0 → 可以继续推进
```

暂停与恢复必须配对。漏掉恢复会使常规 rehash 长期无法推进，额外恢复则可能破坏计数状态。

恢复到 `0` 只是允许后续步骤继续迁移，不意味着恢复操作会立即完成剩余 rehash。

## 3. 使用场景

安全迭代器开始实际遍历时会暂停 rehash，释放迭代器时恢复，避免遍历期间因迁移改变桶与链的分布。`dictScan` 的单次扫描过程也会临时暂停 rehash。

这不意味着整个 `SCAN` 游标遍历期间都保持暂停：多次扫描调用之间仍可能迁移，因此不能把扫描结果当作某个时间点的完整快照。

## 4. 控制边界

`pauserehash` 只控制字典内部遵守暂停状态的 rehash 推进路径，不是 Redis 的全局锁，也不会暂停客户端请求或禁止修改键值。

Redis 7.2 的常规 `_dictRehashStep` 会检查该计数；直接调用底层 `dictRehash` 的代码仍需由调用方保证使用条件，不能认为设置计数就能无条件阻止所有迁移入口。
