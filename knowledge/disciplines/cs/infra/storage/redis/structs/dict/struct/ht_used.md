# ht_used

`ht_used` 是 Redis 7.2 字典中记录两张哈希表各自条目数量的字段，不表示非空桶数量或内存字节数。

## 1. 字段类型

```c
unsigned long ht_used[2];
```

`ht_used[0]` 对应第 `0` 张表，`ht_used[1]` 对应第 `1` 张表。字典当前的总条目数为：

```text
总条目数 = ht_used[0] + ht_used[1]
```

## 2. 条目与桶的区别

例如一张表有 4 个桶，其中第 `0` 个桶保存两个条目，第 `2` 个桶保存一个条目：

```text
[0] → entry A → entry B → NULL
[1] → NULL
[2] → entry C → NULL
[3] → NULL
```

此时桶数量为 `4`，非空桶数量为 `2`，`ht_used` 中对应表的计数为 `3`。一个桶可以容纳多个冲突条目，因此条目数量也可以超过桶数量。

## 3. 计数变化

- 插入新键时，目标表的计数增加；仅更新已有键的值，不增加条目数量。
- 删除键时，所在表的计数减少。
- rehash 迁移条目时，旧表计数减少，新表计数增加；单纯迁移不会改变总条目数。

当旧表条目全部迁移完毕后，新表接替旧表，备用表的计数重置。条目数量结合桶数量可用于计算负载因子，辅助扩缩容判断。
