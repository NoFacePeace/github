# dictEntry

`dictEntry` 表示字典中的键值条目，通过 `next` 将同一桶中的条目连接起来。以下以 Redis 7.2 的普通键值条目为例；特殊的无值字典等场景可能采用优化形式。

## 1. 主要字段

普通 `dictEntry` 的主要字段如下：

| 字段 | 作用 |
| --- | --- |
| `key` | 键指针，具体解释方式由字典类型决定。 |
| `v` | 值的联合体，可保存指针、无符号整数、有符号整数或浮点数。 |
| `next` | 指向同一个桶中的下一个条目，组成冲突链。 |

字典是通用结构，条目中的值不一定直接是业务对象。例如 ZSet 的字典用于按成员查找分数，而 Hash 的字典保存字段到值的映射。

## 2. 值的联合体

`v` 中的不同成员共享存储空间，应通过对应接口按实际用途访问，而不是同时保存多种值。

| 成员 | 保存内容 |
| --- | --- |
| `val` | 通用指针。 |
| `u64` | 无符号 64 位整数。 |
| `s64` | 有符号 64 位整数。 |
| `d` | 双精度浮点数。 |

## 3. 冲突链

```text
桶 → dictEntry A → dictEntry B → NULL
```

桶数组保存首条目的指针，条目通过 `next` 连接。条目对象不要求在内存中连续排列；查找时沿链比较键，直到命中或到达链尾。
