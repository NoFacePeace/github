# Kafka

Apache Kafka 是一个分布式事件流平台，支持事件的发布、订阅和持久化存储。

- [Topic](Topic.md)：消息的命名集合，由一个或多个分区组成。
- [Consumer Group](ConsumerGroup.md)：协同消费的成员集合，负责分区分配和消费进度管理。
- [Epoch](Epoch.md)：区分新旧代次的机制，以及 Leader Epoch、分区元数据与 Broker 的关系。
- [脚本](scripts/Scripts.md)：Kafka 官方命令行脚本及其用法。
- [API](api/API.md)：Kafka Java Admin API 的调用方式和返回结果。
