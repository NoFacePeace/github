# Prometheus 指标

Prometheus 的指标类型描述数值的含义，例如累计次数、当前值或观测值分布。指标的类型决定了适用的查询方式。

## 1. 四种常见指标类型

| 类型 | 表示什么 | 示例 |
| --- | --- | --- |
| [计数器（Counter）](Counter.md) | 持续累加的值 | 库存查询超时次数 |
| [仪表值（Gauge）](Gauge.md) | 可以上升或下降的当前值 | 当前数据库连接数 |
| [直方图（Histogram）](Histogram.md) | 按桶统计的观测值分布 | 库存查询耗时分布 |
| [摘要（Summary）](Summary.md) | 观测值的次数、总和和可选的预计算分位数 | 应用端计算的库存查询耗时 P95 |
