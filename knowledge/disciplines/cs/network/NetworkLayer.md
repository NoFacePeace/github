# 网络层

网络层（Network Layer）负责逻辑寻址、路由选择和数据包转发，使数据能够跨越不同网络到达目标设备。[IP（Internet Protocol，网际协议）](ip/IP.md)是网络层的核心协议。

## 1. 所在层级

| 网络模型 | 所在层级 |
| --- | --- |
| OSI 七层模型 | 第 3 层：网络层 |
| TCP/IP 四层模型 | 网际层，也常称网络层 |

在 OSI 模型中，网络层位于传输层和数据链路层之间。传输层的数据被封装到 IP 数据包中，再由数据链路层封装为帧，通过具体链路传输。

## 2. 核心职责

- **逻辑寻址**：使用 IP 地址标识网络接口，区分源地址和目的地址。
- **路由选择**：根据路由信息确定数据包到达目的网络的路径。
- **数据包转发**：路由器根据目的 IP 地址查找路由表，将数据包发送到下一跳。

路由选择用于确定路径，转发用于处理每一个实际到达的数据包。

## 3. 常见协议

- **IPv4**：使用 32 位地址，常见表示形式为 `192.168.1.10`。
- **IPv6**：使用 128 位地址，常见表示形式为 `2001:db8::1`。
- **ICMP**：用于报告网络错误和提供诊断信息，例如 `ping` 通常使用 ICMP 回显请求与回显应答。

IP 提供无连接、尽力而为的数据包传输服务，不保证数据包一定到达、按顺序到达或只到达一次。TCP 等上层协议可以在此基础上提供可靠传输。

## 4. 与相邻层的区别

| 层级 | 主要职责 | 常见协议或技术 |
| --- | --- | --- |
| 传输层 | 提供进程之间的数据传输，使用端口区分应用 | TCP、UDP |
| 网络层 | 提供跨网络的寻址与数据包转发 | IP、ICMP |
| 数据链路层 | 在同一链路上传输帧 | 以太网、Wi-Fi 的数据链路功能 |

例如，浏览器通过 TCP 发送 HTTP 请求时，TCP 使用端口区分应用，IP 使用地址将数据包送往目标主机，数据链路层负责当前一跳的帧传输。
