# HTTP/1.0

HTTP/1.0 引入版本字段、状态码和首部，能够描述内容类型及其他报文信息。

## 1. 报文格式

```http
GET /index.html HTTP/1.0
```

使用文本请求行或状态行、首部、空行及可选的报文体。

## 2. 连接管理

默认不保持连接，通常每次请求都建立新连接。部分实现通过 `Connection: keep-alive` 扩展支持持久连接，但这不是 HTTP/1.0 的默认行为。

## 3. 内容与缓存

支持通过 `Content-Type` 描述媒体类型，通过 `Content-Length` 指定内容长度，并使用 `Expires`、`Last-Modified` 等字段支持缓存。没有 HTTP/1.1 的分块传输编码。
