# HTTP/3

HTTP/3 将 HTTP 语义映射到 QUIC，底层通常通过 UDP 传输。QUIC 集成 TLS 1.3，提供可靠传输和多流机制。

## 1. 主要特点

- 多路复用：通过 QUIC 流并发处理请求。
- 首部压缩：使用 QPACK，适配 QUIC 的多流传输。
- 使用二进制帧和伪首部，不使用文本请求行或状态行。
- QUIC 支持连接迁移，可在满足条件时应对网络地址变化。

## 2. 与 HTTP/2 的区别

HTTP/2 基于 TCP，丢包可能阻塞连接上的多个流；HTTP/3 基于 QUIC，不要求不同流的数据统一按序交付，减少这种跨流阻塞。

丢包仍可能阻塞受影响的流，共享拥塞控制也可能影响整个连接的吞吐量，因此不能理解为完全没有阻塞。

## 3. 连接管理

HTTP/3 禁止 `Connection`、`Keep-Alive` 等连接专用首部。请求流和连接生命周期由 HTTP/3 与 QUIC 的机制共同管理。
