# HTTP/1.1

HTTP/1.1 使用文本报文，并完善连接复用、报文分帧、缓存和虚拟主机等机制。

## 1. 主要特点

- 默认使用持久连接，可复用连接处理多个请求。
- 请求必须包含 `Host` 首部，支持同一地址承载多个站点。
- 支持 `Transfer-Encoding: chunked`，无需预先知道完整内容长度。
- 提供 `Cache-Control`、`ETag` 等缓存控制与验证机制。

## 2. 并发与阻塞

客户端通常通过多条连接实现并发。HTTP/1.1 也支持流水线，即不等待前一个响应就发送后续请求，但服务器必须按请求顺序返回响应，可能产生队头阻塞，实际使用较少。

## 3. 连接关闭

任意一方发送 `Connection: close`，当前响应完成后连接不再复用。持久连接不保证永久保持打开。
