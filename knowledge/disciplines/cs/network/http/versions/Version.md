# HTTP 版本

HTTP 版本（HTTP Version）标识使用的 HTTP 协议版本。不同版本保留了方法、[状态码](../status-codes/StatusCode.md)等核心语义，但报文格式和传输机制有所不同。

## 1. 常见版本

| 版本 | 主要特点 |
| --- | --- |
| [HTTP/0.9](0.9.md) | 早期形式，只有简单 GET 请求，响应没有状态行和首部 |
| [HTTP/1.0](1.0.md) | 使用文本报文，默认不保持连接 |
| [HTTP/1.1](1.1.md) | 使用文本报文，默认持久连接，支持分块传输编码 |
| [HTTP/2](2.md) | 使用二进制帧，在一条 TCP 连接上多路复用多个流，使用 HPACK 压缩首部 |
| [HTTP/3](3.md) | 基于 QUIC，使用 QPACK 压缩首部，减少不同流之间因丢包导致的传输阻塞 |

## 2. HTTP/1.x 中的表示

HTTP/1.x 在请求行末尾显式写出版本：

```http
GET /users HTTP/1.1
```

其中 `HTTP/1.1` 是版本字段，位于请求目标之后。响应报文的状态行也包含版本字段。

## 3. HTTP/2 与 HTTP/3

HTTP/2 与 HTTP/3 没有文本请求行，也没有对应的版本伪首部。协议版本在建立连接时确定，例如通过 ALPN 协商 `h2` 或 `h3`。
