# HTTP/2

HTTP/2 保留 HTTP 的核心语义，使用二进制帧和流替代 HTTP/1.x 的文本报文传输格式。

## 1. 主要特点

- 多路复用：同一 TCP 连接上可并发传输多个流。
- 首部压缩：使用 HPACK 减少重复首部传输。
- 伪首部：通过 `:method`、`:path`、`:status` 等字段表达请求和响应控制信息。
- 不使用文本请求行或状态行，不传输原因短语。

## 2. 连接管理

不使用 `Connection`、`Keep-Alive` 等连接专用首部，通过流结束、`RST_STREAM`、`GOAWAY` 等机制管理流和连接。

## 3. 队头阻塞

多路复用减少了 HTTP/1.1 响应必须依次返回的阻塞，但底层 TCP 仍要求字节按序交付。发生丢包时，同一连接上的多个流可能一起等待重传。
