# Server

`Server` 是 HTTP 响应首部，用于描述处理请求的源服务器软件。它是可选字段，不表示服务器的域名或 IP 地址。

## 1. 格式

字段值可以包含产品名称、可选的版本号和注释。

```http
Server: nginx
```

```http
Server: Apache/2.4.62
```

其中 `Apache` 是产品名称，`2.4.62` 是版本号。字段也可以包含多个产品标识。

## 2. 使用注意

服务器可以省略该字段，或只提供简要的软件标识，避免暴露不必要的实现细节。字段值可以被配置或修改，不能仅凭它确认服务器实际使用的软件和版本。

## 3. 与其他字段的区别

| 字段 | 含义 |
| --- | --- |
| Server | 响应中的源服务器软件信息 |
| User-Agent | 请求中的客户端软件信息 |
| Host | HTTP/1.1 请求的目标主机及可选端口 |
| Via | 代理或网关转发报文时记录的中间节点信息 |
