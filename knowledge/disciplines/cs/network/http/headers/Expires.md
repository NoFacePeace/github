# Expires

`Expires` 是 HTTP 响应首部，指定响应的绝对过期时间。

## 1. 格式

```http
Expires: Wed, 14 Oct 2026 08:00:00 GMT
```

字段使用 HTTP 日期格式，以 GMT 表示时间。缓存结合 `Date` 和响应当前年龄计算新鲜度，并非只比较客户端本地时钟。

## 2. 优先级

私有缓存优先使用有效的 `Cache-Control: max-age`，共享缓存优先使用 `s-maxage`，其次是 `max-age`；这些指令存在时忽略 `Expires`，不取最早过期时间。

仅有 `Cache-Control: private` 等非有效期指令时，仍可使用 `Expires`。有 `no-cache` 时，即使尚未过期，复用前也必须验证。

## 3. 过期后的行为

过期不代表立即删除或内容已经变化。有验证标识时，通常发送条件请求；未变化返回 `304`，变化则通常返回 `200` 和新内容。没有验证标识时通常重新获取完整响应。
