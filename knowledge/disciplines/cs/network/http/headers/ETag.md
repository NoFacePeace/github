# ETag

`ETag` 是 HTTP 响应首部，提供所选资源表示的实体标签，用作验证标识。标签是服务器生成的不透明字符串，客户端不应解析其内部含义。

## 1. 格式

```http
ETag: "v1"
```

强实体标签要求相同标签对应的表示数据相同；弱实体标签以 `W/` 开头，允许数据不完全相同但语义等价：

```http
ETag: W/"v1"
```

## 2. 缓存验证

客户端保存标签，需要验证时通过 `If-None-Match` 发送。对于 GET 或 HEAD，标签匹配时服务器返回 `304`；不匹配时通常正常处理并返回最新表示。

`ETag` 本身不要求每次验证。缓存新鲜且允许复用时，可以直接使用缓存。它不依赖秒级修改时间，通常比 `Last-Modified` 更适合精确验证表示变化。
