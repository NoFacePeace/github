# 请求方法

HTTP 请求方法用于表达客户端希望对目标资源执行的操作。

## 1. 常见方法

| 方法 | 含义 |
| --- | --- |
| GET | 获取目标资源的表示 |
| HEAD | 获取与 GET 相同的响应头，但不返回响应体 |
| POST | 让目标资源处理请求体中的数据 |
| PUT | 用请求中的表示创建或替换目标资源的状态 |
| PATCH | 对目标资源进行部分修改 |
| DELETE | 请求删除目标资源与其当前功能之间的关联 |
| OPTIONS | 查询目标资源支持的通信选项 |
| CONNECT | 建立到目标服务器的隧道 |
| TRACE | 执行请求消息的回环测试 |
