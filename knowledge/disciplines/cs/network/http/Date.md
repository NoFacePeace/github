# Date

`Date` 是 HTTP 首部字段，表示报文生成的日期和时间，常见于响应中，也可以出现在请求中。它不是资源的最后修改时间。

## 1. 格式

发送方使用 IMF-fixdate 格式，以 GMT 表示时间，精确到秒。

```http
Date: Tue, 15 Nov 1994 08:12:31 GMT
```

格式包含星期、日期、月份、年份和时间。`GMT` 对应 UTC 零时区，不使用服务器本地时区。

## 2. 请求与响应中的使用

- 响应：具备时钟的源服务器必须在 2xx、3xx 和 4xx 响应中发送 `Date`；在 1xx 和 5xx 响应中可以发送。
- 请求：客户端可以发送 `Date`，通常不是必需字段。
- 没有时钟的源服务器不得自行生成 `Date` 字段。

接收方若有时钟，并准备缓存或转发缺少 `Date` 的响应，必须记录接收时间并补充对应的 `Date` 字段。

## 3. 与其他时间字段的区别

| 字段 | 含义 |
| --- | --- |
| Date | 报文生成时间 |
| Last-Modified | 资源表示的最后修改时间 |
| Expires | 响应被视为过期的时间 |
| Age | 缓存估算的响应年龄，以秒为单位 |

缓存会结合 `Date`、`Age` 和缓存指令判断响应的新鲜度，不能仅凭 `Date` 判断资源是否发生变化。
