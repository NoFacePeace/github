# GET

GET 用于获取目标资源的表示，例如读取用户信息、查询列表或下载文件。

## 1. 请求示例

```http
GET /users?page=1 HTTP/1.1
Host: example.com
Accept: application/json
```

路径指定目标资源，查询字符串提供筛选、分页等参数。GET 请求体没有通用定义的语义，不应依赖它传递参数。

## 2. 安全性与幂等性

GET 是安全且幂等的方法：客户端不要求改变服务器业务状态，重复相同请求的预期效果相同。但响应内容可以随资源变化而变化，也允许日志记录等附带行为。

“安全”指操作语义，不表示传输已加密。敏感信息应避免放入 URL，传输保护应使用 HTTPS。

## 3. 缓存与条件请求

GET 响应通常可缓存，具体遵守缓存指令和匹配规则。需要验证缓存时，可发送 `If-None-Match` 或 `If-Modified-Since`；验证通过返回 304，表示变化时通常返回 200 和最新内容。
