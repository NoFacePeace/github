# 2xx 成功

2xx 状态码表示请求已成功接收、理解并接受。具体结果需要结合状态码和请求方法判断。

## 1. 常见状态码

| 状态码 | 原因短语 | 含义 |
| --- | --- | --- |
| 200 | OK | 请求成功，响应内容的含义取决于请求方法 |
| 201 | Created | 请求成功并创建了一个或多个资源 |
| 202 | Accepted | 请求已接受，但处理尚未完成，也不保证最终成功 |
| 204 | No Content | 请求成功，响应不包含报文体 |
| 206 | Partial Content | 成功返回范围请求所要求的部分内容 |
