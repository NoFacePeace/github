# HTTP 协议

HTTP（Hypertext Transfer Protocol，超文本传输协议）是一种应用层协议，通过请求与响应在客户端和服务器之间传输资源。

在 [B/S 架构](../../architecture/BrowserServer.md)中，浏览器通常通过 HTTP 或 HTTPS 与服务器通信。
