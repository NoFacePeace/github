# 1xx 信息响应

1xx 状态码表示请求处理过程中的临时信息，通常随后还会收到最终响应。1xx 响应不包含报文体。

## 1. 常见状态码

| 状态码 | 原因短语 | 含义 |
| --- | --- | --- |
| 100 | Continue | 客户端可以继续发送请求体，常用于 `Expect: 100-continue` |
| 101 | Switching Protocols | 服务器同意切换协议，用于 HTTP/1.1 的协议升级 |
| 103 | Early Hints | 在最终响应之前提供提示，例如通过 `Link` 首部提示预加载资源 |

HTTP/2 与 HTTP/3 不使用 101 状态码进行协议升级。
