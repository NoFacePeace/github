# 单工通信

单工通信（Simplex）指通信只能沿一个方向进行，一方发送，另一方接收，该通信通道不支持反方向传输。

## 1. 传输方向

```text
发送方 ───── 数据 ─────→ 接收方
         没有反向传输
```

发送方与接收方的角色在该通道上固定，接收方不能通过同一通道返回确认或响应。

## 2. 常见用途

- **传统广播**：广播台向接收设备传输内容，接收设备不通过该广播通道回传数据。
- **单向遥测链路**：设备向监测端发送测量数据，无反向控制通道。
- **单向传输设备**：通过数据二极管等方式，限制信息只能从一个网络流向另一个网络。

如果另有反馈通道，需要明确单工描述的是哪条通道，不能直接把整个系统都视为单工。

## 3. 与单向应用行为的区别

应用只向一个方向发送业务数据，不一定意味着底层通信是单工。例如，TCP 文件上传仍需要反方向的确认报文，且连接支持双方同时发送数据。
