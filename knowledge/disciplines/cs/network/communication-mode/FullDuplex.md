# 全双工通信

全双工通信（Full-Duplex）支持双方同时发送和接收数据，两个方向无需等待对方停止发送后再开始。

## 1. 传输方向

```text
A ───── 数据 ─────→ B
A ←──── 数据 ────── B
   两个方向可以同时传输
```

电话是常见例子，双方可以同时说话和听到对方。现代交换式以太网链路也通常工作在全双工模式。

## 2. TCP 中的全双工

一条 TCP 连接支持双向同时传输。双方各自维护发送序列号，并确认反方向收到的数据，两个方向的接收窗口和发送状态可以不同。

TCP 的两个方向也可以分别关闭。一方发送 FIN 后，表示自己的发送方向结束，但仍可以接收另一方的数据，直到另一方也结束发送。

应用只上传或下载数据时，连接仍然具备全双工能力；应用是否使用两个方向，不改变协议本身的能力。

## 3. UDP 与双向通信

UDP 支持双方同时发送和接收独立的数据报，其无连接特性不表示只能单向传输。应用可以使用单向推送，也可以进行双向交互。

UDP 没有 TCP 式的连接和两个可靠字节流，因此应区分“支持双向同时收发”与“提供全双工 TCP 连接”这两种描述。
