# 半双工通信

半双工通信（Half-Duplex）支持双向传输，但两个方向不能同时传输，需要交替使用通信通道。

## 1. 传输方向

```text
时段 1：A ───── 数据 ─────→ B
时段 2：A ←──── 数据 ────── B
        两个方向交替传输
```

双方都可以发送和接收，只是在同一时刻通常只能由一方发送。

## 2. 常见例子

常见按键式对讲机使用半双工方式：一方按住通话键发送，另一方等待，随后交换角色。

传统共享介质以太网也可以工作在半双工模式，需要处理介质竞争与碰撞；现代交换式以太网通常使用全双工。

## 3. 与应用交替发送的区别

请求后等待响应，并不表示底层通信是半双工。应用可以在全双工连接上采用一问一答的交互方式，通信模式应根据所讨论层次的能力判断。
