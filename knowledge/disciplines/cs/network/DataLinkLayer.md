# 数据链路层

数据链路层（Data Link Layer）负责在同一链路上以帧为单位传输数据，为网络层提供当前一跳的数据传输服务。常见技术包括以太网和 Wi-Fi 的数据链路功能。

## 1. 所在层级

| 网络模型 | 所在层级 |
| --- | --- |
| OSI 七层模型 | 第 2 层：数据链路层 |
| TCP/IP 四层模型 | 网络接口层，也称链路层，涵盖 OSI 数据链路层和物理层的功能 |

在 OSI 模型中，数据链路层位于[网络层](NetworkLayer.md)和物理层之间。网络层数据包被封装为帧，再由物理层通过电信号、光信号或无线信号传输。

## 2. 核心职责

- **成帧**：将上层数据封装为帧，规定帧的格式和边界。
- **链路层寻址**：以太网和 Wi-Fi 等技术使用 MAC 地址标识链路上的接口。
- **介质访问控制**：协调设备使用共享传输介质，例如 Wi-Fi 的信道访问机制。
- **差错检测**：通过帧校验序列等机制检测传输错误；具体是否重传取决于链路协议。

数据链路层不统一保证可靠传输。例如，以太网通常丢弃校验失败的帧，Wi-Fi 则具有链路层确认和重传机制。

## 3. 常见技术与协议

- **[以太网（Ethernet）](Ethernet.md)**：常见的有线局域网技术，定义帧格式、MAC 寻址等机制，也包含物理层规范。
- **Wi-Fi**：基于 IEEE 802.11 的无线局域网技术，包含数据链路层和物理层功能。
- **PPP（Point-to-Point Protocol，点对点协议）**：用于点到点链路的数据封装等功能。
- **[ARP（Address Resolution Protocol，地址解析协议）](ARP.md)**：在同一 IPv4 链路上，将下一跳的 IP 地址解析为 MAC 地址。

ARP 直接封装在以太网帧中，不由 IP 承载，广播请求不会被路由器转发。本知识库将其归入数据链路层；部分教材因其服务于 IP 地址解析而将其归入网络层。

## 4. 与网络层的区别

| 对比项 | 数据链路层 | 网络层 |
| --- | --- | --- |
| 数据单位 | 帧（Frame） | 数据包（Packet） |
| 主要作用范围 | 同一链路上的传输 | 跨网络的寻址和转发 |
| 常见地址 | MAC 地址 | IP 地址 |
| 常见设备功能 | 交换机根据 MAC 地址转发帧 | 路由器根据目的 IP 地址转发数据包 |

例如，主机向其他网络发送 IP 数据包时，通常先将其封装到目的 MAC 地址为网关 MAC 地址的帧中。路由器接收帧、取出 IP 数据包，再根据出站链路重新封装。

每经过一次路由转发，链路层封装通常都会变化；在没有 NAT 等地址转换的情况下，IP 数据包的源地址和目的地址保持不变。
