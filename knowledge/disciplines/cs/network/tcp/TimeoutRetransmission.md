# TCP 超时重传

超时重传（Timeout Retransmission）指重传定时器到期后，发送方重传最早尚未确认的数据。

它是 [TCP 重传](Retransmission.md)的一种方式。

## 1. 过程示例

下面的 `Seq` 表示序列号，`ACK` 后的数值表示确认号，`Len` 表示数据长度（字节）。

```text
发送方                              接收方
  | ---- 数据 Seq=1001, Len=100 ----X  |  数据丢失
  |                                  |
  |  重传定时器到期                   |
  | ---- 重传 Seq=1001, Len=100 ----> |
  | <----------- ACK=1101 ---------- |
```

## 2. 重传超时时间

重传超时时间称为 RTO（Retransmission Timeout）。发送方根据往返时间（RTT）的平滑估计和波动情况计算 RTO，而不是简单地使用一个固定值。

## 3. 退避与测量歧义

发生超时后，RTO 通常按指数退避方式增大，例如从 1 秒增加到 2 秒、4 秒，以避免在网络异常时持续频繁重传。由于重传后的确认可能对应原始发送或重传，通常不使用存在这种歧义的报文来测量 RTT；时间戳选项可以帮助消除歧义。
