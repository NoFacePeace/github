# IP 协议

IP（Internet Protocol，网际协议）是[网络层](../NetworkLayer.md)的核心协议，负责通过 IP 地址进行逻辑寻址，并支持数据包跨网络转发。

## 1. 基本职责

- **寻址**：在数据包中携带源 IP 地址和目的 IP 地址，标识通信双方的网络接口。
- **跨网络转发**：路由器根据目的 IP 地址查找路由表，将数据包转发到下一跳，直到到达目的网络。
- **封装数据**：将 TCP 报文段、UDP 数据报等上层数据封装为 IP 数据包。

IP 地址用于网络层寻址，端口用于传输层区分应用进程。端口不属于 IP 首部。

## 2. 传输特点

IP 提供无连接、尽力而为的传输服务：发送数据包前不需要建立连接，也不保证数据包一定到达、按顺序到达或只到达一次。

需要可靠传输时，可以由 TCP 等上层协议负责确认、重传和排序。

## 3. 协议版本

| 版本 | 地址长度 | 地址示例 |
| --- | --- | --- |
| IPv4 | 32 位 | `192.168.1.10` |
| IPv6 | 128 位 | `2001:db8::1` |

IPv4 通常使用点分十进制表示地址；IPv6 使用冒号分隔的十六进制表示地址，可以按规则省略连续的零。

## 4. 转发示例

当主机向其他网络的目标发送数据时，通常先将 IP 数据包交给默认网关。网关及后续路由器根据路由表逐跳转发数据包。

每一跳的数据链路层帧会重新封装；在没有 NAT 等地址转换的情况下，IP 数据包的源地址和目的地址保持不变。IPv4 的 TTL 或 IPv6 的跳数限制会随路由转发递减，以限制数据包在网络中的存活跳数。
