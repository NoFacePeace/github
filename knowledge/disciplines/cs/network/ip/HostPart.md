# 主机部分

主机部分是 [IPv4 地址](IPv4.md)中位于[网络部分](NetworkPart.md)之后的低位，用于区分同一子网内的网络接口。它的长度由前缀长度或子网掩码决定。

## 1. 位数与取值

IPv4 地址共有 32 位。当前缀长度为 `/n` 时，主机部分共有 `32 - n` 位，可以形成 `2^(32 - n)` 种取值。

例如，`192.168.1.10/24` 的主机部分有 8 位，取值为 `10`，二进制表示为 `00001010`。

主机部分不一定是地址最后一个完整字节。例如，`/26` 的主机部分只有最后 6 位，不能直接把第 4 个十进制数字当作主机部分的值。

## 2. 网络地址与广播地址

在普通 IPv4 子网中，主机部分有两种特殊取值：

- **全部为 `0`**：表示网络地址。
- **全部为 `1`**：表示该子网的广播地址。

以 `192.168.1.0/24` 为例：

| 用途 | 地址 |
| --- | --- |
| 网络地址 | `192.168.1.0` |
| 通常可分配的主机地址 | `192.168.1.1`～`192.168.1.254` |
| 广播地址 | `192.168.1.255` |

因此，普通子网的可用主机地址数量通常为 `2^(32 - n) - 2`。此公式不适用于所有前缀：`/31` 点到点链路可使用两个地址，`/32` 表示单个地址或主机路由。

## 3. 地址唯一性

同一子网内的接口通常需要使用不同的单播 IP 地址，否则可能发生地址冲突。不同子网中的主机部分可以相同，因为完整地址还包含网络部分。

例如，`192.168.1.10/24` 和 `192.168.2.10/24` 的主机部分都是 `10`，但所属网络不同，完整 IP 地址也不同。
