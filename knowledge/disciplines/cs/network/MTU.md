# MTU

MTU（Maximum Transmission Unit，最大传输单元）表示链路一次能够承载的网络层数据包的最大字节数。它是一项链路或接口属性，不是协议，也不是以太网独有的概念。

## 1. 大小的含义

承载 IP 时，MTU 限制的是整个 IP 数据包的大小，包括 IP 首部和 IP 数据，不包含外层链路帧的首部和尾部。

普通以太网的 MTU 通常为 1500 字节。对于不含 VLAN 标签的 Ethernet II 帧，加上 14 字节帧首部和 4 字节 FCS 后，承载这个 IP 数据包的帧共 1518 字节。

PPP、Wi-Fi 和隧道接口等也有各自的 MTU。隧道需要添加额外的封装首部，因此其内部数据包的可用 MTU 通常需要相应减小。

## 2. 路径 MTU

路径 MTU（Path MTU）是从源到目的路径上各链路 MTU 的最小值，决定数据包多大才能沿途不分片地传输。

例如，一条路径上的 MTU 分别为 1500、1400 和 1500 字节，则路径 MTU 为 1400 字节。路由变化后，路径 MTU 也可能变化。

路径 MTU 发现（Path MTU Discovery，PMTUD）可以利用 ICMP 或 ICMPv6 的反馈调整发送大小。如果相关反馈被过滤，可能出现小数据包能通过、较大数据包却无法正常传输的情况。

## 3. 与 MSS 的区别

MSS（Maximum Segment Size，最大报文段大小）限制 TCP 报文段中的数据长度，不包含 IP 首部和 TCP 首部；MTU 则限制整个网络层数据包。

例如，在 MTU 为 1500 字节、IPv4 首部和 TCP 首部各为 20 字节且无额外封装时，TCP 数据最多为 `1500 - 20 - 20 = 1460` 字节。实际可发送的数据长度还需要考虑首部选项等开销。
