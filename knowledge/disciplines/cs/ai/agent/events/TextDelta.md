# text_delta

`text_delta` 表示模型新生成的一段文本，是模型接口统一事件流中的增量事件。

## 1. 数据结构

```ts
type TextDelta = {
  type: "text_delta";
  text: string;
};
```

`text` 只包含本次新增内容，不是截至当前的完整文本，也不保证是完整句子或单词。

## 2. 消费方式

界面可以立即追加显示，Agent 同时按接收顺序拼接文本，形成助手消息。非流式适配器也可以将完整文本作为一个事件返回。

网络中断、取消或输出截断时，已收到的文字只是部分结果，不能仅凭收到文本就认定本轮成功完成。
