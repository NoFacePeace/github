# Tool 消息

Tool 表达工具执行后的结果，包括查询数据、命令输出或执行错误。例如，天气工具返回“上海晴，25°C”。

## 1. 结果与调用关联

每份工具结果应携带对应调用的标识。匹配依据是调用 ID，不是工具名称或结果排列顺序；同一个工具可以在一轮中被调用多次。

模型一次请求多个工具时，程序按依赖关系决定串行或并行执行，并为每个调用回传对应结果。执行失败也应形成明确的错误结果，供模型判断后续步骤。

## 2. 接口表示

不同接口可以使用 tool 角色消息、user 消息中的工具结果内容块，或独立的函数结果 Item。内部可统一为工具结果，再由适配层转换。

工具结果是执行产生的数据，不应仅因它包含类似系统指令的文字，就将其提升为系统或开发者指令。
