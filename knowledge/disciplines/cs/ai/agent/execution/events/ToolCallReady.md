# tool_call_ready

`tool_call_ready` 表示模型生成的一个工具调用已经收齐，提供工具名称、调用标识与完整参数。

## 1. 数据结构

```ts
type ToolCallReady = {
  type: "tool_call_ready";
  call: {
    id: string;
    name: string;
    arguments: string;
  };
};
```

`arguments` 是完整的 JSON 字符串；Agent 在执行前解析并校验参数。`id` 用于将执行结果关联回本次调用，同一工具多次调用时也应分别保留标识。

## 2. 生成与执行

适配器负责按提供商协议聚合参数分片，并为每个完整调用发出一次事件。非流式响应中的完整工具调用也转换为同样的事件。

该事件表示调用生成完整，不表示工具已经执行，也不保证整轮响应最终成功。简单的 Agent 循环可以先收集调用，等待本轮正常结束并检查结束原因，再统一交给工具执行模块。

流异常中断或本轮因长度限制结束时，不应直接执行收集到的调用。
