# 远程沙箱

远程沙箱是在云端或其他服务器上运行的受限执行环境。Agent 通过 API、SDK 或受控连接提交命令和文件操作，在远程执行后获取输出与产物。

## 1. 执行位置与隔离边界

“远程”描述执行位置，“沙箱”描述隔离与访问限制。普通 SSH 登录只提供远程访问，不代表目标环境具备沙箱隔离。沙箱也不一定断网、临时存在或自动销毁，这些由具体策略决定。

| 对比 | 本地沙箱 | 远程沙箱 |
|---|---|---|
| 执行位置 | 用户电脑或当前宿主 | 其他服务器或云端节点 |
| 计算资源 | 本机 CPU、内存和磁盘 | 远程节点分配的资源 |
| 文件来源 | 权限允许的本地路径与挂载 | 上传、同步、拉取仓库或挂载远程存储 |
| 本地影响 | 可直接修改获准的真实本地文件 | 通过同步、下载或共享挂载影响本地文件 |

远程沙箱仍可能通过凭据访问真实数据库、仓库和其他服务；运行在远程不意味着没有外部副作用。

## 2. 组成与调用路径

```text
Agent / 工具客户端
  → 管理 API：创建、查询、暂停和销毁环境
  → 执行接口：提交命令、读写文件和读取输出
  → 远程节点上的沙箱与任务进程
```

控制面负责环境身份、调度、权限和生命周期；执行服务在目标环境中启动程序；隔离运行时约束程序能够访问的资源。这些职责可以由不同组件承担。

Agent 主循环可以位于沙箱外，也可以运行在沙箱内。前者需要分别保存外部会话和沙箱状态；后者还需要考虑沙箱故障导致 Agent 进程一起退出的情况。

SDK 是调用封装，不是统一协议。不同平台的命令、文件和生命周期接口不能仅通过替换服务地址就假定兼容。

## 3. 状态与生命周期

| 状态 | 示例 | 常见保存方式 |
|---|---|---|
| 环境定义 | 镜像、依赖、启动命令、资源配额 | 镜像仓库、模板和配置数据库 |
| 工作文件 | 代码、安装包、构建产物 | 持久卷、对象存储或文件系统快照 |
| 内存与进程 | 变量、运行栈、后台服务 | 进程或虚拟机检查点，具体能力依实现而定 |
| 会话与任务进度 | 消息、工具调用、结果、下一步骤 | 外部数据库或持久化执行记录 |
| 连接 | SSH、WebSocket、数据库连接 | 通常由客户端重连与应用恢复 |

创建、暂停、停止、恢复和删除的语义因平台而异。暂停可能保留内存，停止通常要求重启进程；删除是否同时删除磁盘、快照和关联卷，需要分别确认。
