# Agent 沙箱

沙箱（Sandbox）是为 Agent 执行代码、命令或其他操作提供隔离与访问限制的环境，用于控制操作能够影响的文件、进程、网络和宿主资源。

## 1. 内容范围

- 隔离机制：进程隔离、容器、虚拟机和 microVM 等实现方式及其边界。
- 文件系统：工作目录、挂载、读写权限、临时文件和产物导出。
- 网络与凭据：控制外部访问、凭据注入和对内部服务的访问。
- 资源限制：约束 CPU、内存、磁盘、进程数量和执行时间。
- 生命周期：创建、复用、暂停、快照、恢复、销毁和资源清理。

## 2. 与运行时和工具的关系

运行时管理 Agent 的执行循环、会话状态和工具执行；沙箱为其中需要隔离的操作提供执行环境。运行时可以调用本地、远程或托管沙箱，也可以通过 API 使用外部工具，不要求所有操作都在同一个沙箱中执行。

工具定义可调用的能力，沙箱约束实际操作的影响范围。例如，Shell 工具提交命令后，可由沙箱中的进程执行，再将输出返回给运行时。

## 3. 隔离边界

独立对话上下文不等于文件系统或进程隔离。多个 Agent 可以共享同一个沙箱，也可以分别使用独立沙箱；实际隔离程度取决于底层机制、挂载、网络和权限配置。

沙箱提供隔离，不直接判断操作是否符合任务目标。有外部副作用的操作仍需应用结合权限和业务规则控制。
