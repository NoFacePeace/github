# Agent

人工智能智能体（AI Agent）。按执行机制、任务控制、信息管理、能力扩展、质量与安全、训练方法组织相关知识。

## 1. 分类

- [执行机制](execution/Execution.md)：运行时、模型、会话、消息、运行事件与沙箱。
- [任务控制](control/Control.md)：触发、交互与编排。
- [信息管理](knowledge/Knowledge.md)：上下文、记忆与检索。
- [能力扩展](extensions/Extensions.md)：工具、钩子与插件。
- [质量与安全](quality/Quality.md)：评估、可观测性与安全。
- [训练方法](training/Training.md)：通过训练改善 Agent 能力的方法。
