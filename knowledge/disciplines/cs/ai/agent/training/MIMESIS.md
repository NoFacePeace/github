# MIMESIS

MIMESIS 是专门模拟用户的大语言模型，也是相关研究方法的名称。它以 Qwen3.5 为基础，提供 4B、9B 两种规模，作为 Agent 的交互训练环境。

本文依据论文 v2 整理，核对日期为 2026 年 10 月 9 日。

## 1. 解决的问题

普通助手模型扮演用户时往往过于配合，可能让任务显得比真人交互更容易。MIMESIS 学习真实用户的行为变化，例如隐藏偏好、逐步改变要求和不完整的澄清回答。

## 2. 模拟用户训练

1. 用真实对话学习预测下一条用户回复。
2. 用 ThoughtTrace 中用户自述的动机和反应，监督私有思考及公开回复。
3. 用 GRPO 强化学习 13 类行为，奖励关注行为表现、时机、自然度和任务一致性。

## 3. Agent 训练

冻结模拟用户，与 Qwen3-8B Agent 多轮交互，根据任务奖励训练 Agent。CSD 将模拟用户的思考和反应转成教练反馈，提供额外的 token 级监督；运行时 Agent 只看公开对话。

## 4. 评估与结果

评估分别检查模拟用户的行为保真，以及训练出的 Agent 对未见用户的泛化。在 8 个环境、9 个未参与训练的用户模型上测试，其中 3 个环境未参与训练。

| 训练方式 | 平均任务分数 |
| --- | ---: |
| GPT-5.5 + GRPO | 26.10 |
| MIMESIS-9B + GRPO | 29.54 |
| MIMESIS-9B + GRPO + CSD | 31.09 |

## 5. 局限

以上分数不是实际用户成功率。结果支持对其他模拟用户的泛化改善，不能直接证明对真人的效果。模拟用户产生的私有思考也是模型生成的反馈，不能当作真人内心状态。
