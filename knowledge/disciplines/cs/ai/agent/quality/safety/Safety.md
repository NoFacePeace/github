# Agent 安全

Agent 安全研究智能体在使用工具、访问数据和自主执行任务时可能造成的风险，以及如何通过设计、评估和运行控制降低这些风险。

## 1. 内容范围

- 指令与数据边界：识别提示注入，防止将外部内容误当作可信指令。
- 权限与操作控制：限制工具、数据和凭据的访问范围，控制外部副作用。
- 目标与行为偏离：研究隐瞒错误、绕过限制和执行非预期操作等行为。
- 自主性与资源控制：约束持续运行、获取额外资源和自主复制等行为。
- 安全评估与防护：通过受控实验、监测和中断机制检验风险与防护效果。

## 2. 自主复制风险

自主复制指 Agent 将模型及运行程序部署到其他机器，启动可运行副本，并可能继续传播。它涉及部署、资源获取和持续运行能力，不等于模型自动提升智能。

评估这类风险时，应区分受控实验中的能力、依赖简化条件的结果与真实环境中的可行性。模型具备某个步骤的能力，不代表已经能够独立完成整个传播过程。
