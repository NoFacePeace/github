# Agent 可观测性

Agent 可观测性（Observability）是通过日志、执行轨迹和指标等运行证据，了解 Agent 做了什么、如何执行，以及问题发生在哪里的能力。

## 1. 内容范围

- 日志与执行轨迹：记录模型调用、工具调用、检索、交接和执行结果等事件，并关联到任务和会话。
- 运行指标：统计耗时、Token 消耗、费用、错误率、超时和重试次数等。
- 会话分析：结合用户反馈和执行记录，识别反复调用工具、任务停滞和用户放弃等问题。
- 问题定位：沿执行轨迹检查输入、上下文、工具结果和状态变化，分析失败原因。
- 数据治理：控制记录的访问权限、敏感信息脱敏和保留期限。

## 2. 与评估的关系

可观测性主要帮助理解实际发生了什么；[评估](../evaluation/Evaluation.md) 依据任务目标和评分标准判断表现是否达标。二者可以结合：从运行记录中筛选失败案例，形成测试场景，再验证修改是否有效。

工具请求成功、进程正常退出或延迟较低，并不意味着任务目标已经完成。应结合结果验证理解运行指标。执行轨迹反映可记录的输入、调用和输出，不等于能够读取模型内部的完整思考过程。
