# 手动触发

手动触发是用户明确发起任务，由客户端将要求和上下文交给 Agent 执行。

## 1. 常见入口

- 对话：发送“分析这段日志”“修复这个问题”等要求。
- 命令行：运行 Agent 客户端并传入任务。
- 界面操作：点击运行、审查或重新执行按钮。
- API 或 SDK：用户操作应用后，由应用调用 Agent 接口。

API 或 SDK 本身是调用方式；只有本次执行直接由用户操作发起时，才归为手动触发。

## 2. 执行过程

```text
用户提交任务 → 客户端收集上下文 → 调用 Agent → 展示进度与结果
```

任务可以创建新的会话，也可以继续已有会话。执行可以同步返回结果，也可以在后台运行并提供状态查询。

## 3. 适用场景与要点

适合临时分析、交互式开发和需要用户补充信息的任务。提交时应明确操作对象、预期产物和允许执行的范围；运行中的补充要求可通过交互机制处理。
