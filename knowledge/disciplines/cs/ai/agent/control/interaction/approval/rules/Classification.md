# 规则分类

按规则直接匹配的对象，将规则分为工具规则、命令规则和资源规则。这是整理知识的方式，不代表所有系统都采用相同的数据结构。

## 1. 分类

- [工具规则](Tool.md)：匹配工具名称、所属服务或类别，控制工具调用。
- [命令规则](Command.md)：匹配程序、参数或命令结构，控制命令执行。
- [资源规则](Resource.md)：控制对文件、网络、App、账号与数据等资源的访问。

## 2. 分类边界

工具规则回答“能否调用这个工具”，命令规则回答“能否执行这条命令”，资源规则回答“能对哪些对象做什么”。命令可以通过工具执行，但规则匹配的对象不同，因此单独分类。

一次操作可以同时受三类规则约束。例如通过命令工具运行下载命令，既要允许调用工具，也要满足命令规则和网络资源规则。某一类允许不代表其他类别也允许。

逻辑分类不要求分文件存储。允许、拒绝、需要审批是判断结果，人工与自动是审批方式，都不是这里的规则分类。
