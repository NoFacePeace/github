# Approval

审批是 Agent 执行某项操作前，对操作进行审核并作出是否允许执行的决定的过程。审批可以由用户、其他授权人员或自动审核器完成。

## 1. 审批与批准

- 审批：审核并作出决定的过程，结果可以是批准、拒绝或要求修改。
- 批准：审批的一种结果，表示允许在指定范围内执行操作。

英文 Approval 在不同语境中可以指审批机制或批准结果，需要结合上下文区分。

## 2. 基本流程

操作请求经过权限与审批策略判断，必要时创建审批请求，由审批主体作出决定，再执行或拒绝。具体步骤与分支见[审批流程](Flow.md)。

## 3. 授权范围

审批决定应明确适用的操作、对象、参数和有效期限。例如，允许执行一次命令，与允许会话内一类命令，授权范围不同。

待执行操作发生超出授权范围的变化时，应重新判断是否需要审批。恢复执行时，也需要核对审批决定与当前操作是否仍然匹配。

- [审批主体](Reviewer.md)：由谁审核并作出决定。
