# 工具规则

工具规则控制某个工具是否可调用，以及调用是否需要审批。

## 1. 匹配信息

常见信息包括工具名称、所属服务、工具类别，以及影响权限的调用参数。匹配规则可以由宿主系统统一执行，也可以在工具入口检查。

## 2. 示例

| 条件 | 处理 |
| --- | --- |
| 调用只读查询工具 | 允许 |
| 调用发送邮件工具 | 需要审批 |
| 调用被禁用的 MCP 工具 | 拒绝 |

## 3. 与其他规则的关系

允许调用命令工具，只表示该能力可以使用。具体程序、参数及命令结构由命令规则进一步约束。

允许使用文件写入工具，不代表允许写入任意路径；允许命令执行，也不代表同时开放网络访问。
