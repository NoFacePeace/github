# 外部系统权限

操作系统和外部服务提供 Agent 之外的访问约束，例如文件权限、数据库角色和 API 授权范围。

## 1. 示例

| 系统 | 约束 |
| --- | --- |
| 操作系统 | 运行账号能否读取文件、控制桌面 |
| 数据库 | 连接账号能否查询或修改指定数据 |
| API 服务 | 凭据允许访问的资源及操作 |

## 2. 与审批的关系

这些权限不一定是 Agent 可直接加载的审批规则，也可能只在资源访问时强制执行。Agent 内部批准不能自动改变外部系统权限，需要通过相应授权机制处理。

## 3. MCP 场景

本地 MCP 服务受其进程账号及隔离环境约束；远程 MCP 服务受服务端环境和所用账号权限约束。客户端限制工具调用，不等于限制服务进程的所有行为。
