# 命令规则

命令规则按程序、参数或命令结构判断某次命令执行是否允许、拒绝或需要审批。命令可以通过工具调用，但命令规则直接匹配的是命令内容，因此与工具规则分别描述。

## 1. 匹配信息

- 程序名称或可执行文件路径。
- 子命令、选项及参数值。
- 管道、命令串联、重定向等结构。
- 规则支持时，还可结合工作目录等执行上下文。

具体支持哪些匹配条件取决于实现，不能假定所有命令规则引擎都能完整解析 Shell。

## 2. 示例

以下仅用于说明规则意图，不是完整配置或通用安全结论。

| 条件 | 处理 |
| --- | --- |
| 执行指定范围内的只读查询命令 | 允许 |
| 执行代码推送命令 | 需要审批 |
| 执行明确禁止的命令组合 | 拒绝 |

## 3. 检查边界

检查命令时，应使用解析后的程序和参数，而不是仅凭字符串开头判断。复合命令需要考虑其中的多个动作；无法可靠解析时，应按系统策略请求审批、拒绝或交给受限环境执行。

脚本、解释器、别名和程序内部逻辑可能隐藏文件访问与网络行为。命令规则只能判断可识别的信息，不能代替执行环境的资源限制。

## 4. 与工具和资源规则的关系

允许调用命令工具，不代表允许执行任意命令；允许执行某条命令，也不代表允许它写入任意路径或访问任意网络目标。

例如运行下载命令时，工具规则决定命令工具是否可用，命令规则判断该程序及参数，资源规则限制下载目标和落盘位置。
