# 资源规则

资源规则控制对哪些资源执行哪些操作，以及是否需要审批。

## 1. 资源类型

| 类型 | 判断信息 | 示例 |
| --- | --- | --- |
| 文件与目录 | 路径、读写动作 | 指定目录只读，外部写入需要审批 |
| 网络 | 目标域名、IP、端口、协议 | 禁止外网访问，或只允许指定目标 |
| App | 应用标识、窗口、动作 | 控制未授权 App 前请求批准 |
| 账号与数据 | 账号、项目、数据对象、操作 | 数据库账号仅允许查询指定表 |

## 2. 检查与执行

调用前可以从工具声明、参数及检查代码提取预计访问的资源。对于脚本等不透明行为，无法保证提前识别全部目标，需要由沙箱、网络代理或服务端权限限制实际访问。

## 3. 权限边界

资源规则可能直接拒绝，也可能允许申请例外。审批只能处理系统允许申请的权限，不能自动覆盖操作系统、管理员或外部服务的强制限制。

本地沙箱不自动约束远程 MCP 服务，服务内部的资源访问需要由相应服务端控制。
