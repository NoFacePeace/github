# Agent 插件

插件（Plugin）是为现有 Agent 应用或开发平台增加功能的扩展包，通常作为安装、配置和分发扩展能力的载体。插件的具体内容、格式与执行方式由宿主平台定义，没有统一的组成要求。

## 1. 常见组成

- 工具：提供查询数据库、搜索网页或操作外部系统等可调用能力。
- 技能与说明：描述特定任务的处理流程、使用方法及约束。
- 服务集成：通过 API、MCP 服务或其他接口连接外部能力。
- 配置与资源：包含扩展清单、连接设置、模板或辅助脚本等。

一个插件可以只包含其中一部分。例如，数据库插件可以同时提供查询工具和使用说明；文档处理插件也可能主要提供流程说明与脚本。

## 2. 与相关概念的区别

| 概念 | 主要含义 |
|---|---|
| 插件 | 安装和分发扩展能力的包 |
| 工具 | 可被调用的一项具体能力 |
| Skill（技能） | 指导 Agent 完成某类任务的说明及相关资源，具体形式由平台定义 |
| MCP | 连接应用与外部工具、资源等能力的协议 |
| Subagent（子智能体） | 在主 Agent 协调下承担部分工作的执行者 |

插件可以打包工具、技能或 MCP 服务，也可以在平台支持时提供子智能体配置，但插件本身不等同于这些组成部分。

## 3. 使用流程

1. 选择与宿主平台兼容的插件，了解其功能和依赖。
2. 安装插件，按需配置服务地址、账号连接或认证信息。
3. 启用相应能力，确认可访问的数据与允许执行的操作。
4. Agent 根据任务调用工具或使用插件提供的说明和资源。
5. 根据需要更新、禁用或卸载插件。

安装完成不一定意味着所有功能立即可用。依赖服务、认证状态和宿主支持范围都会影响实际使用；卸载插件也不一定自动删除外部服务中的数据或撤销账号授权。
