# Agent 工具

工具（Tools）是 Agent 与外部系统交互、获取信息或执行操作的接口，例如搜索网页、查询数据库、读写文件和运行命令。

## 1. 内容范围

- 工具定义：名称、用途、参数结构和返回结果，帮助模型理解何时以及如何调用。
- 工具调用（Tool Calling）：模型提出调用请求，执行端校验并执行，将结果返回给模型。
- 工具发现与选择：按任务查找合适的工具，控制可用工具集合。
- 协议与集成：通过函数接口、API 或 MCP 等方式接入外部能力。
- 执行控制：权限、参数校验、超时、重试、幂等性和错误处理。

## 2. 与其他机制的关系

工具提供具体操作能力；编排安排任务和工具之间的执行顺序、依赖与结果传递。模型生成工具调用请求不等于操作已经执行，实际执行由应用或运行平台负责。

[检索](../../knowledge/retrieval/Retrieval.md) 可以通过工具调用实现；[可观测性](../../quality/observability/Observability.md) 记录工具请求与结果；[评估](../../quality/evaluation/Evaluation.md) 检查工具选择、参数和最终效果是否正确。
