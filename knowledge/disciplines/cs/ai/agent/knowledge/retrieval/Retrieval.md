# Agent 检索

检索（Retrieval）是 Agent 从知识库、数据库、网页或历史记录等数据源中查找相关信息，为推理与任务执行提供上下文的过程。

## 1. 内容范围

- 知识库构建：文档解析、分块、元数据管理、向量化与索引更新。
- 检索方法：关键词检索、语义检索、混合检索、过滤与重排序。
- [检索增强生成（RAG）](../../../rag/RAG.md)：将检索结果组织为上下文，供模型生成有依据的回答；既可采用固定流程，也可由 Agent 决定何时检索及是否继续检索。
- 数据源接入：连接知识库、数据库、搜索引擎等信息来源。

## 2. 与知识库和记忆的关系

知识库是资料存储与组织的载体，检索是从数据源中查找信息的过程。本目录同时整理知识库构建及其检索方法，检索的数据源也可以是知识库以外的系统。

记忆关注 Agent 如何保存、更新和使用过去的经历；检索关注如何找到当前任务需要的信息。记忆系统可以使用检索技术召回历史会话或经验，但检索本身不决定哪些经历应被记住或遗忘。
