# 输出要求

摘要指令中的输出要求用于约定摘要的长度、语言、结构和准确性，以及如何更新已有摘要。

## 1. 长度

分别明确目标长度和精确信息的优先级。例如，可以要求目标少于 500 个单词，同时说明不能为满足长度而截断关键路径、错误或代码。

提示词中的长度要求是模型遵循的目标；请求参数中的输出 Token 上限是另一层限制。当前项目设置 `MaxTokens: 2048`，不要求压缩到原文的固定比例。单词数、中文字数和 Token 数不能直接等同。

## 2. 语言与结构

明确是否要求使用特定语言，以及是否按目标、约束、决策、进度和待办等字段组织。没有明确规定语言时，不能仅因指令使用英文就认定输出必须是英文。

固定结构应服务于后续执行，不应为了填满字段编造不存在的信息。

## 3. 准确性

- 区分已确认事实、推测和待验证结论。
- 保留必要的精确标识、数值和引用。
- 对冲突、缺失或无法确认的信息注明状态，避免补写未经支持的结论。

## 4. 已有摘要的更新

存在已有摘要时，要求将其与新增历史合并，形成可独立使用的新摘要。更新已经完成的待办和过时状态，同时保留仍然有效的用户要求和决策依据。
