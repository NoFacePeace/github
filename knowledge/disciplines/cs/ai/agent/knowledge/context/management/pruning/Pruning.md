# 上下文裁剪

上下文裁剪（Context Pruning）是从后续模型输入中移除部分内容，以控制上下文占用的过程。按长度直接截掉部分历史通常称为截断（Truncation）；裁剪也可以根据相关性、重要性或信息是否过时来选择移除对象。

## 1. 常见策略

- 滑动窗口：只保留最近若干轮对话或限定 Token 范围内的历史。
- 相关性筛选：移除与当前任务或当前步骤无关的内容。
- 过时信息清理：移除已被新状态替代的旧结果。
- [计划更新裁剪](UpdatePlan.md)：保留有效的最新计划，移除已被替代的旧计划交互。
- 工具结果裁剪：保留关键片段，移除冗长输出中的无关部分。

## 2. 执行要点

- [保护](Protection.md)：明确保留任务目标、有效约束和仍影响后续操作的决策。
- 维护工具调用与结果之间的关联，遵守模型接口对消息结构的要求。
- 对可能再次使用的信息，先保存原始记录或生成摘要，再从当前上下文移除。

裁剪作用于后续模型输入，不必同时删除持久化的对话历史或日志。

## 3. 与其他机制的关系

- 压缩：用更紧凑的表示承载信息；裁剪直接移除选定内容。
- 外置：在外部保留详细内容，使移出上下文的信息仍可按需读取。

裁剪可以与两者结合。例如，先把旧对话整理成摘要，再移除旧消息；或将完整日志存到文件中，只在当前上下文保留相关错误。
