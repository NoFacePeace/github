# 任务目标

摘要指令中的任务目标用于明确摘要的用途：让后续 Agent 能够根据摘要继续执行任务，保留足以恢复工作的状态与依据。

## 1. 需要说明的内容

- 使用者：摘要将交给继续执行任务的 Agent。
- 用途：替换旧历史，作为后续判断和行动的上下文。
- 完成标准：能够理解用户要求、识别当前状态并推进下一步，避免重复已完成或已失败的工作。

## 2. 表达重点

摘要应围绕任务延续组织信息，不能只罗列讨论过的主题。例如，“讨论了数据库和连接池”不足以恢复工作；还需要说明已经确认什么、哪些仍待验证，以及接下来检查什么。

如果近期消息仍会保留原文，应在指令中明确这一前提，让模型合理分配摘要篇幅。
