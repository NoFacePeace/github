# 保留内容

摘要指令需要明确哪些信息必须保留，以及篇幅有限时的优先级。可以按以下顺序组织。

## 1. 用户意图

保留原始目标、有效约束、纠正意见、授权范围和偏好变化。用户明确修改要求时，应反映最新要求，避免沿用已经失效的限制或目标。

## 2. 决策依据

记录已经作出的选择、拒绝过的方案及原因。重要的失败尝试应保留失败原因，帮助后续 Agent 避免重复走入同一条无效路径。

## 3. 关键事实

保留后续必须准确使用的路径、命令、错误信息、标识、数值和配置值。不能为缩短摘要而改变精确内容；较长证据可以保留可读取的引用。

## 4. 当前状态

明确区分已完成、进行中、受阻和待验证的事项，记录必要的验证结果。将已确认事实与推测分开，避免把尚未验证的假设写成结论。

## 5. 下一步行动

说明接下来优先推进什么，以及必要的前置条件。如果任务已经完成，不应为了填充这一部分而虚构待办。
