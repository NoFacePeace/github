# 最近工具调用保护

最近工具调用及其结果构成当前推理和下一步操作的直接依据。裁剪时通常保留一定数量或预算范围内的完整工具交互，优先处理更早的记录。

## 1. 保护对象

- 工具名称、调用参数和调用标识。
- 对应的工具结果、执行状态和必要错误信息。
- 理解调用目的和结果所需的助手说明。
- 尚未完成的调用及其当前状态。

## 2. 保留范围

可以按最近若干个交互块或一定 Token 预算保留。一条助手消息可能同时发起多个工具调用，因此“若干条结果”和“若干个交互块”不是同一个计数口径。

具体数量应由任务需要和预算决定，没有统一必须保留的条数。

## 3. 结构与内容保护

调用和结果需要成组处理，避免只保留一方。超大结果可以保留必要片段与可读取引用，保护交互块不一定意味着保留所有结果正文。

近期记录也不一定重复：同一参数的多次指标或状态查询可能反映变化，不能仅根据调用参数相同就覆盖旧证据。

## 4. 保护边界

“最近”只是基础规则。较早的调用仍可能包含不可恢复的证据或关键决策依据，应另外保护，避免仅按位置删除。
