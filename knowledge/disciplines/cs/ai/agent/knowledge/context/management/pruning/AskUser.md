# Ask User 保护

Ask User 指 Agent 主动向用户询问缺失信息、偏好或授权的交互。裁剪时需要保留问题与回答之间的关系，避免失去用户选择的含义。

## 1. 保护内容

- 问题本身，以及理解问题所必需的选项和背景。
- 用户给出的回答、纠正或选择。
- 尚未回答的问题及等待状态。
- 授权涉及的对象、范围和条件。

## 2. 消息关联

使用工具发起询问时，应维护工具调用与结果的配对；用户回答以独立消息保存时，还需要保留它与问题的语义关联。

例如，只保留“选第二个”而删除问题和选项，会使回答无法理解。

## 3. 保护边界

已解决的询问可以整理为明确结论，未必需要长期保留全部问答原文。但仍然有效的约束、授权范围和用户纠正应继续保留；不能把没有回答视为同意。
