# Agent 记忆

记忆（Memory）是 Agent 保存、更新和召回过去信息的机制，用于在后续交互与任务中使用历史经历、用户偏好和已有经验。

## 1. 内容范围

- 短期记忆：当前任务或会话中需要保留的信息，例如近期消息、工具结果和阶段性结论。
- 长期记忆：跨会话或任务持久保存的信息，例如用户偏好、历史事实和经验总结。
- 记忆写入：选择值得保留的信息，进行提取、摘要、去重和来源记录。
- 记忆召回：按当前任务选择相关记忆，并组织为模型可用的上下文。
- 记忆维护：处理更新、冲突、过期、遗忘、删除和访问权限。

## 2. 与会话、检索和训练的关系

会话记录是记忆的一种来源，但保存完整聊天历史并不自动构成有效的记忆机制。应用还需要决定保留哪些信息、何时召回，以及如何处理过时或错误的记录。

[检索](../retrieval/Retrieval.md) 帮助查找当前任务需要的信息，可用于召回历史记忆，也可用于查询外部知识库。记忆更关注信息如何从过去的经历中形成、保存和演变。

记忆通常通过外部存储和上下文影响 Agent 的行为，不要求更新模型参数；训练则可以通过更新参数改变模型能力。两者可以结合，但属于不同机制。
