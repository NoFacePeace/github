# Assistant 消息

Assistant 表达模型生成的输出，可以包含面向用户的回答，也可以包含请求程序执行的工具调用。

## 1. 内容与用途

- 回答问题、解释结果或提出澄清请求。
- 生成一个或多个工具调用，提供工具名称与参数。
- 根据工具结果继续生成回答或下一轮调用。

助手输出可能同时包含文本与工具调用，不能只保存文本而丢弃调用信息。部分接口将工具调用表示为独立 Item，适配层可以统一其内部表示。

## 2. 流式聚合

文本增量可以即时展示；工具参数可能分片返回，需要按调用或内容块标识聚合。收齐参数并确认生成状态后，再交给执行模块。

模型请求调用工具不表示工具已执行；执行结果需要由程序单独回传。
