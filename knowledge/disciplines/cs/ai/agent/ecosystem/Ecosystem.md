# Agent 生态

Agent 生态包括围绕智能体的开发框架、托管平台、编排服务、工具协议和执行环境。本目录用于整理相关产品、项目及其集成方式。

## 1. 托管平台与编排服务

- [Claude Managed Agents：多 Agent 编排](https://platform.claude.com/docs/en/managed-agents/multiagent-orchestration)：提供 Subagent 与 Dynamic Workflows 等能力。Dynamic Workflows 由主 Agent 生成编排程序，服务端在后台执行并汇总多个 Agent 的结果。
