# 上下文

上下文（Context）是 Agent 在一次模型调用中可使用的信息，包括指令、用户消息、对话历史、工具结果、检索内容和任务状态等。模型的上下文窗口有容量限制，需要根据当前任务选择和组织这些信息。

## 1. 内容范围

- 上下文构建：将指令、任务信息和相关资料组织为模型输入。
- 信息选择：选择当前步骤需要的历史消息、工具结果和检索内容。
- 容量管理：通过压缩、裁剪、外置等方式控制上下文占用。
