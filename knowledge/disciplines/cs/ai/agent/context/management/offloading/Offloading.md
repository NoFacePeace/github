# 上下文外置

上下文外置（Context Offloading）是将详细内容保存在当前模型上下文之外，在上下文中保留必要摘要、标识或引用，并在需要时重新读取的方式。外部载体可以是文件、数据库、对象存储或可检索的记录系统。

## 1. 适用内容

- [工具结果外置](Tool.md)：完整命令输出、日志和较大的工具结果。
- [Skill 外置](Skill.md)：原文已有外部来源，使用标识和重读提示替换已加载正文。
- 暂时不需要展开的资料、代码和检索结果。
- 长任务的详细执行记录与中间产物。

## 2. 基本流程

1. 确认详细内容存在于可再次访问的位置；尚未保存时先保存，已有来源时直接复用。
2. 在上下文中保留用途说明、关键结论和文件路径或记录标识。
3. 从后续模型输入中移除不必常驻的详细内容。
4. 后续需要证据或细节时，通过工具读取或检索相应内容。

例如，将完整构建日志保存为文件，在上下文中保留“构建失败，错误出现在依赖解析阶段”和日志路径，排查时再读取相关片段。

## 3. 执行要点

- 引用应能稳定定位内容，并注明内容含义，便于判断何时读取。
- 当前步骤必须遵守的要求应保留在上下文中，避免依赖模型主动召回。
- 明确记录的版本和有效期，避免重新读取过时状态。
- 外置会增加读取成本；应按需读取相关片段，避免每次重新加载全部内容。

## 4. 与其他机制的关系

- 压缩：减少信息表示的体积；外置将详细内容转移到外部，两者可以配合使用。
- 裁剪：决定从当前上下文移除哪些内容；外置为后续读取提供保留位置。
- 记忆：关注信息的保存、更新和召回；外置关注当前上下文与外部存储之间的内容安排，两者的实现可以重叠。
