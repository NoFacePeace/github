# 摘要指令

摘要指令用于告诉模型如何将待压缩历史和已有摘要整理为新的任务摘要。当前项目将它作为摘要请求最后一条 `user` 消息发送。

## 1. 任务目标

见[任务目标](Objective.md)：明确摘要的用途，以及后续 Agent 需要如何利用摘要继续工作。

## 2. 保留内容

见[保留内容](Retention.md)：规定用户意图、决策依据、关键事实、当前状态和下一步行动的保留优先级。

## 3. 省略内容

见[省略内容](Omission.md)：识别重复、无关或过时的信息，并明确省略的边界。

## 4. 输出要求

见[输出要求](OutputRequirements.md)：约定长度、语言、结构、准确性和已有摘要的更新方式。
