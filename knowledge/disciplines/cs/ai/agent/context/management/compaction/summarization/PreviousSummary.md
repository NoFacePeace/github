# 已有摘要

已有摘要是上次压缩生成的任务摘要，是摘要请求中的可选部分。将它与本次待压缩历史一起提供给模型，可以延续更早的任务背景，生成覆盖两者的新摘要。

## 1. 消息组织

当前项目将已有摘要放在待压缩历史之后、摘要指令之前，使用一条 `system` 消息包裹：

```text
<previous-summary>
已有摘要内容
</previous-summary>
```

首次压缩或不存在有效旧摘要时，省略这条消息。

## 2. 合并更新

- 保留仍然有效的目标、约束、事实和决策。
- 根据新历史更新进度，移除已过时的待办或假设。
- 区分用户明确修改要求与历史中出现的普通描述。
- 对冲突或尚未验证的信息注明状态，避免直接当作确定结论。

这些是组织合并摘要时应明确的要求；是否得到满足，仍取决于具体摘要指令和模型结果。

## 3. 局限

已有摘要不是原始历史。反复基于摘要生成新摘要可能累积遗漏或偏差；重要的精确数据和证据应保留可读取的原始记录。
