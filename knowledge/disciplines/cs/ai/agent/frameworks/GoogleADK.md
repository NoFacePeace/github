# Google ADK

Google ADK（Agent Development Kit）是 Google 的开源智能体开发框架，用于构建、运行、评估和部署 Agent 及多 Agent 系统。

## 1. 定位

ADK 提供 Agent 定义、工具接入和工作流编排等开发能力。它是开发框架，通过库或包集成到程序中；Gemini Agent 则是面向企业工作的具体产品。

ADK 这个缩写不专属于 Google。例如，IBM 也提供 watsonx Orchestrate ADK，两者是不同项目。

## 2. 模型与部署

Google ADK 针对 Gemini 与 Google 生态进行了优化，同时设计为支持不同模型和部署环境，不限定只能使用 Gemini 或部署到 Google Cloud。具体支持范围应结合所用语言版本和集成方式确认。
