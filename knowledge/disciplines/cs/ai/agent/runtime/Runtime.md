# Agent 运行时

运行时（Runtime）是承载并推进 Agent 执行的软件系统，负责连接模型、工具与执行环境，管理会话状态和任务生命周期。不同框架对运行时的职责划分可能不同。

## 1. 内容范围

- 执行循环：调用模型、接收工具请求、执行工具、返回结果，并判断是否继续。
- 会话与状态：维护消息、工具结果、任务状态和运行标识。
- 工具执行：分发调用，处理异步结果、超时、重试、取消和异常。
- 执行环境：连接本地进程、远程服务或沙箱，管理文件和执行产物。
- 生命周期与恢复：启动、中断、恢复、检查点和资源释放。
- 运行事件与预算：输出进度和执行事件，约束时间、Token 与费用。

## 2. 基本执行流程

```text
用户任务 → 组织上下文 → 调用模型
                         ↓
                  工具请求或最终输出
                         ↓
工具请求 → 校验并执行 → 返回工具结果 → 再次调用模型
最终输出 → 结束本次运行并保存状态
```

模型生成工具调用请求不等于工具已经执行。运行时负责衔接实际执行，但具体工具也可以由客户端或外部服务实现。

## 3. 与其他机制的关系

| 机制 | 主要职责 |
|---|---|
| [编排](../orchestration/Orchestration.md) | 决定谁执行什么、何时执行，以及依赖和结果如何流转 |
| 运行时 | 推进执行循环，管理调用、状态和运行生命周期 |
| [沙箱](../sandbox/Sandbox.md) | 为实际操作提供隔离环境和资源限制 |
| [记忆](../memory/Memory.md) | 选择、保存、更新和召回过去的信息 |
| [可观测性](../observability/Observability.md) | 利用运行事件、轨迹和指标分析执行情况 |

这些职责可以由同一个框架实现，也可以由不同组件承担。例如，编排层安排并行任务，运行时推进每个 Agent 的执行，沙箱分别承载命令和文件操作。
