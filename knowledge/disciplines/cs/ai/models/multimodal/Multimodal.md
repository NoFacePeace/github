# 多模态模型

多模态模型（Multimodal Model）是能够结合处理多种信息形式的模型。常见模态包括文本、图像、音频和视频。

## 1. 分类依据

“多模态”按模型处理的输入与输出模态分类，不指定模型规模、网络架构或生成机制。一个模型可以同时属于大型多模态模型、Transformer 模型和自回归模型。

多模态不要求输入和输出都支持多种形式。例如，输入图片和问题、输出文字回答的模型，也属于多模态模型。

## 2. 常见形式

| 形式 | 输入与输出示例 |
|---|---|
| 视觉语言模型（VLM） | 输入图片和文字，输出图片描述或问题答案 |
| 音频与语言模型 | 输入音频和文字，输出文字或语音 |
| 视频理解模型 | 结合视频帧、时间信息，以及可能存在的音轨或文字，回答相关问题 |
| 多模态生成模型 | 根据文字、图片等条件生成图片、音频或视频 |

具体模型支持的输入、输出组合不同，应查看其能力说明，不能仅凭“多模态”判断是否支持某种格式或生成能力。

## 3. 与其他分类的关系

- 大模型：描述规模，多模态模型也可以是较小的模型。
- 语言模型：描述对语言的建模；语言模型可以通过接入视觉或音频组件扩展为多模态系统。
- 图像与视频生成模型：描述生成任务，多模态模型也可以只理解视觉输入并输出文字。
- 扩散、自回归和流匹配：描述生成机制，可以用于不同模态的生成。

## 4. 典型用途

- 阅读截图、网页、表格和 PDF，结合文字问题提供回答。
- 分析图像或视频中的对象、事件与空间关系。
- 结合语音、文字和视觉信息进行交互。
- 为 Agent 提供视觉理解能力，辅助判断界面状态和选择操作；实际操作仍需工具及运行系统执行。
