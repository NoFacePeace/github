# 模型推理

模型推理（Inference）是使用训练好的模型处理输入，得到预测、表示或生成结果的过程，通常不更新模型参数。例如，语言模型生成回答、嵌入模型生成向量，以及图像模型生成图片，都属于推理。

## 1. 内容范围

- 模型加载：加载权重、配置、分词器及其他必要组件。
- 输入与输出处理：将文本、图像或音频转换为模型输入，并将模型结果转换为应用所需形式。
- 生成与采样：控制生成长度、随机性、停止条件，或图像生成的采样步数等。
- 推理优化：批处理、缓存、量化、计算加速和内存管理。
- 部署与服务：本地执行、模型服务、并发调度、流式输出及资源配置。
- 性能评估：衡量延迟、吞吐量、内存占用、费用及输出质量。

## 2. 与训练和 Agent 的关系

训练通过优化调整模型参数；推理使用已有权重完成计算。基础模型和微调后的模型都可以用于推理，LoRA 等适配参数也可以在推理时配合基础模型使用。

一次 Agent 任务可能包含多次模型推理，以及工具调用、状态管理和结果验证。模型推理是其中的组成部分，不等同于完整的 Agent 执行过程。
