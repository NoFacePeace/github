# Grok Bot

Grok Bot 是 x.ai 官方平台提供的云端 AI 助手产品。用户可以创建具有名字、职责和持续上下文的 Bot，像给同事发消息一样交代工作，由 Bot 使用网站、应用、文件与终端执行多步任务。

信息核对日期：2026-11-06。本文依据官方产品页与文档整理，未实际运行验证；价格、套餐和功能可用性以账户中的最新说明为准。

## 1. 产品定位

Grok Bot 与 Grok 聊天应用是不同产品。Grok Bot 提供持续运行的执行环境，用于完成有明确成果的工作，例如搜集资料、整理报告、处理业务系统中的任务。

Bot 代表持续使用的工作角色。模型提供推理与生成能力，产品负责组织上下文、工具调用、执行环境和协作。官方说明 Grok Bot 自动选择模型，用户不能通过模型选择器指定后端；所选模型可能来自自身或第三方服务商。

## 2. 核心能力

| 能力 | 说明 |
|---|---|
| 多步任务执行 | 使用连接的应用或浏览器，在多个工具之间完成工作 |
| 后台运行 | 任务在云端执行，关闭客户端或笔记本不影响已运行的后台任务 |
| 多 Bot 协作 | 多个 Bot 可并行工作，通过群聊、消息和任务交接协调 |
| 持续上下文 | 保存角色背景、偏好和先前工作的摘要 |
| Skills | 保存执行某类任务的方法，可从用户演示的工作流程中形成草稿 |
| Routines | 将工作流程交给某个 Bot，按计划或支持的事件触发执行 |

例如，用户可以让研究 Bot 搜集有来源的行业消息，再交给编辑 Bot 整理周报，并将结果留待人工审阅。这是使用场景示例，任务质量仍取决于资料、工具可用性和结果检查。

## 3. 运行环境与共享边界

### 3.1 账户共享的云端电脑

同一用户的所有 Bot 共享一台持久云端电脑，包括文件、浏览器会话和应用登录状态；每个 Bot 有自己的屏幕，可以并行处理任务。电脑按用户分配，不是每个 Bot 独占一台。

各 Bot 的对话和角色上下文分别保留，但共享文件、群消息和直接交接可以传递信息。不能把不同 Bot 当作隔离文件和登录凭据的安全边界。

### 3.2 客户端与工具接入

官方文档列出 macOS、Windows、Linux、iOS 和 Android 客户端。客户端用于交互和控制，主要工作在云端电脑执行；本地命令执行属于另行授权的能力。

已有专用连接器时可以直接接入应用，没有连接器时可使用浏览器操作。网站仍可能阻止自动化、要求重新登录或需要人工完成验证码等步骤，不能据此认为 Bot 能无条件操作任意网站。

## 4. 开源与部署状态

截至核对日期，未找到 Grok Bot 产品的官方完整源码仓库、开源许可证或自托管版本；官方提供的是托管服务。

公开的 Grok 模型权重、提示词以及第三方同名仓库，与 Grok Bot 产品本身的源码属于不同对象，不能据此判断产品开源。

## 5. 费用与试用

### 5.1 订阅与用量

官方产品页在核对时列出的个人月付价格如下，单位为美元：

| 套餐 | 每月价格 | 页面说明 |
|---|---:|---|
| Premium | 30 | 包含每周 Grok Bot 用量 |
| Super | 100 | 包含 Premium 的 3.5 倍用量 |
| Ultra | 200 | 包含 Premium 的 12 倍用量 |

长期使用需要符合条件的付费套餐。新客户的 The X Subscription 中，Premium、Super 和 Ultra 包含 Grok Bot，Plus 与 Free 不包含；部分既有 Cursor、SuperGrok 或 X Premium+ 套餐也可取得使用资格，具体取决于账户与关联条件。

包含使用资格不代表无限量使用。在 The X Subscription 中，Grok Bot 与 Cursor、Grok 应用共享每周额度；超额使用涉及预付余额。既有 Cursor 套餐可在启用按需用量时继续计费。订阅额度、附加额度与费用应在对应账户的用量页面核对。

### 5.2 免费试用

部分账户的访问页面会提供 `Start Trial`。官方说明这种试用提供用量额度，同时受 7 天期限限制；额度可能先于期限耗尽。该额度试用不会自动转为付费套餐。

在 iOS App Store 开始的订阅试用是另一套机制，若未及时取消，可能转为 Apple 付费订阅。需要根据实际试用入口判断续费规则。
