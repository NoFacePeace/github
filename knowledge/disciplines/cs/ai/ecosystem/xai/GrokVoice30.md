# Grok Voice 3.0

Grok Voice 3.0 是面向实时语音交互的语音模型，通过 Voice Agent API 提供给开发者。它结合处理音频与语言，属于[多模态模型](../../models/multimodal/Multimodal.md)，可用于电话客服、语音助手等场景。

## 1. 模型与 API 的区别

- Grok Voice 3.0：理解用户话语、生成语音回应并支持工具调用的模型。
- Voice Agent API：应用接入语音模型能力的接口。

应用还需提供业务工具、权限和交互流程。模型提出查询订单或办理退货等工具请求后，实际业务操作由接入系统执行。

## 2. 核心能力

- 语音输入与语音输出，支持多轮对话。
- 处理停顿、轮流发言和用户打断。
- 结合工具调用完成查询、故障排查等任务。

它的定位超出单独的语音识别（音频转文字）或语音合成（文字转音频），面向包含理解、回应和任务执行的语音交互。

## 3. 使用示例

```text
用户语音：“我的设备连不上网。”
              ↓
模型理解问题，并询问具体情况
              ↓
应用执行模型请求的设备状态查询工具
              ↓
模型根据结果，用语音指导用户处理
```

## 4. 发布与使用状态

官方于 2026 年 10 月 14 日发布 Grok Voice 3.0，并宣布可通过 Voice Agent API 使用，发布时价格为每分钟 0.08 美元。价格、可用性与接入方式应以最新官方文档为准。
