# FPT Software

FPT Software（简称 FSOFT）是一家总部位于越南的软件与 IT 服务公司，其 AI Center 开展人工智能研究，并将研究成果应用于软件开发工具与平台。

## 1. AI Center 与 AI4Code

AI4Code 是 FPT Software AI Center 下的研究团队，聚焦利用 AI 提高软件开发效率，研究方向包括代码理解、代码生成、代码大模型和自动化软件工程智能体。

`FSoft-AI4Code` 是该团队发布开源项目的 GitHub 组织名，不代表一家独立公司。组织、团队与项目的关系如下：

```text
FPT Software
└── AI Center
    └── AI4Code 研究团队
        └── FSoft-AI4Code GitHub 组织及开源项目
```

## 2. 开源项目

- [CodeWiki](CodeWiki.md)：结合静态依赖分析和 AI Agent，生成代码库的层次化模块文档、概述与图表。
- HyperAgent：面向多类软件工程任务的通用软件智能体项目。
- AgileCoder：将敏捷开发方法引入多智能体软件开发的项目。
- RepoExec：用于评估仓库级代码生成的基准，关注可执行性、测试正确性和跨文件依赖上下文。
