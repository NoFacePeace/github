# Claude Code 工具

工具是 Claude Code 执行文件读取、编辑、命令运行及外部服务操作的接口。模型决定调用什么工具，运行环境执行并返回结果。本文依据官方文档整理，核对日期为 2026-10-20。

## 1. 工具来源

- 内置工具：例如 `Read`、`Edit`、`Write` 和 `Bash`，具体可用性取决于平台与版本。
- MCP 工具：通过 MCP 服务接入外部能力和数据。

Skills 提供任务说明并通过已有能力完成工作，不会仅因包含脚本就自动成为新工具。Hooks 则由运行时在指定事件发生时触发。

## 2. 执行与输出

工具执行受权限配置、工作目录及运行环境约束。工具结果进入后续模型上下文前，可能经过工具自身的分页、长度控制，以及运行时的截断或文件外置。

不同工具的限制不同，不能将 Bash 的字符限制推广为所有工具的统一限制。正常结果与错误结果也可能采用不同策略。
