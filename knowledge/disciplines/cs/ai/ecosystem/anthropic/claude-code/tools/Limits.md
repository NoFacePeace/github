# Claude Code 工具输出限制

Claude Code 对单次工具输出进行大小控制，不需要等整个上下文接近上限。具体策略按工具类型和结果状态区分。本文依据官方文档整理，核对日期为 2026-10-20，版本更新后应重新核对。

## 1. Bash 输出

命令执行期间，输出流写入工作文件；命令结束后再按读取窗口取回内容。输出超过 5 GB 时命令会被终止。

| 结果类型 | 默认直接展示范围 | 超限后的处理 |
|---|---|---|
| 正常结果 | 约 30,000 字符 | 返回会话目录中的输出文件路径，以及最多前 2,000 字符预览；保存文件也有 64 MiB 上限 |
| 失败结果 | 约 10,000 字符 | 从读取窗口中截取首尾片段，中间省略，不附文件路径 |

这里的“正常结果”按 Bash 工具的规则判定，不完全等于退出码为零。官方列出部分命令的退出码 1 可以视为正常信息性结果，例如 `grep`、`rg` 和 `git diff`；不能推广到任意命令。

### 1.1 配置

- `BASH_MAX_OUTPUT_LENGTH`：控制从工作文件读回的字符窗口，默认 30,000，最高 150,000；它不会单独提高直接展示的上限。
- `bashOutputMaxChars`：从 Claude Code v2.1.261 起，可同时设置正常结果的直接展示上限和读回窗口，最高 128,000 字符；设置后忽略 `BASH_MAX_OUTPUT_LENGTH`。

因此，工作文件大小、读回窗口和直接展示长度是不同限制。失败结果的首尾片段也来自读回窗口，不应默认等同于完整原始输出的首尾。

## 2. MCP 输出

| 限制 | 默认行为 |
|---|---|
| 超过 10,000 Token | 显示输出过大的警告 |
| Token 上限 | 默认 25,000，可通过 `MAX_MCP_OUTPUT_TOKENS` 修改 |
| 成功且不含图片的结果超过 Token 上限 | 保存到文件，以文件引用替换上下文中的结果 |
| 前台成功纯文本结果超过 50,000 字符 | 即使未超过 Token 上限，也保存到文件并返回引用 |
| 错误结果的文本超过约 11,000 字符 | 保留开头和结尾各 5,000 字符，中间标明省略数量 |

外置文件保存在会话的 `tool-results` 目录，位于 `~/.claude/projects/` 下。模型需要细节时再读取文件。

### 2.1 配置与例外

- `MAX_MCP_OUTPUT_TOKENS` 调整默认 Token 上限，不改变 50,000 字符的外置阈值。
- MCP 服务可以通过工具元数据 `_meta["anthropic/maxResultSizeChars"]` 指定文本结果限制，最高 500,000 字符。声明该值后，文本内容使用该工具的限制；图片内容仍受 Token 限制。
- 后台工具结果通过任务通知返回，不能直接套用全部前台结果规则。
- HTTP、SSE 单个响应以及 WebSocket 单条消息还有 16 MiB 等传输限制，超过可能导致失败，而非正常外置。

## 3. 与上下文管理的关系

单次输出控制发生在工具结果返回阶段。外置保存可供后续读取的内容，截断减少直接进入模型的内容；两者可以结合，也可能只截断。

即使每条结果都未超限，多次调用仍会累积上下文，整体上下文的裁剪或摘要压缩需要另外处理。文件外置也不代表无限保存完整数据，仍需注意文件大小限制和结果类型。
