# DigitalOcean

DigitalOcean 是一家美国云计算公司，为开发者和企业提供云服务器、数据库、存储等基础设施，以及模型推理和 Agent 相关托管服务。

## 1. Agent 产品

| 产品 | 定位 |
|---|---|
| [Agent Data Services](AgentDataServices.md) | 整理文档、多媒体和执行记录，向 Agent 提供可检索的上下文 |
| [Agent Learning Services](AgentLearningServices.md) | 观察 Agent 的运行过程，发现问题，通过评估和模拟测试验证改进 |

Data Services 提供数据基础，Learning Services 利用运行记录帮助团队改进 Agent。二者是云服务产品，不等同于某个模型或独立的聊天应用。
