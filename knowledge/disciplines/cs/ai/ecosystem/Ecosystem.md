# AI 生态

AI 生态包括模型、应用产品、开发框架、托管平台与编排服务。本目录用于整理相关产品、项目及其集成方式。

## 1. 开发框架

- [Google ADK](GoogleADK.md)：Google 的开源智能体开发框架。

## 2. 模型与产品平台

- [OpenAI](openai/OpenAI.md)：提供 ChatGPT、Codex 及模型 API 与 Agent 开发能力的公司。
- [Anthropic](anthropic/Anthropic.md)：Claude 模型、应用、编程工具与 Agent 托管平台的开发厂商。
- [DeepSeek（深度求索）](deepseek/DeepSeek.md)：研发大模型，提供聊天助手、模型 API 与 DeepSeek Harness 智能体运行框架的公司。
- [Anomaly](anomaly/Anomaly.md)：开发 OpenCode、SST 等开源开发工具的公司。
- [DigitalOcean](digitalocean/DigitalOcean.md)：提供云计算基础设施、模型推理与 Agent 托管、数据和评估服务的云服务商。
- [Perplexity](perplexity/Perplexity.md)：提供 AI 搜索、问答与 Agent 产品，并开发 SPACE 沙箱平台的公司。
- [NVIDIA](nvidia/NVIDIA.md)：提供 GPU、AI 计算平台和 Nemotron 等模型的公司。
- [xAI / Grok](xai/XAI.md)：Grok 模型、应用及开发者 API 相关产品。
- [Mistral AI](mistral/Mistral.md)：提供语言模型、语音模型及语音 Agent 开发工具的公司。
- [Arize AI](arize/Arize.md)：提供 AI 应用可观测性与评估平台，包括可自托管的 Phoenix。
- [ModelScope（魔搭）](modelscope/ModelScope.md)：提供模型托管、共享和开发资源的社区与平台。
- [FPT Software](fpt/FPTSoftware.md)：软件与 IT 服务公司，其 AI Center 下的 AI4Code 团队开展代码智能与自动化软件开发研究，发布 CodeWiki 等开源项目。

## 3. 智能体产品

- [Gemini Agent](GeminiAgent.md)：Google 面向企业工作的智能体产品。
