# AFK

AFK（AFK AI, Inc.）是开发个人智能体与开源 Agent 系统的公司，GitHub 组织名为 `AFK-surf`。其产品强调将目标交给 Agent 持续执行，减少用户在软件之间操作和反复发出指令的负担。本文依据官方组织资料与项目 README 整理，核对日期为 2026-11-01。

AFK 在日常交流中也是 Away From Keyboard（离开键盘）的缩写；本文指公司及其产品，不泛指所有无人值守的 Agent 项目。

## 1. 产品与项目

- [Comma](comma/Comma.md)：以持久任务为中心的个人 AI Agent，强调跨会话、跨设备延续工作，支持协调其他 Agent 与自托管。
- [Open-Agent](open-agent/OpenAgent.md)：支持多模型、多 Agent 协作和自托管的开源 Agent 系统，项目将自身定位为 Claude Agent SDK、ChatGPT Agents 和 Manus 的开源替代方案。

上述项目均位于 AFK 官方组织下；官方 README 未明确说明两者的版本继承关系，因此不将其视为同一个产品的不同版本。
