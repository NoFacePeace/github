# Voxtral 3

Voxtral 3 是 Mistral AI 于 2026 年 10 月 20 日发布的语音模型系列与 Voice Agent SDK，用于构建能够实时听取语音、推理、调用工具并以语音回应的应用。

## 1. 产品定位

Voxtral 3 提供模型和语音 Agent 开发框架，而非配置好业务能力、开箱即用的成品 Agent。开发者需要接入负责推理决策的语言模型、业务工具或 API，并设置权限和执行规则，才能形成面向具体场景的[智能体](../../agent/Agent.md)。

Voice Agent SDK 已负责串联语音识别、推理、工具调用与语音回复，因此它也包含组织语音 Agent 运行流程的能力。

## 2. 组成与分工

| 组成 | 作用 |
| --- | --- |
| 语音识别模型 | 将音频转为文字，提供实时转写等能力；Voxtral Small Transcribe 3 支持 50 多种语言，并提供说话人区分等能力 |
| 语音合成模型 | 将文字转为语音；Voxtral Mini TTS 3 可根据对话上下文调整语气、节奏和情绪，支持 35 多种语言及 50 多种方言 |
| Voice Agent SDK | 将听取语音、模型推理、工具调用与语音回复接成实时流式流程 |

推理和决策由接入的语言模型承担，例如 Mistral Small。查询订单、创建预约等实际业务操作，由应用接入的工具和后端系统执行。

## 3. 工作流程示例

以电话预约为例：

```text
用户说：“帮我预约下周的门诊。”
              ↓
语音识别模型将声音转成文字
              ↓
语言模型理解需求，并请求调用查询预约工具
              ↓
应用调用业务 API，返回可预约时段
              ↓
语言模型生成确认内容，语音合成模型读出
              ↓
用户确认后，应用执行预约并反馈结果
```

具体工具、确认步骤和执行权限需要由应用实现。

## 4. 使用与部署

- 可通过 Mistral API 接入，也支持在自己的基础设施上部署；具体模型和 SDK 的部署条件以官方文档为准。
- 典型场景包括电话客服、服务台、语音助手和免手持操作的业务应用。
- 自部署可让组织控制音频处理位置、数据处理方式和对话保留策略。
