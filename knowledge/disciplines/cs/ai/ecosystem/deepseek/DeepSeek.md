# DeepSeek

DeepSeek（深度求索）是一家中国人工智能公司，研发大模型，并提供面向用户的 AI 助手、面向开发者的模型 API 和智能体运行框架。日常提到“DeepSeek”时，可能指公司、模型，也可能指聊天产品，需要根据上下文区分。

## 1. 模型与聊天产品

- **DeepSeek 模型**：负责理解输入、推理和生成内容，是应用调用的底层能力。
- **DeepSeek 聊天助手**：通过网页版或 App 与模型交互，可用于问答、写作、翻译、编程和资料分析。

模型与聊天产品属于不同层次：模型提供能力，聊天产品提供用户界面及具体使用流程。

## 2. 开发接口

DeepSeek API 允许开发者在自己的应用中调用模型，也可以作为智能体工具的模型后端。使用时需要在开放平台申请 API Key，并按官方文档配置接口地址和模型名称。

## 3. 智能体运行框架

- [DSH](DSH.md)：DeepSeek Harness，通过插件组合模型、工具和界面等能力，让智能体执行多步任务的开源运行框架。

模型负责生成回复和工具调用请求；运行框架负责组织执行流程、连接工具并将执行结果交回模型。例如，修复项目报错时，框架可以组织读取代码、修改文件、运行检查和根据结果继续处理的过程。
