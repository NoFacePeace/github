# DiffSynth-Studio

DiffSynth-Studio 是 ModelScope 社区维护的开源生成模型引擎，主要提供扩散模型的训练、微调和推理能力，并支持显存管理及生成流程定制。它是使用和开发模型的框架，不是某一个模型。

## 1. 核心能力

| 能力 | 用途 |
|---|---|
| 推理 | 加载 FLUX、Wan 等受支持模型，生成图片或视频等内容 |
| 微调 | 使用自己的数据训练 LoRA，或在受支持配置下进行全量微调 |
| 显存管理 | 通过量化、组件卸载等方式降低资源需求 |
| 流程定制 | 修改推理与训练流程，扩展控制方式或研究方法 |

具体功能、硬件要求与支持范围取决于所选模型和框架版本，应查看对应示例与文档。

## 2. 典型流程

1. 选择受支持的基础模型和对应的推理示例。
2. 下载权重，按硬件条件配置精度和显存管理策略。
3. 直接运行推理生成内容；需要定制时，准备数据并运行相应训练脚本。
4. 加载训练后的权重或 LoRA 参数，再次执行推理并检查效果。

直接生成内容不会自动训练出新模型。LoRA 微调通常得到配合基础模型使用的适配文件；全量微调则更新模型的全部参数。
