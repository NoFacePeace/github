# ChatGPT

ChatGPT 是 OpenAI 面向用户的通用 AI 助手产品，可通过自然语言进行问答、研究、写作、资料分析和任务执行。ChatGPT 是产品名称，不是某一个模型名称。

## 1. 使用方式

- Chat：适合问答、讨论、构思及逐步修改内容。
- ChatGPT Work：围绕明确目标收集上下文、使用工具，并推进到可审阅的结果，例如报告、表格或演示文稿。

实际可用功能取决于账号、客户端、模式和已连接的工具。以上定位依据 2026-10-20 核对的官方说明。

## 2. 与 Agent 的关系

Agent 描述围绕目标进行规划、调用工具、观察结果并继续执行的工作方式。ChatGPT 可以采用这种方式工作，因此不能把它仅理解为一次问答的聊天界面。

## 3. 与 Codex 的区别

[Codex](codex/Codex.md) 更强调软件开发中的项目操作和技术细节；ChatGPT 更强调通用任务和结果表达。两者能力存在重叠，不能据此认定 ChatGPT 不能执行任务，或 Codex 只能编程。

官方桌面产品说明指出，两者在界面、展示的聊天与项目、技术细节以及 PR 视图等方面存在区别。ChatGPT Work 通常隐藏 Git、Shell 等技术细节，Codex 提供差异审阅等开发者视图。

## 4. 扩展能力

ChatGPT 与 Codex 共享插件目录，但单项能力可能依赖具体运行环境。本地脚本或 Codex 的 Hook 配置不能直接假设适用于所有 ChatGPT 模式。
