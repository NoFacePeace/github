# Codex 工具

工具是 Codex 执行实际操作的接口，例如读取文件、修改代码、执行命令和访问外部服务。模型生成调用请求，运行环境负责执行并把结果返回模型。本文依据 OpenAI 官方文档整理，核对日期为 2026-10-20。

## 1. 工具来源

- 运行环境提供的文件、终端和其他内置工具。
- 通过 MCP 等连接接入的外部工具。
- 插件提供的工具连接与配套资源。

具体名称、参数和可用范围取决于客户端、运行环境及版本。Skill 提供如何完成任务的说明，不会仅因包含脚本就自动创建独立工具。

## 2. 执行与输出

工具返回的结果会成为后续模型调用的输入，因此需要控制单次结果大小。工具可以通过分页、筛选或输出参数主动减少结果，运行时也可以对进入历史的结果设置预算。

单次输出限制与整体上下文管理属于不同层次：前者限制一条工具结果，后者处理消息不断累积后的裁剪或摘要。
