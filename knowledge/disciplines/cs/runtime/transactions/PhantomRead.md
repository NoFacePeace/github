# 幻读

## 1. 定义

幻读（Phantom Read）是指同一事务重复执行相同条件或范围查询时，匹配记录集合因其他事务的已提交修改而发生变化。

## 2. 示例

| 顺序 | 事务 A | 事务 B |
| --- | --- | --- |
| 1 | | 查询待处理订单，得到 5 条。 |
| 2 | 插入一条待处理订单并提交。 | |
| 3 | | 重复查询，得到 6 条。 |

除插入外，删除记录或更新条件列，使记录进入、离开查询范围，也可能改变匹配集合。集合变化不一定体现为总条数变化。

## 3. 为什么只锁已有记录可能不够

如果只保护已找到的 5 条记录，其他事务仍可能向查询范围插入第 6 条。保护现有行与保护满足条件的范围是不同需求。

系统可以通过谓词或索引范围保护阻止冲突，也可以通过快照读取保持结果集合的可见性，或通过验证中止冲突事务。快照不会因此阻止其他事务实际插入。

## 4. 隔离保证与边界

经典 REPEATABLE READ 的最低要求允许幻读，但具体产品可能提供更强保证。SERIALIZABLE 不允许破坏可串行化的此类现象。

普通快照读与锁定读的规则可能不同，不能仅凭一次范围查询结果稳定，就认定所有并发异常都已解决。
