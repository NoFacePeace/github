# 读未提交

## 1. 定义

READ UNCOMMITTED（读未提交）是允许脏读的隔离级别，读取可能观察到其他事务尚未提交的修改。

这是允许范围，不表示每次读取都必然读到未提交数据。有的数据库会将该级别实现为更强的行为，应以具体产品为准。

## 2. 示例

事务 A 将余额从 100 改为 0，但尚未提交；事务 B 读到 0。随后 A 回滚，余额恢复为 100，B 曾经读取的 0 从未正式提交。

若 B 根据该值发起不可撤销的外部操作，A 的回滚也无法自动撤销 B 的业务影响。

## 3. 允许的现象

经典分级中，读未提交允许脏读、不可重复读和幻读，不提供稳定的重复读取保证。

允许读取未提交状态，不等于允许任意覆盖其他事务的未提交写入。写入冲突仍需按系统规则协调，不能理解为完全不加锁或没有并发控制。

## 4. 使用边界

只有明确能够容忍不可靠中间结果时才应考虑这种语义，不能用于要求精确余额、库存或权限判断的读取。是否能带来性能收益也依实现而定。
