# 不可重复读

## 1. 定义

不可重复读（Non-repeatable Read）是指同一事务重复读取某条记录时，因其他事务在期间提交修改，观察到不同的值，或发现记录已被删除。

## 2. 示例

| 顺序 | 事务 A | 事务 B |
| --- | --- | --- |
| 1 | | 读取余额，得到 100。 |
| 2 | 将余额改为 80 并提交。 | |
| 3 | | 在同一事务再次读取，得到 80。 |

两次读取都可以只看到已提交数据，因此不存在脏读，也仍可能发生不可重复读。

## 3. 与其他变化的区别

事务自己修改记录后，再次读取到自己的新值，不是由其他事务提交造成的不可重复读。

不可重复读通常强调某条已读取记录的变化；幻读强调同一查询条件的匹配记录集合变化。二者在具体删除或条件列更新场景中可能有所交叉。

## 4. 防范与边界

可以通过适当的可重复读取保证、快照或锁保护相关读取。具体实现中，普通一致性读与锁定读可能采用不同规则，不能把一种读取的快照规则套给所有语句。

稳定读取不自动保证后续业务写入正确，仍需考虑写冲突和跨记录约束。
