# 语法分析

语法分析（Parsing）依据语言的语法规则，识别输入中的结构并构建语法树，例如函数声明、条件分支和调用表达式。

## 1. 输入与输出

| 项目 | 内容 |
| --- | --- |
| 输入 | 通常是词法分析产生的 Token 流；集成式解析库也可以直接接收源码文本 |
| 规则 | 对应语言的 grammar，描述合法语法结构 |
| 输出 | 语法树及语法诊断，节点通常带有源码位置 |

例如，`SaveOrder(id)` 可以被识别为调用表达式，其中 `SaveOrder` 是被调用表达式，`id` 是实参表达式。

## 2. CST 与 AST

- 具体语法树（Concrete Syntax Tree，CST）保留更多具体语法结构，可包含关键字、分隔符等节点，适合需要精确源码位置的工具。
- 抽象语法树（Abstract Syntax Tree，AST）通常省略部分语法细节，突出操作与结构，便于后续语义分析和转换。

具体保留哪些信息取决于实现。语法树节点的位置可以用于截取原始源码，不代表树本身保存了源码全文。

## 3. 能力边界

语法分析能够识别“这里存在一个调用表达式”，但确定调用指向哪个声明、参数类型是否匹配，以及运行时会执行哪个实现，通常需要进一步分析。

错误恢复型解析器可能在输入不完整或存在语法错误时仍返回部分可用的树。调用方应根据用途决定是否接受这些结果。
