# 编译原理

编译原理研究如何分析源程序并将其转换为目标程序，包括词法分析、语法分析、语义分析、中间表示、优化与代码生成。相关分析技术也用于编辑器、静态检查和代码理解工具。

## 1. 典型处理流程

```text
源码 → 词法分析 → 语法分析 → 语义分析 → 中间表示 → 优化 → 代码生成
```

| 阶段 | 主要职责 |
| --- | --- |
| 词法分析 | 识别标识符、关键字、字面量和运算符等 Token |
| 语法分析 | 按语言语法组织 Token，构建语法树 |
| 语义分析 | 进行名称解析、作用域检查、类型检查等 |
| 中间表示 | 用便于分析和转换的结构表示程序 |
| 优化 | 在保持约定语义的前提下改进程序 |
| 代码生成 | 输出机器码、字节码或其他目标形式 |

这是概念上的划分，实际编译器可能合并阶段，或使用多层中间表示。

## 3. 与代码理解的关系

代码理解工具可以只复用编译流程中的部分能力。例如，先解析函数声明和调用表达式，再提取组件及依赖，为检索或文档生成提供结构化素材。

解析出调用表达式不等于完成调用目标绑定；后者可能还需要名称、类型、项目依赖和动态分派分析。
