# 二次探测

二次探测（Quadratic Probing）是开放寻址法中的一种探测策略，使用探测次数的二次函数生成相对于起点的偏移，冲突时依次检查序列中的其他位置。

## 1. 常见公式

```text
位置(i) = (h(key) + c1 × i + c2 × i²) mod B
```

i 从 0 开始，B 是槽位或组的数量，c1、c2 是所选方案的参数。公式必须保证偏移的计算有明确的整数意义，并与容量和覆盖范围的要求配套。

它不是总以固定步长移动。线性探测每次通常前进一个位置，二次探测则让偏移随探测次数非线性变化。

## 2. 简单平方偏移

使用 `i²` 作为偏移、B 为 7、起点为 0 时，探测位置开头为：

```text
i：    0  1  2  3  4  5  6
位置： 0  1  4  2  2  4  1
```

这说明“采用二次公式”不自动保证遍历所有位置。参数不合适时，即使表中仍有空槽，也可能无法沿该序列访问到。

## 3. 三角数偏移

使用 `i(i+1)/2` 作为累计偏移也是一种二次探测，常称为[三角数探测](TriangularProbing.md)。其增量依次为 1、2、3 等，组数为 2 的幂时，前 B 个探测位置可以覆盖全部组。

这里除以 2 是先对相邻整数的乘积做整数除法，再取模，不能随意当成模意义下乘以 2 的逆元。

## 4. 作用与聚集

变化的偏移可以减轻线性探测中连续拥挤区不断扩大的主聚集问题，但相同起始位置的键仍会使用相同探测序列，存在次聚集。

探测策略不替代哈希函数，也不消除高负载、删除标记和差哈希分布的影响。完整键比较仍然必不可少。

## 5. 实现要求

查询和插入必须使用一致的探测规则。删除需要保留路径不变量，不能任意标为空槽；探测应有终止协议，覆盖全部位置也不等于表满时可以无限继续。

选择公式时，应同时确认容量约束、覆盖范围、负载阈值与整数运算溢出处理，而不是只把线性偏移替换为平方。
