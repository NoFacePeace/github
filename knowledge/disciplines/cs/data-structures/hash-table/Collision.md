# Collision

哈希冲突是指不同的键被映射到同一个桶或槽位。即使完整哈希值不同，也可能在映射到有限容量的表后得到相同下标。

## 1. 冲突与键比较

哈希值或桶下标相同不代表键相等。发生冲突时，哈希表必须保留不同的键，并通过键相等比较找到真正匹配的条目。

例如表有 8 个桶，使用 `hash mod 8` 计算下标时，哈希值 `3` 与 `11` 都映射到第 `3` 个桶。

## 2. 拉链法

- [拉链法](SeparateChaining.md)：将冲突条目组织在同一桶的链表等结构中。

## 3. 开放寻址法

- [开放寻址法](OpenAddressing.md)：在表内按探测序列寻找槽位，包括线性探测、二次探测和双重哈希。

## 4. 对性能的影响

冲突越多，桶内比较或槽位探测通常越多。普通链式或探测式实现遇到严重冲突时，单次操作可能退化为 `O(N)`。

良好的哈希分布、合理的负载因子与及时扩容可以降低冲突成本，但扩容不能保证消除所有冲突。对于恶意输入，还需结合带随机种子的哈希等措施评估碰撞攻击风险。
