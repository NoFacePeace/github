# 三角数探测

三角数探测使用三角数 `i(i+1)/2` 作为累计偏移，是二次探测的一种。名称来自偏移序列，不是描述槽位排列成三角形。

## 1. 公式与增量

```text
位置(i) = (起始位置 + i × (i + 1) / 2) mod B
```

| i | 累计偏移 | 相对上一步增加 |
| --- | --- | --- |
| 0 | 0 | 不移动，检查起点 |
| 1 | 1 | 1 |
| 2 | 3 | 2 |
| 3 | 6 | 3 |
| 4 | 10 | 4 |

因此，可以逐步累加步长，不必每次重新计算乘法和除法。

## 2. 递推实现

```text
offset = 起始位置 mod B
step = 0

每次移动到下一位置：
    step += 1
    offset = (offset + step) mod B
```

B 为 2 的幂时，可以使用 `& (B - 1)` 替代相应取模。这里的 offset 是当前实际位置，step 是递增步长，二者不能混淆。

## 3. 示例

B 为 8、起始位置为 5：

```text
起点：5
(5 + 1) mod 8 = 6
(6 + 2) mod 8 = 0
(0 + 3) mod 8 = 3
(3 + 4) mod 8 = 7
(7 + 5) mod 8 = 4
(4 + 6) mod 8 = 2
(2 + 7) mod 8 = 1
```

前 8 个位置为 `5 → 6 → 0 → 3 → 7 → 4 → 2 → 1`，覆盖全部位置且没有重复。后续位置不保证立即从起点重新开始，算法应按自己的终止协议处理，而不是假定序列周期恰好为 B。

## 4. 为什么能覆盖 2 的幂个位置

令 `T(i) = i(i+1)/2`，B 为 `2^k`。假设 `0 <= i < j < B`，且两个偏移模 B 相等，则：

```text
2B 整除 (j-i)(i+j+1)
```

两个因子的和是 `2j+1`，为奇数，因此一奇一偶。由于 2B 是 2 的幂，全部所需的因子 2 必须来自那个偶因子，即偶因子必须被 2B 整除。

但两个因子都为正数且小于 2B，不可能满足。因此前 B 个偏移模 B 不重复，共有 B 个，恰好覆盖全部位置。加入固定起点只会整体平移，不影响覆盖性。

该性质依赖 B 为 2 的幂，不能直接推广到任意容量。

## 5. 用途与限制

该策略可减轻线性探测的主聚集，并在相应容量约束下避免只访问部分位置。但起点相同的键仍沿同一序列探测，不能消除次聚集或所有冲突。

查找遇到匹配键即可成功；按实现规则遇到空位置可判定不存在，删除标记则不能直接作为终点。完整覆盖性不意味着每次必须扫描全部位置，也不意味着操作最坏情况是常数时间。

## 6. Go map 中的应用

Go 1.27.2 的 Swiss Table 表内使用这种序列探测组，核心为：

```go
s.index++
s.offset = (s.offset + s.index) & s.mask
```

mask 等于组数减一。每次定位一个组后，还需通过控制字节筛选组内候选槽，再比较完整键；探测对象是组，不是直接以该公式选择最终槽位。
