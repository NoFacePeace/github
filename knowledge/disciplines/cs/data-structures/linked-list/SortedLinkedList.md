# 有序链表

有序链表（Sorted Linked List）是节点按指定比较规则排列的链表，例如按数值非递减或非递增排列。它描述的是节点之间的顺序约束，可以使用单向链表、双向链表或循环链表实现。

## 1. 顺序约束

按数值非递减排列时，每个节点都满足：如果存在后继节点，则当前节点的值不大于后继节点的值。

```text
head → 1 → 2 → 2 → 4 → nil
```

非递减允许相等元素；严格递增则要求相邻元素不相等。空链表和只有一个节点的链表也满足有序条件。

## 2. 常见操作

### 2.1 查找

从头开始比较节点值。对于非递减链表，如果当前值已经大于目标值，则可以提前结束，因为后续节点不会再等于目标值。

有序性可以减少部分查找，但普通链表不支持按下标随机访问，不能直接获得数组式二分查找的 O(log n) 时间复杂度。

### 2.2 插入

先找到满足顺序约束的插入位置，再调整节点链接。插入重复值时，可以约定放在相等节点之前或之后；如果要求相等元素保持插入顺序，则应放在已有相等节点之后。

### 2.3 删除

先定位目标节点，再调整前后链接。删除节点不会改变剩余节点的相对顺序，因此可以保持原有的有序性。

### 2.4 合并

合并两个按相同规则排列的非递减链表时，比较两个链表当前节点的值，将较小节点接到结果链表尾部，并推进对应链表。一个链表耗尽后，直接接上另一个链表的剩余部分。

如果希望合并具有稳定性，可以在值相等时优先选择第一个链表的节点。复用原节点进行合并会修改原链表的链接。

## 3. 复杂度

设普通有序链表包含 n 个节点，不维护额外的查找索引：

| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| 按值查找 | O(n) | 有序性允许提前结束，但最坏仍需遍历。 |
| 按顺序插入 | O(n) | 查找位置为 O(n)，定位后的链接调整为 O(1)。 |
| 按值删除 | O(n) | 包含定位节点及必要前驱的成本。 |
| 合并两个有序链表 | O(m + n) | m、n 分别为两个链表的长度；迭代复用节点时辅助空间为 O(1)。 |

## 4. 使用注意

- 修改节点用于排序的值时，需要检查顺序约束，必要时将节点摘除后重新插入。
- 有序性与单向、双向、循环等链接形式相互独立。
- 有序链表适合顺序遍历和合并；如果需要频繁按值快速查找，通常还需要额外索引或其他数据结构。
