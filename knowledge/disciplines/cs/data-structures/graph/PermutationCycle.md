# 置换环

## 1. 基本概念

置换是一个有限集合到自身的一一对应。把每个位置看作顶点，把当前位置到目标位置的映射 `i → targetPos[i]` 看作有向边，每个顶点都恰好有一条出边和一条入边，因此整个图由若干个互不相交的有向环组成，这些环称为置换环。

置换环是一种结构；沿着映射遍历并找出所有环的过程，称为置换环分解。

## 2. 示例

对于数组 `[30, 10, 20]`，按数位和从小到大排序后的目标数组为 `[10, 20, 30]`，各元素的原下标到目标下标的映射为：

```text
0 → 2    // 30
1 → 0    // 10
2 → 1    // 20

组成一个环：0 → 2 → 1 → 0
```

已经处于目标位置的元素满足 `i → i`，构成长度为 1 的环，也称自环。

## 3. 最少交换次数

当允许交换任意两个位置，且每个元素的目标位置已经确定时，长度为 `k` 的置换环最少需要 `k - 1` 次交换。每次交换最多使环的数量增加 1，而最终所有元素归位时共有 `n` 个长度为 1 的环，因此至少需要 `n - cycles` 次交换；逐个处理环可以达到这个下界。

```text
最少交换次数 = 各环的（长度 - 1）之和 = n - cycles
```

其中 `n` 是元素数量，`cycles` 是置换环数量，包含长度为 1 的环。如果只允许相邻交换，就不能直接使用这个公式；存在相同元素时，任意指定其目标位置也不一定得到最少交换次数，需要另行考虑目标匹配。

## 4. 遍历方法

使用 `visited` 数组记录已经访问的位置。从每个尚未访问的位置出发，不断执行 `j = targetPos[j]`，直到遇到已经访问的位置，即完成一个环的遍历。每个位置只访问一次，因此环分解的时间复杂度为 `O(n)`，辅助空间复杂度为 `O(n)`。
