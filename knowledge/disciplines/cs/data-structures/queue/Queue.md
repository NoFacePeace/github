# 队列

队列（Queue）是一种遵循先进先出（First In, First Out，FIFO）规则的数据结构。元素从队尾加入，从队头移除，先入队的元素先出队。

## 1. 基本操作

- 入队（Enqueue）：将元素加入队尾。
- 出队（Dequeue）：移除并返回队头元素。
- 查看队头（Front）：读取队头元素，不将其移除。
- 判空（IsEmpty）：判断队列中是否没有元素。

```text
依次入队：A、B、C
队头 → A、B、C ← 队尾
依次出队：A、B、C
```

## 2. 实现方式

- 循环数组：通过队头、队尾位置复用数组空间；动态扩容时需要迁移元素。
- 链表：维护头尾指针，在尾部插入、头部删除。
- 切片配合队头下标：入队时追加元素，出队时递增队头下标，适合一次性遍历；已出队部分仍可能占用底层数组空间。

出队不需要将所有剩余元素向前搬移，否则一次出队可能需要 O(n) 时间。对于保存引用的实现，还应及时清理已出队槽位，避免保留不再需要的对象。

## 3. 复杂度

维护头尾指针的链式队列，其入队、出队、查看队头和判空均可为 O(1)。动态循环数组的入队通常为摊还 O(1)，扩容时单次可能需要 O(n)；出队和查看队头为 O(1)。

保存 n 个元素需要 O(n) 的逻辑空间，实际分配空间还取决于容量、扩缩容及已出队槽位的回收方式。

## 4. 双端队列与单调队列

双端队列（Deque）允许在队头和队尾两端插入、删除元素，是对普通队列操作范围的扩展。

[单调队列](MonotonicQueue.md)通常使用双端队列维护单调排列的候选元素，从队头移除过期元素、从队尾移除不再有用的候选，常用于滑动窗口的最大值或最小值。

## 5. 常见应用

- 广度优先搜索：按发现顺序处理节点，实现逐层扩展。
- 任务排队：按进入顺序等待处理。
- 缓冲与消息传递：暂存尚未消费的数据，具体系统还需明确容量和并发规则。
