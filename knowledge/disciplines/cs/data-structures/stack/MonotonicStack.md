# 单调栈

单调栈（Monotonic Stack）是在栈中维护元素单调顺序的一种使用方式。遍历序列时，先弹出不符合顺序要求的栈顶元素，再将当前元素入栈，常用于寻找左右两侧最近的更大或更小元素。

## 1. 单调顺序

本文统一按“从栈底到栈顶”的方向描述顺序：

- 单调递增栈：元素值从小到大排列，可以根据题意允许相等。
- 单调递减栈：元素值从大到小排列，可以根据题意允许相等。

实际实现通常保存元素的下标，通过原数组比较值。下标还可以用于计算距离、区间宽度或将答案写回对应位置。

## 2. 核心过程

以从左到右查找“右侧第一个严格更大的元素”为例：

1. 栈保存尚未找到答案的元素下标，对应值从栈底到栈顶非递增。
2. 如果当前值大于栈顶对应值，弹出栈顶，并将当前值记为该元素的答案。
3. 持续比较、弹出，直到栈为空或栈顶对应值不小于当前值。
4. 将当前下标入栈，等待后续更大的元素。
5. 遍历结束后，栈中剩余元素的右侧不存在严格更大的元素。

一个下标出栈前，所有已经扫描到的右侧元素都没有使它出栈，因此当前使它出栈的元素就是右侧第一个严格更大的元素。

## 3. Go 示例

下面返回每个元素右侧第一个严格更大的元素值，不存在时记为 `-1`。如果业务数据中 `-1` 也是合法答案，可改为返回下标或额外的存在标记。

```go
func nextGreaterElements(nums []int) []int {
    ans := make([]int, len(nums))
    for i := range ans {
        ans[i] = -1
    }
    stack := []int{}
    for i, v := range nums {
        for len(stack) > 0 && nums[stack[len(stack)-1]] < v {
            idx := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            ans[idx] = v
        }
        stack = append(stack, i)
    }
    return ans
}
```

```text
输入：nums = [2, 1, 2, 4, 3]
输出：[4, 2, 4, -1, -1]
```

遇到第二个 `2` 时，弹出 `1` 并记录答案为 `2`；第一个 `2` 仍保留，因为相等不满足“严格更大”。遇到 `4` 时，两个 `2` 都出栈，答案均为 `4`。

## 4. 复杂度

对于 n 个元素，每个下标最多入栈一次、出栈一次，因此即使存在嵌套循环，总时间复杂度仍为 O(n)。辅助栈最坏保存 n 个下标，需要 O(n) 空间；返回数组也需要 O(n) 空间。

## 5. 适用场景与注意事项

- 下一个更大或更小元素：维护尚未找到答案的候选下标。
- 每日温度：找到右侧第一个更高温度的位置，并计算下标差。
- 柱状图中最大的矩形：确定柱子能够向两侧延伸的边界。
- 接雨水：使用非递增栈，遇到更高柱子时弹出凹槽底部，结合新的栈顶和当前柱子计算新增水量。

遍历方向、比较符号和相等元素的处理需要由题意决定。严格更大与大于等于对应的出栈条件不同；涉及区间贡献统计时，还需要明确重复值由哪一侧负责，避免重复计算。
