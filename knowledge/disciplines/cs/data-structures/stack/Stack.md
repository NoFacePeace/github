# 栈

栈（Stack）是一种遵循后进先出（Last In, First Out，LIFO）规则的数据结构。元素从同一端插入和移除，这一端称为栈顶，另一端称为栈底。

## 1. 基本操作

- 入栈（Push）：将新元素放到栈顶。
- 出栈（Pop）：移除并返回栈顶元素。
- 查看栈顶（Peek）：读取栈顶元素，但不移除它。
- 判空（IsEmpty）：判断栈中是否没有元素。

```text
依次入栈：A、B、C

栈顶 → C
       B
栈底 → A

依次出栈：C、B、A
```

## 2. 实现方式

栈描述的是访问规则，可以通过不同的底层结构实现：

- 数组或动态数组：将末尾作为栈顶，便于在末尾插入和删除。
- 链表：将链表头作为栈顶，通过头部插入和删除实现入栈与出栈。

Go 中通常可以使用切片实现栈，切片的最后一个元素是栈顶。

## 3. Go 示例

```go
stack := []int{}

// 入栈。
stack = append(stack, 1)
stack = append(stack, 2)

// 访问栈顶和出栈前，先判断是否为空。
if len(stack) > 0 {
    top := stack[len(stack)-1]
    stack = stack[:len(stack)-1]
    _ = top
}

empty := len(stack) == 0
_ = empty
```

## 4. 复杂度

以 Go 切片实现的栈为例：

| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| 入栈 | 摊还 O(1) | 扩容时可能分配并复制已有元素，单次最坏为 O(n)。 |
| 出栈 | O(1) | 调整切片长度。 |
| 查看栈顶 | O(1) | 直接访问末尾元素。 |
| 判空 | O(1) | 检查切片长度。 |

保存 n 个元素需要 O(n) 的逻辑存储空间；切片实际保留的内存取决于底层数组容量，出栈不会自动缩小该容量。

## 5. 适用场景与注意事项

- 括号匹配：最近遇到的左括号优先与右括号匹配。
- 深度优先遍历：通过显式栈保存尚未处理的节点或状态。
- 撤销操作：按与执行相反的顺序恢复历史状态。
- 表达式求值：暂存操作数或运算符。

空栈不能直接读取栈顶或出栈，需要先判空，或由接口返回是否成功。若用切片保存指针等引用类型，出栈时可以先将原栈顶槽位置零，再缩短切片，避免底层数组继续保留不再需要的引用。

## 6. 单调栈

[单调栈](MonotonicStack.md)在栈的基础上维护元素的单调顺序，常用于查找每个元素左右两侧最近的更大或更小元素。
