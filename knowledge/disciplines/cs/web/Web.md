# Web 技术

Web 技术涉及浏览器、页面、服务端应用及其交互机制。本目录整理 Web 开发与应用相关知识，通用网络协议基础沿用网络目录中的文档。

HTTP 是规定请求与响应如何交换的通信协议，Web 是包含浏览器、页面和应用交互的更大体系。HTTP 也用于移动应用和服务间调用，不限于网页；本目录侧重 Web 应用如何使用网络能力。

## 1. 流式传输与实时交互

- [SSE](SSE.md)：基于 HTTP 的服务器事件推送机制。
- [NDJSON](NDJSON.md)：用换行符分隔 JSON 记录，适合逐条传输结构化数据。
- [WebSocket](WebSocket.md)：通过持久连接进行双向消息通信的协议。
