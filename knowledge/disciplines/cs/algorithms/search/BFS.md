# 广度优先搜索

广度优先搜索（Breadth-First Search，BFS）是一种搜索或遍历算法。它从起点出发，先访问距离起点最近的一层节点，再逐层向外扩展。这里的距离指从起点到节点所需经过的最少边数。

## 1. 核心思路

1. 将起点标记为已访问，并加入队列。
2. 从队首取出一个节点，处理该节点。
3. 遍历它的相邻节点，将尚未访问的节点标记为已访问，并加入队尾。
4. 重复上述过程，直到队列为空，或满足提前结束条件。

队列先进先出的特性保证较早发现的节点先被处理，从而按层扩展。BFS 属于算法；被遍历的树和图，以及用于实现 BFS 的队列，属于数据结构。

## 2. 遍历示例

假设从左到右访问子节点：

```text
    A
   / \
  B   C
 / \   \
D   E   F
```

从 A 开始，遍历顺序为：

```text
A → B → C → D → E → F
```

各层依次为 A、B 与 C、D 与 E 与 F。同一层内的遍历顺序取决于相邻节点的访问顺序。

## 3. 实现方式

### 3.1 队列实现

下面使用 Go 和邻接表实现，顶点编号范围为 `[0, len(graph))`，并假设起点和相邻顶点编号均有效。

```go
func BFS(graph [][]int, start int) []int {
    visited := make([]bool, len(graph))
    queue := make([]int, 0, len(graph))
    order := make([]int, 0)

    visited[start] = true
    queue = append(queue, start)

    for head := 0; head < len(queue); head++ {
        node := queue[head]
        order = append(order, node)

        for _, next := range graph[node] {
            if !visited[next] {
                visited[next] = true
                queue = append(queue, next)
            }
        }
    }

    return order
}
```

这里通过递增队首下标 `head` 实现出队，每个顶点最多入队一次。应在入队时标记节点，避免多个节点将同一个邻居重复加入队列。

该函数只遍历从起点可达的部分。若要遍历整个非连通图，需要遍历所有顶点，并对每个尚未访问的顶点发起搜索，共用同一份访问记录。

### 3.2 按层处理

如果需要逐层统计节点数或记录层号，可以在每层开始时保存当前队列长度，只处理这一批节点；处理过程中追加的节点属于下一层。

```go
for head := 0; head < len(queue); {
    levelEnd := len(queue)
    for head < levelEnd {
        node := queue[head]
        head++
        // 处理当前节点，并将尚未访问的邻居标记后入队。
        _ = node
    }
    // 当前层处理完毕。
}
```

以上是按层处理的框架，邻居扩展逻辑与前面的实现相同。

## 4. 最短路径

在无权图或所有边权相同的图中，BFS 按经过的边数逐层扩展，因此首次发现一个节点时，已经找到了从起点到该节点的一条边数最少的路径。

- 起点距离设为 0。
- 首次发现相邻节点 `next` 时，记录 `dist[next] = dist[node] + 1`。
- 同时记录前驱 `parent[next] = node`，即可在到达目标后沿前驱反向还原路径。

边权不同时，普通 BFS 不能保证得到总权重最小的路径。边权仅为 0 或 1 时可使用 0-1 BFS；一般非负边权图可使用 Dijkstra 算法。

## 5. 复杂度

对于邻接表表示的图，在完整遍历且每个顶点只入队一次的前提下：

- 时间复杂度：O(V + E)，其中 V 为顶点数，E 为边数。
- 辅助空间复杂度：O(V)，用于访问记录和队列；返回的遍历序列也需要 O(V) 空间。

对于具有 N 个节点的树，遍历需要 O(N) 时间。使用可释放已出队元素的队列且不保存访问记录时，队列空间为 O(W)，其中 W 为树的最大层宽；上面的切片实现保留所有入队元素，占用 O(N) 空间。

## 6. 适用场景与注意事项

- 树的层序遍历、逐层统计。
- 无权图的最短路径、最少操作次数问题。
- 网格中的最短步数、区域探索。
- 多源扩散问题：将多个起点同时标记并入队，可计算各节点到最近起点的最少边数。

BFS 的队列在搜索空间较宽时可能占用较多内存。对于隐式状态空间，需要确保状态表示和去重规则准确；状态数量很大时，还应考虑剪枝或限制搜索范围。
