# 深度优先搜索

深度优先搜索（Depth-First Search，DFS）是一种搜索或遍历算法。它从起点出发，沿着一条路径尽可能深入；当当前节点没有可继续访问的相邻节点时，回退到上一层，继续探索其他分支。

## 1. 核心思路

1. 访问当前节点，并将其标记为已访问。
2. 选择一个尚未访问的相邻节点，继续深入搜索。
3. 当前节点的所有相邻节点都已处理后，回退到上一层。
4. 重复上述过程，直到起点可达的所有节点都已访问，或满足提前结束条件。

DFS 属于算法；被遍历的树和图，以及用于实现 DFS 的栈，属于数据结构。

## 2. 遍历示例

假设从左到右访问子节点：

```text
    A
   / \
  B   C
 / \   \
D   E   F
```

从 A 开始，先访问节点再访问其子节点，遍历顺序为：

```text
A → B → D → E → C → F
```

访问 D 后无法继续深入，回退到 B，再访问 E；B 的分支处理完后，回退到 A，再进入 C 的分支。实际遍历顺序取决于相邻节点的访问顺序。

## 3. 实现方式

### 3.1 递归实现

递归通过函数调用栈保存尚未完成的搜索过程。下面使用 Go 和邻接表实现，顶点编号范围为 `[0, len(graph))`，并假设起点和相邻顶点编号均有效。

```go
func DFS(graph [][]int, start int) []int {
    visited := make([]bool, len(graph))
    order := make([]int, 0)

    var visit func(int)
    visit = func(node int) {
        visited[node] = true
        order = append(order, node)

        for _, next := range graph[node] {
            if !visited[next] {
                visit(next)
            }
        }
    }

    visit(start)
    return order
}
```

进入节点时立即标记，可以避免图中的环导致无限递归。该函数只遍历从起点可达的部分；若要遍历整个非连通图，需要遍历所有顶点，并对每个尚未访问的顶点发起搜索，共用同一份访问记录。

### 3.2 显式栈实现

也可以自行维护栈，保存待处理节点或搜索帧，以模拟递归过程。若要精确复现递归的访问顺序及回退时机，可以在栈帧中记录当前节点和下一个待访问的邻接位置。

显式栈适合搜索深度较大、需要控制调用栈使用的场景，但仍然需要内存来保存搜索状态。

## 4. 复杂度

对于邻接表表示的图，在完整遍历且每个顶点只访问一次的前提下：

- 时间复杂度：O(V + E)，其中 V 为顶点数，E 为边数。
- 辅助空间复杂度：O(V)，用于访问记录及最坏情况下的递归栈或显式栈；返回的遍历序列也需要 O(V) 空间。

对于具有 N 个节点、高度为 H 的树，遍历需要 O(N) 时间；不计输出，递归栈需要 O(H) 空间。树中沿父到子的方向遍历时，通常不需要额外的访问记录。

## 5. 适用场景与注意事项

- 树和图的遍历、可达性判断、无向图连通分量划分。
- 网格中的区域探索，例如岛屿数量、封闭区域判断。
- 结合路径状态的选择与撤销，实现回溯搜索。
- 环检测、拓扑排序等图算法，通常需要额外的状态记录或处理规则。

DFS 首次找到的路径不一定是最短路径。搜索所有方案时，可能需要在回退时撤销当前路径的状态，不能一律使用全局访问标记剪掉所有重复状态。搜索深度过大时，还需要考虑递归栈的限制。
