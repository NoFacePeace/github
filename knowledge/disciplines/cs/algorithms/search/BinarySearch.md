# 二分查找

二分查找（Binary Search）是一种利用有序性或单调性缩小搜索范围的算法。每次检查候选区间的中间位置，根据判断结果排除一半不可能包含答案的区间，直到找到目标或确定目标不存在。

## 1. 核心思路

对于按非递减顺序排列的数组：

1. 确定当前候选区间及其中间位置。
2. 如果中间元素等于目标值，返回其下标。
3. 如果中间元素小于目标值，排除中间位置及其左侧元素。
4. 如果中间元素大于目标值，排除中间位置及其右侧元素。
5. 重复处理剩余区间；区间为空时，目标不存在。

每次排除都需要有依据：有序性保证被排除的一侧不可能包含目标，剩余区间则保留所有尚未排除的候选位置。

## 2. 查找示例

在数组 `[1, 3, 5, 7, 9]` 中查找 `7`，使用从 0 开始的下标：

| 轮次 | 候选区间 | 中间位置及值 | 操作 |
| --- | --- | --- | --- |
| 1 | `[0, 4]` | 下标 2，值为 5 | 5 小于 7，保留 `[3, 4]`。 |
| 2 | `[3, 4]` | 下标 3，值为 7 | 找到目标，返回 3。 |

## 3. Go 实现

下面使用闭区间 `[l, r]`，要求输入数组按非递减顺序排列。存在重复目标值时，返回其中一个匹配下标，不保证是第一个或最后一个。

```go
func binarySearch(nums []int, target int) int {
    l, r := 0, len(nums)-1
    for l <= r {
        mid := l + (r-l)/2
        if nums[mid] == target {
            return mid
        }
        if nums[mid] < target {
            l = mid + 1
        } else {
            r = mid - 1
        }
    }
    return -1
}
```

空数组中 `r` 为 `-1`，循环不会执行，直接返回 `-1`。使用 `l + (r-l)/2` 计算中点，可以避免直接相加 `l + r` 导致的整数溢出。

## 4. 边界查找与单调条件

二分查找也可以用于寻找单调条件的分界位置，例如：

- 第一个大于或等于目标值的元素位置。
- 第一个严格大于目标值的元素位置。
- 在整数答案范围内，寻找第一个使可行性条件成立的值。

以寻找第一个大于或等于目标值的位置为例，条件 `nums[i] >= target` 在有序数组中呈现“先不满足、后满足”的变化。遇到满足条件的中间位置时，仍需保留它并继续向左寻找边界，不能像精确匹配一样立即返回。

二分答案要求可行性条件相对于答案范围具有单调性。仅有“查找最小值”或“查找最大值”的目标，并不足以使用二分。

## 5. 复杂度

对于 n 个元素的数组，假设中间位置访问和比较均为 O(1)：

- 时间复杂度：O(log n)，每轮将候选区间缩小约一半。
- 辅助空间复杂度：迭代实现为 O(1)；递归实现通常需要 O(log n) 的调用栈空间。

若用于二分答案，设候选整数范围包含 M 个值，单次可行性判断成本为 T，则总时间复杂度通常为 O(T log M)。

## 6. 使用注意

- 统一闭区间或左闭右开区间的约定，循环条件和边界更新必须与之匹配。
- 每轮必须缩小候选区间，避免边界停留在原处造成死循环。
- 区分查找任意匹配位置、首个匹配位置和最后一个匹配位置。
- 链表不支持 O(1) 的随机访问，不能直接获得数组二分查找的整体时间复杂度。
- 旋转排序数组并非整体有序，需要判断有序区间及目标范围；存在重复值时，某些变体可能退化为 O(n)。
