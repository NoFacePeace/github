# 拓扑排序

拓扑排序（Topological Sort）是对有向图中的全部节点进行线性排列，使每条有向边 `u → v` 的起点 `u` 都出现在终点 `v` 之前。它用于表达依赖关系，例如任务 `v` 必须在任务 `u` 完成之后才能执行。

## 1. 存在条件与特点

- 有向图存在拓扑序，当且仅当它是有向无环图（DAG）。
- 拓扑序可能不唯一；多个节点都没有未完成的前置依赖时，可以任选一个先处理。
- 孤立节点也必须包含在结果中。
- 拓扑序表达依赖的先后关系，不要求节点编号或数值有序。

例如，依赖关系为 `A → C`、`B → C`、`C → D` 时，`[A, B, C, D]` 和 `[B, A, C, D]` 都是合法拓扑序。

## 2. 实现方式

- [Kahn 算法](Kahn.md)：维护节点入度，反复处理入度为 0 的节点；也可以按轮输出可并行执行的任务。
- 深度优先搜索：沿出边递归，在节点的所有后继处理完成后记录该节点，最终反转完成顺序；需要通过访问状态检测有向环。

## 3. 应用场景

- 课程安排：先完成先修课程，再学习依赖它的课程。
- 构建系统：先构建依赖项，再构建使用它的目标。
- 任务调度：安排满足依赖约束的执行顺序，或划分可并行执行的批次。

普通拓扑排序只给出合法顺序。若还要求最少批次数、任务执行时长或并行数量限制，需要进一步明确调度规则。
