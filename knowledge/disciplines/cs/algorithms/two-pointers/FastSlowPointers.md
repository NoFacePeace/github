# 快慢指针

快慢指针（Fast and Slow Pointers）是双指针的一种使用方式：让两个指针沿相同的后继关系以不同速度推进，根据它们的位置关系判断结构特征。它常用于[链表](../../data-structures/linked-list/LinkedList.md)判环和寻找中点，也可以用于每个状态都有唯一后继的状态序列。

## 1. 基本方式

- 慢指针 `slow` 每轮前进一步。
- 快指针 `fast` 每轮前进两步。
- 两者通常从同一起点出发，根据目标选择终止条件和比较时机。

快慢指针属于算法解题技巧；被遍历的链表等结构属于数据结构。

## 2. 链表判环

如果链表无环，快指针最终会到达空节点，或到达后继为空的尾节点。如果链表有环，两个指针最终都会进入环中；此后快指针每轮相对慢指针多走一步，环内距离按环长取模变化，因此一定会相遇。

下面假设 `ListNode` 为包含 `Next *ListNode` 字段的单向链表节点：

```go
func hasCycle(head *ListNode) bool {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            return true
        }
    }
    return false
}
```

两个指针初始时都指向头节点，因此必须先移动再比较，否则会把非空链表直接判为有环。比较的是节点引用是否相同，而不是节点保存的值是否相等。

## 3. 寻找链表中点

对于无环链表，快指针移动的距离约为慢指针的两倍。当快指针到达末尾时，慢指针位于中间位置。

```go
func middleNode(head *ListNode) *ListNode {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }
    return slow
}
```

上面的实现对奇数个节点返回唯一中点，对偶数个节点返回靠后的中点；空链表返回 `nil`。如果需要靠前的中点，需要相应调整初始化或循环条件，并单独处理空链表。

## 4. 复杂度

- 链表判环：时间复杂度为 O(n)，其中 n 为从头节点可达的不同节点数量；有环时可以写为 O(μ + λ)，μ 为入环前的节点数，λ 为环长。
- 寻找中点：对于 n 个节点的无环链表，时间复杂度为 O(n)。
- 两种实现都只维护固定数量的指针，辅助空间复杂度为 O(1)。

## 5. 使用注意

- 快指针连续前进两步前，要确保当前节点及其后继均非空。
- 寻找中点的实现以无环为前提，有环链表不能依赖空节点终止遍历。
- 固定间隔的双指针通常先让一个指针领先若干步，再让两者同速移动，例如寻找倒数第 k 个节点；它与依赖不同移动速度的快慢指针有所区别。
- 在其他状态序列中使用判环时，需要保证后继规则确定，并明确状态相等的判断方式。
