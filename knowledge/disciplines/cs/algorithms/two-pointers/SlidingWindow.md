# 滑动窗口

滑动窗口（Sliding Window）是一种处理数组或字符串中连续区间的解题技巧。通过移动左右边界扩展或收缩区间，并增量维护区间状态，避免对每个候选区间重新扫描。

## 1. 窗口与状态

可以使用闭区间 `[l, r]` 或左闭右开区间 `[l, r)` 表示窗口，长度分别为 `r - l + 1` 和 `r - l`。实现时应统一边界约定。

窗口状态可以是元素之和、字符频次、不同元素数量等。右边界移动时加入新元素，左边界移动时移除旧元素，使状态与当前窗口一致。

## 2. 常见类型

### 2.1 固定长度窗口

窗口长度固定为 k。每次向右移动时加入新元素、移除离开窗口的元素，再更新答案，例如求长度为 k 的连续子数组的最大和。

### 2.2 可变长度窗口

窗口长度由条件决定，常见方式有：

- 求满足条件的最长区间：扩展右边界，违反条件时收缩左边界，恢复合法后更新最大长度。
- 求满足条件的最短区间：扩展右边界，满足条件后记录答案并持续收缩，直到不再满足。

以上是常见模式，具体更新答案的时机取决于题目条件和窗口状态。

## 3. 正确性与适用条件

使用可变长度窗口前，需要证明边界移动不会遗漏候选答案。例如，求无重复字符的最长子串时，右侧加入重复字符后，必须将左边界移过窗口中原有的同一字符；只删除更早的字符无法消除这次重复。

不能仅因为题目要求连续区间就使用滑动窗口。例如，数组包含负数时，收缩窗口不一定使区间和减小，基于非负元素的区间和窗口规则不能直接套用。

## 4. 复杂度

当左右边界均不回退时，每个元素最多进入和离开窗口各一次。若状态更新为 O(1)，总时间复杂度为 O(n)；使用哈希表维护状态时，通常是期望 O(n)。辅助空间取决于状态规模，例如字符频次表需要存储窗口涉及的字符。
