# 快速排序

快速排序（Quicksort）是一种基于分治思想的排序算法。它选择一个元素作为基准（pivot），通过划分确定左右区间的大小关系，再分别对两侧排序，最终使整个数组有序。

## 1. 核心思路

以升序排序为例，使用将基准放到最终位置的划分方式：

1. 从当前区间选择一个元素作为基准。
2. 重新排列元素，使基准左侧的元素小于基准，右侧的元素大于或等于基准。
3. 基准已经位于排序后的最终位置，不再参与后续递归。
4. 分别对左右区间重复上述过程，直到区间长度不超过 1。

划分完成时，两侧内部不一定有序；只有分别排序两侧后，整个区间才有序。快速排序的主要工作发生在划分阶段，递归结束后不需要额外合并两个有序区间。

上述步骤使用基准归位的划分方式。也可以使用 [Hoare 划分](../../basics/partition/HoarePartition.md)，它返回左右分区的边界，不保证基准归位；此时递归处理的是边界两侧的完整区间，不能直接跳过边界元素。

## 2. 排序示例

对数组 `[3, 1, 4, 2]` 排序，每次选择当前区间的最后一个元素作为基准：

```text
初始数组：       [3, 1, 4, 2]
以 2 为基准划分：[1] 2 [4, 3]
以 3 为基准划分：[1] 2 [ ] 3 [4]
最终结果：       [1, 2, 3, 4]
```

第一次划分后，2 已经位于最终位置；左侧只有一个元素，无须继续处理，右侧 `[4, 3]` 则继续划分。

## 3. Go 实现

下面采用 [Lomuto 划分](../../basics/partition/LomutoPartition.md)，固定选择区间最后一个元素作为基准，直接在原数组中交换元素。

```go
func QuickSort(nums []int) {
    var sortRange func(left, right int)
    sortRange = func(left, right int) {
        if left >= right {
            return
        }

        pivot := nums[right]
        boundary := left
        for i := left; i < right; i++ {
            if nums[i] < pivot {
                nums[boundary], nums[i] = nums[i], nums[boundary]
                boundary++
            }
        }
        nums[boundary], nums[right] = nums[right], nums[boundary]

        sortRange(left, boundary-1)
        sortRange(boundary+1, right)
    }

    sortRange(0, len(nums)-1)
}
```

扫描过程中，`[left, boundary)` 保存小于基准的元素，`[boundary, i)` 保存大于或等于基准的元素。扫描结束后，将基准交换到 `boundary`，即可确定它的最终位置。

空数组和单元素数组会直接返回。这个实现便于理解，但在有序数组或大量重复元素的输入上容易产生不均衡划分。

## 4. 复杂度与稳定性

| 指标 | 复杂度或性质 | 说明 |
| --- | --- | --- |
| 最好时间复杂度 | O(n log n) | 每次划分都较均衡 |
| 平均时间复杂度 | O(n log n) | 例如输入为互异元素的随机排列 |
| 最坏时间复杂度 | O(n²) | 每次只排除一个基准，剩余元素都在同一侧 |
| 平均辅助空间复杂度 | O(log n) | 上述递归实现的调用栈 |
| 最坏辅助空间复杂度 | O(n) | 递归深度退化为线性 |
| 稳定性 | 不稳定 | 交换可能改变相等元素的原始相对顺序 |

一次划分需要 O(n) 时间。划分均衡时，递归深度为 O(log n)，每层的总工作量为 O(n)；持续出现极端不均衡划分时，总工作量变为 `n + (n-1) + ... + 1`，即 O(n²)。

划分本身只需要 O(1) 额外空间，但整个递归算法还需要调用栈，不能直接将总辅助空间写成 O(1)。

## 5. 优化与使用要点

- 随机选择基准：先随机选取元素并交换到区间末尾，再执行划分，可降低特定输入顺序持续产生极端划分的概率；对于互异元素，期望时间复杂度为 O(n log n)，最坏情况仍为 O(n²)。
- 三路划分：将元素分为小于、等于、大于基准的三部分，只递归处理小于和大于的区间，适合重复元素较多的输入。仅随机选择基准不能解决上述实现对全相等数组的退化。
- 控制递归深度：递归处理较小区间，通过循环处理较大区间，可以将调用栈空间控制在 O(log n)，但不改变最坏时间复杂度。
- 小区间优化：区间较小时，可以切换为插入排序，减少递归和划分的开销。

快速排序适合数组等支持随机访问的数据。如果业务要求相等元素保持原始顺序，应选择稳定排序算法，或额外设计稳定性处理方案。
