# Hoare 划分

Hoare 划分（Hoare partition scheme）是一种以快速排序提出者 Tony Hoare 命名的数组分区方法。它使用左右两个指针相向扫描，交换位于错误一侧的元素，最终返回分区边界。

## 1. 核心思路

以升序排列、闭区间 `[left, right]` 为例：

1. 保存一个基准值 `pivot`，不要求将基准元素移到末尾。
2. 从左向右寻找大于或等于基准的元素。
3. 从右向左寻找小于或等于基准的元素。
4. 指针尚未相遇时交换两者，继续扫描；相遇或交错时返回右指针位置作为边界。

基准值是整数副本，数组中的基准元素被交换也不影响后续比较。返回值是分区边界，不保证对应元素已经处于最终排序位置。

## 2. Go 实现

下面使用经典的单边界返回形式。函数处理至少包含两个元素的有效闭区间。

```go
func hoarePartition(nums []int, left, right int) int {
    pivot := nums[left+(right-left)/2]
    i, j := left-1, right+1

    for {
        for {
            i++
            if nums[i] >= pivot {
                break
            }
        }
        for {
            j--
            if nums[j] <= pivot {
                break
            }
        }

        if i >= j {
            return j
        }
        nums[i], nums[j] = nums[j], nums[i]
    }
}
```

每轮扫描先移动指针，即使交换的是相等元素，下一轮仍能继续推进。基准来自区间内部，扫描时总能遇到使条件停止的元素。

这里选择向下取整的中间下标。对于两个元素的区间，它选择左元素；配合当前返回规则，可以保证返回边界满足 `left <= boundary < right`，后续区间严格缩小。不能随意更改基准选择和边界规则，例如对 `[1, 2]` 选择右元素 `2`，这份代码就可能返回 `right`。

## 3. 返回边界的含义

设返回边界为 `b`，划分结束后保证：

```text
[left, b]      小于等于 pivot
[b+1, right]   大于等于 pivot
```

两侧内部都不一定有序，基准元素也不一定处于最终位置。例如 `[1, 2, 3, 5, 4]` 以 `3` 为基准，返回边界 `2`，右侧仍为 `[5, 4]`。边界与基准位置在这个例子中恰好重合，不是算法的一般保证。

因此不能根据 `target == b` 直接返回 `pivot` 或 `nums[b]`。

## 4. 如何使用返回值

- 快速排序：继续排序 `[left, b]` 和 `[b+1, right]`。
- 快速选择：目标升序下标 `target <= b` 时保留左侧，否则保留右侧。区间只剩一个元素时返回该元素。

这份实现不需要最后再交换基准，也不能把边界两侧写成 `[left, b-1]` 和 `[b+1, right]`，否则会错误地跳过尚未归位的元素。

## 5. 与双边界写法的区别

另一种相向扫描写法使用 `for l <= r`，扫描后若 `l <= r` 就交换，并立即执行 `l++、r--`。结束时 `l > r`，得到左区间 `[left, r]`、右区间 `[l, right]`，以及可能存在的一个等于基准的中间位置。

两种写法的边界处理不同：经典形式返回一个分区边界；双边界形式保留交错后的两个指针。循环条件、相等元素处理和后续区间判断必须配套，不能混用。

## 6. 复杂度与注意事项

一次划分的时间复杂度为 O(m)，额外空间为 O(1)，其中 m 为当前区间长度。

全相等数组中，两个指针仍会相向推进，区间通常能较均衡地拆开。但固定规则选择基准仍可能遇到不均衡划分，不能据此保证快速排序或快速选择的最坏时间复杂度。
