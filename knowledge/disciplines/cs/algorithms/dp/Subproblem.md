# 子问题

子问题（Subproblem）是求解原问题时，需要先解决的较小或较简单的问题。它通常与原问题具有相同或相近的结构，但处理的输入范围更小，或约束更具体。

子问题指的是一个需要求解的任务，而不是这个任务的答案。

## 1. 与原问题的关系

例如，原问题是求第 5 个斐波那契数 `F(5)`。根据递推关系：

```text
F(5) = F(4) + F(3)
```

需要先求出 `F(4)` 和 `F(3)`，因此“求 `F(4)`”和“求 `F(3)`”是原问题的子问题。

子问题还可以继续拆分：

```text
F(4) = F(3) + F(2)
F(3) = F(2) + F(1)
F(2) = F(1) + F(0)
```

当拆分到 `F(0) = 0`、`F(1) = 1` 时，可以直接得到答案，不需要继续拆分。这些是基本情形，对应动态规划中的初始条件。

“原问题”和“子问题”是相对的：求 `F(4)` 是求 `F(5)` 的子问题，而相对于求 `F(3)` 和 `F(2)`，求 `F(4)` 又是需要解决的原问题。

## 2. 重叠子问题

不同求解路径可能遇到同一个子问题，这种情况称为重叠子问题。

在上面的例子中，计算 `F(5)` 需要 `F(3)`，计算 `F(4)` 也需要 `F(3)`。如果直接递归且不保存结果，就会重复求解同一个任务。

动态规划会保存这些子问题的结果。例如，`F(3)` 已经求出为 2，后续再次需要时直接复用，无须重新计算。

只有子问题相同、相关条件一致时，才能复用结果。不能因为两个子问题的答案碰巧相同，就认为它们是同一个子问题。

## 3. 与状态、状态值的区别

| 概念 | 回答的问题 | 斐波那契数列示例 |
| --- | --- | --- |
| 子问题 | 要解决什么具体任务？ | 求 `F(3)` |
| 状态 | 用哪些信息描述并区分这个任务？ | `i = 3` |
| 状态值 | 这个任务的答案是什么？ | `dp[3] = 2` |

状态描述子问题，状态值记录子问题的答案。状态转移方程则描述如何利用其他子问题的答案，计算当前子问题的答案：

```text
dp[i] = dp[i - 1] + dp[i - 2]，i >= 2
```

复杂问题可能需要多个变量共同描述一个子问题。例如，0/1 背包中的状态 `(i, c)` 可以表示：“只考虑前 `i` 件物品，容量不超过 `c` 时，能获得的最大价值是多少？”其中 `dp[i][c]` 记录该子问题的答案。

## 4. 在动态规划中的作用

动态规划需要明确子问题之间的依赖关系，通过状态转移将相关子问题的答案用于求解当前问题，并保存结果以供后续复用。

- 记忆化搜索：从原问题出发，按需求解依赖的子问题；已求解的子问题直接读取缓存。
- 递推填表：从初始条件出发，按依赖顺序逐步求出各个子问题的答案，最终得到原问题的答案。

拆分子问题并非动态规划独有，分治等方法也会拆分问题。识别并复用重叠子问题的结果，是动态规划的重要特点。
