# 状态转移方程

状态转移方程（State Transition Equation）是描述状态值之间计算关系的公式。在动态规划中，它说明如何利用相关子问题的答案，计算当前子问题的答案。

状态定义回答“要求解什么”，状态转移方程回答“如何利用其他子问题的结果求解它”。它是动态规划的核心内容，但“状态转移”这一概念并非动态规划独有。

## 1. 方程描述的内容

一个状态转移方程通常需要明确：

- 依赖状态：当前子问题需要哪些其他子问题的结果。
- 合法决策：在当前约束下，可以选择哪些操作或方案。
- 计算规则：如何利用依赖状态的结果及当前决策，得到候选答案。
- 汇总方式：如何将候选答案合并为当前状态值，例如求最大值、最小值或方案数之和。
- 适用条件：方程在哪些状态范围和约束条件下成立。

方程中的运算取决于问题含义，不是所有动态规划都使用加法或取最优值。

## 2. 斐波那契数列示例

定义 `dp[i]` 表示第 `i` 个斐波那契数 `F(i)`。根据数列定义，当前数等于前两个数之和，因此：

```text
dp[i] = dp[i - 1] + dp[i - 2]，i >= 2
```

其中：

- `dp[i]` 是当前子问题的答案。
- `dp[i - 1]`、`dp[i - 2]` 是依赖的子问题的答案。
- `+` 是计算当前答案的规则。
- `i >= 2` 是方程的适用范围。

结合初始条件 `dp[0] = 0`、`dp[1] = 1`，可以依次计算：

```text
dp[2] = dp[1] + dp[0] = 1
dp[3] = dp[2] + dp[1] = 2
dp[4] = dp[3] + dp[2] = 3
```

## 3. 0/1 背包示例

假设第 `i` 件物品的重量为正整数 `w[i]`，价值为非负数 `v[i]`，每件物品最多选择一次，背包容量为非负整数 `C`。

定义 `dp[i][c]` 表示：只考虑前 `i` 件物品、总重量不超过 `c` 时，能够获得的最大价值。

按照是否选择第 `i` 件物品，将所有可行方案分为两类：

1. 不选第 `i` 件物品：最大价值为 `dp[i - 1][c]`。
2. 选择第 `i` 件物品：要求 `c >= w[i]`，最大价值为 `dp[i - 1][c - w[i]] + v[i]`。

因此，对 `1 <= i <= n`、`0 <= c <= C`：

```text
当 c < w[i]：
dp[i][c] = dp[i - 1][c]

当 c >= w[i]：
dp[i][c] = max(dp[i - 1][c], dp[i - 1][c - w[i]] + v[i])
```

两种选择都只依赖前 `i - 1` 件物品的结果，从而保证第 `i` 件物品不会被重复选择。`max` 表示从合法候选方案中取最大价值。

初始条件为 `dp[0][c] = 0`；由于物品重量均为正数，也有 `dp[i][0] = 0`。最终答案为 `dp[n][C]`。

## 4. 推导步骤

1. 明确状态值的含义，包括输入范围、限制条件，以及要求最优值、计数还是可行性。
2. 根据最后一步操作、当前决策或划分位置，将方案分类讨论。
3. 对每一类方案，找出决策之后剩余的子问题，并写出对应状态。
4. 根据子问题结果和当前决策，计算该类方案的候选答案。
5. 按问题目标合并候选答案，并补充合法条件及边界处理。

推导后应检查分类是否覆盖所有合法方案。对于计数问题，还应检查是否重复统计；只有各类方案不重叠时，才能直接将其数量相加。

## 5. 初始条件与计算顺序

状态转移方程描述计算关系，通常还需要初始条件，才能得到具体结果。例如，仅知道 `dp[i] = dp[i - 1] + dp[i - 2]`，并不能确定整个数列，仍需给出前两个数。

递推填表时，计算顺序必须满足依赖关系：

- 斐波那契数列依赖前两个位置，因此可以按 `i` 从小到大计算。
- 上述二维背包方程依赖前一行，因此可以按物品编号逐行计算。
- 0/1 背包压缩为一维存储后，容量通常需要倒序遍历，确保读取的仍是上一物品阶段的值。

记忆化搜索则通过递归按需求解依赖状态，再缓存结果。若依赖存在循环，仅靠普通递归缓存或一次填表不足以直接完成求解。

## 6. 常见注意事项

- 先定义状态，再写方程，不能只记公式而忽略每个下标的含义。
- 区分“不超过容量”和“恰好装满”等不同模型，它们可能使用相似方程，但初始条件和不可达状态不同。
- 不可达状态应使用符合问题语义的标记，不能一律初始化为 0；涉及无穷值标记时，应避免直接运算导致溢出。
- 最优化问题需要说明为何相关子问题的最优值足以构造当前最优值；若不成立，应重新检查状态定义或转移方式。
- 方程正确不代表实现一定正确，还需要检查遍历顺序、数组边界和数值范围。
