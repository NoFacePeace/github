# 等价转化

等价转化是指在保留目标所需性质的前提下，改变问题的表达、状态或操作，使问题更容易求解。

“等价”需要结合目标说明：可以是可行解对应，也可以是最优值相同，不要求转化前后的所有数值完全一致。

## 1. 示例：使数组元素相等

给定长度为 n 的非空整数数组，每次选择 n−1 个元素加一，求使所有元素相等的最少操作次数。

### 1.1 操作转化

一次操作可以拆成两步：

1. 所有元素都加一。
2. 未被选中的那个元素减一。

所有元素一起加一不会改变元素之间的差值，也不会影响它们是否相等。因此，以“元素是否相等”为目标，可以消去这部分整体变化，将原操作等价为“选择一个元素减一”。

例如，数组 `[1, 2, 3]` 中选择前两个元素加一，得到 `[2, 3, 3]`；转化后选择第三个元素减一，得到 `[1, 2, 2]`。两个结果整体相差一，但元素之间的差值相同。

### 1.2 等价性的依据

对于相同的未选中元素序列，执行 k 次操作后，原数组状态等于转化后的数组状态中每个元素再加 k。

因此，两种操作序列在相同的步数后同时达到“所有元素相等”，最少操作次数也相同。这种转化保留的是相对差值和操作次数，实际的最终数值可以不同。

### 1.3 最少操作次数

转化后只能减少元素。设原数组最小值为 m，最终的共同值为 t，则 t ≤ m。

将所有元素减到 t 需要的操作次数为：

```text
操作次数 = Σ(a[i] − t) = Σa[i] − n × t
```

要使操作次数最少，应取最大的可行值 t = m。于是：

```text
最少操作次数 = Σ(a[i] − m) = Σa[i] − n × m
```

例如，`[1, 2, 3]` 需要 `0 + 1 + 2 = 3` 次操作。遍历数组求和与最小值即可，时间复杂度为 O(n)，额外空间复杂度为 O(1)。

## 2. 使用要点

1. 明确目标依赖哪些性质，例如相对大小、元素差值或可达性。
2. 找出不影响这些性质的共同变化，并尝试消去。
3. 证明转化前后的操作或解存在对应关系。
4. 求最优值时，检查转化是否保留操作代价与最优值。

本例的关键是整体平移不改变相对差值。如果目标还要求最终元素等于某个指定值，就不能直接忽略整体平移。
