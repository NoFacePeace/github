# 迭代

迭代（Iteration）是一种组织计算过程的方式：重复执行步骤，并使用当前状态产生下一状态，直到达到结束条件。在程序中通常通过循环实现。

## 1. 构成要素

1. 初始状态：开始重复处理前，各变量或数据结构的值。
2. 重复步骤：每轮执行的操作。
3. 状态更新：如何从当前状态推进到下一状态。
4. 结束条件：何时停止重复，并得到结果。

状态更新需要与结束条件配合。即使写出了结束条件，如果状态始终无法达到它，循环仍然可能无法终止。

## 2. 示例：计算前 n 个正整数之和

下面使用 Go 实现，假设 `n >= 0`，且计算结果不超过 `int` 的表示范围：

```go
func sumIterative(n int) int {
    total := 0
    for remaining := n; remaining > 0; remaining-- {
        total += remaining
    }
    return total
}
```

初始时 `total = 0`、`remaining = n`。每轮将 `remaining` 加到累计结果，再将它减一；当 `remaining = 0` 时结束。输入 `n = 0` 时，循环不执行，直接返回 0。

## 3. 正确性与复杂度

可以用循环不变式描述始终成立的关系：每轮开始时，`total` 已包含从 `remaining + 1` 到 n 的所有整数之和，尚未累加的部分为 1 到 `remaining`。

初始时已处理部分为空；每轮把一个待处理值加入结果，保持这一关系；结束时待处理部分为空，因此 `total` 就是所求的和。

- 时间复杂度：O(n)，循环执行 n 次，每次做常数次操作。
- 辅助空间复杂度：O(1)，只维护固定数量的变量。

迭代不保证常数空间。如果使用显式栈、队列或状态表，还需要计入这些结构占用的空间；嵌套循环的复杂度也应根据总执行次数分析。

## 4. 与递推、迭代法的区别

- 迭代描述重复执行和更新状态的过程，不要求存在一个数学递推式。
- 递推描述根据已知项计算后续项的关系，常通过循环求值，但关系本身与具体实现方式不同。
- 数值计算中的迭代法使用当前近似值产生新的近似值，例如牛顿法；还需要分析收敛性、误差及停止准则。

因此，“使用了迭代”只说明计算过程的一部分组织方式，不能据此确定具体算法及其正确性。
