# 划分

划分（Partition）是按某个条件重新组织元素的操作。例如，给定基准值，将数组分成较小元素与较大元素所在的区间。它是快速排序、快速选择等算法共享的基础操作，不专属于其中某一个算法。

## 1. 目标与结果

划分主要确定不同区间之间的大小关系，不要求每个区间内部已经有序。基准可以取自首元素、中间元素、末尾元素或随机位置，具体选择需要与划分实现的边界规则配套。

需要区分基准值、基准元素和分区边界：

- 基准值：用于比较的值，可以单独保存，数组交换不会改变这个副本。
- 基准元素：最初选中的数组元素，划分时可能被交换到其他位置。
- 分区边界：描述划分结果的位置，不一定是基准元素的最终排序位置。

## 2. 常见实现

| 方法 | 划分结果 | 返回值 |
| --- | --- | --- |
| [Lomuto 划分](LomutoPartition.md) | 小于基准、基准、大于等于基准 | 基准的最终排序位置 |
| [Hoare 划分](HoarePartition.md) | 小于等于基准的左区间、大于等于基准的右区间 | 左右分区的边界 |
| 三路划分 | 小于、等于、大于基准的三个区间 | 等值区间的左右边界 |

只有部分实现会专门将基准归位。是否需要最后交换基准，以及返回位置能否直接用来判断排名，都由具体划分方案决定。

## 3. 在完整算法中的作用

- 快速排序：划分后继续处理左右两侧，使整个区间有序。
- 快速选择：划分后只继续处理目标排名所在的一侧；目标位置已经确定时返回。

调用方必须遵守划分函数的边界约定。例如，基准归位后可以跳过该位置；只返回分区边界时，则不能把边界误当成已经归位的元素而跳过。
