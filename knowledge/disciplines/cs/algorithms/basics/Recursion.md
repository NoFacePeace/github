# 递归

递归（Recursion）是一种组织计算过程的方式：函数直接或间接调用自身，将当前问题转化为同类子问题，直到可以直接处理的基本情形。直接调用自身称为直接递归，经由其他函数再次调用自身称为间接递归。

## 1. 构成要素

1. 基本情形：哪些输入可以直接得到结果，不再继续调用。
2. 递归关系：如何利用同类子问题的结果求出当前结果。
3. 终止进展：每次展开如何向基本情形推进，例如让非负整数参数减小，或进入有限树的子节点。

只有基本情形还不足以保证终止，递归调用必须能够到达它。在有环的图上搜索时，还需要通过访问标记等机制避免反复进入相同状态。

## 2. 示例：计算前 n 个正整数之和

定义 `S(0) = 0`，当 `n > 0` 时，`S(n) = n + S(n-1)`。

下面使用 Go 实现，假设 `n >= 0`，且计算结果不超过 `int` 的表示范围：

```go
func sumRecursive(n int) int {
    if n == 0 {
        return 0
    }
    return n + sumRecursive(n-1)
}
```

计算 `S(3)` 时，先依次调用 `S(2)`、`S(1)`、`S(0)`；得到 `S(0) = 0` 后，再逐层返回 1、3、6。

## 4. 使用注意

- 树遍历、分治和回溯等过程常适合用递归表达，但递归本身不等同于这些算法或方法。
- 子问题重复出现时，直接递归可能重复计算；是否使用缓存需要结合状态定义和依赖关系判断。
- 递归深度较大时，需要考虑调用栈的空间开销及运行环境限制。
- 尾递归表示递归调用是返回前的最后一步，但空间是否得到优化取决于语言和实现。Go 不保证尾调用优化，不能据此认定辅助空间为 O(1)。
