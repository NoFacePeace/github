# 前缀和

前缀和（Prefix Sum）是一种预处理与区间计算技巧：保存从序列开头到各个位置的累加结果，再通过两个前缀和之差求出区间和，避免每次查询都重新遍历区间。

## 1. 定义与递推

对于长度为 n 的数组 `nums`，定义长度为 n+1 的数组 `prefix`，其中 `prefix[i]` 表示前 i 个元素的和，即左闭右开区间 `[0, i)` 的和。

```text
prefix[0] = 0
prefix[i+1] = prefix[i] + nums[i]
```

额外保留 `prefix[0] = 0`，可以统一处理从下标 0 开始的区间，不需要为左端点单独分支。

## 2. 区间求和

对于闭区间 `[l, r]`，其中 `0 <= l <= r < n`：

```text
sum(l, r) = prefix[r+1] - prefix[l]
```

前 `r+1` 个元素的和减去前 l 个元素的和，恰好保留下标 l 到 r 的元素。如果使用左闭右开区间 `[l, r)`，对应公式为 `prefix[r] - prefix[l]`。

例如：

```text
nums   = [2, -1, 3, 4]
prefix = [0, 2, 1, 4, 8]

闭区间 [1, 3] 的和：prefix[4] - prefix[1] = 8 - 2 = 6
```

## 3. Go 实现

下面使用 `int64` 保存累加结果，区间查询假设下标有效。

```go
func buildPrefixSum(nums []int) []int64 {
    prefix := make([]int64, len(nums)+1)
    for i, v := range nums {
        prefix[i+1] = prefix[i] + int64(v)
    }
    return prefix
}

func rangeSum(prefix []int64, l, r int) int64 {
    return prefix[r+1] - prefix[l]
}
```

空数组对应的前缀和数组为 `[0]`，此时没有可查询的非空有效区间。

## 4. 与哈希表结合

对于“和为 k 的子数组”这类计数问题，可以将区间条件转化为两个前缀和之间的关系：

```text
prefix[i] - prefix[j] = k，且 j < i
prefix[j] = prefix[i] - k
```

使用哈希表统计此前各个前缀和的出现次数，扫描到当前前缀和时，查找 `当前前缀和 - k` 的出现次数，即可得到以当前位置结尾、和为 k 的非空子数组数量。

初始需要记录前缀和 0 出现一次，以覆盖从数组开头开始的子数组。应先查询此前的次数，再记录当前前缀和，避免在 k 为 0 时把空区间计入答案。不同位置可能有相同前缀和，因此计数问题需要保存出现次数，而非仅记录是否存在。

## 5. 复杂度

- 构建前缀和：O(n) 时间、O(n) 辅助空间。
- 已构建后的单次区间求和：O(1) 时间。
- 结合哈希表统计区间数量：在哈希表操作平均为 O(1) 的前提下，总时间通常为 O(n)，辅助空间为 O(n)。只使用当前累加值时，无需额外保存完整前缀和数组。

以上分析将整数加减视为常数时间操作。

## 6. 使用注意

- 统一区间边界约定，区分 `prefix[i]` 与 `nums[i]` 对应的位置。
- 前缀和允许原数组包含负数；此时前缀和本身不一定单调，不能直接套用依赖单调性的查找规则。
- 累加值和子数组数量可能超过单个元素的取值范围，需要根据数据规模选择整数类型；使用 `int64` 也仍需确保结果不超出其范围。
- 普通前缀和适合原数组不变时的多次查询。修改一个元素后，其后续前缀和都可能需要更新，单次更新最坏为 O(n)。
