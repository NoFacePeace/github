# fork

`fork` 是 Unix/Linux 提供的系统调用，用于从当前进程创建子进程。调用者是父进程，新创建的进程是子进程。

## 1. 执行与返回值

调用成功后，父子进程都从 `fork` 返回的位置继续执行，通过返回值区分执行路径：

| 执行位置 | 返回值 |
| --- | --- |
| 父进程 | 子进程的进程 ID。 |
| 子进程 | `0`。 |
| 创建失败 | 父进程中返回 `-1`，不创建子进程。 |

父子进程由操作系统分别调度，不保证谁先执行。子进程可以继续运行原程序，也可以调用 `exec` 系列接口加载其他程序；父进程可以使用 `wait` 或 `waitpid` 等待并回收子进程。

## 2. 地址空间与资源继承

子进程拥有独立的进程 ID 和虚拟地址空间。对于普通私有内存，创建时父子进程看到相同的内容，之后一方修改不会直接改变另一方看到的内容；显式共享内存另当别论。

子进程继承父进程的文件描述符，其对应项指向相同的打开文件描述，因此可能共享文件偏移等状态。`fork` 不代表所有资源都获得完全独立的副本。

## 3. 写时复制

Linux 通常通过[写时复制](CopyOnWrite.md)实现普通私有内存页的延迟复制：创建子进程时先共享物理页，写入时再按需复制，避免立即复制全部内存数据。

`fork` 仍需要创建进程和处理页表等工作，不能理解为完全没有开销。在多线程进程中调用 `fork` 时，子进程只保留调用它的线程，需要特别注意继承的锁状态。
