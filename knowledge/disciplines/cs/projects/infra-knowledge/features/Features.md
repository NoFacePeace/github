# 功能

本目录从使用者视角整理 Infra 知识库提供的能力、使用场景和完整流程。以下为功能规划，具体范围随项目设计确定。

## 1. 文档

从指定版本源码生成文档，支持内容浏览、检索和来源定位，也可接入人工维护的文档。工作流说明从输入仓库版本到得到可用文档的完整过程。

- [文档](documents/Documents.md)：文档构建工作流及各环节说明。

## 2. 代码图谱

将源码中的实体和关系组织为图谱，用于查询代码关联、路径及影响范围，并关联对应源码版本。

## 3. 功能与实现的边界

功能说明回答系统能做什么、使用者提供什么以及得到什么结果。模块分工、调用链、调度机制和数据结构由实现专题说明，避免在功能介绍中重复展开。
