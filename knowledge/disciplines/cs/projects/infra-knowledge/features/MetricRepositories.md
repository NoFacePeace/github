# 按指标找仓库

按指标找仓库接收完整指标名，返回知识库中已记录的关联仓库，帮助使用者从告警、监控面板或指标名称定位后续代码调查范围。

## 1. 使用场景

- 已知指标名，但不清楚它可能由哪个代码项目定义或暴露。
- 排查告警时，需要先确认可能相关的仓库，再阅读文档或源码。
- 为 Agent 提供仓库候选，避免根据指标名称自行猜测项目。

## 2. 输入与结果

- 输入：完整指标名，以及可选的分页参数。
- 结果：匹配的仓库名称、地址、负责人、所属项目和分页信息。

同一指标可以对应多个仓库，因此结果是候选集合，不要求唯一。

## 3. 使用流程

```text
取得告警或面板中的完整指标名
  → 提交指标名查询
  → 查看关联仓库候选
  → 结合服务与项目上下文确认目标
  → 选择版本，进一步读取文档、图谱或源码证据
```

该能力按完整名称匹配，不直接接收整段时序查询表达式。未找到关联时返回空结果，不能据此断定指标不存在。

## 4. 结果含义与限制

关联来自历史成功发布的指标目录，记录的是已发现的指标与仓库关系。命中不证明当前版本仍暴露该指标，也不证明线上某条序列实际来自该仓库。

该功能用于定位仓库，不返回实时指标值，不代替监控系统的时序查询。指标类型、单位、标签及行为定义需要继续查阅相应版本的参考文档与源码。
