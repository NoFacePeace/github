# Agent 主导模式

Agent 主导模式是当前文档生成路径：Agent 按 Skill 要求使用工具调查固定版本的安全源码快照并生成文档，程序负责快照校验和产物验收。

## 1. 输入与输出

| 项目 | 内容 |
| --- | --- |
| 输入 | 已校验的安全源码快照、文件清单、文档目标、Skills、工具与预算配置 |
| 输出 | 文档文件、来源引用、执行记录及未覆盖项说明 |

## 2. 处理流程

```text
源码快照与任务要求
  → 校验来源版本、清单及文件完整性
  → 按文档目标执行 Skills
  → Agent 搜索、读取源码
  → 整理源码证据并组织内容
  → 编写文档
  → 程序校验产物
```

Agent 可以根据已读内容选择下一步需要查看的文件或符号。允许的探索范围、可用工具和输出位置由运行配置明确规定。

## 3. Skill 与运行时的分工

- Skill 描述调查步骤、覆盖要求、证据规范和输出格式。
- 模型选择工具、理解返回结果并撰写说明。
- 运行时执行工具调用，管理会话、超时和取消。
- 宿主程序验收生成物，决定是否进入后续索引和发布阶段。

## 4. 输出范围与边界

基础输出覆盖系统设计、API、指标与配置；版本变更需要可比较的前序版本。模块规划和页面按配置启用，不是每次构建的必需输出。

以约定的输出清单、必需内容和来源引用判断完成，不以 Agent 自行宣告完成作为唯一依据。

任务结束不等于产物合格。超时、预算耗尽、文件缺失或输出不完整时，应记录原因并拒绝将其当作完整批次发布。Skill 中的路径约定不等于操作系统层面的权限隔离。
