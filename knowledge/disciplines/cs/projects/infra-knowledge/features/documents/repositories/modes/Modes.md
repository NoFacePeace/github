# 文档生成模式

文档生成模式决定取得固定版本源码后如何生成文档。当前采用 Agent Skills 生成路径；跟踪方式负责版本选择，两者分别配置。

## 1. 当前生成方式

- [Agent 主导](Agent.md)：Agent 按 Skill 要求探索安全源码快照，生成文档，由程序校验并交给索引与发布流程。

文档生成不再将程序提取 AST、推导组件图和规则划分模块作为固定前置流水线。

## 2. 文档范围

| 内容 | 生成边界 |
| --- | --- |
| 系统设计、API、指标、配置 | 基础文档范围 |
| 版本变更 | 有可比较的前序版本时生成 |
| 模块规划与模块页面 | 显式启用时生成，关闭时不要求这些产物 |

模块文档开关属于输出范围配置，不代表切换到另一个生成引擎。关闭模块生成时，基础文档仍可独立生成。

## 3. 配置与校验

生成模式作为有限枚举校验，不使用任意文本决定执行路径。模型接入、输入预算、模块文档开关和全量或增量生成策略分别配置；具体对外字段以接口契约为准。

每次构建记录实际生成契约，避免任务恢复时改变必需产物集合。增量复用需要验证版本、来源快照、已发布文档和配置兼容性。

## 4. Skill 与运行时

Skill 规定调查步骤、证据要求及输出格式；Agent 运行时负责模型调用和工具执行；宿主程序验证快照、验收产物并组织后续处理。

运行时正常结束不等于文档合格，必须通过产物校验后才能进入发布流程。
