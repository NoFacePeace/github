# 文档构建工作流

本文从整体上梳理源码转化为可查阅、可检索文档的过程，先明确各环节的输入、处理和输出，再逐步补充专题。本文采用 Agent Skills 文档生成路径描述当前设计，对外接口与存储细节由相应专题约定。

## 1. 整体流程

```text
登记仓库
  → 发现或选择版本
  → 登记固定版本
  → 创建文档构建任务
  → Worker 领取任务
  → 准备指定版本的安全源码快照与清单
  → 校验快照身份及文件完整性
  → Agent 按 Skills 调查源码并生成文档
  → 校验文档与输出清单
  → 建立检索索引
  → 发布文档与索引
```

手动请求可以从已有版本开始，失败重试可以从经过验证的检查点恢复，不要求每次都从仓库登记开始。

## 2. 仓库与版本准备

| 环节 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 登记仓库 | 仓库地址、身份和跟踪规则 | 校验并保存仓库配置 | 仓库记录 |
| 发现或选择版本 | 跟踪规则或手动选择 | 查询版本来源，将引用解析为完整 Commit SHA | 仓库身份、完整 SHA 和来源信息 |
| 登记版本 | 仓库身份、完整 SHA、提交信息 | 校验版本身份，复用或创建记录 | 可关联任务和产物的版本记录 |

分支和 Tag 可以变化；本次构建一旦确定 SHA，后续都使用该版本，避免生成过程中混入更新后的源码。

## 3. 任务创建与领取

| 环节 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 创建任务 | 版本记录、文档构建选项 | 处理重复请求，登记待执行任务 | 任务身份与初始状态 |
| Worker 领取 | 待执行任务、可用执行容量 | 协调执行归属并启动处理 | 执行中的构建尝试 |

任务受理和实际执行分开，调度、状态及恢复机制在后续设计中展开。

## 4. 源码准备与读取

| 环节 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 准备安全快照 | 仓库、完整 SHA、来源筛选与敏感内容处理规则 | 获取精确版本，生成经过筛选与处理的文件及清单 | 安全源码快照、文件清单及来源标识 |
| 校验快照身份 | 源码快照、目标版本、处理策略 | 校验版本、来源及快照指纹是否匹配 | 可交付的固定版本输入 |
| 读取文件 | 已确认清单、内容预算 | 校验路径，按清单读取文件并检查大小和哈希 | 文件内容、完整来源清单及相关诊断 |

文件选择和敏感内容处理在快照准备阶段完成。文档生成适配层消费准备好的清单，不重新运行旧的按语言 AST 过滤与组件图分析流水线；有语法错误的源码也可能作为需要解释的证据。

## 5. Skills 文档生成

| 环节 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 准备生成任务 | 已校验快照、生成契约与选项 | 确定基础文档、适用的版本变更及模块文档开关 | 各 Skill 的任务输入与输出要求 |
| 准备增量上下文 | 当前源码、兼容基线及已有文档 | 选择全量或增量执行，核实来源与契约 | 本次生成所需上下文 |
| 执行 Skills | 源码与任务要求 | Agent 搜索、读取源码，整理证据并撰写文档 | 待校验的文档集合 |
| 可选模块生成 | 显式启用的模块文档选项 | 按 Skill 生成模块计划及相应页面 | 模块导航与页面 |
| 校验产物 | 文档集合、输出要求及来源信息 | 检查完整性、格式、引用及适用的必需产物 | 可进入索引阶段的批次 |

基础文档覆盖系统设计、API、指标和配置；版本变更需要可比较的前序版本。关闭模块生成时，不要求模块计划和页面，也不应把意外输出的模块内容默认为有效交付。

模块计划由生成任务产生，不代表内置静态聚类引擎。程序通过校验与发布约束控制交付，模型解释仍需要源码证据支持，不能代替运行时事实。

## 6. 索引与发布

| 环节 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 建立检索索引 | 已校验文档、索引配置 | 组织章节和检索单元，生成关键词与向量等检索表示 | 与文档批次匹配的索引 |
| 发布 | 文档批次、索引及版本关联 | 校验产物齐备，使文档和对应索引作为一致批次可见 | 可浏览、可检索的已发布版本 |

新批次准备期间保留上一批可用内容；失败的构建不能让不完整产物成为默认查询结果。

## 7. 贯穿流程的信息

- 仓库身份与完整 SHA：确定源码和产物对应哪个版本。
- 任务与尝试身份：区分重复请求、重试及重新生成。
- 配置与生成版本：判断产物是否兼容、是否允许复用。
- 阶段、进度与诊断：说明执行到哪里，以及失败或遗漏的原因。
- 产物批次与发布状态：区分暂存结果和已对外可见的内容。

后续专题按上述环节展开，重点补充数据结构、调用流程、异常及恢复条件。
