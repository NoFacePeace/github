# 文档生成批次

文档生成批次记录一次完整生成结果的归属、恢复检查点和发布状态，支持从已经保存的文档继续建立索引。

## 1. 主要信息

| 信息 | 用途 |
| --- | --- |
| 批次标识 | 唯一定位本次生成结果 |
| 所属版本与生成目标 | 关联源码版本和产物来源 |
| 原始构建与当前构建 | 区分生成者及恢复执行的持有者 |
| 文档数量与产物清单 | 确认批次完整性 |
| 检查点与哈希 | 保存恢复所需上下文并验证一致性 |
| 索引配置 | 固定切分、模型等索引契约 |
| 状态与时间 | 记录就绪、发布和被替代等生命周期 |

## 2. 保存形式

归属、状态与时间使用结构化字段；检查点可使用 JSON，较大内容也可通过不可变对象存储引用保存。完整 Markdown 正文由文档存储负责，批次记录用于协调和恢复。

## 3. 生命周期

```text
完整文档已暂存，检查点就绪
  → 根据固定配置建立索引
  → 校验批次与执行归属
  → 发布批次
  → 后续由新批次替代
```

恢复执行时校验批次身份、内容指纹和索引配置。不能把未完成的生成结果标成可恢复的完整检查点，也不能在恢复期间悄悄更换输入或配置。
