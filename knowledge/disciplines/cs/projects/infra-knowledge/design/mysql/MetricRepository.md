# 指标与仓库映射

指标与仓库映射保存从已发布指标参考文档中提取的关联，支持按完整指标名反查仓库。

## 1. 主要信息

| 信息 | 用途 |
| --- | --- |
| 完整指标名 | 精确查询键，保留名称大小写 |
| 仓库标识 | 关联仓库登记记录 |
| 创建时间 | 记录首次保存该关联的时间 |

同一指标名与仓库标识的组合需要唯一，避免重复发布造成重复映射。同一指标可以出现在多个仓库，一个仓库也可以包含多个指标。

## 2. 写入流程

```text
生成指标参考文档
  → 解析指标名称及显式别名
  → 校验并准备待合并名称集合
  → 暂存文档并完成索引
  → 最终发布事务中合并指标与仓库关联
  → 已有组合去重
  → 随发布事务提交后生效
```

Agent 只生成文档，映射由应用与持久化代码写入。生成、暂存或索引成功都不单独令映射生效；发布事务回滚时，本次新增关联也不生效。

## 3. 查询方式

根据完整指标名精确匹配，再关联[仓库存储](Repositories.md)取得名称、地址、负责人等登记信息，并关联所属项目信息。

映射以仓库为归属，不以 Commit 为查询维度。不通过全文检索或向量相似度猜测指标名称。

## 4. 累积语义

成功发布时追加合并关联，新版本不再包含某个指标时，不因此删除历史关联。它表达历史上已发现的归属线索，不是当前版本的实时指标集合。

是否清理关联应另行规定生命周期，不能将文档批次替换误认为映射同步全量替换。
