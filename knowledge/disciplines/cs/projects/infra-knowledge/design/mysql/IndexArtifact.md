# 索引产物存储

索引产物存储保存从文档派生的检索数据，与权威 Markdown 正文分开管理。同一文档可以拥有多种索引产物。

## 1. 主要信息

| 信息 | 用途 |
| --- | --- |
| 文档产物关联 | 定位索引对应的文档 |
| 索引类型与版本 | 区分检索用途及格式 |
| 索引载荷 | 保存序列化数据或不可变内容引用 |
| 正文哈希 | 保证索引对应指定正文 |
| 分块数量 | 记录切分规模 |
| 模型名称与向量维度 | 识别向量生成契约 |
| 切分与章节解析版本 | 判断重建与兼容性 |

## 2. 生成方式

```text
读取已暂存的完整 Markdown
  → 按章节与容量切分
  → 生成检索表示及适用的向量
  → 保存索引产物
  → 检查文档集合与索引配置匹配
```

具体载荷和存储格式由索引类型决定，不等同于直接复制 Markdown。正文、分块和向量属于不同数据层次。

## 3. 发布与重建

索引就绪后才能将对应文档批次作为可检索结果发布。切分规则、模型或维度改变时，应按新配置准备匹配索引，不能直接复用不兼容的旧产物。

索引是派生数据，满足输入完整性与配置条件时可以重建，不应成为恢复文档正文的唯一来源。
