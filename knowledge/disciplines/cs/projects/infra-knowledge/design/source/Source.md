# 源码访问

源码访问为客户端提供固定版本的只读代码浏览与搜索能力，支持列目录、找文件、读取正文和搜索内容。它不要求先完成文档或图谱构建，与构建阶段准备源码快照的职责分别组织。

## 1. 输入与输出

- 输入：已登记仓库、可选的完整 Commit、仓库相对路径，以及对应操作参数。
- 输出：目录条目、文件正文或搜索命中，以及实际解析的版本、分页或截断信息。

所有操作返回实际版本标识，后续调用沿用该版本，避免多次访问期间发生版本漂移。

## 2. 访问能力

| 操作 | 作用 | 主要参数与结果 |
| --- | --- | --- |
| 列目录 | 查看一个目录的直接条目 | 路径、条目类型、分页；返回名称、路径与对象标识 |
| 找文件 | 递归匹配文件路径 | 根路径、包含与排除模式、分页 |
| 读文件 | 读取完整正文、头尾或行范围 | 文件路径、模式、起始行与行数；返回正文及行号 |
| 搜索内容 | 在限定文件范围内匹配正文 | 路径范围、文本或正则、大小写与上下文行数 |

找文件匹配路径，搜索内容匹配正文，不能将两者视为同一种检索。

## 3. 共用处理流程

```text
接收仓库、版本与操作参数
  → 校验路径、模式与容量限制
  → 读取仓库登记信息
  → 确定固定 Commit，确认其属于该仓库的已登记版本
  → 根据登记地址定位仓库平台项目
  → 核对远端提交身份
  → 获取文件树或文件内容
  → 正文经过脱敏检查
  → 执行路径匹配、行范围截取或内容搜索
  → 返回结果与实际 Commit
```

未指定 Commit 时使用约定的活动版本；没有可用版本应报错，不随意选择远端最新提交。显式提交也必须属于该仓库的登记记录，不能只凭另一个仓库存在相同 SHA 就放行。

仓库平台 API 的访问受服务端凭据和允许范围控制，不向调用方公开凭据，也不把任意输入 URL 当作可访问目标。

## 4. 正文读取

通过仓库平台 API 获取固定版本的文件内容，完成文本与脱敏检查后，在内存中按行截取。行范围输出不意味着远端只读取了这些行，读取过程仍需限制完整文件大小。

返回起止行、总行数与是否截断。保留原始行数有助于文档或图谱的来源定位；旧产物的行号是否可用，还需校验版本与处理策略。

## 5. 内容搜索

搜索在限定范围内枚举文件，对允许的正文执行字面文本或 Go/RE2 正则匹配，返回文件路径、行号、命中文本与上下文。

全局源码搜索范围与调用方包含、排除条件共同限制输入，显式指定文件不能绕过全局限制。源码搜索不使用文档的 BM25、Embedding 或向量索引。

控制扫描条目数、文件数、累计读取字节、匹配数、响应大小及执行时间，返回实际扫描统计和停止原因。达到预算、跳过文件或输入缺失时，不能据空结果证明目标代码不存在。

## 6. 执行边界

源码访问不执行仓库代码，不修改文件，不触发构建或发布。列目录与正文访问分别受对应校验约束，脱敏不可用或失败时不直接返回原始正文。

仓库未登记、版本未登记、远端不可用、路径非法、二进制内容、超限和无匹配结果应分别表达，便于调用方缩小范围或补充信息。
