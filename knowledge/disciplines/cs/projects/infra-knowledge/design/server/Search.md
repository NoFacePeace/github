# 搜索

搜索入口接收客户端的文档检索请求，完成协议转换、身份与权限检查、输入校验，再调用检索能力返回相关内容。

## 1. 使用方与接入方式

| 使用方 | 接入方式 | 用途 |
| --- | --- | --- |
| Web 页面 | HTTP 查询接口 | 用户搜索已发布文档 |
| Agent | HTTP 工具接口 | 查找回答问题所需的文档证据 |
| MCP 客户端 | MCP 搜索工具 | 通过工具协议检索知识库 |

各协议入口复用同一应用能力，接口路径和工具名称由对外契约定义。

## 2. 输入与输出

- 输入：查询文本、仓库、可选版本、标签和结果数量限制。
- 输出：命中章节、正文与来源、相关性分数，以及实际解析的版本和适用的降级信息。

未显式指定版本时，应按约定解析查询版本，不能将同仓库的不同版本产物无条件混合。

## 3. 处理流程

```text
页面、Agent 或 MCP 请求
  → 协议解析、身份与权限检查
  → 校验查询文本和范围参数
  → 解析目标源码版本
  → 调用检索服务
  → 转换结果与错误
  → 返回正文、来源及实际查询范围
```

具体召回和排序由[检索](../retrieval/Retrieval.md)负责，包括已发布批次选择、索引加载、全文与向量召回、结果融合及章节聚合。

## 4. 职责边界

Server 不在请求处理器中重新实现分词、BM25 或向量近邻搜索。查询不触发文档构建或发布，客户端也不直接读取索引存储。

无匹配结果、非法范围、权限不足与依赖失败需要分别表达。检索发生允许的降级时，响应应保留相关信息，避免调用方误以为所有检索分支均正常执行。
