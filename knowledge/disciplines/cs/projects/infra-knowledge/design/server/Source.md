# 源码接口

源码接口接收页面或 Agent 的只读源码访问请求，完成协议处理、鉴权与输入转换，再调用源码访问服务。HTTP 和 MCP 入口复用应用逻辑，各自维护传输契约。

## 1. 操作入口

| 操作 | 请求内容 | 返回内容 |
| --- | --- | --- |
| 列目录 | 仓库、版本、目录及分页 | 直接条目与下一页 |
| 找文件 | 仓库、版本、根路径及路径模式 | 递归匹配条目与分页信息 |
| 读文件 | 仓库、版本、文件路径与读取模式 | 脱敏正文、行号及截断状态 |
| 搜索内容 | 仓库、版本、路径范围与匹配条件 | 命中、上下文、扫描统计与停止原因 |

## 2. 请求流程

```text
HTTP 或 MCP 请求
  → 身份、权限及输入校验
  → 转换为源码访问操作
  → 调用源码访问服务
  → 记录实际版本及请求范围
  → 转换响应与错误
```

版本解析、仓库平台调用、读取与搜索机制见 [源码访问](../source/Source.md)。Server 不在处理函数中实现另一套文件获取或脱敏流程。

## 3. 响应约定

响应包含实际解析的 Commit，客户端翻页与后续读取应沿用它。分页未结束或搜索已截断时，必须显式返回状态，不能把不完整结果伪装成完整集合。

仓库平台错误转换为稳定错误类型，不将原始上游响应、敏感地址或凭据透传给客户端。非法版本、权限不足、文件不存在与超限等情况分别处理。
