# 仓库接口

仓库接口负责接收仓库登记、配置更新和查询请求，将经过校验的输入交给应用逻辑处理。本文为 Infra 知识库的接口设计规划，具体路径、字段、状态码及存储实现尚待确定。

## 1. 接口范围

| 操作 | 职责 |
| --- | --- |
| 登记仓库 | 将代码项目及其跟踪配置纳入管理 |
| 更新配置 | 修改已登记仓库的可变配置 |
| 查询仓库 | 查询列表或单个仓库的登记信息 |

创建与更新是否共用接口，需要明确其身份匹配、字段省略和冲突处理语义。

## 2. 登记输入与输出

- 输入：仓库名称与地址、来源平台身份、归属、跟踪及文档生成配置。
- 输出：稳定仓库身份与已保存配置，或明确的校验、权限及冲突错误。

接口不要求在登记请求中同步获取全部源码或完成构建。登记成功只表示接入信息已经保存。

## 3. 处理链路

```text
请求接入
  → 身份验证与权限检查
  → 解码和校验参数
  → 调用仓库登记或更新用例
  → 转换业务结果与错误
  → 返回响应
```

远端仓库访问校验、唯一性判断及持久化由对应应用与存储能力协作完成，请求处理器不重复实现业务规则。

仓库信息的持久化、唯一性约束及更新事务见 [仓库存储设计](../../mysql/Repositories.md)。

## 4. 待明确的契约

- 仓库如何唯一标识，重名和重复请求如何处理。
- 更新时字段省略、空值和显式清空的区别。
- 跟踪及生成配置的合法值与默认行为。
- 查询的过滤、分页和权限范围。
- 凭据引用的接收方式及响应中的敏感字段隐藏规则。
