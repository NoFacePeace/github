# 按指标找仓库

按指标找仓库根据完整指标名查询已登记的指标与仓库关联，帮助用户或 Agent 定位相关代码项目。它不搜索文档正文，也不查询在线时序数据。

## 1. 输入与输出

- 输入：完整指标名、页码与每页数量。
- 输出：仓库名称、地址、负责人及所属项目等信息，以及分页统计。

同一指标可以对应多个仓库，结果应保留候选，不能直接认定某一个仓库就是目标。

## 2. 查询流程

```text
接收 HTTP 或 MCP 请求
  → 校验指标名及分页参数
  → 按完整指标名精确匹配映射
  → 关联仓库及所属项目
  → 排序、分页并返回结果
```

持久化依据见 [指标与仓库映射](../mysql/MetricRepository.md)。查询不调用语言模型，不执行全文或向量检索，也不临时扫描源码。

## 3. 结果解释

映射来自成功发布的指标目录，是累积关联。命中表示该仓库曾在发布的文档中包含此指标，不证明当前版本仍然暴露它，也不证明线上某条指标序列实际来自该仓库。

返回的是仓库登记信息，不是某个版本的完整指标定义。需要核对实现时，应进一步选择版本、读取指标参考与源码证据。
