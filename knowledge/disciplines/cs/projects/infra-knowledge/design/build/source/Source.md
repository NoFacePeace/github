# 源码准备

源码准备为文档构建和图谱构建提供固定版本的安全源码快照。各构建组件在内部调用这套共用能力，按缓存情况复用快照或重新获取、筛选和处理源码。

## 1. 输入与输出

- 输入：仓库标识、固定 Commit、文件筛选与脱敏策略、取消上下文。
- 输出：本次构建的独立工作目录路径，目录中包含处理后的文件、文件清单与来源信息。

文件清单记录路径、处理状态、大小与内容哈希；来源信息标识仓库、原始版本与处理策略，供消费端校验。

## 2. 处理流程

```text
根据仓库、版本和策略检查快照缓存
  → 命中且校验通过：复用安全快照
  → 未命中：获取文件树 → 筛选路径 → 读取内容
             → 检查大小、编码与内容特征 → 脱敏
             → 写入安全快照 → 生成清单并缓存
  → 创建本次构建的独立副本
  → 交付目录路径
  → 消费端校验清单、版本与文件哈希，再读取内容
```

[文件树](FileTree.md) 提供路径、类型与对象标识。先根据这些元信息筛选，再读取选中文件的内容，避免无差别获取全部文件。

## 3. 文件筛选

筛选 先根据路径和文件类型判断，再读取内容检查。路径规则由内置默认排除规则、自定义追加排除规则和保留例外组成。保留例外可以覆盖路径排除，但不能绕过路径安全、文件大小和编码等检查。

符号链接、子模块及不满足输入要求的文件不进入后续生成。跳过的文件应在清单中保留相应状态，便于解释输入范围。

## 4. 快照与执行隔离

缓存保存经过处理的源码快照；每次执行使用独立副本，避免构建过程中修改共享缓存。源码版本相同但处理策略不同，也需要区分缓存身份。

文档与图谱共用源码准备能力，各自调用时可以复用符合条件的缓存；这不表示文档生成依赖图谱产物。

安全快照表示源码经过既定筛选和脱敏规则处理，不保证识别所有敏感信息。
