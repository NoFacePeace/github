# 脱敏

脱敏接收通过筛选的文件路径与正文，在内存中检测敏感信息并替换命中内容。处理结果复检通过后，才交给[安全快照](SafeSnapshot.md)写入流程。

## 1. 输入与输出

- 输入：仓库相对路径、文件内容、检测规则与取消上下文。
- 输出：处理后的文件内容；没有命中时返回原内容，检测或替换失败时返回错误。

## 2. 处理流程

```text
通过筛选的文件内容
  → 检测敏感信息
  → 无命中：返回原内容
  → 有命中：校验字节范围 → 合并重叠范围 → 替换敏感内容
             → 再次检测 → 无命中才返回处理结果
  → 校验换行数量保持一致
  → 交给安全快照写入流程
```

检测器在 Go 进程内运行，接入方式见 [Gitleaks Go 使用](../../../../../lang/go/libraries/gitleaks/Gitleaks.md)。检测器负责识别命中项，调用方负责范围转换、替换、复检和错误处理。

## 3. 替换规则

校验命中范围位于原始内容内，并确认范围内的字节与检测到的敏感内容一致。将重叠范围合并后，按原始字节位置替换为 `<REDACTED>`，避免前一次替换改变后续命中位置。

```yaml
# 替换前：假设该值命中检测规则
api_key: "example-secret-value"

# 替换后
api_key: "<REDACTED>"
```

跨行命中按行处理并保留原有换行符，维持源码行号对应关系。替换可能改变列位置和语法，不能假定处理后的文件仍可编译或运行。

## 4. 失败处理

- 规则扫描失败、命中位置无效或内容不匹配：返回错误。
- 替换后复检仍有命中：返回错误。
- 替换改变换行数量：返回错误。

失败时不将该文件交给安全快照写入流程。原始内容仅作为处理输入，不先写入安全快照目录。

## 5. 能力边界

检测结果取决于规则覆盖范围，复检无命中不代表所有敏感信息都已识别。脱敏副本用于后续分析和生成；对于已经泄露的凭据，还需要撤销或轮换。
