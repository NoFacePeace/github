# 文件类型

文件类型通过文件树条目的 Git 模式判断，不根据文件扩展名判断，也不需要读取文件正文。

## 1. 模式与处理

| Git 模式 | 类型 | 处理 |
| --- | --- | --- |
| `100644` | 普通文件 | 继续筛选 |
| `100755` | 可执行文件 | 继续筛选 |
| `120000` | 符号链接 | 记录状态并跳过 |
| `160000` | 子模块 | 记录状态并跳过 |
| 其他模式 | 不支持的类型 | 返回错误 |

目录模式为 `040000`，正常在文件树获取阶段处理，不作为普通文件交给后续写入流程。

## 2. 特殊类型

符号链接保存它指向的路径，例如 `config.yaml → configs/production.yaml`。不跟随链接读取内容，避免访问快照目录之外的文件。

子模块引用另一个仓库的指定 Commit。主仓库中记录提交标识，展开其源码需要额外获取仓库；当前筛选流程不递归展开。

## 3. 判断示例

```go
switch 文件.Mode {
case "100644", "100755":
    继续筛选()
case "120000", "160000":
    记录并跳过()
default:
    return 错误
}
```

保留例外不能覆盖文件类型检查。
