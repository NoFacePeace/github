# 路径校验

路径校验要求输入为规范化的仓库相对路径，确保后续读取和写入都位于预期目录内。

## 1. 拒绝条件

| 条件 | 示例 |
| --- | --- |
| 空路径、当前目录或上级目录 | 空字符串、`.`、`..` |
| 绝对路径 | `/etc/passwd` |
| 逃出根目录或包含需要整理的路径段 | `../config.yaml`、`src/../config.yaml` |
| 非规范化路径 | `./main.go`、`src//main.go`、`src/` |
| 包含反斜杠、NUL、回车、换行或 Tab | 路径中出现这些字符 |
| 任意路径段为 `.git`，不区分大小写 | `.git/config`、`src/.GIT/config` |

## 2. 处理结果

路径不合法时返回错误并终止源码准备。路径合法才继续检查文件类型；保留例外不能绕过此检查。
