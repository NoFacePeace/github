# 路径规则

路径规则根据文件路径决定是否获取正文，由内置默认排除规则、自定义追加排除规则和保留例外组成。

## 1. 判断顺序

```text
路径安全与类型检查通过
  → 命中保留例外：允许读取内容，继续检查
  → 否则命中排除规则：跳过
  → 否则允许读取内容，继续检查
```

自定义排除规则与内置默认规则合并。保留例外可以覆盖路径排除及后续测试框架特征筛选，不能绕过路径安全、类型、大小、编码和脱敏要求。

## 2. 匹配方式

- 不带 `/` 的模式匹配任意深度的路径段，例如 `vendor`、`*_test.go`。
- 带 `/` 的模式匹配完整仓库相对路径。
- `*`、`?` 和字符组匹配单个路径段内的字符。
- 独立路径段 `**` 可以跨越零个或多个路径层级，例如 `generated/**`。

## 3. 示例

假设排除规则为 `vendor` 和 `*_test.go`，保留例外为 `vendor/example.go`：

| 文件路径 | 结果 |
| --- | --- |
| `src/main.go` | 读取内容继续检查 |
| `src/main_test.go` | 跳过 |
| `vendor/lib.go` | 跳过 |
| `vendor/example.go` | 例外保留，读取内容继续检查 |
