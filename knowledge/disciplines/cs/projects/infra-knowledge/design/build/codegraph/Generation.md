# 生成

图谱生成读取指定版本的安全源码，调用提取工具生成包含节点、边及相关元信息的 JSON 产物。它与文档生成的 Agent Skills 路径分别执行。

## 1. 输入与输出

- 输入：安全源码执行副本的目录、固定版本身份、输出目录、工具配置与取消上下文。
- 输出：本次执行生成的 `graph.json`，以及工具执行结果或错误。

节点可以表示文件、函数、类等代码实体；边可以表示包含、导入和调用等关系。具体支持的语言、实体、关系与字段以所用提取工具版本为准。

## 2. 工具调用

可以使用开源工具 [Graphify](../../../../../../../tools/graphify/Graphify.md)，通过 Go 标准库 `os/exec` 启动外部程序：

```go
cmd := exec.CommandContext(ctx,
    "graphify", "extract", sourceDir,
    "--out", stagingDir, "--code-only",
)
output, err := cmd.CombinedOutput()
if err != nil {
    return 执行错误(output, err)
}
```

示例仅展示调用方式，实际执行需要管理日志、超时与输出大小。工具运行在构建机器上，需要提前安装匹配版本。

## 3. 生成流程

```text
取得独立的安全源码目录
  → 创建本次执行专用的临时产物目录
  → 调用提取工具
  → 等待进程结束并处理错误
  → 确认本次生成的 JSON 文件存在
  → 读取产物，交给后续检查
```

固定版本任务需要使用本次执行的新产物，不能因输出目录存在旧 JSON 就把它当作本次成功结果。已统一筛选的安全源码不应被另一套不一致的规则再次筛掉保留例外。

## 4. 执行边界

生成阶段不负责数据库发布，也不建立文档检索使用的全文或向量索引。外层继续管理任务心跳与执行归属。

源码静态提取结果存在语言和分析能力边界；JSON 中出现调用关系，不直接证明该路径在运行环境中实际发生。
