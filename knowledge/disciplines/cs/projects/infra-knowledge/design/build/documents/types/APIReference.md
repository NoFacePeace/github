# API 参考文档

API 参考文档按实际注册的入口组织接口目录，帮助读者定位可调用能力。

## 1. 核心内容

- 协议、方法、完整挂载路径或 RPC 与工具名称。
- 显式请求类型、响应类型和处理函数。
- 简短用途，以及必要的注册、鉴权或代理条件。
- 动态路径、缺失依赖等未确认范围。

## 2. 产物与用途

典型产物为 `api/api-reference.md`，主要形式是接口目录表。适合回答“有没有这个接口”“入口在哪里”“请求响应使用什么类型”。

## 3. 内容边界

不默认展开每个 DTO 的字段、全部错误分支或完整下游执行链路。未确认的类型标为未知；未注册的客户端方法、测试和示例不当作对外接口。
