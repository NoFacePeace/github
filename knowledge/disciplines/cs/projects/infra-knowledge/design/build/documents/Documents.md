# 文档构建

文档构建将固定版本源码转化为可校验、可检索的文档产物。当前设计采用 Agent Skills 生成路径，读取已准备的安全源码快照，再校验生成物并组织后续索引与发布。

## 1. 输入与输出

- 输入：固定版本的安全源码快照及清单、生成契约、配置、执行身份与取消上下文。
- 输出：文档批次、来源引用、生成诊断及索引准备结果。

## 2. 处理流程

```text
调用源码准备，获取固定版本的安全快照
  → 校验快照身份、来源与文件完整性
  → 确定生成模式，准备 Skill 任务及适用的增量上下文
  → Agent 调查源码，生成基础文档与适用的变更文档
  → 按开关生成模块计划和页面
  → 校验文档集合、输出契约与引用
  → 暂存完整文档及生成批次检查点
  → 准备匹配的检索索引
  → 校验并发布就绪批次
  → 交付产物及结果
```

共用输入能力见 [源码准备](../source/Source.md)，负责缓存检查、源码获取、筛选、脱敏及快照交付。

基础文档包括系统设计、API、指标及配置。模块规划与模块页面需要显式启用；它们不是所有文档的前置依赖。适配层消费源码清单，不内置语言 AST 分析或组件图生成引擎。

生成器返回经校验的文档集合，文档应用层组织暂存、索引和发布，不能仅以模型返回文本作为完成依据。

## 7. 执行边界

组件响应执行上下文的取消，返回成功、错误及必要诊断。任务领取和心跳由外层执行编排管理。

发布前应确认源码版本、生成配置和产物批次一致。失败重试是否复用已有文档或索引，需要验证检查点完整性与配置兼容性。

## 8. 存储与发布

- [文档存储](../../mysql/Document.md)：按文档保存完整 Markdown 或不可变内容引用，关联仓库、Commit 和批次。
- [文档生成批次](../../mysql/GenerationBatch.md)：保存批次身份、恢复检查点及发布状态。
- [索引构建](index/Index.md)：切分文本，构建全文和向量索引并保存产物。

生成成功后先暂存文档和检查点，再建立匹配索引，最后发布完整批次。恢复执行可以复用完整检查点，从索引阶段继续；暂存不等于查询可见。

## 9. 发布

[发布](Publication.md) 在索引就绪后校验批次与执行归属，通过数据库事务切换已发布批次并记录构建结果。
