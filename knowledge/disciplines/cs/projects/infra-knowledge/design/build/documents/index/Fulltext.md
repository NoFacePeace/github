# 全文索引

全文索引以 Chunk 为检索单元，通过词到文本块的倒排映射召回候选，在查询时使用 BM25 评分。

## 1. 构建流程

```text
Chunk 正文
  → 分词并统一大小写
  → 统计每块词频
  → 建立词到 Chunk 的倒排表
  → 计算包含词的块数及平均块长度
  → 序列化并保存全文索引产物
```

示例：

```text
Chunk A：worker renews lease
Chunk B：worker executes tasks

worker → A:1，B:1
lease  → A:1
tasks  → B:1
```

## 2. 分词与统计

简单分词可以将连续字母和数字组成词，标点作为分隔，并将常见中文汉字逐字处理。例如“任务续约”切为“任、务、续、约”。这不是中文词语分词，不保证短语相邻或语序一致。

每个词记录其在各 Chunk 中的次数；同时保存包含该词的块数、各块长度和平均长度。切块时使用分词定位边界，建立倒排索引时再次对 Chunk 正文分词计数。

## 3. 查询用途

用户查询使用相同分词规则，按词查找候选 Chunk，再综合词频、词的稀有程度与文本长度进行 BM25 排序。适合函数名、错误码、配置项等词语明确的查询；标识符中的标点也受分词规则影响，不等同于原字符串精确匹配。

全文索引产物保存文本块、倒排表及评分统计，查询加载时无需重新对全部正文分词。索引构建不需要调用语言模型。
