# 版本变更文档

版本变更文档比较两个固定源码版本，解释有证据支持的行为变化。

## 1. 核心内容

- 基线与目标版本身份，以及比较对象的选择规则。
- 变化摘要，相关行为的前后对比。
- 受影响的接口、配置、指标、数据与执行机制。
- 兼容性验证建议及比较范围限制。

## 2. 产物与用途

生成阶段的典型文件为 `changes/version-changes.md`，发布时可以按前后版本标识归档。适合回答“这个版本改了什么”“哪些能力受影响”。

## 3. 生成条件与边界

需要适用的固定前一版本；它不一定是 Git 的直接父提交，也不一定与增量更新文档的基线相同。

版本变更是独立内容类型，全量生成基础文档时也可以生成变更说明。源码被筛选或脱敏后的缺失信息不能直接解释为行为删除。
