# 系统设计文档

系统设计文档解释系统如何工作，重点是组件、链路和机制之间的因果关系。

## 1. 核心内容

- 系统用途、职责范围、架构与运行拓扑。
- 入口、核心流程、状态变化与真正的完成条件。
- 并发、幂等、重试、取消、部分失败和恢复保证。
- 资源瓶颈、配置生效、可观测性及证据缺口。

## 2. 产物与用途

典型产物为 `design/system-design.md`。适合回答“请求如何执行”“任务为什么停住”“失败如何传播”等问题。

## 3. 内容边界

保留解释机制所需的接口、指标和配置标识，不复制其他参考目录。静态代码分析不能被表述为已部署行为或已完成的运行验证。
