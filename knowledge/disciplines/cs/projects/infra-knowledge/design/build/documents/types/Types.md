# 文档类型

文档类型按最终产物的内容与用途划分，区别于生成模式和 Skill 执行任务。同一种文档可以全量生成，也可以增量更新。

## 1. 基础类型

- [系统设计](SystemDesign.md)：解释架构、执行流程、状态、资源与失败恢复机制。
- [API 参考](APIReference.md)：提供实际注册的接口身份与简要定义。
- [指标参考](MetricsReference.md)：提供实际暴露指标的精确名称和观测语义。
- [配置参考](ConfigurationReference.md)：提供配置来源、默认值、约束与生效方式。

基础文档按主题分别生成和验收，各自可以独立阅读。

## 2. 条件与可选类型

- [版本变更](VersionChanges.md)：有适用的固定前一版本时，解释前后行为变化。
- [模块设计](ModuleDesign.md)：显式启用模块文档后，提供模块索引与各模块页面。

按内容主题共六类。模块规划的 JSON 是供后续任务使用的中间产物，不属于最终 Markdown 文档类型。
