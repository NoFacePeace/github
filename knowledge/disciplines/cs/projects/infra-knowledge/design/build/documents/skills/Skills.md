# Skills

Skill 规定一个文档主题如何调查源码、组织内容、引用证据和完成输出。构建服务负责选择 Skill、准备输入并验收产物，Agent 在执行环境中读取 Skill 指令并完成任务。

本文目录记录各类文档生成 Skill 的设计职责，不是可直接安装的 Agent Skill 包。

## 1. 基础主题

- [系统设计](SystemDesign.md)：梳理系统职责、架构、组件与关键执行链路。
- [API 参考](APIReference.md)：整理接口入口、请求响应、鉴权和错误行为。
- [指标参考](MetricsReference.md)：整理指标定义、标签、注册与观测语义。
- [配置参考](ConfigurationReference.md)：整理配置来源、默认值、校验和生效方式。

各基础主题独立调查提供的源码，不以其他主题生成的文档作为前置证据。

## 2. 版本变更

- [版本变更](VersionChanges.md)：根据固定的前后源码版本解释行为变化及影响。

## 3. 可选模块文档

- [模块规划](ModulePlan.md)：划分模块范围并生成后续模块任务计划。
- [模块设计](ModuleDesign.md)：按计划调查指定模块，生成模块页面。

模块文档需要显式启用。模块规划和模块设计是两个执行阶段，可以由同一 Skill 根据任务阶段区分处理。

## 4. 共用输入与执行约束

输入包括当前安全源码、文件清单、处理范围、仓库与版本身份、输出路径和预算。增量模式还提供已有文档、基线源码与差异资料。

Skill 应明确调查步骤、输出结构、证据引用、检查点和停止条件。全量与增量可以使用同一个 Skill，通过任务参数选择不同分支；Agent 不自行选择基线。

完成后由构建服务导出并校验文档或计划，不能只凭对话中的完成声明判断成功。
