# 生成模式

生成模式决定文档构建是基于当前源码重新生成，还是结合已有文档与源码差异更新。两种模式使用同一套 Agent Skills，由构建服务确定模式，再通过任务参数与输入资料传给 Agent。

## 1. 具体模式

- [全量](Full.md)：基于当前安全源码快照重新生成各主题文档。
- [增量](Incremental.md)：基于兼容的已发布文档、基线源码和当前源码更新文档。

## 2. 模式来源

触发构建时传入 `generationMode`，支持显式选择 `full` 或 `incremental`；未指定时默认全量。模式选择与生成引擎选择是不同概念，不由 Agent 自行决定。

## 3. 自动选择策略

内部可以提供 `auto` 选择策略：有合格基线时选择增量，没有时选择全量并记录原因。它最终仍落到上述两种具体生成模式，不代表第三种生成算法。

查询或读取失败应返回错误，不能当成无基线静默回退；增量执行失败也不自动切换为全量。

## 4. 输入与执行一致性

确定实际模式后，保存目标版本、生成契约及适用的基线身份，恢复执行时沿用已固定的决定。全量和增量可以共用主题 Skill，通过任务参数和增量分支约束其行为。
