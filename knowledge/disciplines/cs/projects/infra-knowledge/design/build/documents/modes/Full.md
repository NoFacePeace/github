# 全量

全量模式基于当前版本的安全源码重新生成各主题文档，不以旧文档作为更新基线。请求值为 `full`，也是未指定模式时的默认选择。

## 1. 输入

- 当前版本的安全源码快照及来源信息。
- 文件清单、Skill 身份、输出路径和容量限制等任务要求。

## 2. 处理流程

```text
校验并读取当前快照
  → 确定全量模式
  → 为各主题准备源码、输入清单与任务说明
  → 创建 Agent 会话，确认 Skill 可用并选择模型
  → 发送指令，调查源码并生成文档
  → 导出和校验完整文档集合
  → 交给后续索引与发布流程
```

基础主题包括系统设计、API、指标和配置。模块计划及模块页面按开关启用。

## 3. 与变更说明的区别

全量模式不使用旧文档作为更新依据，但有适用的前一版本时，可以另外生成版本变更说明。变更说明需要前后源码，不表示基础主题采用增量模式。
