# 全文检索

全文检索根据查询中的词语，通过倒排表召回文本块，再使用 BM25 评分排序。它消费已构建的全文索引，不在每次查询时重新扫描所有文档。

## 1. 输入与输出

- 输入：查询文本、仓库、固定版本、标签等过滤条件和候选数量限制。
- 输出：候选 Chunk 标识、所属章节标识及全文相关性分数。

## 2. 处理流程

```text
加载选定发布范围的全文索引
  → 使用与建索引一致的规则对查询分词
  → 去除重复查询词
  → 按词查倒排表，取得 Chunk 与词频
  → 过滤不符合查询范围的候选
  → 累加各词的 BM25 分数
  → 按分数排序，截取候选集合
  → 返回给后续融合与章节聚合
```

索引数据的生成方式见 [全文索引构建](../build/documents/index/Fulltext.md)。

## 3. 查询示例

```text
查询：worker lease
分词：worker、lease

倒排表：
worker → A:1，B:1
lease  → A:1

分别计算并累加得分，再排序返回。
```

BM25 综合词频、包含词的块数、总块数、块长度和平均长度；同词出现更多不意味着分数无限线性增长。

## 4. 分词与匹配边界

简单分词会统一大小写，按标点分隔字母数字串，对常见中文汉字逐字处理。例如“续约”拆成“续、约”，它不保证短语相邻或顺序一致，也不等同于字符串精确匹配。

全文检索适合名称和词语明确的查询，但同义表达可能遗漏。未命中返回空候选；索引加载或校验失败应返回错误，不能作为空结果隐藏。
