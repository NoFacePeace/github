# Infra 知识库

Infra 知识库（Infra Knowledge Base）是面向基础设施领域的知识平台，目标是将服务源码、架构、配置、指标和排障知识组织为可查阅、可检索的上下文，供开发者与 AI 助手使用。

## 1. 项目定位

从源码生成文档是建设知识库的一种方式；平台也可容纳人工维护的 Markdown 文档。项目关注版本对应、源码证据和检索能力，帮助使用者理解系统及定位调查入口。

拟用仓库名为 `infra-knowledge`。

## 2. 能力规划

功能定位与使用流程见 [功能](features/Features.md)。

计划围绕以下能力建设，具体范围与实现方案在后续设计中明确：

- 以固定 Git Commit 的安全源码快照为输入，通过 Agent Skills 生成系统设计、API、指标、配置及适用的版本变更文档。
- 按配置启用模块规划与模块页面，作为可选的代码导航内容。
- 对文档构建关键词与向量检索索引，并在索引就绪后发布。
- 独立构建代码图谱，提供关系、路径与影响范围查询。
- 通过网页、REST 和只读 MCP 提供文档与代码上下文。

## 3. 源码到文档的处理思路

文档功能先梳理整体构建流程，再展开各环节。

```text
固定版本源码
  → 准备安全快照与文件清单
  → 校验快照身份及文件内容
  → Agent 按 Skills 调查源码并生成文档
  → 校验产物，建立索引并发布
```

生成流程以源码证据组织解释；运行时故障原因仍需结合实际日志、指标、Trace 与部署状态验证。
