# deadline

`deadline` 是调度记录 JSON 中的排队超时截止时间，使用毫秒时间戳，不是独立 Redis key。

## 1. 计算方式

```text
deadline = queuedAt + 排队时限
```

排队时限默认 10 分钟，可通过运行配置调整。入队时将截止时间固定在记录中，后续检查不需要根据新的平台配置重新计算。

## 2. 超时判断

确认调度记录仍处于 `queued` 后，比较：

```text
当前时间 >= deadline → 排队超时
```

超时则将调度状态改为失败，不继续为该请求分配 Runner。实际处理时刻可能略晚于截止时间，取决于调度器何时检查。

## 3. 与有效期的区别

`deadline` 是业务截止时间，不是 Redis TTL。到达该时间不会自动删除记录；结果确认后的 24 小时清理 TTL 由后续逻辑设置。
