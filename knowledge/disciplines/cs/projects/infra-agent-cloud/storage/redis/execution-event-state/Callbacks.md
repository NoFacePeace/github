# callbacks

`callbacks` 是执行事件状态 Hash 中的字段，用于记录本轮是否注册了服务端执行回调。

## 1. 取值

| 值 | 含义 |
| --- | --- |
| `"1"` | 本轮注册了服务端执行回调。 |
| `"0"` | 本轮未注册服务端执行回调。 |

该字段只保存标记，不保存回调函数、外部通知 URL 或页面 SSE 连接信息。

## 2. 写入时机

提交调度队列之前，通过 `HSET` 写入该字段，并通过 `EXPIRE` 将所属 key 的有效期设为 24 小时；两步在同一 Lua 脚本中执行。

提前登记可以避免 Runner 的执行事件先于回调标记到达。

## 3. 使用目的

事件处理层据此决定是否保留供回调消费的回放输出，避免没有回调时积累无人消费的输出。

登记为 `"0"` 不影响任务执行及状态、结果的保存。
