# extra_info

`extra_info` 是 Session 表中可空的 JSON 字段，代码属性名为 `extraInfo`，用于保存本轮执行的扩展信息。

## 1. 调度信息

字段 [runnerDispatch](RunnerDispatch.md) 保存调度状态的业务侧副本。例如：

```json
{
  "runnerDispatch": {
    "state": "queued",
    "queuedAt": 1800000000000,
    "deadline": 1800000600000
  }
}
```

以上为示例值。它记录本轮正在排队等调度细节，不能将其中的 `state` 与 Session 的主状态混为一谈。

## 2. 停止请求

`runnerStopRequested` 记录是否已请求停止。状态同步流程会检查该标记，按当前调度和执行阶段尝试取消排队或发送停止指令。

停止请求标记表示停止意图，不代表 Runner 进程已经退出。

## 3. 更新方式

更新某一项扩展信息时，应保留已有 JSON 内容，避免覆盖同一轮执行的其他信息。调度状态同步会在事务中锁定 Session 记录，再按当前状态决定是否更新。

## 4. 其他用途

该字段也可保存内部工具上下文标识、启动错误和执行统计等扩展数据，并非专门的调度字段。上下文标识用于定位工具上下文，不等于将上下文本体或凭证写入此字段。
