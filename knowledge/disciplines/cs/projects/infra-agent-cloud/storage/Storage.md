# 存储

整理 Agent 云平台中结构化数据、执行协调状态与文件产物的存储职责。

## 1. 职责划分

| 类型 | 典型用途 |
| --- | --- |
| 关系型数据库 | 持久化任务、执行记录和配置等结构化数据。 |
| 内存键值存储 | 承载缓存、任务队列、租约、心跳和执行协调状态。 |
| 对象存储 | 保存文件、执行产物和工作目录备份。 |

## 2. 存储组件

- [Redis](redis/Redis.md)：缓存、队列与执行协调。
- [MySQL](mysql/MySQL.md)：结构化业务数据持久化。
- [对象存储](ObjectStorage.md)：文件、执行产物与备份存储。
