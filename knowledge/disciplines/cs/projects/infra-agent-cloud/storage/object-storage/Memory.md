# memory

保存 Agent 可跨执行复用的记忆文件，如用户偏好、项目约定和参考信息。它与引擎对话历史分别管理。

## 1. 任务路径

```text
任务备份：tasks/<taskUuid>/memory/
本地目录：<dataRoot>/tasks/<taskUuid>/memory/
```

长期记忆另按 Agent、共享或个人范围组织，不能只从任务备份前缀理解其全部来源。

## 2. 生成与同步

平台提供使用说明，Agent 在执行过程中创建或修改本地记忆文件。Runner 监听新增、修改与删除；结束时有变化才上传任务记忆目录，并通知 Server 创建同步任务。

Server 按共享、个人范围同步到长期记忆存储，必要时调用模型合并新旧内容。该流程不是每次结束都将全部对话自动总结为记忆。

## 3. 初始化与恢复

任务文件恢复阶段可尝试恢复已有任务记忆备份。后续 Memory 准备阶段还会向 Server 请求初始化结果，取得长期记忆的基础路径、文件清单、入口路径及说明，再从对象存储下载到本地。

初始化会准备个人与共享目录，并将适用的入口文件内容和使用说明加入本轮提示词。普通任务结束的配置、会话备份与记忆变化上传是不同流程，不能假设每次都产生新的 Memory 备份。
