# 对象存储

对象存储保存任务配置、执行日志及记忆文件等内容，供恢复与跨轮次使用。以下使用通用任务标识和目录，不记录内部服务名称。

## 1. 任务备份目录

```text
tasks/<taskUuid>/
├── config/
├── memory/
└── session/
```

| 内容 | 说明 |
| --- | --- |
| [config](Config.md) | 引擎配置及自身会话数据的适用备份。 |
| [memory](Memory.md) | 本次任务的记忆文件变化，以及用于长期复用的记忆资料。 |
| [session](Session.md) | 平台按执行轮次记录的日志和输出。 |

## 2. 本地对应关系

任务备份路径通常对应 Runner 的 `<dataRoot>/tasks/<taskUuid>/<目录>/`。本地根目录可配置，同一 Task 的不同轮次使用同一套任务目录。

## 3. 恢复边界

有引擎恢复会话标识时才进入任务文件恢复流程。目标本地目录已有有效内容时跳过相应恢复，否则列出对象存储中对应前缀下的文件并下载。

当前任务备份流程没有实现 `workspace` 备份，也不备份 `home`、`tmp` 整套目录，不能将任务文件恢复理解为完整工作区或进程恢复。
