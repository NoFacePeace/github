# Server

Server 是平台的业务与调度组件，接收用户请求，管理任务及执行记录，并协调执行过程。

## 1. 核心职责

- 处理 Agent 配置、身份认证与操作授权。
- 创建任务和执行记录，持久化业务状态。
- 提交请求，协调调度、停止和继续执行。
- 接收执行事件，更新进度并保存结果。

## 2. 处理执行事件

[处理执行事件](handle-events/HandleEvents.md) 说明消费 Runner 回传事件、校验执行归属、保存结果及确认清理的过程，适用于发起任务与继续任务等远程执行场景。

## 3. 定时任务

[定时任务](scheduled-tasks/ScheduledTasks.md) 说明远程执行恢复与执行授权清理，负责事件缺失、租约失效或收尾中断后的补偿处理。

## 4. 聊天

[聊天](chat/Chat.md) 说明 SSE 连接、用户消息、回放读取和回复推送，以及多实例的协作边界。
