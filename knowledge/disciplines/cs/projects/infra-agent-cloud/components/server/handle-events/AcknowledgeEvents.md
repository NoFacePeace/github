# 确认与清理事件

事件处理成功后，Server 对原始事件 Stream 消息进行确认和清理，为后续事件写入释放队列空间。

## 1. 原子清理

在同一 Redis Lua 脚本中：

1. 读取待清理消息的 payload 大小。
2. 用 `XACK` 移除消费组中的待确认状态。
3. 用 `XDEL` 删除 Stream 消息本体。
4. 从[事件字节计数](../../../storage/redis/RunnerEventBytes.md)中扣减对应大小，结果不小于零。

若计数 key 不存在，此处不直接重建；发布侧可在后续写入时按现有 Stream 内容重建计数。

## 2. 与 Job 消费的区别

事件流消费成功后同时确认并删除原消息；Job 消费的正常确认仅使用 `XACK`，不会在该确认步骤删除消息本体。

这里只清理已处理的传输消息，不等于删除业务执行记录或另行保存的日志、回放内容。
