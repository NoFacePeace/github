# 聊天

Server 管理前端聊天连接、接收用户消息，并通过执行回调将回复推送给前端。它与原始执行事件消费、定时恢复是同级能力，不限于发起任务。

## 1. 交互流程

从[建立 SSE 连接](ConnectSse.md)开始，沿后续链接阅读：

```text
建立 SSE 连接
  → POST 发送用户消息
  → 注册执行回调并监听回放记录
  → 转换为聊天消息，通过 SSE 推送
  → 连接断开时清理聊天登记
```

## 2. 多实例协作

原始事件可由 Server B 消费并保存为共享回放记录，持有 SSE 连接的 Server A 再读取回放并执行本地回调。SSE 不需要转移到 B，也不直接订阅 Runner。

SSE 连接与聊天处理对象保存在实例内存中。发送消息的请求需要到达持有相应聊天登记的实例；当前代码不足以确认部署层采用了哪种粘性或会话路由策略。
