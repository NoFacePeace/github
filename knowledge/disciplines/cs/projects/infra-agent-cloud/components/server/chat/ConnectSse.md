# 建立 SSE 连接

前端携带 Task UUID 和认证信息请求事件接口。Server 校验任务归属后，准备聊天适配器与会话管理对象。

## 1. 连接准备

新连接按当前实现释放旧缓存的聊天运行对象，再从数据库恢复所需状态。这里的聊天运行对象属于 Server，不是执行任务的 Runner。

响应使用 `text/event-stream`、禁用缓存、保持连接，并禁用适用的代理缓冲。先发送连接初始化消息，再按会话标识登记写入该响应的回调。

## 2. 标识与生命周期

聊天传输层使用的会话标识在此取 Task UUID，不能与数据库每轮执行的 Session UUID 混淆。请求关闭时移除对应登记，并防止旧连接的清理误伤新连接。

## 3. 后续步骤

连接建立后，可通过独立请求[发送用户消息](SendMessage.md)。SSE 是接收通道，不承载前端向 Server 发送输入的 POST 操作。
