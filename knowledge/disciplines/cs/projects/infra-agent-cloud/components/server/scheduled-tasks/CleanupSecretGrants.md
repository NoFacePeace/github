# 执行授权清理

Server 每 60 秒扫描符合条件的到期执行授权，作为正常终态撤销之外的补偿机制。

## 1. 运行条件

同一实例正在清理时不重复进入。只有配置了运行时服务身份能力时，才执行此清理任务。

## 2. 查询授权

从 MySQL 的 [SecretGrant](../../../storage/mysql/secret-grant/SecretGrant.md) 表按主键游标分批读取 `expires_at` 不晚于本次扫描开始时间的记录，每批最多 100 条。

## 3. 检查执行归属

根据授权绑定中的 Session 和运行范围，查询[执行租约](../../../storage/redis/ExecutionLease.md)。

- 绑定缺失或有效租约不匹配：撤销授权，删除对应记录。
- 有效租约仍匹配：保留，不仅凭授权的原始截止时间删除。
- 查询存储失败：延后到下一次扫描，不把查询失败当成租约不存在。

授权截止时间是应用判断条件，不是 MySQL 自动删除机制。该任务不直接删除 Runner 本机文件或终止进程。
