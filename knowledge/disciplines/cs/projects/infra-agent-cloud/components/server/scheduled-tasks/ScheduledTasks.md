# 定时任务

Server 内部通过定时间隔任务执行补偿和清理，不依赖 Runner 主动回传事件，也不限于发起任务链路。

## 1. 远程执行恢复

[远程执行恢复](RecoverRemoteSessions.md) 每 30 秒扫描仍在运行的远程执行，推进调度恢复、补做终态落库，或在租约失效时结束异常执行。

## 2. 执行授权清理

[执行授权清理](CleanupSecretGrants.md) 每 60 秒检查到期授权，结合有效执行租约判断是否撤销。

## 3. 运行边界

两项任务各自通过进程内标记避免同一实例重复进入。间隔表示扫描频率，不保证异常恰好在该时间内完成处理；还受租约有效期、启动宽限和存储可用性影响。

业务收尾不能直接清理已失联节点上的进程或文件，也不自动把正在运行的 Agent 迁移到另一节点。节点本地清理需由其恢复及生命周期流程负责。
