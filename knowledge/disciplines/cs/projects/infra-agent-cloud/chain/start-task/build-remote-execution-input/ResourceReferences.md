# 技能与插件引用

将执行所需的技能与插件表达为可定位、可校验的资源引用，供后续获取和加载。

## 1. 技能引用

比较版本默认技能与本次实际技能，组织需要增加或移除的清单。

技能引用应明确名称、来源和具体版本。未固定版本时，需要查询技能版本记录补全版本；无法找到有效版本时返回错误。

## 2. 插件引用

组织插件名称及固定 Commit 等定位信息。与版本默认插件配置比较，存在变化时提供本次插件清单。

引用描述需要加载哪些资源，不表示插件文件已经下载，也不自动授予插件访问外部服务的权限。

## 3. 文件获取

Runner 准备环境时按授权获取资源。不同来源可能使用 Git 文件或对象存储中的文件、归档，不应假设每个资源都来自同一种存储。
