# 提交

Server 将用户首次消息转换为可供调度器处理的执行请求。现有步骤归入本阶段，入队成功是本阶段的交付边界。

## 1. 处理顺序

从[查询 Agent](QueryAgent.md) 开始，沿各步骤的后续链接阅读：

```text
查询 Agent
  → 查询 Agent 版本
  → 组装执行配置
  → 创建 Task
  → 创建 Session
  → 准备内部工具上下文（需要时）
  → 构建远程执行输入
  → 关联内部工具上下文（存在时）
  → 登记执行回调
  → 提交调度队列
```

## 2. 阶段结果

任务与首轮执行记录已经保存，执行输入进入调度记录，Session 加入等待集合，并发出唤醒通知。此时尚不代表已经分配 Runner 或启动 Agent。
