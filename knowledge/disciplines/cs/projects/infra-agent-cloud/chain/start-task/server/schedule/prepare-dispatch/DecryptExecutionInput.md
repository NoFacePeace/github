# 解密执行输入

从已读取的[调度记录](../../../../../storage/redis/dispatch-record/DispatchRecord.md)取得 `encryptedInput`，调用密钥管理服务进行信封解密，并将 JSON 解析为提交输入。

## 1. 恢复内容

恢复作业信息、调用模式、凭证使用方式、用户信息、Agent 资源与准备配置，以及模型服务配置等适用内容。

输入可能包含敏感数据，不能将解密结果输出到普通日志。缺少加密输入或解密失败时，不继续按正常请求派发。

## 2. 后续步骤

进入[检查遗留租约](CheckExistingLease.md)，确认是否有前次准备过程留下的容量预留。
