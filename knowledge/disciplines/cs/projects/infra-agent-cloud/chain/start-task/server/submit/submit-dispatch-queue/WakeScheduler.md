# 唤醒调度器

入队后，通过 Redis Pub/Sub 向[调度通知频道](../../../../../storage/redis/DispatchNotification.md)发布通知，提示订阅方尝试处理等待队列。

## 1. 操作

```text
PUBLISH <调度通知频道> ""
```

通知内容为空字符串，不携带执行请求。调度器收到通知后读取已保存的等待队列与调度记录，再尝试分配 Runner。

## 2. 通知与队列

频道只传递检查队列的信号，不是任务存储。Pub/Sub 不持久化消息，未订阅或断线的消费者不会收到这次通知；已入队的任务数据仍保存在 Redis 中。

唤醒也不表示一定立即执行，是否能够分配还取决于 Runner 的能力、状态与可用容量。
