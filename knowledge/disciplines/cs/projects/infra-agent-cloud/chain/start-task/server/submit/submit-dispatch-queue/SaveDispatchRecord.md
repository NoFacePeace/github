# 保存调度记录

将任务与本轮执行的信息组织为调度记录，保存到 Redis 的[调度记录](../../../../../storage/redis/dispatch-record/DispatchRecord.md)。

## 1. 组织内容

记录 Task UUID、Session UUID、Job ID、初始排队状态、排队时间与超时截止时间。

执行请求中包含配置、资源引用及敏感输入，因此将完整提交输入加密后保存，不将敏感内容作为明文调度字段写入。

## 2. 重复提交

若同一 Session 已有调度记录，校验身份并复用已有记录，避免重复入队或覆盖原请求。

## 3. 原子写入

在 Lua 脚本中再次检查记录是否存在；不存在时保存调度记录，并同步将 Session 加入待调度集合。
