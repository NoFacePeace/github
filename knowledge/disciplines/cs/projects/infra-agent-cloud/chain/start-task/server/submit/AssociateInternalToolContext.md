# 关联内部工具上下文

远程执行输入构建成功后，若本轮创建了内部工具上下文，将其标识保存到 [Session](../../../../storage/mysql/session/Session.md)，记录本轮执行与工具上下文的关联。

## 1. 执行条件

存在内部工具上下文 ID 时执行更新；没有上下文时跳过，继续登记执行回调。

## 2. 更新记录

在数据库事务中，按 Session 的数据库主键查询本轮记录并加悲观写锁。保留已有扩展信息，加入内部工具上下文 ID 后保存。

这是对已有 Session 的更新，不是插入新的执行记录。以下示例仅表示通用数据关系，字段名与值均用于说明：

```json
{
  "extraInfo": {
    "internalToolContextId": "context-example"
  }
}
```

## 3. 关联用途

上下文本体已在前面的准备阶段保存到 Redis；Session 此时只记录 ID，不复制工具配置或访问令牌。

执行结束或启动失败后，服务端可根据保存的 ID 找到并撤销上下文。正常调用 MCP 时，Agent 使用工具连接地址中的上下文 ID 和请求头中的令牌，服务端据此验证并读取上下文，无需先查询 Session 获取 ID。

## 4. 后续步骤

关联成功后，进入[登记执行回调](RegisterExecutionCallbacks.md)，再提交调度队列。应在任务进入调度前完成关联，方便后续执行收尾。没有内部工具上下文时可直接进入回调登记。
