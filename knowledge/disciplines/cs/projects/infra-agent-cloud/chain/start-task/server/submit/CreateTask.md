# 创建 Task

执行配置组装与启动前检查完成后，创建并持久化 [Task](../../../../storage/mysql/task/Task.md) 记录，建立本次任务的身份与执行归属。

## 1. 生成任务标识

生成任务 UUID，用于接口返回、执行请求与事件关联。数据库自增主键 `id` 与任务 UUID 分别使用；后续 Session 的 `task_id` 关联数据库主键。

需要任务标识才能生成的提示词或上下文，可在此时补齐。

## 2. 组织任务字段

| 字段 | 内容 |
| --- | --- |
| uuid | 新生成的任务 UUID。 |
| agent_id | 本次使用的 Agent 主键，未绑定时可为空。 |
| version_id | 选中版本记录的主键，未绑定时可为空。 |
| engine | 本次实际选择的执行引擎。 |
| runtime_type | 服务端选择的运行方式。 |
| status | 初始任务状态。 |
| creator | 任务创建者。 |

初始状态即使标记为运行中，也不代表 Agent 进程已经启动；任务可能仍处于准备或调度阶段。

## 3. 保存记录

将任务记录写入数据库，取得持久化后的主键。任务表保存任务级信息，不应将完整执行配置或凭证原样写入。

## 4. 后续步骤

保存 Task 后，进入[创建 Session](CreateSession.md)，将首次消息作为本轮输入，并通过 `task_id` 关联 Task。任务与首轮执行记录准备完成后，再异步提交。
