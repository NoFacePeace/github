# 检查遗留租约

解密输入后，按 Session 标识查询 Redis 中的[执行租约](../../../../../storage/redis/ExecutionLease.md)。

## 1. 遗留预留处理

`queued` 阶段尚无可下发的已提交作业。如果存在前次准备过程留下的租约，先核对其 Task 身份，并通过带 claim 令牌的受控保存确认当前调度处理权仍有效，再释放遗留租约。

身份不符或 claim 已失效时返回冲突，不直接释放他人的预留。

## 2. 后续步骤

进入[选择 Runner 与预留容量](ResolveRunner.md)，为本次准备过程取得适用的节点与租约。
