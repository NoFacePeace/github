# 签发执行授权

目标 Runner 与执行租约确定后，为需要真实执行资源和凭证的作业签发受控授权。

## 1. 授权绑定

结合 Job、Runner 实例、适用的用户身份、Agent 输入及模型服务配置，准备后续获取执行凭证与资源所需的授权。合成测试作业可跳过此流程。

此时不是由 Server 直接启动 Agent，也不将全部凭证明文写入普通消息；Runner 后续按授权领取所需信息。

签发时在 MySQL 的 [SecretGrant](../../../../../storage/mysql/secret-grant/SecretGrant.md) 表新增授权记录，保存执行绑定、加密凭证快照与领取截止时间，再将授权引用加入 Job。

## 2. 失败处理

签发失败时回滚本次派发预留，避免容量被无效请求占用，再将错误交给调度流程处理。

## 3. 后续步骤

授权准备完成后，进入[保存派发信息](SaveDispatchPreparation.md)。
