# 配置差异

配置差异表示本次实际执行配置相对选中版本原始配置的调整。

## 1. 比较基准

以版本原始配置为基准，与合并用户设置、请求参数和平台上下文后的配置比较。不能用已经修改过的配置作为原始基准。

## 2. 差异内容

- 模型与推理设置等覆盖值。
- 提示词的变化或追加内容。
- 工具配置等字段的调整与移除。
- 其他需要在执行环境中应用的配置变化。

例如版本默认模型为 M1，本次实际模型为 M2，则将 M2 作为本次覆盖项，保留版本默认值的含义。

## 3. 应用方式

Runner 获取版本资源后，将调整应用到本轮配置，不因此修改已保存的版本记录。配置中的敏感部分需单独组织。
