# 构建远程执行输入

Task 和首个 Session 创建、按需准备内部工具上下文后，复用已选版本及本次执行配置，将其整理为供远程调度和 Runner 使用的数据。本阶段不重新选择 Agent 版本。

## 1. 输入与输出

输入包括已选版本、版本原始配置、本次实际执行配置及任务上下文。输出包括资源来源、配置调整、技能与插件引用，以及单独组织的敏感输入；随后与 Task UUID、Session UUID、本轮提示词和执行引擎一起组织成调度请求。

本阶段以协议转换和数据组织为主，同时完成必要的资源引用补全与校验。

## 2. 构建内容

- [资源来源](ResourceSource.md)：定位选中版本的 Git 或草稿资源。
- [配置差异](ConfigOverrides.md)：表达本次配置相对版本默认值的调整。
- [技能与插件引用](ResourceReferences.md)：确定执行所需的资源版本及增删清单。
- [敏感输入](SensitiveInputs.md)：单独组织凭证和敏感配置，供受控交付。

## 3. 存储边界

本阶段主要在内存中构造数据。必要时读取 Git 项目与标签信息，或查询未固定的技能版本；构建函数本身不更新任务与执行记录、不写 Redis，也不上传对象存储文件。

配置准备时已经读取的内容可直接复用。技能、插件等文件按引用在后续环境准备阶段获取，不需要全部塞入调度消息。

## 4. 后续步骤

输入构建完成后，进入[关联内部工具上下文](../AssociateInternalToolContext.md)，按需将其标识保存到 Session，再登记执行回调标记，最后提交调度队列。这些存储写入属于后续步骤。
