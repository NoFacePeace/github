# 资源来源

资源来源描述 Runner 应从哪里取得已选版本的配置文件，不承担版本选择职责。

## 1. Git 来源

组织仓库地址、固定 Commit 及适用的分支信息。对标签发布的版本，查询远程标签并验证其 Commit 与选中版本记录一致；不一致时返回错误。

固定 Commit 用于明确实际执行内容，避免仅凭可移动的分支或标签名称确定内容。

## 2. 草稿来源

组织 Agent 标识、版本记录标识及草稿更新时间。后续获取草稿文件时，由服务端校验访问权限和草稿状态，再提供对应资源。

## 3. 获取时机

构建来源引用不等于立即下载文件。Runner 准备执行环境时，再依据来源及授权获取文件。
