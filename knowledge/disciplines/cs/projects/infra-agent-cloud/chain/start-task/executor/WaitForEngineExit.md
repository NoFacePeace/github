# 等待引擎退出

Executor 等待引擎进程退出，同时继续消费输出和处理适用的追加输入命令。等待使用异步句柄，不阻塞整个进程的事件循环。

## 1. 退出后处理

1. 取得进程退出码。
2. 标记控制命令消费结束，等待当前正在处理的命令完成。
3. 等待标准输出、标准错误读取完成，避免漏掉退出前最后一段输出。
4. 结合停止标记与中止信号，判断本轮是否属于主动停止。

运行期间收到停止信号时，会尝试向引擎子进程发送 `SIGINT`。异常处理分支在子进程仍存活时尝试发送 `SIGTERM`。

## 2. 存储操作

等待与状态判断使用进程句柄和内存状态，本步骤不直接读写 MySQL、Redis 或对象存储。输出消费期间仍可能写入本地日志。
