# 持续读取并解析输出

Executor 在引擎运行期间消费标准输出和标准错误，记录日志并通过进程管道上报事件。

## 1. 处理流程

从[逐行读取输出](ReadOutput.md)开始：

```text
逐行读取输出
  → 记录本地日志
  → 上报原始输出事件
  → 解析会话、进度和回复
  → 上报解析事件
  → Runtime 接收并转发事件
```

上述流程随输出逐行重复。标准错误分支记录日志并上报 `stderr`，不进行标准输出的进度和回复解析。支持追加输入时，还会并行处理控制命令。

## 2. 并行关系

输出消费与等待引擎退出同时进行，并非等引擎退出后才开始上报。引擎退出后，Executor 等待输出读取与事件发送完成，再解析最终结果。
