# 准备 MCP Gateway

Executor 合成执行配置后，若配置了 MCP 服务，则准备本轮工具网关，连接工具服务并转换引擎使用的连接配置。

## 1. 处理顺序

从[连接工具服务](ConnectServices.md)开始，沿后续链接处理：

```text
检查是否配置 MCP 服务
  → 并发尝试连接各工具服务
  → 有成功连接时启动本地 HTTP 入口
  → 转换成功连接的工具配置
  → 后续写入引擎配置
```

没有 MCP 服务则跳过本阶段。Gateway 位于执行环境内，不是 Server 的 SSE 服务，也不负责外层 bwrap 资源隔离。

## 2. 存储与通信

本阶段主要使用进程内连接状态、本地子进程和网络连接，不直接操作平台 MySQL 或 Redis。工具服务本身是否访问存储由其实现决定。
