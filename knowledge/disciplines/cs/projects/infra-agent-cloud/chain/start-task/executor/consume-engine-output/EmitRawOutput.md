# 上报原始输出事件

本行日志写入完成后，Executor 调用 `emit`，先发出 `stdout` 或 `stderr` 事件。

## 1. 事件内容

`payload.data` 保存带换行符的原始行。若日志过滤结果与原始行不同，还会携带 `logData`；被排除的日志行对应空字符串。

这里的“上报”是将事件写入 Executor 标准输出管道，交给 Runtime。Executor 不直接连接 Redis。

## 2. 顺序

标准输出先发出 `stdout` 事件，再解析本行中的会话、MCP 状态、进度和通道输出。因此，一行引擎输出可能产生多个事件。

标准错误上报 `stderr` 后继续读取下一行，不进入标准输出解析分支。

标准输出进入[解析输出内容](ParseOutput.md)。
