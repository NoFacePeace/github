# 转换引擎工具配置

遍历原 MCP 服务配置，根据 Gateway 的连接结果生成引擎实际使用的配置。

## 1. 成功连接的服务

将连接配置转换为指向本地 Gateway 的 HTTP 地址，并保留适用的工具允许列表。原服务的启动参数与认证信息由 Gateway 侧使用，不必原样交给引擎连接该服务。

```text
Agent 引擎 → 本地 Gateway → 原 MCP 服务
```

## 2. 未成功连接的服务

保留原始配置，供引擎尝试直接连接。这是适用的直连回退，不保证原服务后续一定可用，也不代表绕过网络与访问权限限制。

## 3. 后续步骤

Executor 随后进入[写入引擎配置](../WriteEngineConfig.md)，将转换后的配置交给具体引擎适配器，再准备插件、打开执行日志并启动引擎。
