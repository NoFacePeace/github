# 连接工具服务

根据合成后的 MCP 配置，并发尝试建立各服务的连接，分别记录成功和失败结果。

## 1. 连接方式

- stdio：按配置启动工具进程，通过标准输入输出通信，并提供适用的环境变量。
- HTTP：连接工具服务地址，并使用适用的认证请求头。

含有未解析变量占位符的配置会被拒绝。诊断信息按规则脱敏，不能直接输出工具凭证。

## 2. 失败处理

单个服务连接失败时记录失败结果，不必直接终止全部连接尝试；取消信号仍需要传播。网关整体启动抛错时，执行流程不会将其一律当作普通工具连接失败忽略。

## 3. 后续步骤

连接尝试结束后，进入[启动本地入口](StartLocalEndpoint.md)。
