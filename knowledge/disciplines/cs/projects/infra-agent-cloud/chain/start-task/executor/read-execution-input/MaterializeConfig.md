# 合成执行配置

Executor 将执行描述中的普通配置与已校验的敏感输入组织为引擎可用配置。

## 1. 配置覆盖

以 manifest 的 `config` 为基础，用敏感输入中的 `configOverrides` 覆盖对应顶层字段，再按规则注入环境变量、模型凭证或引擎认证信息。这不是对所有嵌套对象做统一深度合并。

## 2. 兼容校验

- 再次确认敏感输入与执行描述的 `executionId` 一致。
- 拒绝将一种引擎的专用认证用于另一种引擎。
- 敏感 MCP 配置只能引用已声明的服务。
- stdio 工具使用适用的环境变量，HTTP 工具使用适用的请求头，不能混用两种敏感配置。

## 3. 后续步骤

得到内存中的最终配置后，进入[准备 MCP Gateway](../prepare-mcp-gateway/PrepareMcpGateway.md)，后续写入引擎配置并启动引擎。合成配置本身不表示配置文件已经写入，也不代表 Agent 已经启动。
