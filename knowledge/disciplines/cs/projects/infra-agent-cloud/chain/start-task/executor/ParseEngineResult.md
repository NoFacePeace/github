# 解析最终结果

引擎退出、输出读取完成后，Executor 调用 `engine.parseResult`，根据收集的标准输出和执行描述提取最终结果。

## 1. 结果内容

终态事件载荷包含退出码、最终结果、引擎会话 ID、汇总的 MCP 状态和产物引用；引擎提供时，还包含用量、费用及费用估算标记。

引擎会话 ID 来自此前的输出解析，初值可以是本次恢复使用的会话 ID。它用于后续继续对话，与平台 Session 标识不同。

## 2. 存储操作

此步骤解析内存中收集的输出；具体引擎适配器还可按实现读取本地结果文件。不在这里直接更新平台数据库，产物引用也不等于已经完成文件上传。

## 3. 下一步

整理结果后[上报终态事件](ReportTerminalEvent.md)。
