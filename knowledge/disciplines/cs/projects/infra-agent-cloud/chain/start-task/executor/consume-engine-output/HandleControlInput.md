# 处理追加输入

引擎句柄支持 `steer` 且提供控制命令流时，Executor 在消费输出的同时接收追加输入。

## 1. 处理流程

1. 支持交互的句柄就绪后发出 `executor_ready`。
2. 逐条读取控制命令，按 `commandId` 查询内存回执。
3. 尚未处理时准备新提示词，调用引擎的 `steer`。
4. 保存成功或失败回执，发出 `steer_result`。

同一命令重复投递时复用回执，避免再次写入引擎。控制输入通道异常会记录诊断并触发停止子进程。

## 2. 存储与生命周期

回执保存在本轮 Executor 内存中，不是新增 MySQL 表或 Redis key。引擎退出后停止继续处理新命令，并等待正在处理的命令完成。
