# 读取敏感输入

真实 Agent 执行从 stdin 接收 Runtime 传入的敏感数据，解析并校验其协议结构。

## 1. 输入模式

普通模式读取一次性敏感输入；支持运行中指令的模式使用控制输入协议，从同一通道取得初始敏感数据并保留后续指令读取能力。

普通一次性输入有大小和等待时限约束：最多 1 MiB，默认等待 5 秒。读取超时、内容过大或格式无效时失败。

## 2. 执行绑定

敏感输入中的 `executionId` 必须与 manifest 一致，避免把其他轮次的凭证用于当前执行。它不是平台 Session UUID，也不是底层引擎会话 ID。

## 3. 后续步骤

Executor 注册适用的停止信号处理，进入[合成执行配置](MaterializeConfig.md)。不应将敏感输入写入普通日志。
