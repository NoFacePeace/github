# 准备 Agent 版本资源

根据 Job 中的 Agent 来源、准备描述及已领取的资源凭证，准备本轮实际使用的版本文件和配置。

## 1. 获取与应用

根据来源获取 Git 或草稿文件，按授权获取适用的技能与插件资源，并应用模型、提示词和工具等配置调整。资源请求通过 Server 校验后获取，Runner 不直接查询版本业务表。

准备过程受取消、租约失效和超时信号控制，文件落入受控的任务目录。

## 2. 分离敏感输入

资源准备完成后，从交给 Executor 的敏感输入中移除仅供版本准备使用的敏感部分，保留实际执行需要的配置与凭证。

## 3. 后续步骤

检查停止请求后，进入[准备 Memory](PrepareMemory.md)。
