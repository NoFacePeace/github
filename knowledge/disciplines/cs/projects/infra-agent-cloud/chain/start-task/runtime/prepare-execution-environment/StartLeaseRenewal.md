# 启动租约续期

为本轮执行建立租约维护流程，通过 Server 接口续期[执行租约](../../../../storage/redis/ExecutionLease.md)，持续确认自己仍有执行权。

## 1. 维护执行权

启动租约维护后，准备与执行阶段使用其失效信号。租约丢失时触发停止本轮执行，避免在失去归属后继续运行。

这是 Runner 执行租约的维护，不是 Server 调度 claim 的续期，两者不能共用 30 秒、10 秒等参数推断。

## 2. 后续步骤

再次检查停止或关闭要求；需要停止时关闭租约维护并结束，否则进入[恢复任务文件](RestoreTaskFiles.md)。
