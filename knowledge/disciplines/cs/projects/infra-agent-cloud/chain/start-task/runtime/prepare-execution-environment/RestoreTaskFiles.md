# 恢复任务文件

在准备版本资源前，按任务身份和执行描述恢复已有文件备份，为继续执行提供目录基础。

## 1. 恢复协调

若本进程存在同一任务的备份操作，先请求取消并等待其结束，再恢复文件，避免同一目录同时备份与恢复。

恢复同时受准备取消、租约失效与备份操作超时信号控制。

## 2. 存储操作

恢复涉及[对象存储](../../../../storage/object-storage/ObjectStorage.md)中的适用备份及 Runner 本地任务目录。新任务与已有任务所需恢复的数据可能不同，不能假设每次都有完整工作目录备份。

## 3. 后续步骤

恢复完成后进入[准备 Agent 版本资源](PrepareAgentResources.md)。
