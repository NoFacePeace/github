# 查询 Agent

发起任务并指定 Agent 时，先读取智能体的管理信息，再根据请求与版本选择规则确定执行配置。

## 1. 查询主体

根据请求中的 Agent 标识查询 [Agent](../../storage/mysql/agent/Agent.md)，确认记录存在，并读取状态、当前默认发布版本号及多版本开关等信息。

- 记录不存在：返回错误。
- 状态未启用：普通调用会被拒绝；草稿或显式版本记录的调用需结合具体权限与校验规则判断。
- `published_version`：当前默认发布版本号，不是版本记录的主键。

## 2. 确定版本

读取 Agent 管理信息后，进入[查询 Agent 版本](query-agent-version/QueryAgentVersion.md)，根据请求、灰度规则或默认发布版本号确定本次任务使用的版本。

## 3. 交给配置准备阶段

读取选中版本的模型、提示词、工具、技能和插件配置，继续合并用户设置与本次请求配置，并检查授权。

Agent 的启用状态、版本的发布状态和任务的执行状态分别描述不同对象，不能混为一谈。
