# 继续任务

用户向已有 Task 发送新消息，创建新的平台 Session，按条件恢复引擎对话并启动执行。代码中的任务恢复入口称为 resumeTask。

## 1. 适用条件

上一轮正常完成、停止或失败后都可以继续，前提是任务产物仍可用、没有 running Session，且配置与授权校验通过。Stop 请求已返回不保证 Session 已进入终态。

Continue 新建平台 Session；引擎 Resume 恢复已有对话。二者可以在同一次请求中同时发生，不是依据上一轮成功或失败来选择。

## 2. 执行流程

从[接收继续任务请求](ReceiveMessage.md)开始，沿每一步的下一步链接阅读：

```text
接收继续任务请求
  → 获取任务锁
  → 查询已有任务
  → 检查运行中的执行轮次
  → 查询上一轮 Session
  → 解析配置并检查授权
  → 准备本轮提示词
  → 查找引擎会话标识
  → 创建新 Session
  → 登记回调与开始通知
  → 更新任务状态
  → 异步提交远程执行
  → 调度本轮执行
  → 恢复文件并准备环境
  → 启动引擎并恢复对话
  → 回传结果与执行收尾
```

## 3. 与首次发起的区别

不创建新 Task；新 Session 关联已有 Task 与上一轮 Session。发布模式保留原版本绑定，草稿模式可读取最新草稿。后续提交、调度、运行与收尾复用共用能力，文档在对应步骤链接现有说明。
