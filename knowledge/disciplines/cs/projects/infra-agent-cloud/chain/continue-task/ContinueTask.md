# 继续任务

用户向已有 Task 发送新消息，补充信息或提出后续要求，启动新一轮执行。对应 Continue / Resume。

## 1. 操作含义

沿用已有 Task，创建新的 Session。适用时恢复底层引擎会话，延续之前的对话与任务文件；恢复会话并不等于恢复旧进程。

如果已有任务绑定 Agent 版本，继续时沿用其绑定版本，不因默认版本变化而直接切换。

## 2. 链路范围

```text
接收已有任务的新消息
  → 查询任务并校验继续条件
  → 解析适用配置与授权
  → 创建新一轮 Session
  → 准备恢复输入
  → 调度并执行
  → 回传结果并更新状态
```

这是学习入口的阶段概览；具体分支与逐步存储操作后续展开。

## 3. 与其他操作的区别

Start 创建新 Task 和首轮 Session；Continue 沿用 Task 并新建 Session。执行中的追加指令属于 Steer，不能把所有新消息都理解为创建新一轮执行。
