# 解析配置并检查授权

## 1. 处理内容

关联 Agent 时，重新解析适用版本及模型、提示词、MCP、技能、环境变量等配置，并合并本次请求允许注入的内容。版本主体见 [AgentVersion](../../storage/mysql/agent-version/AgentVersion.md)。

发布模式使用已有版本绑定；草稿模式按请求读取最新草稿，不能把所有 Continue 都理解为重新选择默认版本。

解析运行配置并检查引擎、模型家族兼容性，准备版本产物、运行时注入与插件配置，检查适用的认证和模型密钥。预检查分支在这些校验后返回，不创建 Session。
