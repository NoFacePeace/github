# 认领回执并保存指令

## 1. 处理内容

按回执 Session 标识和 messageId 创建或认领 MySQL 持久化投递回执，判断本请求是否拥有投递权。其他请求已认领时，按已有回执返回结果。

同时在 [Session 扩展信息](../../storage/mysql/session/ExtraInfo.md)中保存追加指令记录，含提示词、来源、创建者、时间和投递状态等。持久化回执与扩展信息镜像是两类记录，不是 Executor 的内存去重表。

有投递能力时进入发送；尚未就绪时记录 queued，并按条件告知调用方可在就绪后重试。记录写入失败时还会调整适用回执状态，不能直接当作已发送。

## 2. 分支处理

未就绪、明确拒绝和超时不确定分别按[处理未送达与不确定结果](HandleDeliveryFailure.md)处理，不能统一立即重发。

## 3. 后续流程

正常路径进入[发布追加指令命令](PublishSteerCommand.md)。
