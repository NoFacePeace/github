# 执行中追加指令

在任务仍在执行时，将新指令交给当前运行中的引擎，对应 Steer。需要执行模式和引擎句柄支持。

## 1. 操作含义

成功送达当前执行时，由当前 Session 继续处理，不为这条指令立即创建新的 Session。与执行结束后通过 Continue 启动新一轮执行不同。

## 2. 链路范围

```text
接收执行中的新指令
  → 判断当前执行是否支持追加输入
  → 定位当前执行与控制通道
  → Runtime 将控制命令交给 Executor
  → Executor 调用引擎交互能力
  → 返回命令回执并持续回传输出
```

不支持、执行已结束或送达状态不确定时，需要按调用方的分支处理，不能默认所有消息都已经交给当前引擎。

## 3. Executor 侧处理

具体的命令去重、引擎调用和回执行为见[处理追加输入](../start-task/executor/consume-engine-output/HandleControlInput.md)。该处理能力可以被不同任务入口复用。
