# 停止准备或运行中的执行

## 1. 处理内容

根据本轮状态分别处理：

- 尚未登记活动执行：在内存中记录待停止标记，并中止匹配的执行准备控制器。
- 已登记执行但租约不匹配：忽略旧执行命令。
- 正在执行且未进入收尾：调用 Runtime 停止能力。
- 已在收尾：不重复停止，等待本轮完成。

这些准备标记与活动句柄保存在 Runner 内存，不是新增 MySQL 表。启动流程也会检查待停止标记，避免准备与停止并发时漏停。

## 2. 后续流程

活动进程需要[停止执行进程](StopExecutionProcesses.md)；准备中被中止的执行走适用失败、停止和收尾路径，不假设已经创建了引擎进程。
