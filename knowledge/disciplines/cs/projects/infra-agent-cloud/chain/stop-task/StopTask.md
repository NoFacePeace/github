# 停止任务

用户要求终止任务执行，对应 Stop。接口支持按 Task 停止，也支持指定某个 Session 停止。

## 1. 操作含义

停止针对当前执行生命周期，不等于删除 Task、Session 或历史对话。处理方式取决于请求仍在排队、准备执行，还是已经运行。

## 2. 链路范围

```text
接收停止请求
  → 校验操作权限并定位执行轮次
  → 根据执行阶段取消排队或通知运行中的执行节点停止
  → 处理停止结果与状态
  → 清理适用的租约和执行资源
```

这是阶段概览；状态更新顺序、取消与派发的并发处理、停止信号及存储操作需在细节链路中分别确认。

## 3. 学习重点

区分业务停止状态、调度队列取消和实际引擎进程退出。请求已被接收，不等于执行进程已经完成退出与资源清理。
