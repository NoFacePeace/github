# Infra Agent Cloud

Infra Agent Cloud 是面向基础设施工作的 Agent 云平台，目标是让用户通过自然语言委托任务，由 Agent 在云端执行，并交付可审阅、可继续修改的结果。

## 1. 项目定位

平台围绕任务的完整执行过程组织能力：用户描述目标、提供上下文与工具权限，Agent 规划步骤、获取信息、调用工具并检查结果；用户可以查看进度、补充信息、调整方向，并审批关键操作。

拟用仓库名为 `infra-agent-cloud`。

## 2. 能力规划

以下为初步规划，具体范围与实现方案待后续设计明确：

- 任务与会话：保存目标、执行状态和上下文，支持追问、调整与继续执行。
- 云端运行环境：为任务提供隔离的执行空间，管理计算资源、依赖与生命周期。
- 工具与上下文：接入文件、知识库、MCP 服务及基础设施工具，按授权获取信息和执行操作。
- 成果交付：保存分析报告、文档、脚本等产物，支持审阅与迭代。
- 执行控制：提供进度展示、取消、权限控制、关键操作审批及审计记录。
- 持续任务：支持定时执行、状态监控和满足条件时通知用户。

## 3. 产品参考

OpenAI 将 ChatGPT Work 定位为把实际工作委托给 ChatGPT 的方式，强调明确的任务目标、多步骤执行，以及可供用户审阅和使用的成果。网页版在托管云环境中运行，桌面端在功能可用时也支持本地工作。

该产品可作为任务交互与成果交付体验的参考；本项目的领域范围、架构与实现需独立设计。
