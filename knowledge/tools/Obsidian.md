# Obsidian

Obsidian 是一款以本地 Markdown 文件为基础的笔记与知识管理工具。它通过双向链接、反向链接和关系图谱连接笔记，帮助整理知识并发现内容之间的关联。笔记以普通文件保存在本地，便于备份、迁移和版本管理，还可以通过插件与主题扩展功能和调整界面。

## 1. 概念

| 概念 | 含义 | 存储格式 | 示例 |
| --- | --- | --- | --- |
| 笔记（Note） | 一篇文档，用来记录具体内容 | `.md` | `Obsidian.md` |
| 白板（Canvas） | 可以摆放文字卡片、笔记、图片，并用连线展示关系的画布 | `.canvas` | 梳理知识关系、绘制流程 |
| 数据库（Base） | 根据笔记属性，以表格、卡片等视图汇总笔记，支持筛选和排序 | `.base` | 将带有 `tools` 标签的笔记整理为工具清单 |
| 仓库（Vault） | Obsidian 打开的文件夹，包含笔记、白板、附件和配置 | 普通文件夹 | 将 `knowledge` 作为一个仓库打开 |

数据库由核心插件 Bases 提供。数据仍保存在 Markdown 笔记及其属性中，`.base` 文件保存的是视图配置。

仓库容纳所有内容，笔记记录内容，白板展示关系，数据库按属性汇总内容。Obsidian 仓库与 Git 仓库是不同的概念，但同一个文件夹可以同时作为两者使用。

## 2. 快捷键

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 打开命令面板 | `⌘ + P` | `Ctrl + P` |
| 后退：返回上一个浏览位置 | `⌘ + ⌥ + ←` | `Ctrl + Alt + ←` |
| 前进：前往下一个浏览位置 | `⌘ + ⌥ + →` | `Ctrl + Alt + →` |

可以在「设置 → 快捷键」中搜索“后退”或“前进”，查看或修改对应的快捷键。

## 3. 命令

命令用于执行 Obsidian 中的具体操作。按 `⌘ + P`（macOS）或 `Ctrl + P`（Windows / Linux）打开命令面板，输入命令名称进行搜索，再选择执行。

| 命令 | 用途 |
| --- | --- |
| 打开局部关系图 | 以当前笔记为中心，查看与它关联的笔记 |
