# ChatGPT

ChatGPT 是 OpenAI 提供的 AI 工具，可通过自然语言进行问答、写作、资料研究、文件分析和任务执行。

信息核对日期：2026 年 10 月 9 日。以下依据 OpenAI 官方文档整理；具体功能以账户、订阅方案和工作区设置为准。

## 1. 使用方式

| 方式 | 适合的任务 | 示例 |
| --- | --- | --- |
| Chat | 问答与多轮讨论 | 解释概念、整理思路、比较方案、修改文稿 |
| ChatGPT Work | 执行有明确成果的多步骤任务 | 研究报告、文件分析、文档和演示文稿制作 |
| Codex | 使用开发工具处理技术任务 | 修改代码、排查错误、运行测试、审查改动 |

Work 与 Codex 的能力存在重叠。Codex 也可处理研究和文档任务，两者的界面与结果呈现侧重点不同。

## 2. 任务与上下文

使用时说明目标、提供必要文件和背景，并按需要接入搜索、项目或插件。任务过程中可以补充信息和调整方向，完成后检查结果。

Work 可以在云端环境执行；桌面应用在相应能力启用时，还可以使用本地文件、应用和浏览器。
