# 游泳

## 1. 零基础学习顺序

先建立水中呼吸、平衡和安全停止的能力，再逐步学习泳姿，不以第一次能游多远为目标。

| 阶段 | 学习内容 | 阶段目标 |
| --- | --- | --- |
| 熟悉水 | 安全出入水、扶池边移动、让脸逐渐接触水 | 能平静地把脸放进水里 |
| [呼吸](Breathing.md) | 嘴露出水面吸气，脸入水后缓慢吐气 | 能反复换气，不靠一直憋气 |
| 漂浮与站起 | 在教练辅助下练习俯漂、仰漂，以及收腿恢复站立 | 漂起后知道如何停止并站稳 |
| 滑行 | 在教练保护下练习身体伸展和短距离蹬壁滑行 | 保持平衡，并能控制停止 |
| 泳姿配合 | 分别练习腿部、手部动作，再加入呼吸 | 能边游边换气，而非憋气冲刺 |

具体进度由教练根据实际表现调整。第一次练习可以先以敢把脸入水、能在水里吐气、在辅助下漂起后站稳为目标。

## 2. 阶段衔接与最低进阶要求

### 2.1 是否必须完成上一阶段

不需要把每个阶段练到完美才进入下一阶段。这些阶段代表学习重点的顺序，不是严格的考试关卡；表格中的阶段目标是逐渐建立的能力，而非必须全部达标才能接触下一项。

- 熟悉水与呼吸可以一起练，不必等到完全不怕水才开始吐气。
- 呼吸与漂浮可以交替练，学习泳姿时也要继续巩固基础。
- 手脚分解动作可以在辅助下提前练习；是否减少辅助、增加滑行或游动距离，由教练根据控制能力决定。
- 加入新动作后，如果开始慌乱、一直憋气或动作失控，应降低难度，回到基础练习。

**动作不够熟练，可以在辅助下继续学；不知道如何安全停止，就不应自行增加难度。**

### 2.2 最低进阶检查表

以下是供学习者与教练参考的保守检查表，不是官方考核标准，也不是统一的秒数或距离要求。适用于有教练保护、能够站稳且口鼻露出水面的浅水区；教练可根据个人情况调整辅助方式与学习顺序。

| 准备进入 | 建议先具备的最低能力 |
| --- | --- |
| 呼吸练习 | 能扶稳池边、站稳，愿意让口鼻短暂入水；不要求完全不怕水 |
| 漂浮练习 | 能把脸入水并吐气，再抬头吸气，不因脸入水而立即慌乱 |
| 蹬壁滑行 | 能从俯漂收腿、双脚落地并恢复站立；还不会时，只在教练直接辅助下尝试 |
| 泳姿配合 | 能短距离滑行后主动停下、恢复站立；手脚分解动作可提前在辅助下练 |
| 增加连续游动距离 | 能在动作中换气，疲劳或失去节奏时知道如何停止、站稳或扶住池边 |

判断重点不是偶尔成功一次，而是能重复做到，并知道动作失败时如何安全结束。减少辅助或增加难度前，应由教练观察确认。

### 2.3 与深水区能力的区别

满足上述检查项，不代表可以进入深水区。浅水区的恢复站立依赖能够踩到池底，不能替代深水中的漂浮、踩水和自主返回池边能力。

不能只凭会一种泳姿判断深水区能力；完整的水中基本能力还包括浮起或踩水、转向、游向出口和安全出水。

## 3. 安全注意事项

- 找有资质的游泳教练，在有救生员的泳池学习；初期选择能稳稳站立且口鼻露出水面的浅水区。
- 不独自练习，不直接进入深水区或江河湖海。
- 不练极限憋气，不在憋气前连续快速深呼吸。
- 漂浮、转向、返回池边和出水，应与泳姿一起学习。
- 在泳池里能够游一段距离，不代表具备开放水域的游泳能力。

## 4. 入门目标

除了能游动，还应逐步掌握控制呼吸、漂浮或踩水、转身找到池边、返回安全位置并出水的能力。

## 5. 相关网站

以下均为英文资源，分别侧重学习体系、水上安全与水中基本能力，并非都是泳姿教学网站。

| 网站与页面 | 主要内容 | 适合查阅的问题 |
| --- | --- | --- |
| [Swim England：Learn to Swim](https://www.swimming.org/learntoswim/) | 儿童与成人游泳学习体系、分级目标及课程信息 | 从零开始学什么、如何理解学习阶段 |
| [STA：Adult Series](https://www.sta.co.uk/international-learn-to-swim-programme/additional-programmes/adult-series/) | 成人游泳课程 Adult 1–4 的分阶段学习目标，涵盖呼吸、漂浮、踩水与泳姿 | 如何参考课程目标判断漂浮等技能的进度 |
| [美国红十字会：Water Safety](https://www.redcross.org/get-help/how-to-prepare-for-emergencies/types-of-emergencies/water-safety.html) | 水上安全、防溺水与游泳学习相关资源 | 下水前需要注意哪些安全事项 |
| [Water Safety USA：Water Competency](https://www.watersafetyusa.org/water-competency.html) | 水中基本能力的组成，以及游泳技能与水上安全的关系 | 为什么会一种泳姿不等于具备完整的水中安全能力 |

成人入门可进一步查看 Swim England 的 [Adult Swimming Awards](https://www.swimming.org/learntoswim/swim-england-awards-badges-certificates/adult-awards/) 专区。

STA 的漂浮目标示例：Adult 2 要求俯漂或仰漂 5 秒，该阶段未另行说明的项目允许使用浮具；Adult 3 要求任意姿势漂浮 10 秒，该项目不允许使用浮具。两者均允许轻轻划手维持姿势。这些是该课程的阶段目标，不是通用的合格标准，也不能当作俯漂憋气时长任务。

这些资源用于辅助理解，不能替代现场教学与保护；本文的最低进阶检查表是保守整理，不是上述机构发布的统一考核标准。
