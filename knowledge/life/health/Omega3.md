# Omega-3

## 1. 简介

Omega-3（ω-3）是一类多不饱和脂肪酸，是细胞膜的重要组成部分，参与神经系统、视网膜及炎症反应等生理过程。常见类型包括 ALA、EPA 和 DHA。

| 类型 | 中文名称 | 主要食物来源 |
| --- | --- | --- |
| ALA | α-亚麻酸 | 亚麻籽、奇亚籽、核桃、菜籽油等 |
| EPA | 二十碳五烯酸 | 三文鱼、沙丁鱼、鲭鱼等富脂鱼类 |
| DHA | 二十二碳六烯酸 | 富脂鱼类及部分藻类 |

ALA 是人体无法自行合成的必需脂肪酸，需要从饮食中获取。人体可以将部分 ALA 转化为 EPA 和 DHA，但转化效率有限，因此植物来源的 ALA 不能完全等同于直接摄入 EPA 和 DHA。

## 2. 获取与补充

日常可通过鱼类、坚果和种子等食物获取 Omega-3。鱼油通常提供 EPA 和 DHA，藻油可提供 DHA，部分产品也含 EPA。

选择补充剂时，应关注每份 **EPA 和 DHA 的实际含量**，而不只看鱼油总重量。例如，标注「鱼油 1,000 mg」并不代表含有 1,000 mg 的 EPA 和 DHA。

Omega-3 补充剂并非人人必需，其作用取决于饮食状况、剂量和具体健康问题。处方级高剂量 Omega-3 可用于降低甘油三酯，但普通补充剂不能替代相关治疗，也不能保证预防心血管疾病。

## 3. 每日参考摄入量

对于健康成年人，EPA 和 DHA 的常见日常参考摄入量为每天合计 **250–500 mg**，包括食物和补充剂提供的量，并非必须额外补充的剂量。不同机构的建议有所差异，目前没有统一的 EPA 和 DHA 每日推荐摄入量。

- 每周吃约 **2 次鱼，其中包含富脂鱼类**，通常可以优先通过饮食获取。
- 很少吃鱼时，可考虑每天补充 **250–500 mg EPA + DHA**，并结合实际饮食摄入调整。
- 计算补充剂剂量时，将标签上的 EPA 和 DHA 含量相加，并核对每份包含几粒。例如，每粒含 EPA 180 mg、DHA 120 mg，合计为 300 mg。
- 降低甘油三酯使用的 **2–4 g/天 EPA + DHA** 属于治疗剂量，应由医生根据具体制剂和病情指导使用。

植物来源的 ALA，成人适宜摄入量为男性约 **1.6 g/天**、女性约 **1.1 g/天**。ALA 不能按同等重量替代 EPA 和 DHA。以上日常参考量适用于一般健康成年人；儿童、孕期及哺乳期等人群需采用相应建议。

## 4. 注意事项

- 补充剂可能引起鱼腥味打嗝、恶心或腹泻等不适。
- 高剂量补充在部分人群中可能增加房颤风险，不宜自行长期大量服用。
- 正在使用抗凝或抗血小板药物、有房颤病史，或计划使用高剂量补充剂时，应先与医生讨论。
- 鱼肝油与普通鱼油不同，还可能含较多维生素 A 和 D，使用时需关注这些成分的总摄入量。
