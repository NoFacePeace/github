# Configuration

## 1. Server

以下按职责整理配置项及代码默认值；建议值单独标注，不记录实际部署的连接地址、凭据或资源标识。

| 分类 | 配置项 | 值 | 说明 |
| --- | --- | --- | --- |
| Scheduler | 排队调度超时 | 10 分钟 | 未指定 Deadline 时，从入队时间计算截止时间 |
| Scheduler | 调度与恢复扫描间隔 | 30 秒 | 定期恢复 Session 并扫描待调度 Job；唤醒通知可提前触发调度 |
| Scheduler | 调度器异常重启等待 | 1 秒 | 调度循环发生异常后等待重启 |
| Scheduler | 调度锁有效期 | 30 秒 | 限制单条 Job 的调度处理权，初次领取和续约保持一致 |
| Scheduler | 调度锁续期间隔 | 10 秒 | 调度过程中保持锁有效，应小于锁有效期 |
| Scheduler | 单次调度锁续约超时 | 10 秒 | 限制单次续约请求耗时 |
| Execution | 执行租约有效期 | 5 分钟 | 预占执行资格和 Runner 容量 |
| Execution | 执行租约续约间隔（Runner 侧） | 尚未实现；建议为剩余有效期的 1/3 | 首次执行前立即确认，5 分钟有效期下正常约为 100 秒，预留失败重试时间 |
| Execution | Session 启动宽限期 | 5 分钟 | 恢复扫描判断无有效租约的会话是否已超过启动宽限期 |
| Execution | 恢复扫描分页大小 | 100 条 | 每页查询的恢复候选数量 |
| Execution | 补偿超时 | 5 秒 | 限制入队失败后的状态收尾、调度锁释放等操作耗时 |
| Redis | 连接参数 | 由外部注入 | 地址、认证、数据库编号、超时和连接池等由部署配置提供，本文不保存实际值 |
| Redis | key 命名空间 | 代码中固定，具体值省略 | 隔离业务数据，不记录具体项目前缀或实际 key |
| Redis | 调度记录收尾保留时间 | 24 小时 | 确认调度结束后设置 TTL，排队中的记录不使用该期限 |
| Redis | 发布去重标记保留时间 | 24 小时与租约剩余有效期的较大值 | 覆盖投递重试窗口及有效租约期限 |
| Redis | Runner Job Stream 长度目标 | 10,000 条 | 使用 XADD MAXLEN 近似裁剪，实际长度可能超过目标值 |

执行租约续约由 Runner 发起，续约间隔属于 Runner 配置，此处列出其与租约有效期的关系；与 Scheduler 中的调度锁续约间隔相互独立。

引擎、模型和系统提示词属于 Agent 版本配置；Runner 并发上限属于节点配置，不纳入 Server 全局执行配置。
