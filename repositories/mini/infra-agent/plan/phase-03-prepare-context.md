# 阶段 03：准备运行上下文

## 1. 业务流程

```text
launch → 解析工作区 → 解析模型连接和能力
→ 构造系统指令与用户消息 → 保存用户消息 → 生成运行输入
```

依赖阶段 02。先处理当前输入，历史、附件和摘要在阶段 08 增加。

## 2. 工作区与模型选择

- [ ] P03-01 【工作区】选择已有目录或创建内置目录，在此处加入需要的 Workspace 类型与路径约定。
- [ ] P03-02 【配置】补充数据目录和默认工作区值，校验目录存在性与访问条件。
- [ ] P03-03 【模型选择】从请求或默认值解析供应商和模型标识，获取连接参数，失败时终止启动。
- [ ] P03-04 【配置】随解析功能加入端点、密钥来源和默认模型，日志及响应隐藏密钥。

## 3. 消息与记录

- [ ] P03-05 【上下文】定义本步骤需要的 system／user 消息，组装基础系统指令和当前用户输入。
- [ ] P03-06 【记录】确定 Run 的 JSONL 路径、格式版本及稳定标识，实际保存用户消息。
- [ ] P03-07 【任务服务】记录初始化失败时标记运行失败，不进入模型调用。

## 4. 传递运行输入

- [ ] P03-08 【上下文】生成包含消息与模型设置的运行输入，业务表查询留在外层。
- [ ] P03-09 【应用装配】在 launch 中调用准备逻辑，向后续执行传入输入和模型依赖。

## 5. 验收事项

- [ ] P03-10 【验收】指定和默认工作区均能生成正确目录及运行输入。
- [ ] P03-11 【验收】重试准备不会重复追加同一条用户消息。
- [ ] P03-12 【验收】模型未配置、目录非法或记录失败时，Run 以可查询错误结束。
