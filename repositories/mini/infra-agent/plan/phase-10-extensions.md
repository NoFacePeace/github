# 阶段 10：扩展与产品能力

## 1. 目标与前置

基于已验收的核心服务按需交付扩展，不要求一次完成本阶段全部模块。各扩展沿用统一策略、取消和记录链路。

## 2. 工具与能力扩展

- [ ] P10-01 Skills：实现发现、描述注入、按需读取及资源路径限制，不将技能内容视为额外权限。
- [ ] P10-02 MCP：接入 HTTP 或 stdio 连接器，处理工具发现、命名冲突、参数 Schema、超时、取消和网络策略。
- [ ] P10-03 搜索与网页读取：实现目标访问限制、重定向检查、响应大小限制和正文提取。
- [ ] P10-04 记忆与知识检索：明确作用域、来源、更新与删除，检索内容按外部数据处理。
- [ ] P10-05 专用 Git 工具：如需增加状态、差异和提交工具，明确其命令执行与沙箱路径，避免与 bash 权限出现不一致。

## 3. 调度与产品接口

- [ ] P10-06 定时任务和 webhook：实现触发记录、去重、并发限制及失败重试，沿用 Task／Run 创建入口。
- [ ] P10-07 实现任务删除／归档、工作区管理、文件和产物查看、供应商及模型管理接口。
- [ ] P10-08 实现用户策略、审批授权和敏感配置的管理权限及变更记录。
- [ ] P10-09 增加流式模型输出，只有完整的工具调用参数才能进入执行，断流不能误记为完成。

## 4. 界面与观测

- [ ] P10-10 提供任务列表、对话、执行状态、事件和工具详情、取消、审批及补充输入界面。
- [ ] P10-11 客户端按事件游标重连，去重显示；明确区分正在取消、已取消和等待审批。
- [ ] P10-12 展示工作区文件与修改历史，支持定位工具对应的执行产物。
- [ ] P10-13 汇总模型用量、请求延迟、工具失败、等待时长、裁剪次数和恢复结果。

## 5. 验收事项

- [ ] P10-14 每个扩展至少提供一次正常使用和一次失败／取消演示。
- [ ] P10-15 外部工具断连、网页超限、流式中断不破坏核心消息、状态和恢复能力。
- [ ] P10-16 管理界面和 API 的资源访问权限一致，敏感配置不通过事件、错误或页面泄露。
- [ ] P10-17 根据实际使用确定后续优先级；每次只启用已通过验收的扩展。
