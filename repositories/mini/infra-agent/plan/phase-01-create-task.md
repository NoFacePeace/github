# 阶段 01：创建任务

## 1. 业务流程

```text
POST /v1/tasks → 校验目标 → 生成 Task ID → 保存 Task → 返回任务
GET /v1/tasks/{id} → 查询 Task → 返回详情或不存在
```

暂无前置阶段。先完成任务创建与查询，本阶段不自动启动模型执行。

## 2. 接口入口

- [ ] P01-01 【API】注册创建和详情路由，接收 `goal`，约定响应字段。
- [ ] P01-02 【Handler】校验目标非空及长度，参数错误返回 400，不存在返回 404。

## 3. 创建与保存

- [ ] P01-03 【任务服务】实现 Create，按本步骤需要定义 Task、请求类型及 ID 生成规则。
- [ ] P01-04 【存储】补充创建和按 ID 查询的最小接口，实现 SQLite 表、迁移和唯一约束。
- [ ] P01-05 【应用装配】将实际 Store 注入 Service，将 Service 注入 Handler，完成请求到数据库的接线。
- [ ] P01-06 【配置】提供本步骤必需的监听地址和数据库位置并校验，其余配置随后续流程加入。

## 4. 返回与查询

- [ ] P01-07 【Handler】创建成功返回 201 和 Task ID，存储失败不能返回成功。
- [ ] P01-08 【任务服务】实现详情查询，保持 ID、目标和创建时间等已返回字段稳定。

## 5. 验收事项

- [ ] P01-09 【验收】用 HTTP 创建任务，再按 ID 查询到相同目标。
- [ ] P01-10 【验收】关闭并重启服务后，任务仍可查询。
- [ ] P01-11 【验收】验证空目标、不存在 ID、数据库失败和重复 ID。

## 6. 当前步骤边界

模型配置、Run 状态、工具注册、审批表和完整配置覆盖机制不作为本阶段前置条件。需要的最小类型随创建请求链路引入。
