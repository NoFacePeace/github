# 阶段 05：文件与命令工具

## 1. 目标与前置

依赖阶段 04，交付 M2。在临时工作区完成实际文件修改与命令任务。人工审批在阶段 06 引入；本阶段仅允许配置已明确放行的操作，其余操作拒绝。

## 2. 工作区与文件访问

- [ ] P05-01 统一解析相对路径、绝对路径和符号链接，校验工作区与授权目录的真实边界。
- [ ] P05-02 定义读取、写入权限，拒绝目录穿越、只读目录写入和不受支持的文件类型。
- [ ] P05-03 实现 `read`、`list_dir`、`glob`、`grep`，限制文件大小、结果数量和超时。
- [ ] P05-04 实现 `write`、`edit`、`apply_patch`，支持文件模式保留、修改摘要与结构化错误。
- [ ] P05-05 读取返回内容哈希，覆盖已有文件要求预期哈希；修改前重新校验。
- [ ] P05-06 采用同目录临时文件加替换的写入方式；本进程按规范化路径协调“读取／校验／写入”。
- [ ] P05-07 明确并发保障范围：普通路径锁不阻止外部编辑器和任意 Shell 修改；多执行器优先隔离工作目录，不宣称哈希检查等于原子比较写入。

## 3. 命令执行与沙箱

- [ ] P05-08 定义命令执行接口，接收命令、工作目录、环境、网络许可及超时。
- [ ] P05-09 首先接入一个实际部署平台的可用隔离后端，限制文件读写和网络访问。
- [ ] P05-10 沙箱不可用时返回明确错误；允许无隔离执行必须是显式配置，不静默降级。
- [ ] P05-11 实现 `bash` 工具，限制输出，取消／超时时终止进程组或容器内对应执行，避免残留子进程。
- [ ] P05-12 实现用户工具策略与基本风险检查；所有工具都检查硬性禁止规则，工具要求审批不能绕过禁止。

## 4. 记录与产物

- [ ] P05-13 大结果完整保存，给模型返回受限内容及可定位的产物引用。
- [ ] P05-14 文件修改记录变更前后哈希和工具调用 ID；失败发生在实际修改之后时，明确反馈副作用已经发生。

## 5. 验收事项

- [ ] P05-15 在临时仓库完成“读取 → 修改 → 运行测试 → 回答”，核对文件和执行记录。
- [ ] P05-16 验证越界、符号链接、哈希冲突、重名临时文件、输出超限和命令取消。
- [ ] P05-17 实测沙箱内只读和禁止联网限制；测试针对实际部署后端运行。
