# 阶段 05：执行工具并继续循环

## 1. 业务流程

```text
模型返回工具调用 → 保存助手消息 → 查找工具并校验参数
→ 检查权限 → 保存 tool_started → 执行 → 保存 tool_result
→ 追加工具结果消息 → 再次调用模型 → 最终回答
```

依赖阶段 04。先用简单工具接通循环，再接入文件和命令。人工审批在阶段 07 引入，本阶段仅允许配置明确放行的操作，其余拒绝。

## 2. 接通工具分支

- [ ] P05-01 【模型适配】在请求加入工具定义，解析一个或多个工具调用，保留调用 ID 和原始参数。
- [ ] P05-02 【工具注册】在首个工具实际使用处定义名称、描述、Schema、风险及执行方法，拒绝重名注册。
- [x] P05-03 【工具执行器】使用成熟 Schema 库校验参数，未知工具和普通执行错误返回工具结果，基础设施故障终止运行。
- [x] P05-04 【Loop】先串行执行一批工具，按调用 ID 追加结果再调用模型；等待与完成使用明确契约。
- [x] P05-05 【配置／Loop】引入 MaxSteps，按模型调用次数计步，最后一步禁用工具；无最终回答则明确失败。
- [ ] P05-06 【验收】用无外部副作用的简单工具完成多轮交互，覆盖多个调用、错误参数、未知工具和步数耗尽。

## 3. 接入文件操作

- [ ] P05-07 【文件访问】统一解析路径和符号链接，按真实边界校验读写、目录穿越和文件类型。
- [ ] P05-08 【工具】实现 `read`、`list_dir`、`glob`、`grep`，限制文件大小、结果数量和超时。
- [ ] P05-09 【工具】实现 `write`、`edit`、`apply_patch`，保留文件模式并返回修改摘要及结构化错误。
- [ ] P05-10 【文件访问】读取返回哈希，覆盖前检查预期哈希；同目录临时文件替换，本进程按规范化路径协调校验和写入。
- [ ] P05-11 【文件访问】明确锁不阻止外部编辑器或任意 Shell 修改，多执行器优先隔离目录，不把哈希校验当成原子比较写入。

## 4. 接入命令与权限检查

- [ ] P05-12 【工具执行器】统一检查风险、工具和资源策略，随实际判断加入配置；硬性禁止不能被工具声明覆盖。
- [ ] P05-13 【沙箱】接收命令、目录、环境、网络许可和超时，接入一个实际部署平台的隔离后端。
- [ ] P05-14 【沙箱】后端不可用明确失败，无隔离执行必须显式配置；验证只读及网络限制。
- [ ] P05-15 【工具】接入 `bash` 并限制输出，超时或 Context 取消终止进程组或容器内对应执行。

## 5. 保存结果与产物

- [ ] P05-16 【记录】大结果完整保存，给模型返回受限内容和产物引用，结果保存成功后才进入下一轮。
- [ ] P05-17 【记录】记录修改前后哈希和调用 ID，修改后发生错误时明确说明副作用已经发生。

## 6. 验收事项

- [ ] P05-18 【验收】在临时仓库完成“读取 → 修改 → 测试 → 反馈模型 → 回答”，核对文件和日志。
- [ ] P05-19 【验收】覆盖越界、符号链接、哈希冲突、临时文件冲突、输出超限与命令超时。
- [ ] P05-20 【验收】在阶段 06 接入 HTTP 取消前，先验证工具自身响应 Context 取消且无残留子进程。
