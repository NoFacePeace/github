# 阶段 07：上下文管理

## 1. 目标与前置

依赖阶段 04、06，交付 M3。支持历史与附件输入，预算超限时通过裁剪或摘要继续执行。

## 2. 上下文构建与附件

- [ ] P07-01 外层加载系统指令、当前输入、历史根 Run 和检查点，向 Loop 传入可直接使用的消息。
- [ ] P07-02 区分新 Run 与恢复同一 Run，恢复时不重复追加原用户消息。
- [ ] P07-03 实现附件上传、元数据、Run 关联与清理，校验大小及类型。
- [ ] P07-04 将附件说明合入用户消息；按模型能力加入图片等内容，不支持时提供明确说明。

## 3. Token 预算与估算

- [ ] P07-05 外层根据模型上下文窗口和预算比例计算输入预算，校验与输出预留及协议开销的关系。
- [ ] P07-06 请求估算包含消息正文、推理字段、工具调用、工具结果和工具定义，明确图片等特殊内容的估算边界。
- [ ] P07-07 实现可配置的 ASCII／非 ASCII 粗估，缺少供应商实际用量时使用粗估。
- [ ] P07-08 在 Run 内保存前次粗估、对应实际用量及最大校准比例，增量预测本次请求，不能混用不同请求的估算和实际用量。

## 4. Loop 内裁剪

- [ ] P07-09 达到配置阈值后依次处理重复工具结果、旧计划、过大结果与可删除历史块。
- [ ] P07-10 保护系统指令、当前用户输入和必要的近期消息，按完整调用／结果块删除。
- [ ] P07-11 按字节保留目标裁剪，随后按完整请求重新预测；仍超限时明确失败，不无限重试。
- [ ] P07-12 保留完整持久化事实，仅改变发给模型的上下文，并记录裁剪前后大小及删除统计。

## 5. 跨 Run 历史摘要

- [ ] P07-13 新 Run 启动前统计既有摘要和未覆盖的历史根 Run 消息，超过阈值时触发摘要。
- [ ] P07-14 保留最近一段原文，将较早内容合并已有摘要进行总结；参数单位和估算口径明确。
- [ ] P07-15 设置摘要输入预算与输出上限，保存摘要、保留起点和消息偏移，避免重复摘要或跳过历史。
- [ ] P07-16 摘要失败时保持旧检查点有效，不写入不完整游标；摘要内容按历史数据处理，不提升为系统指令权限。

## 6. 验收事项

- [ ] P07-17 验证中英文、工具定义、长工具结果、图片、连续裁剪和摘要边界。
- [ ] P07-18 多个 Run 连续对话后能加载“摘要＋保留原文＋当前输入”，不重复拼接历史。
- [ ] P07-19 裁剪和恢复后，请求中的工具调用与结果始终完整配对。

## 7. 初始参数参考

以配置文档为配置项索引。初始可参考预算比例 85%、触发比例 80%、Loop 字节保留比例 50%、历史原文保留约 16,000 Token；摘要输出可先采用 2,048 Token。上述参数是起点，需要按模型窗口和任务验证，不能只比较不同单位的百分比。
