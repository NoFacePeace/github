# 阶段 06：审批与暂停恢复

## 1. 目标与前置

依赖阶段 04、05。任务可以等待用户批准或补充输入，再准确继续尚未完成的工具调用。

## 2. 策略与授权

- [ ] P06-01 定义工具审批要求、用户工具策略、联网策略、路径策略以及人工／策略／自动审批模式。
- [ ] P06-02 统一先评估禁止规则，再合并工具要求和资源权限，禁止决定不能被自动审批或复用授权覆盖。
- [ ] P06-03 用结构化权限需求表达工具授权、联网和路径读写，避免从风险原因字符串推断审批类型。
- [ ] P06-04 定义工具匹配键与单次／Run／工作区范围；网络按 Run 授权，路径按目录覆盖和读写授权。
- [ ] P06-05 分别满足本次实际缺少的权限，已有工作区基础权限不重复审批，工具授权不能代替缺少的联网或路径授权。
- [ ] P06-06 明确自动审批例外，默认保留未授权联网的人工确认；配置和 UI 说明保持一致。

## 3. 审批与输入存储

- [ ] P06-07 持久化审批请求、决定、原因和范围，以 Run ID、工具调用 ID 关联并避免重复创建。
- [ ] P06-08 条件提交待决定请求，在同一事务内保存决定、生成授权和记录业务事件，禁止重复决定覆盖。
- [ ] P06-09 实现 `ask_user` 请求、用户回答及输入等待状态。
- [ ] P06-10 取消或终态转换时使未完成请求失效；审批、输入和恢复接口拒绝继续已取消 Run。

## 4. 执行恢复与 API

- [ ] P06-11 实现审批决定、运行输入提交和继续执行接口，协调重复提交与同时恢复。
- [ ] P06-12 等待时不产生伪造工具结果；恢复时重建消息并定位未完成调用。
- [ ] P06-13 批量工具调用按顺序推进：保留已完成结果，在等待项处暂停，后续调用留待恢复。
- [ ] P06-14 拒绝工具生成带调用 ID 的拒绝结果，再按批量策略处理剩余调用；批准后再次检查必要权限与参数有效性。

## 5. 验收事项

- [ ] P06-15 覆盖单次批准、授权复用、拒绝、自动审批、审批过期和存储失败。
- [ ] P06-16 一个批次有多个待审批调用时，多次恢复均不丢失或重复执行工具。
- [ ] P06-17 审批与取消、审批与恢复并发时，已取消 Run 不重新运行，决定不会被重复消费。
