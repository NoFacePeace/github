# 阶段 02：模型接入

## 1. 目标与前置

依赖阶段 01。先接入一家支持工具调用的供应商，形成供应商无关的模型接口。

## 2. 模型接口与数据

- [ ] P02-01 定义模型请求、响应、消息角色、工具定义、工具调用、调用结果及 Token 用量。
- [ ] P02-02 明确模型标识、供应商连接配置和模型能力的解析位置，由外层完成选择后注入。
- [ ] P02-03 记录上下文窗口、输出上限、工具调用等能力，集中处理供应商参数差异。

## 3. 供应商适配

- [ ] P02-04 实现文本及多工具调用的请求编码、响应解析，保留工具调用 ID 和原始参数。
- [ ] P02-05 实现超时、Context 取消、鉴权错误、限流、无效响应和网络错误映射。
- [ ] P02-06 明确重试条件和次数，避免请求已产生输出后不受控地重复调用。
- [ ] P02-07 将供应商输入、输出和缓存用量映射为统一字段；未返回的用量不伪造为实测值。

## 4. 验收事项

- [ ] P02-08 用可控 HTTP 测试端验证文本、多个工具调用、格式错误、超时及取消。
- [ ] P02-09 在配置凭证的本地环境完成一次真实模型调用；自动测试使用可重复的测试端。
- [ ] P02-10 请求日志隐藏密钥，敏感正文是否记录有明确配置。

## 5. 后续扩展

首版可先使用完整响应。流式文本、工具参数增量拼接及断流处理在阶段 10 交付；统一数据模型应保留扩展空间。
