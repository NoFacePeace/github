# 文档规则

## Mindmap Markdown

- mindmap 文档使用标准 Markdown 编写。
- 使用标题和嵌套列表表达思维导图层级。
- 不使用 Mermaid 思维导图代码块。
- 不使用反引号，避免 Markdown 转思维导图工具无法识别节点内容。
- 转换已有 mindmap 文档时，保留原有知识点和层级关系。

## 源码复刻规则

- 复刻 Go 源码实现时，同时说明编译期间的展开逻辑和运行期间的 runtime 实现。
- 编译期间的内容包括编译器生成的条件判断、参数计算、栈分配优化和 runtime 调用。
- 运行期间的内容包括内存分配、数据复制、扩容和返回值构造。
- 无法在普通 Go 代码中完整复刻的逻辑，例如逃逸分析、垃圾回收协作、编译器内建优化和真实栈分配，使用中文注释说明原因。
- 注释中说明模拟代码与 Go 源码的对应关系，以及无法完全一致的部分。
- 相关源码分析和复刻结论同步补充到对应的 Markdown 文档。
