# array

## 1. 数组声明和初始化

### 1.1 显式声明类型

```go
var a [3]int
```

### 1.2 使用 var 声明并初始化

```go
var b = [3]int{1, 2, 3}
```

### 1.3 使用短变量声明

```go
c := [3]int{1, 2, 3}
```

### 1.4 自动推断数组长度

```go
d := [...]int{1, 2, 3}
```
