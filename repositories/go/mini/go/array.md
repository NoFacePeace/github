## 8. 数组底层实现

### 8.1 内存布局

`[N]T` 是一个完整的值，元素在内存中连续排列。数组赋值和按值传参会复制整个数组，但编译器可能优化该复制。

### 8.2 分配位置

数组的分配位置由逃逸分析和对象大小决定：

- 不逃逸的局部数组通常在栈上，也可能被编译器优化掉。
- 逃逸或过大的局部数组通常在堆上。
- 当前编译器默认限制：显式局部变量 128 KiB，`new([N]T)` 和 `&[N]T{}` 等隐式对象 64 KiB；这是编译器实现策略，不是语言规范保证。
- 取地址或使用 `new([N]T)` 不代表一定在堆上。
- 包级数组位于 `.bss` 或 `.data` 等静态数据区。

可以使用下列命令查看具体程序的逃逸分析结果：

```bash
go build -gcflags='-m=2' .
```
