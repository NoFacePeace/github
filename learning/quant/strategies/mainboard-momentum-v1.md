# 沪深主板动量策略 V1

> 用途：量化研究和每日买卖信号生成，不构成收益承诺或个股推荐。

## 1. 投资约束

| 项目 | 设置 |
| --- | --- |
| 初始资金 | 100,000 元 |
| 风格 | 激进 |
| 目标最大回撤 | 10%（目标而非保证） |
| 投资期限 | 5 年 |
| 信号频率 | 每个交易日收盘后 |
| 调仓频率 | 原则上每周一次；止损和市场风控每日检查 |
| 市场 | 沪深主板 A 股 |
| 交易方向 | 只做多，不融资、不做空 |
| 输出方式 | 只生成买卖信号，人工下单 |
| 最大持股数 | 8 只 |
| 单只目标仓位 | 约总资产的 11% |
| 单只仓位上限 | 总资产的 12.5% |

激进风格与 10% 最大回撤目标存在冲突。跳空、跌停、停牌等情况可能使实际回撤超过 10%。

## 2. 数据接口与口径

### MCP 工具

- `list_stocks`：返回 A 股股票代码、名称和市场。
- `get_kline_since`：返回指定代码从指定日期起的日 K 线。

### K 线字段

- `date`
- `open`
- `high`
- `low`
- `last`：收盘价
- `volume`
- `amout`：成交额（接口字段原名如此）

### 数据约定

- 股票 K 线已经是前复权数据，不再重复复权。
- 沪深 300 指数代码为 `sh000300`。
- 只使用最近一个已经收盘的完整交易日。
- 信号使用当日收盘后已知的数据计算，最早在下一交易日执行。

### 当前接口的限制

现有两个工具没有直接提供以下字段：

- 历史 ST 状态
- 财务公告日期和净利润
- 总市值、流通市值
- 明确的上市、退市日期
- 每日涨停价、跌停价和停牌标记

因此，当前可以生成价格动量版实时信号，但不能完整执行“排除历史亏损股、小市值股”和严格无偏的多年回测。若只用 `list_stocks` 的当前名称判断 ST，也无法还原历史戴帽、摘帽日期。

## 3. 股票池

先从 `list_stocks` 结果中筛选：

1. `market == "主板"`。
2. 名称不包含 `ST`，匹配时不区分大小写；同时排除 `ST` 和 `*ST`。
3. 至少有 250 个有效交易日数据，用作次新股的近似过滤。
4. 最近 20 个交易日平均成交额不低于 5,000 万元。
5. 最近价格和成交量数据完整。

当补充财务、市值和状态数据后，再严格执行：

- 排除滚动净利润小于或等于 0 的股票。
- 排除沪深主板总市值排名最低 30% 的股票。
- 排除停牌、退市整理股票。
- 排除上市不足 250 个交易日的股票。

## 4. 市场状态与总仓位

使用沪深 300 指数 `sh000300`：

| 状态 | 判定条件 | 最大股票仓位 |
| --- | --- | ---: |
| 强势 | 收盘价高于 200 日均线，且 20 日均线高于 60 日均线 | 90% |
| 中性 | 收盘价高于 200 日均线，但 20 日均线不高于 60 日均线 | 50% |
| 弱势 | 收盘价低于 200 日均线 | 0% |

为了减少在 200 日均线附近反复切换，可在后续版本增加“三日确认”：

- 连续 3 个交易日低于 200 日均线才确认弱势。
- 连续 3 个交易日重新站上 200 日均线才恢复仓位。

V1 当前仍按单日收盘规则执行，启用三日确认前必须重新回测。

## 5. 个股入选条件

候选股票必须同时满足：

1. 收盘价高于 20 日均线。
2. 20 日均线高于 60 日均线。
3. 过去 60 个交易日收益率大于 0。
4. 当前收盘价距离过去 120 个交易日最高价不超过 15%。
5. 通过股票池的流动性、ST 和交易历史过滤。

## 6. 动量评分

每项指标先转换为当日候选股票池中的百分位排名，再加权求和：

| 因子 | 权重 | 方向 |
| --- | ---: | --- |
| 60 日相对强度 | 30% | 越高越好 |
| 120 日相对强度 | 25% | 越高越好 |
| 距离 120 日最高价 | 15% | 越接近越好 |
| 20 日成交额增长 | 10% | 越高越好 |
| 20 日波动率倒数 | 10% | 波动越低越好 |
| 过去 60 日最大回撤倒数 | 10% | 回撤越小越好 |

相对强度定义：

```text
个股同期收益率 - 沪深300同期收益率
```

每周选择综合得分最高的 8 只股票。

## 7. 买入规则

1. 交易日 T 收盘后计算信号。
2. 在下一个可交易日 T+1 开盘执行。
3. 回测使用 T+1 的实际开盘价。
4. 实盘人工下单时，使用接近当时卖一价的限价单。
5. 最高允许买入价：

```text
信号日收盘价 × 1.02
```

6. 如果 T+1 开盘价高于最高允许买入价，不追高，该买入信号失效。
7. 如果股票涨停、停牌或无法成交，不买入，不用排名靠后的股票临时替代。
8. 只有市场状态为强势或中性时才能产生买入信号。

## 8. 卖出规则

### 正常卖出

出现任一条件，在下一个可交易日卖出：

- 每周排名跌出前 16 名。
- 收盘价连续 2 个交易日低于 20 日均线。
- 股票不再满足股票池条件。
- 股票被实施风险警示。
- 沪深 300 市场状态转为弱势。

采用“买入前 8、跌出前 16 才卖”的缓冲区，减少排名边缘的反复交易。

### 止损卖出

每日检查，出现任一条件则在下一可交易日卖出：

- 收盘价相对买入成本下跌 8%。
- 收盘价从持有后的最高收盘价回撤 12%。
- 收盘价低于“持有后的最高收盘价减去 3 倍 ATR”。

跌停、停牌时可能无法按计划卖出，因此止损比例不是实际亏损上限。

## 9. 组合回撤控制

以组合历史最高净值为基准：

| 组合回撤 | 动作 |
| --- | --- |
| 4% | 最大仓位降至 50% |
| 7% | 停止新开仓，已有仓位减半 |
| 10% | 发出全部卖出信号 |

清仓后至少观察 10 个交易日，并且沪深 300 重新满足恢复条件后才能开仓。

## 10. 交易费用

根据券商标准费率截图：

| 费用 | 标准 |
| --- | --- |
| 佣金 | 成交金额的万分之 2.354，买卖双向，每笔最低 5 元 |
| 沪市过户费 | 成交金额的十万分之 1，买卖双向 |
| 深市过户费 | 已包含在佣金中 |
| 印花税 | 成交金额的万分之 5，仅卖出收取 |
| 滑点 | 暂按单边 0.05% |

单只约 1.1 万元的交易会触发最低 5 元佣金。一次完整买卖的显性费用约为成交额的 0.14%，加入双边滑点后的综合成本约为 0.24%。

截图展示的是标准费率；若实际账户有优惠，应以交割单中的实际佣金替换。

## 11. 每日信号生成顺序

1. 读取最近完整交易日的沪深 300 K 线。
2. 计算 20、60、200 日均线，判断市场状态和最大仓位。
3. 若市场为弱势：
   - 不扫描新买入候选。
   - 空仓账户继续持有现金。
   - 已有持仓全部生成卖出信号。
4. 若市场为强势或中性：
   - 获取沪深主板股票池。
   - 排除名称包含 `ST` 的股票。
   - 获取并验证每只股票的 K 线。
   - 执行流动性和趋势过滤。
   - 计算动量评分和排名。
   - 结合当前持仓生成买入、卖出、继续持有信号。
5. 按资金、仓位上限和可成交数量计算建议股数。
6. 输出信号日期、代码、名称、动作、目标仓位、建议价格、建议数量和触发原因。
