# 价值投资表更新规范

本目录用于维护 `value_investing_ranges.md` 中的股票估值与操作区间。

## 触发流程

1. 当用户说“更新价格”时，使用 `list_stocks` 工具获取股票列表、最新价格、市值和市场信息，并更新“当前价格”和“市值（亿元）”列。
2. 当用户指定某只股票时，直接使用 `get_latest_report` 获取最新财报，并使用 `get_annual_report_summaries` 获取历史年报；“最新财报”列只填写报告名称或报告期，不填写链接。需要估值分析时，再阅读官方财报、确定正常化 EPS、计算五档价格区间，并将结论写入“备注”列。

## 表格约定

- 保留列顺序：股票名称、股票代码、市场、市值（亿元）、当前价格、最新财报、五个价格区间、备注。
- 市值使用亿元；价格使用人民币元。
- 未获取或无法验证的数据保持为空，不得填入推测值。
- 财报与价格数据应注明获取日期或报告期。
- 区间结论必须以财报数据、正常化 EPS 和明确的估值倍数为基础。

## 行业估值方法

### 稳定增长公司

适用于消费、公共事业、电信和业务波动较小的成熟制造业。

1. 用近 3—5 年归母净利润、自由现金流和 EPS 判断正常化盈利。
2. 关注收入增长、现金流转换率、分红率、ROE 和负债。
3. 用正常化 EPS 乘以 PE 区间计算价格；PE 的高低由可持续增长、分红能力和风险决定。
4. 若收入、利润和现金流趋势背离，优先降低正常化 EPS，而不是提高 PE。

### 周期性公司

适用于石油、煤炭、有色、化工、航运和强周期制造业。

1. 覆盖至少一个完整景气周期，优先使用近 5—10 年周期中枢盈利。
2. 记录产品价格、供需、库存、产能投放和单位成本，不使用景气高点 EPS 直接估值。
3. 用周期中枢 EPS 乘以偏低 PE 计算价格区间；高景气时提高安全边际要求。
4. 在备注中说明当前处于周期上行、中性或下行阶段，以及盈利对商品价格的敏感性。

### 银行和保险

银行与保险公司以 PB 和 ROE 为主，PE 只作辅助验证。

1. 获取每股净资产、ROE、不良率、拨备覆盖率、资本充足率、净息差和分红率。
2. 根据可持续 ROE、股权成本和增长判断合理 PB；可用 `合理 PB ≈ (ROE - 增长率) ÷ (股权成本 - 增长率)` 作为起点。
3. 用 `每股净资产 × 合理 PB` 计算价格区间，再用 PE 校验利润估值是否一致。
4. 若资产质量、净息差或资本充足率恶化，优先下调 PB 和 ROE 假设。

### 高成长科技与先进制造

适用于半导体、新能源、软件、AI 基础设施和高研发投入制造业。

1. 分业务预测未来 3 年收入：销量或出货量 × 单价，并单独预测毛利率。
2. 评估研发投入、资本开支、产能利用率、营运资金、市场份额、客户集中度和竞争格局。
3. 用基准情景的正常化 EPS 计算 PE 区间，同时以 DCF 或 EV/EBITDA 交叉验证。
4. 建立悲观、基准、乐观情景；不得同时假设高 EPS 增长和高 PE。
5. 强安全边际应采用悲观或周期中枢 EPS 与较低估值倍数。
