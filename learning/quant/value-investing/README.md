## 估值模型分类

| 模型分类 | 模型名称 | 核心公式或估值逻辑 |
| --- | --- | --- |
| 绝对估值 | DCF | 企业价值 = 预测自由现金流现值之和 + 终值现值 |
| 绝对估值 | FCFF DCF | 企业价值 = Σ FCFF / (1 + WACC)^t + 终值现值；股权价值 = 企业价值 - 净负债 |
| 绝对估值 | FCFE DCF | 股权价值 = Σ FCFE / (1 + 股权成本)^t + 终值现值 |
| 绝对估值 | DDM | 每股价值 = 预测股利现值之和 + 终值现值 |
| 绝对估值 | Residual Income（剩余收益模型，RIM） | 股权价值 = 期初账面净资产 + 未来剩余收益现值；剩余收益 = 净利润 - 股权成本 × 期初账面净资产 |
| 绝对估值 | NAV | 股权价值 = 资产公允价值 - 负债公允价值 |
| 绝对估值 | 储量 NAV（资源项目 NAV） | 股权价值 = 各资源项目现金流折现值之和 + 其他资产价值 - 净负债；项目现金流基于储量、产量、价格、成本、资本开支和税费预测 |
| 绝对估值 | 清算价值法 | 股权价值 = 资产可变现价值 - 负债 - 税费 - 清算与处置成本 |
| 相对估值 | PE | 目标价 = 每股收益 × PE 倍数 |
| 相对估值 | PB | 目标价 = 每股净资产 × PB 倍数 |
| 相对估值 | P/EV（Price-to-Embedded Value） | 目标市值 = 内含价值 × 合理 P/EV 倍数；目标价 = 每股内含价值 × 合理 P/EV 倍数 |
| 相对估值 | EV/EBITDA | 企业价值 = EBITDA × 倍数；股权价值 = 企业价值 - 净负债 |
| 相对估值 | EV/EBIT | 企业价值 = EBIT × 倍数；股权价值 = 企业价值 - 净负债 |
| 相对估值 | EV/Sales | 企业价值 = 销售收入 × 倍数；股权价值 = 企业价值 - 净负债 |
| 相对估值 | P/S | 目标市值 = 销售收入 × P/S 倍数；目标价 = 每股销售收入 × P/S 倍数 |
| 相对估值 | PB-ROE | PB = (ROE - g) / (股权成本 - g)；目标价 = 每股净资产 × PB |
| 相对估值 | Forward PE | 目标价 = 预测每股收益 × 远期 PE 倍数 |
| 相对估值 | FCF Yield（自由现金流收益率） | 目标股权价值 = 预测归属股东自由现金流 / 目标 FCF Yield；目标价 = 每股自由现金流 / 目标 FCF Yield |
| 相对估值 | 归一化 PE | 目标价 = 归一化每股收益 × 正常化 PE 倍数 |
| 分部加总估值（SOTP） | SOTP | 股权价值 = 各业务或资产分部价值之和 - 净负债 |

> 注：`Mid-cycle`（中周期）是对周期行业盈利的正常化假设，不是独立估值模型。例如，Mid-cycle EV/EBITDA 仍属于 EV/EBITDA 相对估值，Mid-cycle DCF 仍属于 DCF 绝对估值。
>
> 注：PE、PB、EV/EBITDA、FCF Yield 等严格而言是估值倍数；本表将基于这些倍数推导目标价值的方法统称为“估值模型”。

| 分类 | 主估值模型 | 交叉验证模型1 | 交叉验证模型2 | 所需财报年数 |
| --- | --- | --- | --- | --- |
| 银行型 | PB-ROE（基于可持续 ROE） | Forward PE（基于一致预期） | 股息折现模型（DDM） | 10 年（最近 3 年 + 最新季报作预测锚点） |
| 周期型 | 归一化 PE（基于跨周期平均盈利） | PB-ROE（基于中枢 ROE） | DCF（基于正常化现金流） | 10 年（覆盖至少一个完整周期） |
| 油气一体化型 | SOTP（上游 NAV/FCFF DCF + 下游 Mid-cycle EV/EBITDA） | 归一化 PE | 集团 FCFF DCF | 10 年（覆盖至少一个油价周期；最近 3 年 + 最新季报作预测锚点） |
| 成熟消费型 | DCF（基于长期收入增长、经营利润率与自由现金流） | Forward PE | FCF Yield | 10 年（最近 3 年 + 最新季报作预测锚点） |
