# RTSP

RTSP（Real-Time Streaming Protocol，实时流传输协议）是一种应用层协议，主要用于控制音视频流媒体会话，常见于网络摄像头、视频监控和流媒体服务。它的作用类似播放器的遥控器，可以建立会话，并控制媒体的播放、暂停和停止。

## 1. 常见方法

常见的 RTSP 方法包括：

- `OPTIONS`：查询服务端支持的方法。
- `DESCRIBE`：获取媒体描述信息，通常返回 SDP。
- `SETUP`：协商媒体传输方式并建立会话。
- `PLAY`：开始或继续播放媒体。
- `PAUSE`：暂停播放媒体。
- `TEARDOWN`：结束会话并释放资源。

## 2. 相关协议

RTSP 主要负责控制媒体会话，音视频数据通常由 RTP 传输，RTCP 则用于传输质量统计和同步等控制信息：

```text
RTSP：建立和控制流媒体会话
RTP：传输音视频数据
RTCP：反馈传输质量和辅助媒体同步
```

在网络分层模型中，RTSP、RTP 和 RTCP 都属于应用层协议；它们依赖传输层的 TCP 或 UDP 完成端到端传输。

## 3. 传输方式

RTSP 可以使用 TCP 或 UDP，默认端口是 `554`。RTP 和 RTCP 可以使用独立的 UDP 端口，也可以通过 RTSP TCP 连接进行交错传输，以便穿过防火墙或 NAT。

## 4. 地址格式

RTSP 地址通常采用以下格式：

```text
rtsp://用户名:密码@主机:554/媒体路径
```

例如：

```text
rtsp://admin:password@192.168.1.100:554/stream
```
