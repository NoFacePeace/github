## 1. 基本概念

树是一种表达层次关系的数据结构。在有根树中，除根节点外，每个节点都有唯一的父节点，可以有零个或多个子节点；没有子节点的节点称为叶子节点。

树可以按子节点数量、结构形态、排序规则和用途等维度分类。这些分类可以交叉，例如一棵树可以同时是二叉树、二叉搜索树和平衡树。

## 2. 按子节点数量分类

| 类型 | 特点 |
| --- | --- |
| 一般树 | 不对每个节点的子节点数量设定统一上限 |
| 二叉树 | 每个节点最多有两个子节点，区分左子节点和右子节点 |
| m 叉树 | 每个节点最多有 m 个子节点；二叉树是 m = 2 的情况 |

## 3. 二叉树的常见形态

| 类型 | 特点 |
| --- | --- |
| 满二叉树（国内教材常用定义） | 每一层都达到最大节点数，对应英文 perfect binary tree |
| 严格二叉树 | 每个节点要么没有子节点，要么恰好有两个子节点，对应英文 full/proper binary tree |
| 完全二叉树 | 除最后一层外均填满，最后一层的节点从左到右连续排列 |
| 平衡二叉树 | 通过高度等约束避免树过度倾斜；具体平衡条件取决于树的类型 |
| 退化二叉树 | 每个非叶节点只有一个子节点，整体形状类似链表 |

“满二叉树”在不同资料中的译法可能不同，阅读时应确认指的是 perfect 还是 full。按本节定义，满二叉树一定是完全二叉树，完全二叉树不一定是满二叉树。

## 4. 常见树结构及用途

### 4.1 搜索树

搜索树通过键的有序关系缩小查找范围。

| 类型 | 特点 |
| --- | --- |
| 二叉搜索树（BST） | 对于不含重复键的情况，左子树的键小于当前键，右子树的键大于当前键；重复键需要约定处理策略 |
| AVL 树 | 自平衡二叉搜索树，每个节点的左右子树高度差不超过 1 |
| [红黑树](red-black-tree.md) | 自平衡二叉搜索树，通过颜色约束、旋转和重新着色维持平衡 |
| B 树 | 平衡多路搜索树，一个节点可以保存多个键，所有叶子处于同一深度 |
| B+ 树 | B 树的一种变体，内部节点用于索引，数据条目集中在叶子节点，叶子通常相连以支持范围扫描 |

AVL 树与红黑树都属于二叉搜索树；B 树和 B+ 树属于多路搜索树，不属于二叉搜索树。

红黑树、B 树和 B+ 树的优劣与适用场景如下：

| 树结构 | 优势 | 劣势 | 适用场景 |
| --- | --- | --- | --- |
| [红黑树](red-black-tree.md) | 常见指针实现通过调整连接、旋转和重新着色维护平衡，无需搬移成组的键；容易保持未删除元素的地址稳定；无需选择节点的键容量 | 分支少，树通常较高；逐节点分配和指针有额外开销，缓存局部性通常不如连续存放多个键的节点 | 内存中的有序集合、映射，尤其是频繁增删且需要保持元素引用稳定的容器 |
| B 树 | 多键、多分支节点可按页组织，降低树高和页访问次数；内部节点命中即可返回数据；键通常只保存一次，相较 B+ 树减少索引键的重复存储 | 内部节点携带数据或引用，相同页大小下可能比 B+ 树容纳更少分支；范围遍历可能在内部节点和叶子之间切换；更新可能搬移多个条目，分裂、合并也有成本 | 磁盘索引、文件系统索引；以单键查询为主，希望利用内部节点直接命中、减少索引键重复的存储结构 |
| B+ 树 | 内部节点只存索引键和子节点指针，通常能容纳更多分支，减少访问层数；数据集中在叶子，便于沿叶子链表进行范围查询和批量顺序扫描 | 查询数据必须到达叶子；内部节点通常重复保存部分叶子键，增加索引键开销；更新可能搬移多个条目，并维护分裂、合并及叶子链接 | 数据库索引，以及需要范围查询、排序读取和批量扫描的存储结构 |

三者的查找、插入、删除都能保证最坏 O(log N) 时间复杂度，其中 N 为键的数量，B 树和 B+ 树的节点容量视为固定常数。这不是红黑树独有的优势。

表中的优势有具体前提：

- **地址稳定性**：红黑树需采用独立分配节点、删除时移接节点等实现方式。B 树和 B+ 树也能通过间接引用保持对象地址稳定，但会增加额外开销。
- **查询性能**：B 树只有部分查询能在内部节点提前结束，不保证单键查询比 B+ 树快；B 树和 B+ 树也可能凭借更好的缓存局部性，在内存中比红黑树快。
- **空间占用**：B 树减少的是相较于 B+ 树的索引键重复，不代表总空间一定更小；实际还取决于节点利用率、指针开销及索引键压缩方式。B+ 树的索引键重复也不代表对应数据重复存储。
- **顺序扫描**：B+ 树的叶子链接提供按键序访问，不代表磁盘页物理连续。实际性能还受页大小、缓存命中率和访问模式影响。

### 4.2 堆

堆用于快速取得最大值或最小值。二叉堆通常具有完全二叉树的形态，并满足堆序关系：

- **最大堆**：父节点的值不小于子节点，根节点是最大值。
- **最小堆**：父节点的值不大于子节点，根节点是最小值。

堆不要求左子树的值都小于右子树，因此不是二叉搜索树。二叉堆可以用数组存储，不必使用节点指针。

### 4.3 字典树

字典树（Trie）按键的组成部分逐层组织路径，例如每层对应字符串的一个字符。共享前缀的键共享路径，适合前缀查询。压缩字典树可以合并连续的单分支路径，减少节点数量。

### 4.4 区间与空间查询树

| 类型 | 主要用途 |
| --- | --- |
| 线段树 | 将区间逐层划分，支持区间求和、最值查询及更新等操作 |
| 区间树 | 保存区间并查询与给定区间或点重叠的对象 |
| KD 树 | 按不同坐标维度划分空间，用于多维点的范围或近邻查询 |
| 四叉树 / 八叉树 | 将空间递归划分为四个或八个子区域，常用于二维或三维空间数据 |

### 4.5 编码与语法树

| 类型 | 主要用途 |
| --- | --- |
| 哈夫曼树 | 根据权重构造前缀编码，使加权路径长度最小 |
| 表达式树 / 抽象语法树（AST） | 表达运算或程序的结构，用于计算、编译和分析 |

## 5. 学习顺序

1. 树的基本术语与遍历：前序、中序（二叉树）、后序和层序遍历。
2. 二叉树的结构：满二叉树、完全二叉树及数组、链式存储。
3. 二叉搜索树的查找、插入、删除，以及退化问题。
4. 树的旋转、AVL 树与红黑树。
5. 二叉堆、Trie、B 树和 B+ 树，再根据需求学习其他树结构。
