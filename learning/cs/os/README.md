# 操作系统

从硬件基础和系统调用开始，逐步理解操作系统如何管理 CPU、内存、文件和设备，并结合 Linux 工具与实验验证核心机制。

## 1. 相关领域

计算机组成原理、操作系统和计算机网络通常作为计算机专业的核心基础课程并列开设，但它们研究的对象和所处的抽象层次不同。网络编程更偏向实践应用，需要综合使用操作系统和计算机网络知识。

### 1.1 计算机组成原理

计算机组成原理研究一台计算机的硬件如何组织和工作，主要包括 CPU、指令系统、Cache、内存、总线、中断、DMA 和 I/O 设备等内容，重点解释硬件如何执行指令和传输数据。

### 1.2 操作系统

操作系统位于应用程序和硬件之间，负责管理 CPU、内存、文件和设备等资源，并通过系统调用向应用程序提供统一、安全的使用接口，重点解决多个程序如何安全、高效地运行。

### 1.3 计算机网络

计算机网络研究不同计算机之间如何交换数据，主要包括网络分层、以太网、IP、TCP、UDP、DNS、HTTP 和 TLS 等内容，重点解释数据如何从一台计算机传输到另一台计算机。

### 1.4 网络编程

网络编程是操作系统与计算机网络的交叉实践。它使用操作系统提供的 Socket 等接口，按照网络协议实现客户端、服务器和分布式系统之间的通信。

### 1.5 对比

| 对比维度 | 计算机组成原理 | 操作系统 | 计算机网络 | 网络编程 |
| --- | --- | --- | --- | --- |
| 研究对象 | 计算机硬件系统 | 单机软硬件资源 | 多台计算机之间的通信 | 参与网络通信的应用程序 |
| 所处层次 | 硬件层 | 系统软件层 | 跨主机通信体系 | 应用开发与系统编程层 |
| 核心问题 | 硬件如何执行指令 | 如何管理资源并服务应用 | 数据如何跨网络传输 | 如何实现网络客户端和服务器 |
| 典型内容 | CPU、指令、Cache、内存、总线、I/O | 进程、线程、调度、虚拟内存、文件、设备 | TCP/IP、路由、DNS、HTTP、TLS | Socket、并发连接、I/O 多路复用、协议实现 |
| 常见实践 | 分析指令执行、缓存和设备数据路径 | 观察进程、内存、文件和 I/O 行为 | 抓包、协议分析和网络故障排查 | 编写客户端、Web 服务器或 RPC 服务 |
| 知识性质 | 基础理论 | 基础理论与系统实现 | 基础理论 | 综合实践 |

从课程设置看，计算机组成原理、操作系统和计算机网络是并列关系；从知识层次看，计算机组成原理为操作系统提供硬件基础，操作系统和计算机网络共同为网络编程提供理论与接口支持。

```text
计算机组成原理
        ↓
操作系统 ─────────┐
                  ├──→ 网络编程
计算机网络 ────────┘
```

## 2. 学习路线

按以下顺序学习，每一阶段都配合 Linux 命令、源码阅读或小实验巩固：

1. **操作系统基础**：了解计算机硬件、操作系统职责、用户态与内核态、系统调用流程和权限隔离。
2. **进程与线程**：先理解进程，再学习线程、进程间通信与线程间共享。
3. **CPU 调度**：理解调度策略、优先级、时间片、抢占式调度和多核调度。
4. **并发与同步**：学习原子操作、互斥锁、读写锁、信号量、条件变量、线程安全和死锁。
5. **内存管理**：理解地址空间、虚拟内存、分页、页表、地址转换、缺页处理和内存分配。
6. **文件系统**：掌握文件与目录、inode、空间分配、Page Cache、日志和持久化。
7. **I/O**：学习文件描述符、阻塞与非阻塞 I/O、同步与异步 I/O 以及 I/O 多路复用。
8. **设备管理**：学习设备驱动、中断、DMA 和网络设备收包机制。
9. **虚拟化与容器**：理解虚拟机、Namespace、cgroup、资源隔离和容器运行时的基本原理。
10. **综合实践**：结合 Linux 工具与源码，完成进程、内存、文件系统和网络 I/O 相关实验，形成问题定位与性能分析能力。
