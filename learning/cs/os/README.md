# 操作系统

从硬件基础和系统调用开始，逐步理解操作系统如何管理 CPU、内存、文件和设备，并结合 Linux 工具与实验验证核心机制。

计算机组成原理、操作系统和计算机网络通常作为计算机专业的核心基础课程并列开设，但它们研究的对象和所处的抽象层次不同。网络编程更偏向实践应用，需要综合使用操作系统和计算机网络知识。

## 1. 计算机组成原理

计算机组成原理研究一台计算机的硬件如何组织和工作，重点解释程序指令最终如何被硬件执行。

主要内容包括：

- 数据表示、数字逻辑和指令系统。
- CPU、寄存器、运算器、控制器和流水线。
- Cache、主存、虚拟地址转换和存储层次。
- 总线、中断、DMA、磁盘和网卡等 I/O 机制。

它关注的是“硬件如何执行指令和传输数据”。

## 2. 操作系统

操作系统位于应用程序和硬件之间，负责管理计算机资源，并向应用程序提供统一、安全的使用接口。

主要内容包括：

- 进程、线程和 CPU 调度。
- 并发、同步和进程间通信。
- 虚拟内存和物理内存管理。
- 文件系统、设备管理和 I/O。
- 用户态、内核态和系统调用。

它关注的是“如何管理硬件，并让多个程序安全、高效地运行”。

## 3. 计算机网络

计算机网络研究不同计算机之间如何交换数据，重点理解网络分层、通信协议和数据传输过程。

主要内容包括：

- OSI 和 TCP/IP 分层模型。
- 以太网、ARP、IP、ICMP 和路由。
- TCP、UDP、可靠传输和拥塞控制。
- DNS、HTTP、HTTPS 和 TLS。
- 网络性能、安全和故障排查。

它关注的是“数据如何从一台计算机传输到另一台计算机”。

## 4. 网络编程

网络编程是计算机网络知识的实践应用。它通过操作系统提供的 Socket 等接口，实现客户端、服务器和分布式系统之间的通信。

主要内容包括：

- Socket、IP 地址、端口和连接。
- `socket`、`bind`、`listen`、`accept`、`connect`、`send` 和 `recv` 等接口。
- TCP、UDP 客户端与服务器开发。
- 阻塞、非阻塞和 I/O 多路复用。
- 连接管理、协议设计、超时、重试和错误处理。

它关注的是“如何编写能够通过网络通信的程序”。

## 5. 对比

| 对比维度 | 计算机组成原理 | 操作系统 | 计算机网络 | 网络编程 |
| --- | --- | --- | --- | --- |
| 研究对象 | 计算机硬件系统 | 单机软硬件资源 | 多台计算机之间的通信 | 参与网络通信的应用程序 |
| 所处层次 | 硬件层 | 系统软件层 | 跨主机通信体系 | 应用开发与系统编程层 |
| 核心问题 | 硬件如何执行指令 | 如何管理资源并服务应用 | 数据如何跨网络传输 | 如何实现网络客户端和服务器 |
| 典型内容 | CPU、指令、Cache、内存、总线、I/O | 进程、线程、调度、虚拟内存、文件、设备 | TCP/IP、路由、DNS、HTTP、TLS | Socket、并发连接、I/O 多路复用、协议实现 |
| 常见实践 | 分析指令执行、缓存和设备数据路径 | 编写系统调用实验，观察进程、内存和 I/O | 抓包、协议分析和网络故障排查 | 编写聊天程序、Web 服务器或 RPC 服务 |
| 主要依赖 | 数字逻辑和计算机体系结构 | 依赖组成原理提供的硬件基础 | 涉及操作系统和网络设备 | 直接依赖操作系统接口与网络协议 |
| 知识性质 | 基础理论 | 基础理论与系统实现 | 基础理论 | 综合实践 |

## 6. 四者之间的关系

从课程设置看，计算机组成原理、操作系统和计算机网络通常是并列的核心课程；从知识层次看，它们存在衔接和协作关系。网络编程则不是与三者完全并列的基础理论，而是操作系统与计算机网络的交叉实践。

可以概括为：

```text
计算机组成原理
        ↓ 提供硬件基础
操作系统 ─────────┐
                  ├──→ 网络编程
计算机网络 ────────┘
```

- 计算机组成原理解释 CPU、内存和网卡等硬件如何工作。
- 操作系统管理这些硬件，并通过系统调用和 Socket 向程序提供能力。
- 计算机网络定义主机之间通信所遵循的协议和规则。
- 网络编程使用操作系统接口，按照网络协议实现具体应用。

## 7. 一次网络请求中的分工

以浏览器访问一个网站为例：

1. 网络编程层面的浏览器或客户端构造 HTTP 请求，并通过 Socket 发出数据。
2. 操作系统管理 Socket、端口、连接、缓冲区和网络 I/O。
3. 计算机网络中的 DNS、TCP、IP、以太网和 HTTP 等协议共同完成寻址与传输。
4. 计算机组成原理解释 CPU 如何执行指令，以及网卡如何通过中断、DMA 和内存交换数据。

因此，同一个网络请求会同时涉及四个领域，只是每个领域观察和解决的问题不同。

## 8. 操作系统学习路线

按以下顺序学习，每一阶段都配合 Linux 命令、源码阅读或小实验巩固：

1. **操作系统基础**：了解计算机硬件、操作系统职责、用户态与内核态、系统调用流程和权限隔离。
2. **进程与线程**：先理解进程，再学习线程、进程间通信与线程间共享。
3. **CPU 调度**：理解调度策略、优先级、时间片、抢占式调度和多核调度。
4. **并发与同步**：学习原子操作、互斥锁、读写锁、信号量、条件变量、线程安全和死锁。
5. **内存管理**：理解地址空间、虚拟内存、分页、页表、地址转换、缺页处理和内存分配。
6. **文件系统**：掌握文件与目录、inode、空间分配、Page Cache、日志和持久化。
7. **I/O**：学习文件描述符、阻塞与非阻塞 I/O、同步与异步 I/O 以及 I/O 多路复用。
8. **设备管理**：学习设备驱动、中断、DMA 和网络设备收包机制。
9. **虚拟化与容器**：理解虚拟机、Namespace、cgroup、资源隔离和容器运行时的基本原理。
10. **综合实践**：结合 Linux 工具与源码，完成进程、内存、文件系统和网络 I/O 相关实验，形成问题定位与性能分析能力。
