# 操作系统学习

学习操作系统的核心概念、运行机制与实现原理，结合 Linux 理解系统如何管理硬件资源并为应用程序提供服务。

## 学习内容

- 进程与线程：生命周期、上下文切换、进程间通信与线程模型。
- CPU 调度：调度策略、优先级、时间片与多核调度。
- 并发与同步：互斥锁、信号量、条件变量、原子操作与死锁。
- 内存管理：虚拟内存、分页、地址转换、缺页处理与内存分配。
- 文件系统：文件与目录、inode、空间分配、日志与缓存。
- I/O 与设备管理：中断、DMA、阻塞与非阻塞 I/O、I/O 多路复用。
- 系统调用：用户态与内核态、系统调用流程与权限隔离。
- 虚拟化与容器：虚拟机、Namespace、cgroup 与资源隔离。

## I/O

- [I/O 学习笔记](io.md)：输入输出的基本概念、数据传输流程、I/O 模型与性能分析。

## 学习方式

- 整理核心概念与机制，记录设计取舍。
- 编写小型实验，观察进程、内存、文件与 I/O 行为。
- 结合 Linux 工具与源码验证理解，积累排查问题的经验。
