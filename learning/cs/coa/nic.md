# NIC

NIC（Network Interface Controller/Card，网络接口控制器/网卡）是连接计算机与网络的硬件设备，负责收发网络数据帧。

## 1. 主要组成

- 网络接口和物理层收发器
- 网卡控制器
- 发送和接收队列
- DMA 引擎
- 中断和状态寄存器
- 可选的校验和、VLAN、GRO 等硬件卸载能力

普通 NIC 通常包含专用硬件逻辑和 DMA 引擎，不是通用 CPU。SmartNIC 或 DPU 可能额外集成 ARM 等通用处理器，用于运行网络处理程序。

## 2. 与主机的连接

服务器网卡通常通过 PCIe 与主机连接。网卡内部的 DMA 引擎可以通过 PCIe 访问主机内存，将收到的数据写入内存缓冲区，或读取待发送的数据。

网卡硬件本身属于计算机硬件；网卡驱动、DMA 配置、中断处理和 NAPI 属于操作系统设备管理。
