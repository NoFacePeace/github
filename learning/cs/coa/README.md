# 计算机组成原理

本目录用于系统学习计算机组成原理（Computer Organization and Architecture，COA），重点理解数据如何在计算机各个部件之间流动，以及 CPU、内存、总线、I/O 设备和存储设备如何共同完成程序执行。整体学习路线如下：

1. 从计算机系统概述、数据表示和数字逻辑开始，建立理解硬件的基础。
2. 学习指令系统、汇编语言、CPU 组成和指令执行过程，理解程序如何在处理器中运行。
3. 学习流水线、Cache、主存、虚拟内存和地址转换，掌握处理器与内存系统之间的协作。
4. 学习总线、I/O、中断、异常和 DMA，理解 CPU 如何与外部设备通信。
5. 以存储设备和网络设备为例，学习 HDD、SSD、RAID、网卡、设备队列和数据传输路径。
6. 通过性能指标、Linux 工具和综合实践，将硬件原理与真实系统中的指令执行、系统调用、网卡收包和磁盘读写联系起来。

## 1. 计算机系统概述

了解计算机组成与体系结构，以及 CPU、内存、总线、I/O 和存储设备的职责；建立程序从编译、装载到执行的整体认识。

## 2. 数据表示

学习二进制、十六进制、有符号数、补码、位运算、整数溢出、浮点数和字符编码。

## 3. 数字逻辑基础

学习逻辑门、布尔代数、组合逻辑、加法器、比较器、译码器、时序逻辑、触发器和寄存器。

## 4. 指令系统与汇编

学习指令格式、操作码、操作数、寻址方式、寄存器、栈和函数调用，并结合 x86-64 或 ARM64 汇编理解基本指令。

## 5. CPU 组成与指令执行

学习控制器、运算器、数据通路和控制信号，理解指令经过取指、译码、执行、访存和写回的过程。

## 6. CPU 性能优化

学习流水线、数据冒险、控制冒险、分支预测、超标量、乱序执行、SIMD 和向量处理。

## 7. 存储层次与 Cache

学习寄存器、Cache、主存、磁盘和远程存储，重点理解局部性、缓存行、映射方式、替换策略、写策略和缓存一致性。

## 8. 主存与内存系统

学习 SRAM、DRAM、内存条、内存控制器、内存通道、内存带宽、访问延迟和 NUMA。

## 9. 虚拟内存与地址转换

学习虚拟地址、物理地址、页表、多级页表、TLB、缺页异常和内存保护，并联系操作系统中的进程地址空间。

## 10. 总线与 I/O 系统

学习地址总线、数据总线、控制总线、内存映射 I/O、端口映射 I/O、PCIe、USB、SATA、设备寄存器和 I/O 队列。

## 11. 中断与异常

学习硬件中断、软件中断、异常、中断向量、中断优先级、中断处理流程和中断上下文。

## 12. DMA 与设备访问

学习 DMA 描述符、DMA 缓冲区、IOMMU、缓存一致性，以及 CPU、设备和内存之间的数据传输。相关笔记包括：[中断](interrupt.md) 和 [DMA](dma.md)。

## 13. 存储设备

学习 HDD、SSD、NAND Flash、SATA、SAS、NVMe、RAID、持久化和掉电保护。相关笔记包括：[存储](storage.md)。

## 14. 网络设备

学习网卡组成、PCIe 与网卡通信、收发队列、网卡 DMA、中断、NAPI 和硬件卸载。相关笔记包括：[NIC](nic.md)。

## 15. 系统性能分析

学习延迟、吞吐量、带宽、IOPS、并发度、队列长度和缓存命中率，并使用 `perf`、`fio`、`iostat`、`strace` 以及 Linux `/proc` 和 `/sys` 文件系统进行观察。

## 16. 综合实践

分析一条指令、一次系统调用、一次网卡收包和一次磁盘读写从应用程序、操作系统到硬件的完整路径，并用实验验证前面学习的硬件机制。
