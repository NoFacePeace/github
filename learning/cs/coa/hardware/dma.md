# DMA

DMA（Direct Memory Access，直接内存访问）允许设备直接读写内存，避免 CPU 逐字节搬运数据。

## 1. 基本流程

```text
CPU 配置 DMA
    ↓
设备与内存直接传输数据
    ↓
传输完成后产生中断
    ↓
CPU 处理传输结果
```

以网卡收包为例：

```text
网卡 → 网卡内部 DMA 引擎 → 主机内存
```

普通网卡中，DMA 引擎通常集成在网卡控制器内部；在 SoC 中，网卡和 DMA 功能也可能集成在同一芯片中。

## 2. CPU 与 DMA 的分工

CPU 负责准备缓冲区、配置地址和长度、启动传输，以及在传输完成后处理结果。大量数据的实际读写由 DMA 引擎完成。

DMA 减少了 CPU 的数据复制工作，但 CPU 仍然需要处理协议、检查状态和管理缓冲区。IOMMU 还可以负责设备地址转换和访问隔离，缓存一致性则取决于硬件架构与驱动处理方式。
