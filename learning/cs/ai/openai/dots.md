# Dots

## 1. 产品定位

Dots 是 OpenAI 面向用户的持续运行 Agent 产品。用户交付目标后，它可以在对话之间继续推进工作，带回结果，并在需要用户判断时联系用户。

根据 OpenAI 官方介绍，Dots 由 GPT-6 Astra 驱动，拥有自己的云端电脑和浏览器，可开展研究、分析数据、准备文档和开发软件。

## 2. 与模型和 API 的关系

| 层级 | 定位 |
| --- | --- |
| 模型 | 理解任务、推理并决定下一步 |
| Responses API 与 Agents API | 开发者调用模型或构建 Agent 应用的接口 |
| Dots | 用户直接使用的 Agent 产品，提供任务管理、运行环境和交互入口 |

Dots 是产品名称，不是模型名称。上述分层用于理解概念，不代表官方披露了 Dots 内部具体采用哪些 API。

## 3. 工作方式

Dots 会保留与任务相关的上下文，跟踪进度并根据新信息继续处理。用户可以在它工作时补充要求、调整优先级或讨论结果。

例如，可以委派“跟踪 Agent 技术动态，整理值得关注的变化”，并明确来源范围、更新条件和交付形式。这是使用示例，实际执行取决于可用工具和权限。

## 4. 云端电脑与连接权限

云端工作可以在用户电脑关闭后继续。涉及用户本地文件或应用时，则需要连接本地电脑，且电脑在线、ChatGPT 应用保持打开。

消息渠道、应用插件和本地电脑是不同连接：能在一个渠道与 Dots 聊天，不代表它自动拥有其他服务或电脑的访问权限。

## 5. 使用与开放状态

可在 ChatGPT 桌面应用或桌面浏览器中创建 Dots。目前逐步向符合条件的账户开放，实际可用性取决于套餐、地区和工作空间要求。
