## 1. Perplexity 开源 SPACE Agent 沙箱

发布日期：2026 年 10 月 15 日。

SPACE（Sandboxed Platform for Agentic Code Execution）用于在隔离的 Firecracker microVM 中运行 Agent 和用户代码，采用 Apache 2.0 许可证。

应用通过 HTTP API 创建 Linux 执行环境、启动命令、读取输出，并管理沙箱的暂停、恢复和删除。应用决定任务与结果处理，SPACE 承载沙箱及其进程。

工程关注点：执行环境隔离边界、生命周期、网络出口策略、预热池，以及命令输出连接的管理。开源沙箱平台不等于完整的 Perplexity Computer 产品开源。

- 来源：[官方仓库](https://github.com/perplexityai/SPACE)、[同期报道](https://www.semafor.com/article/10/15/2026/perplexity-to-give-away-its-ai-security-software)、[使用指南](https://space.docs.perplexity.ai/guide/index.html)。
- 知识笔记：[SPACE](../../../knowledge/disciplines/cs/ai/ecosystem/perplexity/SPACE.md)、[Agent 沙箱](../../../knowledge/disciplines/cs/ai/agent/execution/sandbox/Sandbox.md)。

## 2. DigitalOcean 发布 Agent Learning 与 Data Services

发布日期：2026 年 10 月 12 日。

DigitalOcean 将 Agent 数据处理、执行观测和评估组织为一组托管服务：

| 服务 | 定位 | 发布时状态 |
|---|---|---|
| Agent Data Services | 整理资料、会话与执行轨迹，提供统一检索和查询 | 私有预览 |
| Agent Learning Services | 通过 Insights、Signals、Evaluations & Simulations 记录执行、发现问题并验证修改 | 公开预览 |

典型流程是：记录 Agent 实际运行，筛选工具失败或用户放弃等问题会话，将其转为模拟场景，再测试候选修改。Data Services 同时为上下文获取与历史记录分析提供数据基础。

“学习”不等于每次对话自动更新模型参数。公告中当前自动优化包括根据评估选择模型；将自动改进循环扩展到 Agent 工作流仍是后续计划。它们以托管云服务提供，不能理解为可直接下载自建的完整开源系统。

- 来源：[官方发布公告](https://investors.digitalocean.com/news/news-details/2026/DigitalOcean-Launches-Agent-Learning-and-Data-Services-for-Recursively-Self-Improving-AI-Agents/default.aspx)、[Data Services 介绍](https://www.digitalocean.com/blog/introducing-agent-data-services)、[Signals 与 Simulations 操作说明](https://www.digitalocean.com/blog/introducing-signals-and-simulations)。
- 知识笔记：[Agent Data Services](../../../knowledge/disciplines/cs/ai/ecosystem/digitalocean/AgentDataServices.md)、[Agent Learning Services](../../../knowledge/disciplines/cs/ai/ecosystem/digitalocean/AgentLearningServices.md)。

## 3. NVIDIA 发布 Nemotron 3.5 Super VL 与 Bolt

发布日期：2026 年 10 月 15 日。

两款模型面向多模态理解和 Agent 工作，定位有所不同：

| 模型 | 主要定位 |
|---|---|
| Super VL | 视觉理解、文本生成、工具调用和企业多步任务，120B 总参数、约 12B 激活参数 |
| Bolt 74B-A9B 24GB | 从较大模型压缩并量化，面向本地 Agent，74B 总参数、约 9B 激活参数 |

两者提供开放权重，具体许可应查看对应资源。Super VL 还发布相关数据集和训练方法。Bolt 的 24GB 版本针对内存效率优化，不能据此认定所有 24GB 显存设备都能运行任意上下文和配置。

发布时，Super VL 和 Bolt 74B-A9B 已可获取；更小的 Bolt E4B 4GB 计划于 10 月 23 日发布，属于本期之外的预告。

- 来源：[NVIDIA 官方发布](https://blogs.nvidia.com/blog/nemotron-3-5-super-vl/)、[Bolt 技术介绍](https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/)。

## 4. Grok Voice 3.0 上线 Voice Agent API

发布日期：2026 年 10 月 14 日。

Grok Voice 3.0 是面向实时语音交互的模型，通过 Voice Agent API 接入应用，支持多轮对话、打断处理和工具调用。

例如客服场景中，模型理解语音、询问情况并提出查询请求；应用执行实际业务工具，模型根据结果生成语音回应。模型与 API 需要业务系统配合，不是安装后即可完成所有业务的独立客服系统。

官方发布时公布价格为每分钟 0.08 美元，已通过 API 提供。性能与成本比较属于发布材料中的说明，不代表本地测试结论。

- 来源：[官方发布](https://x.ai/news/grok-voice-3)。
- 知识笔记：[Grok Voice 3.0](../../../knowledge/disciplines/cs/ai/ecosystem/xai/GrokVoice30.md)。

## 5. Anthropic 发布模型自主复制研究

发布日期：2026 年 10 月 12 日。

研究关注模型能否在陌生硬件上配置推理服务，以及能否将部署与复制相关步骤串联起来。它还演示了模型在多台低成本设备上的分布式运行。

实验在受控环境中进行，简化了部分网络访问与入侵条件；部分测试由独立服务器运行执行任务的模型，在目标机器上部署用于比较的 Llama 3.1 8B，而非完整地让模型独立复制自身。

因此，它属于 Agent 自主复制风险与相关能力的研究，不等于证明 AI 已能在真实互联网上不受限制地自主传播。“复制副本”与“模型变得更聪明”也应区分。

- 来源：[Anthropic 原始研究](https://www.anthropic.com/research/self-replicating-ai)。
- 知识笔记：[研究说明](../../../knowledge/disciplines/cs/ai/ecosystem/anthropic/SelfReplicatingAI.md)、[Agent 安全](../../../knowledge/disciplines/cs/ai/agent/quality/safety/Safety.md)。
