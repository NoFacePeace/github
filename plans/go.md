# Go 源码学习计划

## 1. 学习目标

以熟练使用 Go 开发为前提，理解语言特性的底层实现、runtime 的运行机制，以及编译器如何影响程序行为。

相关笔记：[Go](../knowledge/disciplines/cs/lang/go/Go.md)。

## 2. 学习模块

按以下模块顺序学习。开始前固定 Go 版本与目标架构，阅读时区分语言规范保证的行为与当前版本的实现。遇到后续模块的调用时，先理解其作用，再在对应模块补全实现。

### 2.1 编译与运行概览

了解编译阶段、程序启动流程、编译器与 runtime 的分工，以及调用约定概览，建立程序从源码到执行的整体认识。

### 2.2 类型表示与数据结构

理解对象布局、指针、slice、string、map、接口与类型信息的底层表示及主要操作的实现。

### 2.3 函数与控制流实现

理解函数调用、闭包与变量捕获，以及 defer、panic、recover 的编译处理和运行时机制。

### 2.4 goroutine 调度

理解 G/M/P、运行队列、阻塞与唤醒、抢占，以及系统调用和网络轮询与调度器的协作。

### 2.5 并发通信与同步

从 Go 内存模型和原子操作出发，理解 channel、select、sync 与 runtime 信号量的实现及同步保证。

### 2.6 内存管理

理解 goroutine 栈管理、堆分配、GC 周期、写屏障与 GC 调节，追踪对象从分配到回收的过程。

#### 2.6.1 栈管理

- [ ] 理解栈与堆的分工，以及 goroutine 栈帧的布局。
- [ ] 追踪栈增长、栈复制与指针调整的实现。
- [ ] 理解栈收缩的条件及其与 GC 的协作。

#### 2.6.2 堆分配

- [ ] 理解对象大小、内存对齐，以及 page、span、大小类别组成的堆结构。
- [ ] 阅读 mcache、mcentral、mheap 的职责与协作机制。
- [ ] 追踪微小、小、大对象的分配路径，理解含指针与不含指针对象的分配差异及内存清零。

#### 2.6.3 GC

- [ ] 理解指针信息、可达性与对象存活判定，以及 GC 根和栈扫描。
- [ ] 阅读 GC 周期、并发标记与写屏障，理解各阶段的 STW 及其原因。
- [ ] 追踪清扫、对象槽位复用，以及 scavenger 向操作系统归还空闲页的机制。
- [ ] 理解 GC 触发、pacer、辅助标记，以及 GOGC、GOMEMLIMIT 的影响。
- [ ] 结合 GC 日志与堆剖析，验证分配量、存活堆与回收行为。

### 2.7 编译优化与代码生成

理解逃逸分析、内联、去虚拟化在编译流程中的位置，以及 SSA 表示、优化、边界检查消除和代码生成，解释优化如何影响运行时行为。

## 3. 学习记录

记录核心问题、源码位置、关键调用链和验证结果，注明 Go 版本与目标架构；笔记归档到 Go 知识目录。每个模块结束后，整理尚未解决的问题。
